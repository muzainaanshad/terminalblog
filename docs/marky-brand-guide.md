# terminalblog — Marky Social Media Brand Guide

## Brand Voice
- **Tone**: Terminal hacker meets meme lord. Smart but not pretentious.
- **Personality**: That one friend who works in tech and sends you articles with "lol this is wild" as the caption.
- **Humor**: Dry, self-deprecating, slightly unhinged. Think "the code is lying to me again" energy.
- **Never**: Corporate, bland, "excited to announce", "we're thrilled", "game-changer"

## Visual Style
- **Background**: #0a0a0a (pure black terminal)
- **Primary text**: #e0e0e0 (light gray terminal text)
- **Accent**: #22c55e (green terminal cursor/highlight)
- **Warning**: #f59e0b (amber for emphasis)
- **Error**: #ef4444 (red for bugs/issues)
- **Font**: Monospace only (JetBrains Mono, Fira Code, or system monospace)
- **Layout**: Code-block aesthetic. Think terminal windows, command outputs, ASCII art.

## Post Types (rotate daily)

### 1. Bug Alert (when we publish a bug article)
```
🔴 BUG ALERT
[Agent name] just did [funny description of what went wrong]

The good news: it's documented.
The bad news: your files aren't.

Full writeup: [link]

#CodingAgents #BugAlert
```

### 2. Hot Take (when we publish an opinion piece)
```
🧵 HOT TAKE

[One sentence that would make someone argue in the comments]

[2-3 sentences expanding on the take]

Agree? Fight me in the replies.

[link]

#TechHotTake
```

### 3. Quick Tip (when we publish a how-to/guide)
```
💡 TERMINAL TIP

$ [command or action that solves a problem]

[One sentence explaining why this matters]

Bookmark this. You'll need it at 2 AM.

[link]

#DevTips
```

### 4. Comparison (when we publish a comparison)
```
⚔️ HEAD TO HEAD

[Agent A] vs [Agent B]

Winner: [Agent] (by a mile)
Loser: Your wallet

Full breakdown: [link]

#AIAgents
```

### 5. Number Drop (when we publish a pricing/benchmark)
```
📊 THE NUMBERS

[Agent]: $[price]/month
What you get: [one-line summary]
What you don't: [one-line summary]

Do the math: [link]

#CodingAgents
```

### 6. Meme Post (filler content, 2x per week)
```
When your coding agent says "I'll just fix one thing" and deletes your entire project:

[meme image or ASCII art]

Read more about agent disasters: [link]

#DevMemes #CodingLife
```

## Content Mix (per week)
- 3x article promotions (rotate types above)
- 2x meme/humor posts
- 1x tip or trick
- 1x community engagement (reply to comments, share other people's posts)

## Hashtags (use 2-3 per post, rotate)
Primary: #CodingAgents #TerminalBlog #AICoding
Secondary: #DevLife #TechBugs #CodeHumor #DevMemes
Platform-specific: #TechTwitter #Developer #Programmer

## Facebook Specifics
- Longer captions OK (150-300 words)
- Include the article link at the end
- Ask a question to drive comments
- Use code-block formatting (monospace font in posts)

## Instagram Specifics
- Short captions (50-100 words max)
- Carousel posts for comparisons (each slide = one agent)
- Reels: screen recordings of terminal commands with text overlay
- Stories: "Did you know?" facts about coding agents
- Always include link in bio (terminalblog.com)
