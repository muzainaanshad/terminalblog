Hermes Agent v0.22.4 dropped four hours ago. It's a patch release — the kind that doesn't make headlines but makes your daily workflow noticeably less annoying.

## The Headline Fix: Suggestion Pills Are Gone

You know those pills that appeared above the composer nudging you to set up MCP servers? The ones that showed up for no clear reason and refused to go away? **Gone.** The entire feature and the helper code that only it used have been removed ([#142559](https://github.com/NousResearch/hermes-agent/pull/142559)).

If you've been clicking "Dismiss" on those every session, you just got time back. More importantly, you got mental bandwidth back — no more UI clutter fighting for your attention while you're trying to think.

## Plugins That Install Nothing No Longer Ask For Consent

A plugin that declares zero dependencies — or whose `pyproject.toml` installs nothing — now enables without throwing an empty consent prompt at you ([#142569](https://github.com/NousResearch/hermes-agent/pull/142569)). One less click. One less "why is this asking me?" moment.

This matters more than it sounds. The plugin ecosystem is growing fast (see the new catalog additions below), and removing friction from zero-dependency plugins means more people will actually try them. Lower barrier to entry = more experimentation = better ecosystem.

## WhatsApp Re-pairing Finally Works

Logged out of WhatsApp in the dashboard and couldn't pair it again? Fixed ([#142439](https://github.com/NousResearch/hermes-agent/pull/142439)). You can now safely re-pair after logging out.

This was a genuine workflow blocker for anyone using the WhatsApp integration. Fixed.

## Small Desktop Polish That Adds Up

- **Approval-mode chip follows the active profile** — no more confusion about which mode you're actually in ([#142565](https://github.com/NousResearch/hermes-agent/pull/142565))
- **Plugin review lint relaxed** — prototype writes no longer flag automatically; reviewers check them manually ([#142586](https://github.com/NousResearch/hermes-agent/pull/142586))
- **Release builds get more time** — pre-build verification doesn't time out on slow storage ([#142623](https://github.com/NousResearch/hermes-agent/pull/142623))

None of these are "features" in the marketing sense. They're the kind of fixes you only notice when they're *missing*. The approval-mode chip following the profile? That's the difference between "which mode am I in?" and just knowing.

## New in the Plugin Catalog (Ecosystem Growing)

- **bubblewrap** — bwrap terminal backend on Linux (sandboxed execution)
- **Singularity/Apptainer** — container runtime support for HPC/scientific workloads
- **mcp-serve** — run Hermes as an MCP server (huge for interop)
- **agent-importers** — `hermes import-agent` now supports Cursor (migration path!)
- **inbox** and **workflow-record** from Hermes Labs (experimental workflow tooling)
- Telegram Business moved to Hermes Labs community tier

The `mcp-serve` addition is particularly interesting — it means Hermes can now act as an MCP server for other agents. The `agent-importers` with Cursor support signals they're serious about lowering switching costs.

## By the Numbers

Since v0.22.3: **14 non-merge commits**, **82 changed files** (+1,475 / −3,022 lines), **13 merged PRs**. Net negative lines — code removed exceeds code added. That's the good kind of patch release: cleaning up more than adding.
