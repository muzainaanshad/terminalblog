We spent the last year worrying about agents inventing APIs. The new failure is stranger and worse: agents inventing *us*.
Here's the scenario. A long session runs deep enough that the context window fills. The agent does the sensible thing — it compacts, summarizing the older turns into a compressed snapshot so the conversation can continue. Except the summary that comes back contains a request the user never made. A whole task, phrased in the user's voice, attributed to the user, sitting at the top of the fresh context like gospel. The agent reads it, believes it, and asks: "You wanted a wallet analysis earlier — still relevant?" The user never said anything about wallets.

This isn't a model being sloppy inside a single turn. It's the memory layer itself fabricating history. And it's recurring — the same phantom request resurfaces session after session, because once a compaction bakes a lie into the snapshot, later compactions summarize *that*, laundering the fabrication into something that looks like established fact.

Think about why this is categorically nastier than a normal hallucination. When a model invents a function name, the code fails to compile and you catch it. When retrieval fabricates a source, a careful developer can smell the missing citation. But when compaction invents *your intent*, there's nothing to check against — the original transcript is exactly what got thrown away to make room. The summary is the only surviving record, and the summary is the thing that's lying. The agent has no way to know. It trusts its own memory by design, the same way it trusts its own tools.

The deeper problem is that compaction is a lossy generative step we quietly treat as lossless bookkeeping. We ask a language model to compress a conversation, and language models don't compress — they *reconstruct*. Given a partial trace and a prompt that says "summarize the user's asks," a model under pressure will smooth over gaps by generating plausible-sounding requests. Plausible, confident, and wrong. The instruction "summarize what happened" silently became "produce a coherent narrative," and coherence is not the same as truth.

For anyone building agents in 2026, this reframes the priority. Every serious agent now leans on compaction to survive real work — long refactors, multi-hour debugging, anything past the context limit. That means every serious agent has this attack surface. The fix isn't a better summarizer. It's a discipline: compaction output must be traceable to actual messages, pending tasks must be quotable to a real turn, and anything the summarizer can't ground should come back empty rather than invented.

An agent that forgets is annoying. An agent that misremembers, confidently, about what you asked for — that's an agent you can't trust with a long session at all.
