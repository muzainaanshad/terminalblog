**OpenHands v1.40 landed November 12** — and for the first time, the desktop app feels like something you'd actually keep open all day. Not a CLI wrapper. Not an electron experiment. A real agent workspace with persistent memory, visual canvas, and model-agnostic flexibility.

---

## The Headline: Agent Canvas Desktop App Is Now Legit

OpenHands has had a desktop app for months. v1.40 is the first version where it **doesn't feel like a wrapper around the CLI**.

### What's Actually Better

| Area | Before v1.40 | v1.40 |
|------|-------------|-------|
| **Startup** | Spins up Docker, waits, sometimes times out | Native binary, ~3s cold start |
| **Memory** | Conversations lost on restart | Persistent sidebar with searchable history |
| **Model switching** | Edit config, restart | Dropdown in UI, instant |
| **Canvas view** | Barely worked | Drag-drop tasks, visual dependency graph |
| **Codex/Claude auth** | Manual token juggling | Guided OAuth flow built in |

The macOS `.dmg`, Windows `.exe`, Linux `.deb/.rpm/.AppImage` are all first-class downloads now — no more "download the CLI then figure out the UI."

---

## Codex Subscription Authentication — Finally Documented

If you pay for Codex (OpenAI's coding agent), v1.40 adds **official guidance** for wiring it into OpenHands.

The problem: Codex uses a custom OAuth flow that doesn't map cleanly to OpenHands' provider model. The fix: a new auth helper that walks you through the token exchange, stores it securely, and refreshes automatically.

```bash
# In Agent Canvas desktop app:
Settings → Providers → Codex → "Connect Account"
# Opens browser, you approve, done
```

No more `export OPENAI_API_KEY=...` in your shell profile. No more token expiry at 3 AM mid-refactor.

## The Quiet Fixes That Matter

The changelog looks boring. The experience doesn't.

| Fix | Why You Care |
|-----|--------------|
| Chat messages no longer disappear at history page boundaries | Long sessions stay coherent |
| Delayed echoes don't delete newer drafts | Your prompt isn't eaten by a race condition |
| Self-hosted instances respect "Agent Profiles off" setting | Enterprise configs actually work |
| Git uses repo's real default branch (not assumed `main`) | Works on `master`, `trunk`, `develop` out of the box |
| Indonesian translations for Codex keys | Global team support |

These are the "papercut" fixes that separate "works in demo" from "works in production."

## What This Means for You

### If You're New to OpenHands
v1.40 is the version to start with. Download the desktop app, connect your API keys (or Codex subscription), and you have a visual agent workspace in 5 minutes. No Docker, no YAML, no `docker-compose up` debugging.

### If You're on v1.38 or Earlier
The desktop app alone justifies the update. Persistent conversation history + model dropdown + canvas view = a different class of tool.

### If You Manage a Team
Agent Canvas gives you a shared visual workspace. Drag a task from "backlog" to "in progress," assign a subagent, watch the dependency graph update. It's project management *inside* the agent, not a separate Jira board.

## Quick Start

```bash
# Desktop (recommended)
# Download from https://github.com/OpenHands/OpenHands/releases/tag/v1.40.0
# macOS: OpenHands-Agent-Canvas-1.40.0-universal.dmg
# Windows: OpenHands-Agent-Canvas-Setup-1.40.0.exe
# Linux: .deb, .rpm, or .AppImage

# CLI (unchanged)
pip install --upgrade openhands
# or
docker pull ghcr.io/openhands/openhands:1.40.0
```

Verify:
```bash
openhands --version
# Should show 1.40.0
```
