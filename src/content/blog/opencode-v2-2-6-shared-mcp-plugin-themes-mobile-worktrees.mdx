OpenCode **v2.2.6** released November 6. This is a substantial feature release — shared MCP connections, mobile-first composer, worktree automation, and a plugin theme system.

## Headline Features

### Shared MCP Connections (Connection Pooling)
Turn on `pool: true` for an MCP server to share **one connection across projects** with the same setup. Fewer processes, faster startup. ([#61185](https://github.com/anomalyco/opencode/pull/61185))

```json
// opencode.json
{
  "mcp": {
    "my-server": {
      "pool": true
    }
  }
}
```

### Mobile Composer Dock
On phones/tablets, composer actions now sit in a **touch dock above the keyboard** with 44px targets — proper mobile UX, not a squashed desktop UI. ([#61773](https://github.com/anomalyco/opencode/pull/61773))

### Scripted Runs in Worktrees
```bash
# New worktree, auto-named
opencode run -w

# Named worktree
opencode run --worktree=feature-auth
```
Runs in a fresh git worktree. Cannot combine with `--continue` or `--session`. ([#60712](https://github.com/anomalyco/opencode/pull/60712))

### Automatically Archived Runs
```bash
opencode run --archived
```
Scripted/CI sessions stay out of your inbox, home, and session lists. Hidden from TUI session list and skipped by `--continue`. ([#61270](https://github.com/anomalyco/opencode/pull/61270))

## Plugin System Gets Themes & Native Components

GUI plugins can now:
- Contribute **color themes** via the `Theme` registry
- Render custom **code blocks** and add actions (`CodeBlock`, `CodeBlockAction` registries)
- Use native **settings layout** and **menu components**
- Set/persist sidebar width

This moves plugins from "hacky UI injections" to first-class citizens. ([#61485](https://github.com/anomalyco/opencode/pull/61485), [#61533](https://github.com/anomalyco/opencode/pull/61533), [#61527](https://github.com/anomalyco/opencode/pull/61527), [#61509](https://github.com/anomalyco/opencode/pull/61509))

## Other Notable Improvements

**Core:**
- Provider/model-specific session warming with `interval: "auto"` (based on cache TTL)
- `OPENCODE_FLAGS=all` or `experimental.all_flags` to enable all feature flags
- Experimental bytecode VM for Code Mode (`experimental.codemode_vm: true`)
- Microsoft Store PowerShell 7 support on Windows
- Azure Messages support for Foundry Claude models

**TUI:**
- "Scroll on send" setting — choose **Keep** to retain reading position after submit
- Ctrl+Z suspends OpenCode even with forms/dialogs open

**Desktop:**
- Unread-session grouping in Inbox, failed-run indicators on tabs
- MCP sign-in accepts pasted redirect URL when auto-redirect fails
- Markdown previews show frontmatter as properties list
- Command palette shows dates for sessions 7+ days old
- Prompt history up to 200 (newest 100 keep attachments)

**SDK:**
- `client.experimental.job.list()` for background shell/subagent/image jobs
- Custom `fetch` implementation for embedders

## Bug Fixes Worth Noting

- `opencode run` now **waits for background jobs** (shell commands, subagents, images) before exiting — prints `waiting for N background job(s)`
- SIGTERM cancels session + background jobs, exits 143
- File reads/media served as sandboxed downloads; cross-site browser navigations refused
- Webfetch/Code Mode `fetch` reject URLs with credentials, ignore `#fragment` for permission matching
- MCP servers connecting within 2s now reach first prompt and `opencode run`
- OpenCode Console config requests timeout at 5s (no more startup hangs)
- `opencode acp` removes sessions created by clients that close without prompting

## Upgrading

```bash
# npm
npm update -g opencode

# Or your package manager
brew upgrade opencode  # macOS
```

## Why This Release Matters

v2.2.x has been iterating fast on **workflow automation** (worktrees, archived runs, MCP pooling) and **plugin extensibility** (themes, native components). The mobile composer dock signals serious investment in non-desktop workflows.

If you run OpenCode in CI, the `--archived` + `--worktree` combo is a clean pattern: isolated, reproducible runs that don't pollute your session history.
