### 2. 166 Platform-Specific Binaries — Sigstore Signed

**What it is:** Every release now publishes **166 artifacts** covering:
- **Linux musl** (x86_64, aarch64) — `bwrap-*.tar.gz` + `.sigstore`
- **macOS** (Apple Silicon) — `codex-*.dmg` / `.tar.gz` / `.zst`
- **Windows** (ARM64) — `codex-*.exe`
- **Source** — `.zip` / `.tar.gz`

**Every binary has a `.sigstore` signature** — cryptographic proof of provenance. Verify with `cosign` or `sigstore-python`.

```bash
# Verify a binary
cosign verify-blob --signature bwrap-x86_64-unknown-linux-musl.sigstore \
  --certificate bwrap-x86_64-unknown-linux-musl.crt \
  bwrap-x86_64-unknown-linux-musl.tar.gz
```

**Why it matters:** Supply chain security for local-first tools. You *know* what you're running. No `npm install` supply chain. No `pip` dependency confusion. **Single binary, verified, done.**

### 4. Harness Emulation — Switch Personalities

**What it is:** The `/harness` command lets you emulate other agents:

```bash
> /harness

native          # Open Interpreter native

claude-code-bare
zcode
kimi-code       # Kimi CLI style
kimi-cli
qwen-code       # Qwen Code style
deepseek-tui
swe-agent
minimal
```

**Why it matters:** You like Kimi's keybindings but want GLM 5.3? `kimi-code` harness + GLM model. You want Codex shortcuts on local models? `native` harness. **One binary, every workflow.**
