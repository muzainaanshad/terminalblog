**Cursor for iOS 1.16.0 dropped on October 23, 2026.** The headline feature: **voice calls that show up on your Lock Screen and Dynamic Island**. You can now mute, hang up, or answer an agent call without unlocking your phone. During a call, the chat hides your transcribed speech and empty "Worked" sections — you only see the agent's replies, questions, plans, and edits.

This isn't a gimmick. It's the first time a coding agent platform treats voice as a first-class interaction mode on mobile.

## What's New in 1.16.0

### Voice Calls on Lock Screen & Dynamic Island

When iOS can't show a voice call on the system call screen, Cursor for iOS surfaces it as a Live Activity on the Lock Screen and Dynamic Island. You get:

- **Mute / hang up** from the Lock Screen
- **Call cards appear inline** in the conversation where the call started (not pinned to the bottom)
- **Clean chat view during calls** — your transcribed speech and empty "Worked" sections are hidden; you see only agent replies, questions, plans, and edits

This matters because agent conversations are often long-running. You start a refactor, walk away, and the agent calls you when it needs input. Now that interruption lives where iOS puts calls — not buried in a chat list.

### iPhone Duo Split-Screen Support

On iOS 27.1+, when iPhone Duo is half-open in landscape, the agents sidebar ends at the hinge. The sidebar and chat each sit on their own half of the screen instead of straddling the fold. If either side would be too narrow, the usual layout stays.

This is a thoughtful foldable adaptation — Cursor didn't just stretch the UI; they respected the hardware seam.

### Polish & Fixes

- **Layout fixes** on iPhone and iPad: composer and iPad sidebar account row sit on the bottom safe area, no extra gap above home indicator
- **Toolbar icons** match native toolbar symbol sizes
- **Sheet grabber** only shows on resizable sheets
- **Access Disabled screen** keeps readable width on iPad
- **Crash fixes** on iOS 27 when loading conversations or profile screen
- **Thinking step timing** — a lone Thinking step now shows how long it took once it finishes
- **Repo picker** no longer lists or preselects unpublished "Start from scratch" drafts

## Why Voice Calls Change the Mobile Agent Loop

Until now, mobile agent control meant: open app → read transcript → type reply → wait. That's fine for quick check-ins. It's painful for:

- **Walking the dog** while an agent asks "which API version?"
- **Cooking dinner** when the agent hits a test failure and needs direction
- **Commuting** when a long-running migration completes and the agent wants merge approval

Voice calls let you **stay in the flow without stopping what you're doing**. The agent calls. You answer. You speak. The agent continues. Your hands stay free.

This is the difference between "mobile access" and "mobile-native agent supervision."

## The Bigger Picture: Cursor's Mobile Strategy

Cursor has been building mobile incrementally:

| Release | Date | What It Added |

## FAQ

**Does this work with Remote Control (local agents)?**
Yes — voice calls work for both cloud agents and local agents via Remote Control.

**Can I start a voice call from the agent side?**
The agent initiates the call when it needs input. You can't currently "call the agent" — it's a one-way summon.

**What if I miss the call?**
The call card stays in the conversation. Tap it to see the transcript and respond when you're free.

**Android?**
"Coming soon" per Cursor team. iOS is the launch platform.

**Enterprise plans?**
Voice calls work on all paid plans (Pro, Pro+, Ultra, Teams, Enterprise). Enterprise admins can disable Remote Control but voice calls for cloud agents are unaffected.
