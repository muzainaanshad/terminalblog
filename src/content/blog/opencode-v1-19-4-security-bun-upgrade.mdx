OpenCode **v1.19.4 dropped October 22, 2026** — and it's the kind of release you don't notice until you realize *nothing broke*.

No flashy features. No new commands. Just a **security upgrade to the Bun runtime (1.4.4)** that patches vulnerabilities across the entire network stack your agent uses every day.

If you run OpenCode, **update today**. This is the "sleep better at night" release.

## The One-Line Summary

**Bun 1.4.4 security fixes now bundled. TLS, HTTP/3, WebSocket, Brotli, fetch — all patched. Root certificates updated. Update and forget.**

---

## What Actually Changed

OpenCode bundles its own Bun runtime. v1.19.4 upgrades it to **Bun 1.4.4**, which includes [security fixes](https://bun.com/blog/bun-v1.4.4#security) for:

| Component | What Was Fixed |
|-----------|----------------|
| **Brotli** | Decompression vulnerabilities |
| **TLS** | Certificate validation edge cases |
| **HTTP/1.1** | Request smuggling / parsing issues |
| **HTTP/2** | Header handling / flow control bugs |
| **HTTP/3** | QUIC transport vulnerabilities |
| **WebSocket** | Frame parsing / memory safety |
| **fetch** | Redirect / origin validation flaws |

**Plus:** Root certificates updated to **NSS 3.131.1** — your agent now trusts the current CA bundle, not one from months ago.

---

## Why This Matters (Even If You Don't See It)

Your coding agent makes **hundreds of network calls per session**:

- Fetching model endpoints (Anthropic, OpenAI, OpenRouter, etc.)
- Downloading MCP server definitions
- Pulling GitHub repos, issues, PRs
- Installing npm packages via `npm install` / `bun add`
- Communicating with local servers (TUI ↔ backend, Desktop ↔ CLI)

**Every single one of those calls goes through the Bun runtime.**

A vulnerability in TLS handling? Your agent could accept a spoofed model endpoint. A WebSocket frame parsing bug? A malicious MCP server could crash — or worse, execute code on your machine. An HTTP/3 QUIC flaw? Your traffic could be intercepted.

**v1.19.4 closes those doors.** You don't need to understand the CVEs. You just need to run the update.

## How to Update

```bash
# If you haven't moved to v2 yet (recommended path)
opencode upgrade --major

# If you're already on v1.19.x
opencode update

# Or re-run the installer (always works)
curl -fsSL https://opencode.ai/install | bash

# Verify
opencode --version
# Should show 1.19.4
```

The `/update` command in the TUI also works — no more surprise auto-installs mid-session.
