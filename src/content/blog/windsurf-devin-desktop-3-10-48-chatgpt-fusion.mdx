## Fusion Without Fable — The Gatekeeper Is Gone

**The old rule:** Fusion (Cognition's multi-model orchestration) required **Claude Fable 5.1** as the lead model. No Fable 5.1 access? No Fusion.

**The new rule:** **Fusion activates even when Claude Fable 5.1 isn't available.**

This matters because Fable 5.1 access is gated (enterprise/anthropic-partner). Now you can run Fusion with **GPT-6 Astra lead + SWE-2 sidekick** — both available via ChatGPT sign-in or OpenRouter.

**What Fusion actually does:** One coordinator model plans and delegates; a faster/cheaper sidekick model executes the code edits. You get "smart planner + fast coder" without paying premium for every token.

## FAQ

**Does ChatGPT sign-in work with Free tier?**
No — only ChatGPT **Plus ($20/mo)** or **Pro ($200/mo)** plans are eligible. Free tier users need API keys or OpenRouter.

**Can I use ChatGPT models *and* Anthropic models in the same session?**
Yes — Fusion lets you pick lead/sidekick independently. GPT-6 Astra (ChatGPT) lead + SWE-2 (Cognition) sidekick is the recommended combo.

**Is "Devin Desktop" different from "Windsurf"?**
No. Rebrand only. Same binary, same Cascade agent, same Wave numbers. Your config, sessions, and settings carry over.

**What about Arena Mode / Plan Mode from Wave 14?**
Those launched in **3.10.23 (Sep 10)**. If you're on 3.10.23+, you already have them. 3.10.48 adds ChatGPT + stability.

**Enterprise: any SSO/Entra changes?**
Not in 3.10.48. Enterprise auth still flows through Cognition's org settings. ChatGPT sign-in is for individual Plus/Pro accounts.
