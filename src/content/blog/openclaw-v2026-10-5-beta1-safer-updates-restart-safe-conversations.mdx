OpenClaw **2026.10.5-beta.1** dropped **October 11** — and it's the beta that finally solves the update nightmare. You know the one: update starts, something interrupts it (Windows elevation prompt, network blip, laptop sleep), and you're left with a stranded install that blocks *future* updates.

**This beta fixes that.** Updates now finish across devices, filesystems, Windows elevation prompts, and interrupted activations — and recover from stale leases or changed evidence instead of stranding your install.

Plus: **restart-safe conversations** (interrupted turns resume after Gateway restart), **faster Gateway** (reads move to worker threads), **reliable subagent turns**, **X/Twitter channel plugin**, **voice calls with briefs and voicemail detection**, **smarter model pickers**, and **ClawHub plugin browsing inside the Gateway**.

If you run OpenClaw in production — especially on Windows — this beta is worth testing.

## 1. Updates That Don't Strand You (The Big One)

**What it does:** Updates now **finish across devices, filesystems, Windows elevation, and interrupted activations**. They **recover from stale leases or changed evidence** instead of stranding the install or blocking future updates (#164636, #164769, #165257, #165863, #166548, #166695, #168043, #166394, #167302).

**In English:** You hit "update." Windows asks for elevation. You get distracted. Laptop sleeps. Network hiccups. **Before:** Stranded install, blocked future updates, manual cleanup. **Now:** Update recovers. Next time you run it, it picks up where it left off or cleanly restarts.

**Why beginners care:** Updating agent runtimes used to be a "clear your schedule" event. Now it's **fire-and-forget**. This is the difference between "hobby project" and "production infrastructure."

---

## 2. Conversations That Survive Gateway Restarts

**What it does:** **Interrupted turns, first messages during worktree preparation, and deferred tasks resume after a Gateway restart.** User input and committed session data survive restarts, concurrent writes, and failed publications (#165333, #166042, #165184, #166238, #165502, #167570, #163258, #166010, #167662).

**Before:** Gateway restarts (crash, update, maintenance) → in-flight turns lost, user messages vanished, deferred tasks abandoned.

**Now:** **Everything resumes.** The turn you were mid-way through? Continues. The message you typed while it was restarting? Delivered. The background task waiting to run? Wakes up.

**Why it matters:** OpenClaw is becoming **infrastructure you can trust with real work** — not "restart and hope."

---

## 3. Faster Gateway: Reads Move Off the Main Thread

**What it does:** Session, transcript, history, and metadata reads move onto **worker threads** with far less SQLite work per turn. **Startup maintenance runs after readiness** so busy Gateways stay responsive (#164744, #165470, #165614, #166587, #167194, #164779, #165028, #166041, #167278, #165993).

**The experience:** You open a session with 50K messages. **Before:** Gateway freezes, UI hangs, "is it dead?" **Now:** Main thread stays free. Reads happen in background. UI stays snappy.

**Why it matters:** As your usage grows, the Gateway **scales with you** instead of becoming the bottleneck.

---

## 4. Subagent Turns That Don't Lose Results

**What it does:** Turns recover from **stalled streams, reused tool-call IDs, and expired ChatGPT websockets**. Incomplete turns end with a **visible notice** (not silent failure). Subagent results keep returning through **follow-ups, restarts, and expired delivery windows** (#165983, #167013, #165212, #167063, #167972, #164282, #168068, #166846, #166139, #165987).

**If you've ever:** Launched a subagent → connection blipped → result vanished → "where did my code review go?" → **Fixed.** Results now persist through the chaos.

---

## 5. X (Twitter) Channel Plugin: Answer Mentions From Your Agent

**What it does:** New **X channel plugin** with **Activity API streaming and backfill**, **repository-question guest mode** with hidden same-agent helpers, **GitHub-verified repository writers**, and **daily/monthly X API cost limits** (#165138, #165337, #165354, #165351, #165543, #168071).

**What you get:**
- Stream X mentions directly into OpenClaw
- Guest mode: anyone can ask repo questions (with hidden helper agents)
- Only verified repo writers can trigger actions
- Hard cost limits so a viral tweet doesn't bankrupt your API budget

**Why it matters:** Your agent becomes a **social media operator** — triaging issues, answering questions, creating tickets from mentions.

---

## 6. Voice Calls: Briefs, Reports, Live Steering, Voicemail Detection

**What it does:** Voice calls gain **per-call briefs, call reports, live steering, callbacks, and voicemail detection** (#165716).

**What this enables:**
- **Brief:** "Call with @designer about auth flow — 3 min"
- **Report:** Full transcript + action items + decisions after call
- **Live steering:** Interrupt, redirect, add context mid-call
- **Callbacks:** "Call me back when the deploy finishes"
- **Voicemail detection:** Know when you hit a machine vs human

**For teams:** Voice becomes a **first-class collaboration channel** — not a side conversation that gets lost.

---

## 7. Smarter Model Pickers: Recommended Models First, New Models Auto-Appear

**What it does:** Pickers **lead with each provider's recommended models**, show **newly listed Claude, ChatGPT, and Ollama models without waiting for an OpenClaw release**, and **stay responsive while catalogs load** (#167370, #166737, #167658, #167387, #167463, #165989).

**Before:** New model drops → wait for OpenClaw release → update → model appears.

**Now:** New model drops → **appears in picker automatically** (provider-recommended ones first).

**Why beginners care:** You always see the **best current options** — no config hunting, no version lag.

---

## 8. ClawHub in the Gateway: Browse Plugins/Skills Without Leaving

**What it does:** Browse and search **ClawHub plugins and skills from the Gateway**. Plugins **automatically pick the newest official release your OpenClaw supports** and keep a working plugin when its matching release is unavailable (#163459, #167485, #166588).

**The workflow:** Need a Jira plugin? Open Gateway → search ClawHub → install → done. **No browser tabs, no version matching, no "which release works with my version?"**
