## Key Insights

**Most feature-complete agents:** Hermes and Claude Code lead with 7-8 features each. Hermes adds local-first and cron; Claude Code adds vision and subagents.

**Best for specific needs:**
- **Automation/cron:** Hermes, OpenClaw, pi.dev
- **Vision:** Claude Code, Cursor, Hermes, Mimo Code, OpenClaw, Oh My Pi
- **Multi-provider flexibility:** Hermes, Cursor, OpenCode, Mimo Code, AmpCode, Goose
- **Subagents:** Claude Code, Cursor, Hermes, Codex, AmpCode, Copilot CLI, Oh My Pi, pi.dev

**No single agent has everything.** The best setup combines 2-3 agents for different tasks.
