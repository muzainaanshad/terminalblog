**Opencode v1.19.5 dropped October 28, 2026** — a patch release with one fix that matters if you live in the terminal: **failed TUI worker requests now return an error instead of leaving the caller hanging forever.**

Before: you trigger a worker request in the TUI → something fails → the request just... sits there. No error, no timeout, no feedback. You're stuck wondering if it's slow or broken.

After: **you get an error immediately.** You know it failed. You can retry, debug, or move on.

---

## The Fix

| Issue | Before | After |
|-------|--------|-------|
| Failed TUI worker request | Hangs indefinitely, no feedback | Returns error immediately |

**PR:** [fix(opencode): answer a failed TUI worker request instead of hanging (#54936)](https://github.com/anomalyco/opencode/pull/54936) by [@Nowaker](https://github.com/Nowaker)
