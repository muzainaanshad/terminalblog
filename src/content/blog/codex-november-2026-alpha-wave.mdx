**Codex shipped three alpha releases in four days** (Nov 1–5) — v0.167.0-alpha.2 through .5, then v0.168.0-alpha.1 through .3. That's not a typo. The October velocity (four stables in three weeks) didn't slow down; it just went alpha-first.

If you're on **v0.166.0 stable** (released Oct 29), you're fine. These alphas are for testing. But they signal where the terminal agent is heading: **parallel background agents, cleaner Windows support, and transcript rendering that finally stops flickering.**

## What Actually Changed (Ranked by Impact)

### 1. Parallel Agent Scaffolding — The Big One (v0.167.0-alpha.5 → v0.168)

**What it is:** Internal refactor to support **multiple background sessions running simultaneously**. The TUI, session manager, and message bus now track session IDs per-agent instead of assuming one active session.

**Why it matters:** Today Codex runs one agent at a time. The alphas lay groundwork for `codex spawn --background` — fire off a refactor in session A, a test-gen in session B, a doc pass in session C, then `codex list` to see all three.

```bash
# Coming soon (not in alpha yet):
codex spawn --background "add JWT auth to API"
codex spawn --background "write integration tests for auth"
codex spawn --background "update API docs for auth"
codex list  # shows all 3 sessions + status
```

**For beginners:** This is the shift from "AI pair programmer" to "AI team lead." You'll delegate, not just chat.

---

### 2. Transcript Rendering Consistency (v0.168.0-alpha.2)

**What it is:** Unified Markdown renderer across **all surfaces** — transcript, async prompts, choices, Guardian safety blocks, tool outputs. No more "why does this table render in the answer but break in the prompt?"

**Why it matters:** v0.166.0 added keyboard transcript selection. v0.168 makes the *content* of that transcript render identically everywhere. Tables, code fences, lists, links — one code path.

**For beginners:** If you've ever copied a table from Codex output and pasted into Notion/Markdown and it broke — this fixes the root cause.

---

### 3. Windows Sandbox Hardening (v0.167.0-alpha.4)

**What it is:** Fixes for **Windows Smart App Control** and corporate sandbox policies that silently killed Codex subprocesses.

- Bubblewrap (Linux sandbox) path now validated on WSL
- Windows Defender exclusions auto-suggested on first run
- `codex doctor --windows-sandbox` diagnostic added
- Silent exit → explicit error with remediation steps

**Why it matters:** Windows users on managed laptops (CrowdStrike, SentinelOne, Defender ASR) were hitting "works once, then nothing" with zero logs. Now you get `codex doctor` output telling you exactly which policy blocked it.

---

### 4. Model Switching Without Context Loss (v0.167.0-alpha.3)

**What it is:** Switching models mid-session (`/model gpt-6.1-terra` → `/model gpt-6.1-luna`) now **preserves the full transcript and tool state**. Previously it soft-reset context.

**Why it matters:** You're deep in a refactor with Terra (reasoning heavy). Need quick boilerplate? Switch to Luna (speed), generate, switch back. Context survives.

```bash
# In Codex TUI:
/model gpt-6.1-luna   # fast boilerplate
# ... generate ...
/model gpt-6.1-terra  # back to reasoning, full context intact
```

---

### 5. Transcript Search Fixes (v0.167.0-alpha.2)

**What it is:** `/search` in transcript now handles:
- Multi-line regex (`/error\n.*stack`)
- Case-insensitive toggle (`/pattern/i`)
- Jump to *tool call* not just text (`/tool:bash`)
- Results stay highlighted across scroll

## Quick Start: Test Alpha Safely (5 Minutes)

```bash
# 1. Keep stable intact
codex --version  # should show 0.166.0

# 2. Install alpha side-by-side (npm)
npm install -g @openai/codex@alpha
# Or download from: https://github.com/openai/codex/releases/tag/rust-v0.168.0-alpha.3

# 3. Run alpha with explicit binary
# Linux/macOS:
~/.npm-global/bin/codex --version  # shows 0.168.0-alpha.3
# Windows (PowerShell):
codex-alpha --version

# 4. Test the new stuff
codex-alpha doctor --network-only     # v0.166 feature, works in alpha
codex-alpha doctor --windows-sandbox  # NEW in v0.167-alpha.4
# In TUI: try /model switching, transcript search
```

**Pro tip:** Add alias in `.bashrc`/`.zshrc`:
```bash
alias codex-stable="codex"
alias codex-alpha="~/.npm-global/bin/codex"
```
