Goose v1.56.0 dropped **October 23, 2026** — and this one changes how the agent *thinks*, how it *recovers*, and how you *install it on Windows*. The headlines: **automatic thinking level** (the model picks its own reasoning depth), **resume failed subagents**, **view-only subagent sessions in the UI**, **concurrent subagent limits**, **Windows NSIS installer**, **IO Intelligence provider**, and **Boa JavaScript runtime replacing PCTX**.

If you've been waiting for Goose to feel more like a platform and less like a CLI experiment — this is the release.

---

## The Headline Features (Ranked by What You'll Actually Notice)

### 1. Automatic Thinking Level — The Model Decides How Hard to Think

**What it is:** Goose now supports automatic thinking level operation ([#12237](https://github.com/block/goose/pull/12237)). Instead of you setting a fixed "thinking budget" per model, the model *itself* decides how much reasoning a task needs — simple edits get fast responses, complex architecture decisions get deep reasoning.

**Why it matters:** You stop managing sliders. The agent becomes adaptive — Claude Sonnet 5.5, Haiku 5.5, GPT-6 Sol, Opus 5.5 all pick their own depth per turn. Set `GOOSE_CLI_SHOW_THINKING=1` once and watch it work.

**For beginners:** This is the "it just works" moment. You ask a question, the agent thinks *appropriately*, you get the answer. No config tuning required.

---

### 2. Resume Failed or Cancelled Delegate Subagents

**What it is:** When a delegate subagent fails or gets cancelled, you can now **resume it** ([#13015](https://github.com/block/goose/pull/13015)) instead of starting over.

**Why it matters:** Long-running delegated tasks (refactor this module, write these tests, migrate this API) no longer evaporate when something hiccups. The subagent picks up where it left off.

**For beginners:** You hit "delegate" → something goes wrong → you hit "resume" → it keeps going. The mental model is finally "tasks can be paused and continued," not "tasks are all-or-nothing."

---

### 3. Subagent Session Links in UI — View-Only Sessions

**What it is:** The desktop UI now shows **subagent session links** with **view-only access** ([#12998](https://github.com/block/goose/pull/12998)). Click a subagent in the main session → see its full transcript, tools, reasoning — read-only.

**Why it matters:** Debugging multi-agent workflows used to mean guessing what the subagent did. Now you open its session like a log file. See every tool call, every reasoning block, every decision.

---

### 4. Limit Concurrent Subagents — `GOOSE_MAX_CONCURRENT_SUBAGENTS`

**What it is:** New env var `GOOSE_MAX_CONCURRENT_SUBAGENTS` ([#12946](https://github.com/block/goose/pull/12946)) caps how many delegate subagents run simultaneously.

**Why it matters:** Prevents the "thundering herd" problem where one prompt spawns 20 subagents and your API bill / rate limits / local resources explode. Set it to `3` or `5` and sleep better.

---

### 5. Windows NSIS Installer — Finally, a Real Windows Install Experience

**What it is:** Goose now ships a proper **NSIS installer for Windows Desktop** ([#12869](https://github.com/block/goose/pull/12869)). Download `.exe`, run, get Start Menu entry, uninstaller, auto-updates — the works.

**Why it matters:** Before this, Windows users got a ZIP or Scoop/Chocolatey. Now it's a first-class citizen. Double-click, install, launch from Start Menu. No PATH fiddling, no "how do I update this?"

**For beginners:** This is the single biggest Windows UX improvement since v1.0. If you've been holding off on Goose Desktop because "Windows support feels second-class" — it's not anymore.

---

### 6. IO Intelligence Provider — New Model Access

**What it is:** New **IO Intelligence provider** ([#12795](https://github.com/block/goose/pull/12795)) added to the provider catalog.

**Why it matters:** More model choice without leaving Goose. If IO Intelligence has models you want (or pricing you like), it's now a native option.

---

### 7. Provider-Defined Cache Prices — Accurate Cost Estimates

**What it is:** Providers can now define **cache prices** ([#12944](https://github.com/block/goose/pull/12944)). Goose uses these for cost estimates instead of guessing.

**Why it matters:** If you use prompt caching (Anthropic, OpenAI, OpenRouter), your cost estimates were wrong. Now they're right — provider tells Goose the real cache hit/miss pricing.

---

### 8. Dangerous Include History Option

**What is is:** New option to **include full history in delegation** ([#13051](https://github.com/block/goose/pull/13051)) — marked "dangerous" because it sends the entire conversation to subagents.

**Why it matters:** Sometimes a subagent *needs* full context to make the right call. This unlocks that, with a warning label. Use intentionally.

---

### 9. Boa JavaScript Runtime Replaces PCTX Code Mode

**What it is:** The legacy **PCTX code mode is gone**, replaced by **Boa JavaScript runtime** ([#12952](https://github.com/block/goose/pull/12952)) in the GDK.

**Why it matters:** PCTX was a custom thing. Boa is a standards-compliant JS engine. If you're building on Goose's GDK (Goose Development Kit), your tool definitions, recipes, and extensions now run on real JavaScript — better compatibility, better debugging, standard semantics.

---

### 10. Session Status via OSC 7501 in CLI

**What it is:** CLI now reports **session status via OSC 7501** ([#12928](https://github.com/block/goose/pull/12928)) — terminal escape sequence that lets terminal emulators (Ghostty, Kitty, iTerm2, WezTerm) show agent state in the tab/title bar.

**Why it matters:** Your terminal tab can now show "Goose: Running" / "Goose: Waiting for input" / "Goose: Complete" without you checking the window. Tiny UX win that compounds.

## What This Means for You

**If you're new to coding agents:** Goose v1.56 doesn't change the "first run" much — but the *reliability* compounds. Automatic thinking means you don't tune reasoning. Resume subagents means failed tasks aren't lost. Windows installer means you install like normal software. The agent feels **solid**, which is the feature beginners appreciate most once they hit their first weird failure.

**If you're on Windows:** This is the release you've been waiting for. NSIS installer + `!` in npx args fixed + Windows build error fixed = Goose Desktop is now a first-class Windows app. Not "works on Windows" — *built for Windows*.

**If you're embedding Goose (IDE plugin, CI bot, custom frontend):** Boa JS runtime = standard JavaScript for your tool definitions. Resume subagents = your orchestration layer can recover from failures. Concurrent limits = your infrastructure won't melt. OSC 7501 = your terminal UI can show agent state. AIgateway (v1.55) + these v1.56 improvements = Goose is a proper runtime.

**If you use Bedrock / OpenRouter / OpenAI caching:** Cache prices + context length fixes = your cost estimates and truncation behavior are finally accurate.

## How to Upgrade

```bash
# CLI
goose upgrade

# Or re-run the installer (now works on Windows!)
curl -fsSL https://raw.githubusercontent.com/block/goose/main/scripts/install.sh | bash

# Desktop: auto-updater handles it (enabled since v1.49)
# Windows: download NSIS installer from releases page
# https://github.com/block/goose/releases/tag/v1.56.0

# Docker
docker pull ghcr.io/block/goose:latest
```

**First things to try after update:**

```bash
# 1. Watch automatic thinking in action
export GOOSE_CLI_SHOW_THINKING=1
goose
# Ask something simple → fast answer

# 2. Test subagent resume
# Delegate a long task → cancel it → resume it → watch it continue

# 3. Check Windows installer
# Download .exe → install → launch from Start Menu → pin to taskbar

# 4. Check provider cache prices
# Use OpenRouter with prompt caching → see accurate costs

# 5. Explore Boa JS runtime (if building on GDK)

```
