Cursor **3.27 dropped October 22** — and it's the first release that makes the Agents Window feel like a **real IDE for agent workflows**, not just a chat panel with extra steps.

The headline: **Project split panes that remember focus**, **List/Board task tracking** built into Project notes, **Filter chips** for tasks, **calmer Project startup**, and a **chat input that refuses to let you accidentally stop the coordinator**.

If you've been using Cursor Projects and thought "this is cool but rough around edges" — 3.27 sands down almost every rough edge.

## The One-Line Summary

**3.27 (Oct 22) → Project split panes persist focus across reloads, Notes become List/Board task tracker with Filter chips, new Projects start calm (single "Setting up" row), chat input locks Send button while coordinator works, prompt attachments finally work reliably. The Agents Window grows up.**

## Split Panes That Actually Remember Where You Were

**Before:** You arrange Project panes perfectly. Reload the window — everything resets. The editor follows the wrong pane. Chats from other Projects bleed into your tab strip.

**After (3.27):**
- The pane you focused **stays focused** when panes return or the window reloads
- The editor panel **follows whichever pane you focus** — including chats dropped in from outside the Project
- A chat you opened in another Project's split **reopens in that split** after reload or Back/Forward
- The Project's own chat tab **stays pinned first** in its tab strip

```bash
# Try it:
# 1. Open a Project → split pane (Cmd/Ctrl + \)
# 2. Focus left pane → reload window (Cmd/Ctrl + R)
# 3. Left pane still focused, editor follows it
# 4. Open chat from Project B in Project A's split → reload → opens in Project A's split
```

**Why it matters:** You build a mental model of your workspace. 3.27 stops breaking it.

## Project Notes → Task Tracker (List + Board Views)

Starting in 3.26 (refined in 3.27), **Project notes are now a task tracker** the coordinator keeps updated.

| View | What You See |
|------|--------------|
| **List** | Each task: status, ID, assigned agents, PRs |
| **Board** | Kanban columns by status — drag to move |

The Project tab **stays pinned first** in the right panel. Header switches between **List / Board / Library**.

**While files sync:** The tab shows a loading state (or error if sync fails) instead of looking empty.

### Filter Tasks — Finally

In the Notes tab, a **Filter button** next to find narrows tasks by:
- **Status** (todo, in-progress, done, blocked)
- **PR** (linked/unlinked)
- **Tags**
- **Owner** (which agent)

Active filters show as **chips** — click to edit, switch "is"/"is not", remove, or clear all. Typing in find bar **also filters by text**.

### Multiple PRs? Single Pill.

A task with several PRs shows **one "N PRs" pill** with icons for each PR's state. Click → menu of that task's pull requests. No more crowded titles.

## Calmer Start for New Projects

**Before:** New Project spins up → conversation reflows through environment setup steps → apps panel open → visual chaos.

**After (3.27):**
- Conversation shows **one "Setting up project" row** until the agent's first output
- New Project starts with **apps panel closed**
- Project app opens **on its own** once the first task appears

**Why it matters:** You describe the goal. Cursor handles the choreography. You see the first real output — not the plumbing.

## No More Accidentally Stopping the Coordinator

**The classic disaster:** Coordinator is grinding through a 20-step migration. You want to send a quick clarification. You type — but the Send button swapped to **Stop**. You hit Enter. Coordinator dies. Work lost.

**3.27 fix:** While the coordinator is working, the chat input **keeps the Send button**. Stop is moved elsewhere. You can keep sending messages **without cutting off a long-running coordinator by mistake**.

---

## Project Picker: Search-First, Everything in One List

Open the project picker → **search field first**. Your repositories, folders, and cloud environments in **one list** with owners shown on results.

- Paste a clone URL → clone from the picker
- Footer: clone a repository, start from scratch, or create new repository

No more tab-switching between "Local" / "Cloud" / "GitHub".

## Chat & Composer Polish

### Project Messages Collapse

When a Project sends messages to an agent, they now collapse into **one centered line**:

> Messages from Hare, Tortoise

Click an agent's name → open Project's chat at that message. Expand "Update from" entry → read the full update.

### Prompt Attachments Finally Work

- Attached images/videos **labeled with file name**
- Images with very long file names **attach instead of failing**
- HEIC/HEIF on Windows/Linux → **explains macOS needed** (instead of silent fail)
- Slow HEIC conversions → **more time + clear timeout message**
- Pasted documents with no local file → **attach to cloud agent prompts**
- Videos/documents that can't attach → **show warning instead of disappearing**

## The Bigger Picture: Agents Window as Infrastructure

October 2026 wasn't a feature drop — it was a **repositioning**. Cursor 3.27 proves it:

| Old Cursor | New Cursor (3.27) |
