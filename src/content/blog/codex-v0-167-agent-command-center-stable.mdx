OpenAI Codex **v0.167.0** landed November 6 as a **stable release** (not alpha). The headline: **Agent Command Center** — a TUI dashboard for managing agents, sessions, and backends — now runs with `codex agents --no-daemon`.

---

## The Feature You'll Open Every Day: Agent Command Center

**What it is:** Run `codex agents --no-daemon` and get a full-screen TUI showing:
- All your agents (local, cloud, embedded)
- Session picker with **unread result markers** — know which sessions have new output
- **Cross-backend switching** — move between connected backends *inside the picker* and keep your drafts
- Task list sorted by recency within status groups

**Why it matters:** Before, you had multiple terminals, multiple `codex` processes, no central view. Now: one command, see everything, jump anywhere, drafts preserved.

**For beginners:** It's `htop` for your coding agents. Open it. See what's running. Switch context. Never lose a draft.

---

## Local Image Previews in the Composer

**What it is:** Paste/drag an image into the TUI composer — **see a thumbnail preview** before you send. Click viewed image paths in the transcript to open them.

**Why it matters:** Screenshots, diagrams, UI mockups — you *see* them inline while composing. No more "wait, which image was that?"

---

## GCP Vertex AI Setup Wizard (Finally)

**What it is:** Under "Sign in another way" → find **API key and cloud provider options**. Enable `gcp_setup_wizard` to set up **Google Cloud Vertex AI** with Application Default Credentials or a credential file.

**Why it matters:** Enterprise users asked for this. No more manual `gcloud auth application-default login` dance — the wizard walks you through it in the TUI.

---

## System Proxy Support (Experimental)

**What it is:** Opt into **macOS or Windows system proxy settings** from `/experimental`. Codex respects your OS proxy config.

**Why it matters:** Corporate networks, restricted environments — it just works now.

---

## Inline Patch Review During Approval Prompts

**What it is:** When an approval prompt opens, **expand patch details directly in the transcript**. See the diff before you approve.

**Why it matters:** No more "approve blindly then check git diff." The diff is *right there* in the prompt.

---

## Cross-Backend Session Switching (Preserves Drafts)

**What it is:** Switch between connected backends from the terminal session picker — **your draft text stays intact**.

**Why it matters:** You're mid-prompt on local backend, need to check cloud session. Switch, look, switch back — draft unchanged.

---

## Ctrl+L Clears Display, Keeps History

**What it is:** `Ctrl+L` clears the terminal display. Earlier messages stay available through `Ctrl+T` (transcript).

**Why it matters:** Clean slate for focus, history one keystroke away.

## Key Bug Fixes (50+)

| Fix | Impact |
|-----|--------|
| Saved chats stay visible after switching model providers | No more "where did my chat go?" on provider swap |
| Network approval prompts close when requests end | No zombie prompts stacking up |
| Concurrent requests to same endpoint prompt one at a time | No approval prompt floods |
| Long realtime V3 conversations save speech to history | Voice transcripts don't vanish |
| Auto context compaction accounts for failed/missing token usage | Compaction math is honest |
| Linux musl builds use fewer allocator arenas | Lower idle memory after conversations unload |
| Preserve unrelated side conversations when archiving/deleting | Bulk actions don't nuke adjacent threads |
| Remote executor auth timeout recovery | Cloud sessions don't brick on token rotation |
| Guardian context caps before elastic allocation | Memory stays bounded |
