## 1. Hooks Finally Get Teeth: `onFailure: "block"`

**Before:** A hook that failed to start, timed out, or exited weirdly — the action went through anyway. Silent failure.

**Now:** Add `"onFailure": "block"` to any command or HTTP hook. If the hook can't run, the tool call **stops**.

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "my-security-check.sh",
        "onFailure": "block"
      }]
    }]
  }
}
```

This is the **permission model you've been asking for**. If your security check crashes, the Bash call dies. No bypass.

## 2. Remote MCP: Exponential Backoff, Not Hammering

The #1 complaint about remote MCP servers: they'd reconnect in a tight loop after every drop, burning CPU and API quota.

**v2.1.295 fixes this at the protocol level:**
- First drop → immediate retry
- Repeated drops → exponential backoff, **capped at 30 seconds**
- Server drops connection right after connect? Backs off instead of spinning

Your remote MCP servers (especially self-hosted ones) just became **production-ready**.

## 3. Mods Get Native Notifications: `$.ui.notify`

Mod authors — you can now raise **system notifications** from your mods:

```javascript
// In your mod
$.ui.notify({
  title: "Security Review",
  body: "Found 3 issues in the last PR",
  channel: "security-review"
})
```

Users see a native OS notification (macOS/Windows/Linux) with your custom channel name. No more polling the UI for mod status.

## 5. Gateway Timeouts + Model Control (For Teams on Bedrock/Vertex/Foundry)

- **`timeouts.upstream_ttfb_ms`** — Set how long a stream may take to start on Bedrock/Vertex/Foundry before failover or 502
- **Optional `models` list per upstream** — Only listed models route there (wildcard `*` supported). Failover respects the list.
- **`forceLoginMethod: "gateway"` + `forceLoginGatewayUrl`** — `/login` opens your corporate gateway on machines without managed settings

No more "which model went where" debugging. You control the routing.

## 9. Code Review: Stops Skipping Your CLAUDE.md

**Fixed:** Code Review was skipping a large `CLAUDE.md`'s rules when the PR edited that file. Now it reads the rules *from the PR's version* — your security guidelines actually apply.
