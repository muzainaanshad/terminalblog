Claude Code **v2.1.296** landed October 9, and it's the kind of release that doesn't scream — it just makes everything work better. The headline: **Claude Haiku 5.5 is now the default Haiku model** (1M context, $0.10/$0.50 per M tokens). But the real story is the 100+ fixes that eliminate daily papercuts.

If you've been fighting Windows hook crashes, MCP server restarts, subagent context limits, or token counting quirks — this update fixes the things that made you sigh.

---

## The Big Changes You'll Notice

### 1. Haiku 5.5 Is Now the Default Haiku

**What changed:** `claude-haiku-5-5` replaces the previous Haiku as the default. 1M context window. Pricing: $0.10 input / $0.50 output per M tokens ($0.50/$2.50 for prompts over 100K).

**Why beginners care:** Haiku 5.5 is genuinely strong at coding now. You get 1M context at Haiku prices. For quick edits, file reads, and everyday tasks, it's the new sweet spot — faster than Sonnet, cheaper than Opus, capable enough for most things.

### 2. Subagents Can Now Auto-Compact Earlier Than Main Conversation

**New:** `autoCompactWindow` in subagent frontmatter and `--agents` definitions.

**What it does:** Your main conversation might have a 200K auto-compact window. A focused subagent doing a code review can compact at 50K. Different agents, different memory strategies.

**Why it matters:** Long-running subagents (like a security reviewer that reads your whole codebase) no longer balloon the main context. They self-manage.

### 3. Read Tool Gets `allow_large` — Read Past Size Limits in One Call

**New:** `allow_large` option on the Read tool.

**What it does:** When Claude needs an entire file and context has room, it can now read past the usual size limit in a single call. No more chunked reads for large config files, generated code, or logs.

**For beginners:** "Read the whole file" now actually works for large files. Less back-and-forth, less context fragmentation.

### 4. Windows: stdio MCP Servers Shut Down Gracefully (Finally)

**Fixed:** stdio MCP servers on Windows now get `stdin` closed first, then 300ms grace period before process tree kill.

**What this means:** No more corrupted MCP server state on Windows. Your database connections, file watches, and background processes in MCP servers get a clean shutdown signal.

### 5. Windows: `claude plugin install` Works Without SSH Keys

**Fixed:** GitHub `owner/repo` plugin sources now retry over HTTPS when no SSH key is configured.

**Why it matters:** Plugin installs on Windows just work now. No more "generate SSH key, add to GitHub, try again" dance.
