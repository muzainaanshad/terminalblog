## What Grok Build Actually Is

**Grok Build CLI** (13K+ GitHub stars, MIT-licensed, npm package `@xai/grok-build`) is a terminal-based coding agent that:

- **Free for xAI subscribers** — included with X Premium+ / xAI API access
- **8 parallel agents** — true concurrent execution, not sequential worktrees
- **Society of Mind architecture** — agents specialize (planner, coder, reviewer, tester) and collaborate
- **Fullscreen TUI** — rich terminal UI with split panes, live agent views
- **Vision support** — analyzes screenshots, diagrams, UI mockups
- **Subagents** — spawn child agents for subtasks
- **Background tasks** — long-running agents persist across sessions
- **Open source** — but xAI models only (no BYO keys)

---

## The Society of Mind: 8 Agents, One Task

This is the architectural differentiator. Instead of one agent doing everything, Grok Build spawns **8 specialized agents**:

| Agent | Role |
|-------|------|
| **Planner** | Breaks task into subtasks, creates spec |
| **Architect** | Designs file structure, interfaces, data flow |
| **Coder 1-3** | Implement different modules in parallel |
| **Reviewer** | Reviews code for bugs, style, security |
| **Tester** | Writes and runs tests, reports coverage |
| **Documenter** | Updates docs, comments, README |

They **communicate via shared context** — a "blackboard" memory all agents read/write. The planner assigns, coders implement, reviewer catches issues, tester verifies, documenter updates. All simultaneously.

**Result:** A 2-hour task finishes in 20 minutes. Not because each agent is faster — because they work *together*.

## Vision: The Agent That Sees

Grok Build has **native vision support** — drag/drop or paste images:

- **Screenshots** → "Implement this UI"
- **Architecture diagrams** → "Generate the code for this system"

The vision model (Grok Vision) processes images **in parallel with coding agents** — the planner sees the diagram while coders start implementing.

## Getting Started

```bash
# Requires xAI API key (from X Premium+ or xAI console)
npm install -g @xai/grok-build

# Configure
grok-build config set apiKey YOUR_XAI_KEY

# Start
grok-build
# Or in a project:
cd your-project && grok-build
```

First run: model selection (Grok 2, Grok 3, etc.), TUI tutorial, parallel agent demo.
