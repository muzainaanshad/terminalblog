**GitHub Copilot CLI v1.0.112 dropped November 13** — and it's the kind of release that doesn't make headlines but makes daily use noticeably better. 80+ fixes. Subagent model switching finally works. Pasted text survives policy loads. Microsoft 365 accounts can now run workflows. This is polish at scale.

---

## The Headline: Subagent Model Picker Finally Behaves

The `/subagents` model picker now **reopens for the same agent** after you switch away and come back. No more losing your place. On/off states and arrows stay visible in narrow terminals. Opening a subagent's view no longer spews escape sequences into your terminal.

If you use subagents heavily, this alone is worth the update.

---

## Pasted Text Survives Policy Load Delays

Ever paste a prompt while Copilot's managed account policy is still loading, press Enter, and get `[Paste #N - M lines]` literal text instead of your actual paste? Fixed. The pasted text now stays intact — press Enter again and it sends correctly.

Small fix. Massive quality-of-life improvement.

---

## Microsoft 365 Accounts Can Run Workflows

`copilot workflow run --help` now lists Microsoft 365 accounts alongside usage-based billing and BYOK (custom model provider while signed out of GitHub). Enterprise teams using M365: you're now first-class citizens for workflow automation.

---

## macOS Sandbox TCP Connections Documented

`copilot help sandbox` now explains the macOS reality: sandbox host rules block direct TCP to local ports (like a build client reaching its daemon). Localhost stays reachable only through the local proxy — HTTP or CONNECT tunnel from a proxy-aware client.

Finally, documentation that matches the actual behavior.

---

## Compact Failures Show Real Errors

A failed `/compact` now shows the **model provider's actual error message** without the internal host-rethrow prefix. Debugging context window issues just got easier.

---

## 80+ UI Polish Fixes (The Invisible Work)

| Area | Fixes |
|------|-------|
| **Sessions sidebar** | No more creating/switching sessions during CLI exit; exit summary resume commands stay valid |
| **Narrow terminals** | Settings editors, permission prompts, model picker, diff search — all keep content visible |
| **Copy/paste** | `/copy` keeps formatting in Word/Outlook/Teams; multi-message responses keep paragraph structure |
| **Vim mode** | Pasted text position preserved on Esc/Ctrl+C; undo/repeat scoped to current draft |
| **Unicode/emoji** | Paths, variable names, search cursors, LSP logs — all handle emoji and CJK correctly |
| **MCP** | Inspection commands warn when workspace config skipped; `copilot mcp get` reports unconfigured servers correctly |
| **Plugin manager** | Skips plugins with file-path catalogs (warning instead of killing all MCP servers) |
| **Autopilot** | Objectives and subagent descriptions readable with escape sequences; subagents respect session AI credit limit |

## The Verdict

v1.0.112 isn't a feature drop. It's **craft**. The kind of release that separates "works in demo" from "works in production."

**If you're on v1.0.110 or earlier:** update. The subagent fixes and paste-handling alone justify it.

**If you're evaluating terminal agents:** Copilot CLI is quietly becoming the most polished of the bunch. Not the flashiest. The most *reliable*.
