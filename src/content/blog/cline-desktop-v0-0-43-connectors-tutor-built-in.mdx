Cline Desktop **v0.0.43** landed October 2, and it does something most dev tools never bother with: **it teaches you how to use its biggest feature.**

The headline is a one-time "What's new" dialog that appears on first launch after the update. It shows Connectors with brand logos, a clickable example prompt, and an **Open Connectors** button that drops you straight into the catalog. You can replay it anytime from **Settings → About → Show what's new**.

If you've ever stared at a feature-rich tool wondering "okay, but where do I start?" — this is the answer. Cline just built onboarding into the product instead of leaving it to documentation you'll never read.

---

## The "What's New" Dialog: Onboarding That Doesn't Suck

Most software updates shove a changelog in your face. Cline v0.0.43 does something different:

- **Visual connector cards** — each with its brand logo, so you recognize GitHub, Linear, Notion, Slack, etc. instantly
- **A working example prompt** — click it, and the composer fills with a real task like "Create a Linear issue from this GitHub discussion"
- **One-click entry** — the **Open Connectors** button opens the catalog with search and browse already visible
- **Replay anytime** — didn't pay attention the first time? Settings → About → Show what's new brings it back

This matters because **Connectors are the difference between "chat with an agent" and "agent that does work across your tools."** A Connector lets Cline create a Linear ticket, post to Slack, update a Notion page, or comment on a GitHub PR — all from the same conversation. But you have to know they exist and how to install them. The dialog solves that.

## Universal macOS DMG Is Now the Standard

Since v0.0.9 (August), Cline Desktop has shipped a **single universal DMG** that runs on both Apple Silicon and Intel Macs. No more "which architecture am I?" confusion. Existing installs migrate automatically on update.

Windows users get a native app with a custom title bar (added in v0.0.24) that follows Windows 11 compact title-bar height. The taskbar icon was updated too. It feels like a Windows app, not an Electron port.

## The Rest of the October 2 Wave (CLI v3.0.70, SDK v0.0.91)

Cline shipped four coordinated releases on October 2 — Desktop v0.0.41, v0.0.42, v0.0.43, CLI v3.0.68→v3.0.70, and SDK v0.0.90→v0.0.91. The v0.0.41/v0.0.42 changes were already covered in [our deep dive](/blog/cline-desktop-free-coding-models-zero-api-keys/#october-2-update-what-v0041-v0042-cli-v3068-and-sdk-v0090-bring-latest-releases). Here's what v0.0.43 + CLI v3.0.70 + SDK v0.0.91 add:

### Desktop v0.0.43
- **One-time "What's new" dialog** for Connectors (the feature above)
- **Settings → About → Show what's new** to replay it

### CLI v3.0.70
- Same Connectors catalog refresh and model defaults as Desktop
- Team performance fixes from SDK v0.0.91

### SDK v0.0.91
- **SQLite team storage schema v2 migration** — compacts existing team data on first open
- **`SqliteTeamStore.vacuum()`** — reclaim freed space explicitly
- **Failed team writes retry instead of dropping** — no more silent data loss in long multi-agent runs
- **Run records keep summaries, not full transcripts** — `team_events` capped at 2000 rows / 30 days per team
- **Stream chunks and heartbeats go to live UIs only, never persisted** — the fix that stopped 1.66 GB databases

**The practical result:** Long multi-agent sessions stay fast. No gradual slowdown. No gigabyte databases eating your disk.

## Free Models Still Included — Zero API Key, Zero Billing

This hasn't changed, but it's worth repeating: Cline provides **free coding models** across Desktop, VS Code extension, and CLI. Select a model marked "(free)" and start coding. No Anthropic account, no OpenAI key, no credit card. Usage limits apply, but Cline shows you exactly when they reset.

For beginners, this remains the lowest-risk way to try a coding agent. The free models won't match Claude Opus 5 or GPT-6 Sol on complex multi-file refactors. But for reading code, explaining functions, writing tests, and small edits — they're more than enough.

## How to Update

**Desktop app (macOS/Windows):** Download from [Cline GitHub Releases](https://github.com/cline/cline/releases) — single universal DMG for Mac, native installer for Windows. Future updates arrive automatically.

**VS Code Extension:** Extensions panel → Cline → Update (or wait for auto-update)

**CLI:**
```bash
npm update -g cline
# Verify
cline --version
# Should show v3.0.70+
```

## The Bigger Picture: Open Source Agents Are Winning on Polish

Six months ago, the gap between commercial (Cursor, Copilot, Devin) and open (Cline, Goose, Aider, OpenCode) was **capability**. Today it's **polish** — and open source is catching up fast.

Cline v0.0.43 doesn't add a new reasoning paradigm. It adds the glue that makes the existing paradigm **usable daily**: a tutor for the feature that unlocks cross-tool workflows, a universal installer that removes architecture anxiety, team storage that doesn't bloat, and model defaults that are actually current.

That's how open source wins — not by being first, but by being the one you don't have to fight.
