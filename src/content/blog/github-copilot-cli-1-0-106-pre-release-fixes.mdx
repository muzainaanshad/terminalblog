GitHub Copilot CLI dropped **two pre-releases in 24 hours** — v1.0.106-1 (Oct 31) and v1.0.106-2 (Nov 1). Combined: **20+ fixes** with zero new features. Just the paper cuts you feel every day.

---

## The One Fix You'll Notice Immediately: Multi-Line Paste Finally Works

**The bug:** You copy a block of code, type `/ask` or `/clear` or `/delegate`, paste — and it all arrives as **one long line**. Indentation gone. Readability gone. You retype it manually.

**v1.0.106-1 fixes this.** Text pasted over several lines after `/clear`, `/new`, `/ask`, `/delegate`, or `/diagnose` now **keeps its line breaks and indentation**.

```bash
# Before v1.0.106-1
/ask
# Paste a 20-line function → arrives as one line

# After v1.0.106-1
/ask
# Paste → arrives exactly as copied, indentation intact
```

This also fixes `/new` (new conversation), `/clear` (clear context), `/delegate` (handoff to subagent), and `/diagnose` (debugging command). If you use slash commands daily, this alone is worth the update.

---

## The Fix That Stops Your Agent From Ghosting: Session Resume Stalls

**The bug:** You close a session, come back later, run `copilot --resume` — and it **stalls for 30 seconds** before showing the conversation.

**v1.0.106-1:** Reopening a recently closed local session no longer stalls. It's instant.

---

## The Fix That Saves Your Work on Ctrl+C

**The bug:** You hit `Ctrl+C` to stop a long-running `copilot -p` task. The process dies **before writing the session shutdown record** — usage totals, code-change counts, all lost.

**v1.0.106-1:** The shutdown record now writes **before exit**. Your usage dashboard stays accurate.

---

## web_fetch Finally Reads Non-UTF-8 Pages

**The bug:** `web_fetch` on ISO-8859-1, windows-1252, or other legacy encodings would reach the model with **mojibake** — accented characters replaced by garbage.

**v1.0.106-1:** `web_fetch` now decodes pages in their declared encoding (Content-Type charset or meta tag). Non-UTF-8 pages **just work**.

---

## WSL Clipboard Copy Fixed

**The bug:** Copy in WSL was broken — `clip.exe` arguments didn't match what cmd.exe expects.

**v1.0.106-1:** Fixed by running `clip.exe` with compatible cmd.exe arguments. Copy/paste in WSL **works now**.

---

## MCP Config Symlinks Preserved

**The bug:** Saving MCP server changes would **break symlinks** — your `mcp-config.json` symlink got replaced with a regular file.

**v1.0.106-2:** Symlinked `mcp-config.json` files are preserved and the symlink target updated. Your dotfile management stays intact.

---

## Screen Reader Users: Errors Now Announce Themselves

**v1.0.106-2:** With `--screen-reader`, failed/rejected tool calls, unknown commands, and warnings now begin with **"Error:"** or **"Warning:"** instead of reading like any other message. Accessibility win.

---

## /resume Stops Duplicating Background Sessions

**v1.0.106-2:** Running `/resume` on an already-running background session now **foregrounds it** instead of showing it twice on exit. Cleaner session management.

---

## HTTP MCP Servers That Hang — Timeout Once, Not Three Times

**v1.0.106-2:** An HTTP MCP server that accepts connections but never answers now holds startup for **its connection timeout once**, instead of retrying three times. Faster failure detection.

---

## Skills Stay In Sync With Session

**v1.0.106-2:** `/skills add`, `/skills remove`, and `/skills reload` now **stay in sync with session skills** and report refresh failures immediately. No more phantom skills.
