## 1. Git Branch Mode — Finally, Code Review That Makes Sense

### What it is

Open the Git Panel → Changes tab → click the new menu at top → **"Compare Against Base"**. Pick any branch (default: `origin/main`). You get every file changed since that base branch — opened as diffs, not staged, not restorable. Pure review.

```bash
# Or from command palette
git panel: show branch changes
```

### Why this changes your workflow

| Before | After |
|--------|-------|
| `git diff origin/main..HEAD` in terminal, scroll, lose context | Click branch → see every changed file → open diffs side-by-side |
| Staging UI clutters review | **Read-only diffs** — no accidental stages |
| Switch branches to compare | Stay on your branch, compare against *any* base |

### The catch

Files in branch mode **cannot be staged or restored**. This is intentional — it's a review view, not a staging view. For staging, switch back to "Changes" mode.

## 2. Bookmark Picker — Your Mental Anchors, Searchable

### What it is

`project bookmarks: toggle` (or `Cmd+Shift+B` / `Ctrl+Shift+B`) opens a searchable, previewable list of **every bookmark in your workspace**.

### Why you'll use it

- **Jump to "that function I marked three weeks ago"** without remembering the file
- **Preview context** before jumping — see the surrounding code in the picker
- **Search by name, file, or content** — fuzzy matching works

This is the feature that makes bookmarks *usable* instead of *theoretical*.

## 3. Configurable Git Date Formats — Your Timestamps, Your Way

### What changed

New settings for **absolute** and **relative** date styles across every Git view:

```json
// settings.json
{
  "git.date_format": "iso",           // "locale" | "iso" | strftime like "%Y-%m-%d %H:%M"
  "git.blame.date_style": "relative", // or "absolute"
  "git.inline_blame.date_style": "absolute",
  "git.branch_picker.date_style": "relative",
  "git.stash_picker.date_style": "relative",
  "git_panel.date_style": "relative",
  "git_graph.date_style": "absolute"
}
```

### Why it matters

- **ISO dates** sort correctly in logs and blame views
- **Relative dates** ("2 hours ago") for quick scanning
- **Per-view control** — blame gets absolute, branch picker gets relative, your call

## 5. Turn Off Auto-Generated Agent Thread Titles — Finally

### The setting

```json
{
  "agent.auto_generate_thread_titles": false
}
```

### Why this matters

Before: every agent thread got a generic title like "Refactor auth module" or "Fix bug in payments." You had 20 threads, all looked identical.

After: **you name them**. Or leave them unnamed. The editor stops assuming it knows what you're doing.

Small setting. Massive mental model shift — *you* organize, not the AI.
