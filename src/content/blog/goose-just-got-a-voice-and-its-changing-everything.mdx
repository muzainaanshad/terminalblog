Goose v1.52.0 landed on September 23, and it's the release that finally answers the question we've all been asking: **\"When will my AI agent just... talk to me?\"**

The answer is **now**. Live voice conversations in the desktop app. Not a demo. Not a prototype. You speak, Goose listens, thinks, and replies — out loud. In real time.

Plus: **BYOK for Claude Opus 5.5, GPT-6 Sol, and GPT-6 Luna**. A new **Decisions provider crate** with OpenRouter and Jev implementations. And 40+ bug fixes that clear the paper cuts you've been tolerating.

This isn't an incremental update. It's the moment Goose stopped feeling like a CLI tool and started feeling like a teammate.

---

## 1. Live Voice Conversations — The Feature You Didn't Know You Needed

Open the desktop app. Click the microphone. Start talking.

Goose hears you, processes your request, and **responds with its own voice**. Not text-to-speech slapped on top — a proper voice conversation loop with turn detection, interruption handling, and natural pacing.

**Why this changes everything:**

- **Hands-free coding** — Dictate a refactor while you're standing at a whiteboard, or review a PR while making coffee
- **Accessibility by default** — No plugins, no configuration, no \"enable experimental features\" toggle. It just works
- **Pair programming, literally** — Talk through architecture decisions out loud. Goose responds. The transcript stays in your session

For beginners: this is the first open-source AI coding agent with **native, production-ready voice**. No API keys for TTS/STT. No external services. It runs locally.

## 2. Opus 5.5, GPT-6 Sol, GPT-6 Luna — BYOK, Zero Friction

The model picker just got the heavyweights:

| Model | Provider | What It's For |

| **Claude Opus 5.5** | Anthropic | 1M context, deepest reasoning, hardest problems |

**For beginners:** You've been reading about these models in [Codex 0.154](/blog/codex-0-154-gpt6-astra-worktrees-windows-daemon/), [Goose v1.50](/blog/goose-v1-50-gpt6-astra-web-search-security-wave/), and [Zed v1.22](/blog/zed-just-dropped-gpt6-astra-and-claude-opus-55-byok/). Now they're in Goose — the agent that's been *local-first, privacy-first, free* since day one.

## 3. The Decisions Provider Crate — Your Agent, Your Logic

Goose v1.52.0 introduces a **Decisions provider crate** with two implementations out of the box:

- **OpenRouter** — Route decisions through 100+ models via one API
- **Jev** — Local decision engine, zero external calls

**What this means:** You can now plug in *how* your agent makes choices. Route planning decisions through Opus 5.5 via OpenRouter. Keep routine decisions local with Jev. Build your own provider. The decision layer is now **yours to compose**.

This is the architectural shift that separates \"agent as tool\" from \"agent as platform.\"

---

## 4. Settings Redesigned — Full-Screen, Finally Usable

Settings isn't a sidebar anymore. It's a **full-screen view** with:

- Search that actually finds things
- Provider cards you can enable/disable without digging
- Recipe limits displayed upfront (max 32 params, 200 select options, 128 KiB)
- Extension transports split out of ExtensionManager — cleaner, faster, less brittle

If you've ever hunted for a buried toggle in Goose's settings, this release is your apology letter.

## 5. The Bug Fixes That Save Your Sanity (40+ of Them)

The highlights you'll feel daily:

| Fix | Why You Care |
|-----|--------------|
| **Cancel elicitation on incomplete CLI input** | No more hanging prompts when you fat-finger a recipe |
| **Protect custom provider configs** | Your local provider files can't be overwritten by updates |
| **Prevent duplicate schedules overwriting recipes** | Your cron jobs stop eating each other |
| **Classify many-image dimension errors as context-length-exceeded** | Clear error message instead of cryptic failure |
| **Set `strict:false` on chat-completions tools** | Fewer \"invalid schema\" errors with complex tools |
| **Allow 60s for provider readiness** | Slow-starting local models don't get killed |
| **Write PATH to login shell files idempotently** | Installer stops breaking your shell on re-run |
| **De-duplicate @radix-ui packages** | Fixes phantom pointer-events on body (desktop app) |
| **Make todo opt-in and soften prompts** | No more nagging when you don't want a task list |
| **Require recipe consent before session/new spawns extensions** | Your extensions don't run without asking |
| **Skills follow working directory updates** | Change folders, skills update automatically |
| **Let recipe settings outrank `GOOSE_SUBAGENT_MODEL/PROVIDER`** | Recipe wins. Always. |
| **Send session usage updates after each provider call** | Real-time cost tracking, not end-of-session surprises |
| **Start chat with no extensions when user selects none** | Respects \"I don't want extensions right now\" |
| **Databricks GLM-5.3 and Kimi K3 reasoning effort** | New models, properly supported |
| **Avoid splitting graphemes in skills list** | Emoji and CJK render correctly in UI |
| **Keep subagent prompt prefix cacheable** | Faster subagent spins, lower token burn |
| **Install libclang and cmake in devcontainer** | Contributors: your environment just works |
