**What is a coding agent?** A coding agent is an AI-powered tool that can autonomously write, edit, and reason about code across multiple files in a codebase. Unlike simple autocomplete (GitHub Copilot), agents can execute terminal commands, navigate project structure, run tests, and complete multi-step tasks from a high-level prompt.

---

The November 2026 open-source coding agent leaderboard is live, and the story isn't who's #1 — it's who wins on **value**.

Codex CLI sits at #1 on raw adoption (57.8). But OpenClaw and Hermes tie on adoption (~57 and ~54) while delivering **2x the value score** because they're free with no paid tiers. OpenCode pulls 40M npm downloads/week but ranks #4 because GitHub stars and commit velocity don't match the hype.

This is the first leaderboard using **v3 multi-signal methodology** — npm/PyPI downloads, GitHub stars/forks, 30-day commits, 30-day issues activity, Reddit/X signals, and data coverage — weighted for real adoption, not hype. Closed-source tools (Cursor, Claude Code, AmpCode, Copilot CLI) are explicitly excluded. Sparse-data tools (Goose, Gitlawb Zero) are dropped.

## The Three Stories That Matter

### 1. OpenClaw Is the Value King — And Nobody's Talking About It

OpenClaw matches Codex on adoption (57.3 vs 57.8) but **doubles the value score** (57.3 vs 28.9) because its price_index is 1 (free) vs Codex's 2 (mid — free CLI but ChatGPT usage costs).

The signals are real: 395K GitHub stars (3x Codex), 83K forks (4x Codex), 4,857 issues opened in 30 days. This isn't a ghost repo — it's a actively maintained, heavily starred desktop agent with vision, cron, multi-provider support, and browser automation.

**Why it's not #1 on adoption:** npm downloads (3M/wk) trail Codex's 26.5M. But stars and forks tell a different story — developers are *watching and contributing*, not just installing.

**The bet:** If you want a free, feature-complete desktop agent with vision and cron that the community is genuinely excited about, OpenClaw is the signal leader.

---

### 2. Hermes: The Quiet Platform That Keeps Winning on Value

Hermes sits at #3 on adoption (53.6) but **ties its value score to adoption (53.6)** because it's completely free (price_index 1). No paid tiers, no cloud dependency, MIT licensed.

The signals: 264K GitHub stars (2x Codex), 59K forks (3x Codex), 5,425 issues opened/30d, 81K PyPI downloads/week. Commits are capped at 500/30d in the methodology but the main branch has seen ~10K commits since v0.22.

**What the data misses:** Hermes is a *platform*, not just a CLI. The leaderboard captures package signals but not the webapp, unified gateway, cron jobs, Telegram ops, plugin marketplace (1,050+), or persistent memory via mem0. Those are infrastructure layers that don't show up in npm/PyPI.

**The bet:** If you need unattended execution, background tasks, multi-provider routing, and a local-first platform that survives restarts — Hermes is the only OSS agent shipping the full stack.

---

### 3. OpenCode: 40M Downloads But Only #4 — The Hype vs. Habit Gap

OpenCode pulls **39.9M npm downloads/week** — 50% more than Codex, 13x more than OpenClaw. But it ranks #4 because GitHub stars (14K) and forks (2.5K) are an order of magnitude lower than the leaders. Commits and issues in the last 30 days: **zero**.

This is the classic "hype ahead of habit" pattern. Developers install it, try it, but don't star, fork, or contribute. The v2.2.0 breaking release (Oct 30) followed by 5 patches in 7 days suggests rapid iteration but also instability.

**What the data misses:** OpenCode *is* the terminal UX benchmark. Persistent Desktop terminals that survive restarts with scrollback, worktree shortcuts (Ctrl+Alt+O/B/X), percentage compaction that works for every model — these are daily-driver features that don't generate GitHub stars.

**The bet:** If you live in a terminal and want the most polished terminal experience — OpenCode. If you need community momentum and platform features — look elsewhere.

## How to Actually Use This

### If you're a solo dev wanting a daily driver
- **Terminal-first:** OpenCode v2.2.5 (best UX, persistent terminals)
- **Platform-first:** Hermes (cron, webapp, memory, plugins, Telegram ops)
- **Desktop with vision:** OpenClaw (cron, vision, browser automation, free)

### If you're a team lead evaluating for adoption
- **Value per dollar:** OpenClaw or Hermes (free, high adoption signals)
- **Enterprise-ready platform:** pi.dev (Helm, systemd, `--check` preflight, managed agents)
- **Editor integration:** Wait for Cursor/Codex to open-source — or use the OSS leaderboard as a proxy for community health

### If you're building on top of an agent
- **Plugin ecosystem:** Hermes (1,050+ plugins, verified tier, auto-updates)
- **Extensibility:** OpenCode (MCP, themes, mobile worktrees, plugin system)
- **Model routing:** Kilo (500+ models in Agent Manager) or Hermes (15+ providers, routing profiles)

## The Methodology (So You Can Audit It)

**v3-oss-multisignal weights:**
- Package downloads (npm + PyPI): 28%
- GitHub stars: 18%
- GitHub forks: 10%
- Commits (30d): 16%
- Issues activity (30d): 10%
- Social (Reddit + X): 8%
- Data coverage (how many signals present): 10%

**Price index:** 1 = free/BYO keys, 2 = mid (free CLI + paid usage), 3 = high, 4 = expensive
**Value score:** adoption_score ÷ price_index

**Data sources:** npmjs, pypistats, GitHub REST API (commits, issues), GitHub GraphQL (stars, forks), Reddit API, X syndication. Rate limits fall back to previous snapshot.

**Updated daily** at ~02:00 UTC via GitHub Actions. Live leaderboard: `/leaderboard/` · Embed: `/embed/leaderboard/`
