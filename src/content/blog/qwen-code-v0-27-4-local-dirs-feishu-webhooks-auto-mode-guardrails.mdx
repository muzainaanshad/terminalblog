**Qwen Code v0.27.4 dropped November 15** — and it's the kind of release that makes managed agents actually usable for real work. Local directory grants without credential persistence. Feishu/WeCom webhooks for team notifications. Auto Mode that finally respects risk. And your `/memory` CLI is back.

If you've been waiting for Qwen Code's managed agent story to mature — **this is the release.**

---

## The One-Line Summary

**Managed Agents get temporary local filesystem access (no stored creds), Feishu/WeCom webhooks for long replies, Auto Mode guardrails for risky actions, multi-workspace Goals, restored `/memory` CLI, and HTTP fallback when native UUID fails. No breaking changes.**

---

## 1. Managed Agents Finally Touch Your Local Files — Safely

**What it is:** Managed Agent sessions can now use **your browser's local filesystem** through **temporary directory grants**. You grant access to a specific folder. The agent reads/writes during the session. **Nothing persists** — no credentials, no paths stored after the session ends.

**Why it matters:** Previously, managed agents were cloud-only. You couldn't say "refactor this local repo" without complex setup. Now: grant `/home/user/my-project` → agent works → session ends → access revoked. Clean.

**For beginners:** Think of it like a browser file picker, but for your AI agent. You pick the folder. Agent gets temporary access. Done.

---

## 2. Feishu & WeCom Webhooks — Long Replies Don't Get Truncated Anymore

**What it is:** 
- **Feishu custom bot webhook** delivery (secret URL, optional signing secret, channel control, scheduled group delivery)
- **WeCom group webhook** (send Notify outputs, prompt results, scheduled-task results to WeCom groups)
- Long managed-channel replies split into **ordered delivery segments** instead of being cut off
- Visible truncation notice if segment limit exceeded

**Why it matters:** If your team lives in Feishu (Lark) or WeCom (Enterprise WeChat), Qwen Code now speaks your language natively. No more "reply truncated" — you get the full output in segments.

**For beginners:** Webhooks = "push updates to our team chat automatically." Feishu = ByteDance's Slack competitor. WeCom = Tencent's enterprise WeChat. Huge in China, growing globally.

---

## 3. Auto Mode Guardrails — Your Agent Asks Before Breaking Things

**What changed:**
- **Explicit authorization required** for destructive, discarding, shared-history, or bulk actions (not just "relevance")
- **Classifier timeout review** — session model reviews fast-classifier timeouts once when identifiers differ
- **No HTTP(S) URL filesystem lookups** — prevents Windows network lookup delays and session termination before requests start
- **Full Access (YOLO) mode visibly marked** — composer trigger shows destructive color icon/label

**Why it matters:** Auto Mode used to be "trust me bro." Now it's "I'll ask for the scary stuff." You stay in control without babysitting.

**For beginners:** Auto Mode = agent runs without asking every step. Guardrails = it still asks before `rm -rf` or pushing to prod.

---

## 4. Web Shell Goals: Multi-Workspace Support

**What it is:** Goals page now:
- **Merges goals from trusted workspaces** (see everything in one view)
- **Shows workspace badges** (know which project a goal belongs to)
- **Lets new goals target a selected workspace** (organize from the start)

**Why it matters:** If you juggle multiple repos/projects, your Goals dashboard finally reflects that reality. No more single-workspace tunnel vision.

---

## 5. `/memory` CLI Is Back — And It Persists

**What it is:** Native `/memory` controls restored in CLI with:
- Workspace settings that **persist across restarts**
- User/Project file or managed-folder actions
- Typed SDK APIs to preview, submit, inspect, cancel, retry Codex memory imports

**Why it matters:** Memory was one of Qwen Code's differentiators. v0.27.x had it partially removed. Now it's back — better, typed, and persistent.

---

## 6. HTTP Fallback — Works Even When Native UUID Fails

**What it is:** Terminal tabs, web previews, local commands, slash commands, and related shell flows now **keep working over plain HTTP** by generating IDs when native UUID support is unavailable.

**Why it matters:** Corporate environments, restricted networks, older systems — Qwen Code doesn't hard-fail anymore. It degrades gracefully.

---

## 7. Security Fixes (Quiet but Critical)

- Updated `qs`, `fast-uri`, `ip-address`, `Hono`, Node adapter security dependencies
- Updated `fast-uri` and `ip-address` in Live Host and CUA Electron builds
- Upgraded `glob` and `minimatch` to secure versions (matching reliability + search regressions fixed)
- Updated `unzipper` to 0.12.5
- Removed obsolete ExcelJS archive dependency paths
- MCP, DOMPurify, and compression request parsing vulnerabilities fixed

**Translation:** Supply chain hygiene. Your agent's foundation got patched.
