OpenHands **v1.38.0** dropped November 10. The headline feature is small but mighty: **conversation budgets with semantic meter fills** — you finally see how much context/tokens you've burned in real time.

---

## The Feature You'll Actually Notice: Budget Meters

**What it is:** A visual meter in the chat UI showing your conversation's token/context usage. Semantic fills (green → yellow → red) so you know when you're approaching limits *before* the agent starts hallucinating or truncating.

**Why it matters:** Before, you'd hit a context limit and wonder why the agent forgot the first half of the conversation. Now you see the meter creeping up. You can `/compact` proactively, start a fresh session, or just know "okay, one more big task then I reset."

**For beginners:** It's a fuel gauge. Green = plenty of room. Yellow = think about compacting. Red = the agent is running on fumes.

---

## Paper Theme for Agent Canvas

**What it is:** A new **Paper theme** — clean, high-contrast, easy on the eyes for long sessions. Joins the existing Light+/Solarized contrast pass (also finished in this release).

**Why it matters:** Agent Canvas is where you spend hours. Themes aren't cosmetic — they're ergonomics. Paper reduces eye strain on marathon coding sessions.

---

## Automation-Aware Installs (Big for Teams)

**What it is:** `mode=automation` + `POST /plugin-spec` lets you install OpenHands configured for automation *without* the full interactive setup. Plugin specs can be pre-configured and deployed programmatically.

**Why it matters:** CI/CD pipelines, fleet deployments, "give every developer the same agent config" — now scriptable. No more "run the wizard on 50 machines."

**For beginners:** If you manage a team, you can now bake your standard agent setup (plugins, models, permissions) into a deployable spec. New hire runs one command → gets your exact setup.

---

## Agent-Profile-Scoped Automations

**What it is:** Automations (prompt presets, plugin presets) can now run **from a specific agent profile** instead of always using `default`.

**Why it matters:** You can have a "code-review" profile with strict permissions and a "feature-dev" profile with broader access. Automations pick the right one. No more permission collisions.

---

## Key Bug Fixes (30+)

| Fix | Impact |
|-----|--------|
| Docker: exit non-zero when agent-server stops responding | CI pipelines actually fail instead of hanging |
| Docker: keep conversation workspaces in persisted volume | Your work survives container restarts |
| Composer stop interrupts agent (not pausing Cloud sandbox) | `Stop` means *stop*, not "pause the cloud VM" |
| Focus stealing: launch view doesn't yank focus when you navigated away | Type in chat, don't fight the UI |
| Onboarding: ACP pick saves to its own profile, not `default` | Editor integrations don't pollute your main profile |
| Fail fast on unwritable Docker bind mounts + documented fix | Clear error instead of mysterious permission denied |
| Reconcile active LLM profile against backend model (race fix) | Model picker stays in sync with what's actually running |
| Diff viewer: release models after editor teardown | Memory doesn't leak when you close diff tabs |
| Hide agent profile switch when self-hosted turns Agent Profiles off | UI respects your config |

## The Bottom Line

v1.38 is a **polish release with one killer feature** (budget meters). The rest is: themes that don't hurt your eyes, automation that deploys cleanly, profiles that don't collide, and Docker that doesn't eat your workspace.

If you run OpenHands daily — **update for the budget meter alone**. It changes how you pace a session.
