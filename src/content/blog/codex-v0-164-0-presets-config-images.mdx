**Codex v0.164.0 dropped October 23** — hot on the heels of v0.163.0's `/config` UI. This release doesn't just add settings; it gives you **muscle memory** with `/presets`, **instant model switching** without leaving the chat, and **actual image rendering** in your terminal.

If v0.163.0 gave you control, v0.164.0 gives you *speed*.

---

## The Headline Features (Ranked by Daily Impact)

### 1. `/presets` — Your Top 10 Prompts, One Keystroke Away

**What it is:** Save up to 10 reusable prompts or slash commands in numbered slots. Open the keyboard menu, pick a slot, done. Supports `/preset 1` through `/preset 0`.

**Why it matters:** You have prompts you use daily — "refactor this with tests," "explain this bug," "write a commit message." Before: retype or scroll history. Now: `/preset 3` and you're moving.

```bash
# In Codex:
/presets
# Menu opens → pick slot → name it → save your prompt
# Later:
/preset 3
# Instantly loads your saved prompt
```

**For beginners:** This is your "speed dial" for the 3–5 things you ask Codex every day. Set it up once.

---

### 2. Inline `/model` and `/permissions` Arguments — Switch Mid-Conversation

**What it is:** Pass model, reasoning effort, speed tier, and permission profiles directly as arguments to `/model` and `/permissions`. No UI detour.

**Why it matters:** You're in a deep debugging session. Need more reasoning? `/model effort=high`. Need speed? `/model speed=fast`. Need stricter perms? `/permissions profile=strict`. All without breaking flow.

```bash
# Examples:
/model gpt-6.1-sol effort=high speed=balanced
/permissions profile=restricted
/model --list  # shows available with current flags
```

**For beginners:** Think of it as CLI flags for your chat. The settings apply *right now*, not after a restart.

---

### 3. Fullscreen Image Preview — Kitty and Sixel Graphics Support

**What it is:** View generated and fetched images in fullscreen inside the transcript on terminals supporting Kitty graphics protocol or Sixel.

**Why it matters:** Your agent generates a chart, a diagram, a UI mockup. Before: open a browser, find the file, view it. Now: it renders *in the terminal* where you're working.

```bash
# Works automatically on:
# - Kitty terminal (native)
# - Ghostty (Kitty protocol)
# - WezTerm (Sixel)
# - iTerm2 3.5+ (Sixel)
# - Any terminal with Sixel support
```

**For beginners:** If your terminal supports images, they just appear. No config needed.

---

### 4. Enterprise MCP Authentication — OAuth Clients with Secrets

**What it is:** Authenticate enterprise MCP connections using eligible Codex account grants *or* dedicated sign-in, including OAuth clients that require client secrets.

**Why it matters:** Corporate MCP servers often need proper OAuth flows. Codex now handles the full dance: discovery, token exchange, secret management — so your internal tools just connect.

```bash
# Configure in /config → MCP → Enterprise
# Or via CLI flags for automation
codex --mcp-enterprise-auth
```

**For beginners:** If your company runs private MCP servers, this is the "it just works" moment. No more manual token wrangling.

---

### 5. Credential Masking for Remote Commands — Security Hardening

**What it is:** Credentials are now masked during supported remote Bash commands and Zsh snapshot sessions, including credentials from custom providers.

**Why it matters:** Your agent runs `ssh`, `kubectl`, `aws cli` on remote hosts. Those commands often carry tokens, keys, certs. Now they're masked in logs, transcripts, and memory — supply-chain hardening that actually works.

---

### 6. Amazon Bedrock Setup Wizard Enabled by Default

**What it is:** The Bedrock setup wizard now shows by default, with API key entry grouped alongside other AWS sign-in methods when credentials are detected.

**Why it matters:** AWS users get a guided path to Bedrock models without hunting through docs. Detected credentials = wizard appears automatically.
