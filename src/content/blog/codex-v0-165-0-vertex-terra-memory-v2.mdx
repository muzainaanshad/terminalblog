**Codex v0.165.0 dropped October 27** — just four days after v0.164.0's presets and image preview. This isn't a polish release. It adds **Vertex AI as a first-class provider**, **GPT-6.1 Terra** to the model catalog, **reasoning effort you can change mid-chat**, and **Memory v2 by default for every new user**.

If v0.164.0 gave you muscle memory, v0.165.0 gives you *infrastructure*.

---

## The Headline Features (Ranked by Long-Term Impact)

### 1. Built-in Google Cloud Vertex AI Provider — `model_provider = "gcp"`

**What it is:** A native Vertex AI provider configured with a single setting. No proxy, no wrapper, no custom integration.

```json
{
  "model_provider": "gcp"
}
```

**Why it matters:** Enterprises on GCP can now use Codex with their existing Vertex AI quotas, VPC-SC perimeters, and IAM policies. No data leaves your Google Cloud project. This is the "it just works" moment for GCP shops.

**For beginners:** If your company uses Google Cloud, you no longer need to route requests through OpenAI's API. Codex talks to Vertex directly.

---

### 2. GPT-6.1 Terra Added to Model Catalogs

**What it is:** OpenAI's newest flagship reasoning model (Terra) is now available in Codex's model picker.

**Why it matters:** Terra is optimized for complex multi-step reasoning, code generation, and agentic tasks. It's the model you want when the problem is "figure out this legacy codebase and refactor it" not "write a quick function."

**For beginners:** When you hit a hard problem, switch to Terra. It thinks longer but gets further.

---

### 3. Reasoning Effort Changes Mid-Conversation — Enabled by Default

**What it is:** You can now change reasoning effort (`effort=high|medium|low`) *during* a conversation for supported models. No restart, no context loss.

```bash
# In Codex:
/model effort=high
# Continue your task — the model now thinks harder
```

**Why it matters:** Start fast (`effort=low`) for exploration. Dial up (`effort=high`) when you hit the hard part. The model adapts to the phase you're in.

**For beginners:** This is a slider for "how hard should the model think right now." Use it liberally.

---

### 4. Memory v2 Enabled by Default for Fresh Profiles

**What it is:** New Codex profiles get Memory v2 automatically — persistent, cross-session memory that actually works. Plus: import memories from other agents (Claude Code, Cursor, etc.).

**Why it matters:** Memory v1 was "notes the model might read." Memory v2 is "context the model *uses*." It structures memories, versions them, and retrieves relevant ones automatically.

**For beginners:** First run of Codex on a new machine? You get the good memory system out of the box. Switching from another agent? Bring your context with you.

---

### 5. Repository Filter + Directory Grouping in Session Picker

**What it is:** The session picker now lets you filter by repository and groups sessions by directory. Essential when you have dozens of worktrees across multiple repos.

**Why it matters:** Worktrees (added in v0.162.0) multiply your sessions. This makes them navigable.

---

### 6. Experimental Attached Thread Forks (App-Server API)

**What it is:** Fork a running thread at any point, explore an alternative path, then merge or discard. Think `git branch` but for agent conversations.

**Why it matters:** "What if I tried this approach instead?" — now you can find out without losing your main thread.

## How to Update

```bash
# Stable (v0.165.0) — RECOMMENDED for daily use
npm install -g @openai/codex@0.165.0

# Or just "latest" on stable channel
npm install -g @openai/codex@latest

# Via installer (auto-updates to stable)
# macOS/Linux
curl -fsSL https://codex.openai.com/install | bash

# Windows (scoop)
scoop update codex

# Verify
codex --version
# Should show 0.165.0
```

**First things to try after update:**

```bash
# 1. Try Vertex AI if you're on GCP
# /config → Model Provider → Google Cloud Vertex AI

# 2. Test GPT-6.1 Terra on a hard problem
/model gpt-6.1-terra effort=high
# "Refactor this authentication module to use JWT with refresh tokens"

# 3. Change reasoning effort mid-task
/model effort=low   # exploration
/model effort=high  # the hard part

# 4. Check Memory v2 (new profiles get it automatically)
/memory
# See structured, versioned, retrievable memories

# 5. Test session picker with repo filter

```
