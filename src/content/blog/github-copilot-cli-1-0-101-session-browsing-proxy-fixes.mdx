## The Fixes That Change Daily Work

### 1. Session Browsing — Your History Finally Works

**What it is:** Improved session browsing that actually lets you find and resume previous work.

**Why it matters:** Before this, digging through session history was clunky. Now you can navigate, search, and resume with context intact. The first prompt no longer hangs silently when no model is selected at startup — the CLI now asks you to pick one with `/model` and **keeps your prompt**.

### 2. Proxy Settings Honored for Sandbox Traffic

**What it is:** Sandbox commands now respect your system/environment proxy configuration.

**Why it matters:** Corporate environments, VPNs, restricted networks — sandbox traffic used to bypass proxy settings entirely. Now it flows through your configured proxy like everything else.

```bash
# Your existing proxy config now works for sandbox too
export HTTP_PROXY=http://proxy.company.com:8080
export HTTPS_PROXY=http://proxy.company.com:8080
# Sandbox commands respect these
```

### 3. Voice Dictation — Unwanted Language Markers Removed

**What it is:** Voice dictation no longer injects language markers (like "period", "comma", "new line") into your code.

**Why it matters:** You dictate "create a function that handles user auth period" — it used to type `create a function that handles user auth period` literally. Now it types `create a function that handles user auth.` like a normal human.

### 4. Shell Commands That Create + Enter Directories — Path Approval Instead of Denial

**What it is:** `mkdir foo && cd foo` used to be denied early. Now it requests path approval properly.

**Why it matters:** This pattern is ubiquitous in developer workflows. The old behavior forced you to pre-approve paths or run commands separately. Fixed.

### 5. Entra MCP Sign-In Recovery — Cached Token Rejection Handled

**What it is:** Explicit Entra MCP sign-in now recovers from rejected cached tokens by continuing to interactive sign-in.

**Why it matters:** Expired/revoked Entra tokens used to leave you stuck. Now it gracefully falls back to interactive auth.

### 6. Google Models — Screenshot Token Usage Reduced

**What it is:** Google models now avoid repeated request rewrites when screenshot-heavy sessions exceed image limits.

**Why it matters:** Each rewrite burned extra tokens. Now the CLI respects registry image limits upfront, reducing token waste on image-heavy workflows.

### 7. Windows Shell Reliability — Restored Sessions Start Cleanly

**What it is:** Windows shell commands now start reliably in restored sessions and clean up orphaned child processes.

**Why it matters:** Restored sessions on Windows were flaky — commands wouldn't start, orphans accumulated. Now they just work.

### 8. Reasoning Effort Switching — No Forced Compaction

**What it is:** Switching only reasoning effort no longer forces compaction in over-budget sessions.

**Why it matters:** You tweak effort level → session compacts → lose context. Now effort changes are lightweight.

### 9. Copy Keys — Mouse Selections Actually Copy

**What it is:** Copy keys now reliably copy mouse selections even when pressed immediately after dragging.

**Why it matters:** Small UX win that eliminates "wait, did that copy?" uncertainty.

### 10. MCP Inventory Reads — No More Startup Failures

**What it is:** Configured MCP inventory reads no longer fail when startup state is unchanged.

**Why it matters:** MCP server discovery at startup was fragile. Now it's idempotent.

## How to Update

```bash
# macOS (Homebrew)
brew upgrade github-copilot-cli

# Windows (winget)
winget upgrade GitHub.CopilotCLI

# Windows (scoop)
scoop update github-copilot-cli

# Linux/macOS (npm)
npm update -g @github/copilot-cli

# Or reinstall latest
npm install -g @github/copilot-cli@latest

# Verify
copilot --version
# Should show 1.0.101
```

**First things to try after update:**

```bash
# 1. Test proxy-aware sandbox
export HTTP_PROXY=http://your-proxy:port
copilot sandbox run "curl ifconfig.me"

# 2. Try session browsing
# Start a session → do work → exit → restart → browse history

# 3. Test voice dictation (if you use it)
# Speak naturally → check no "period/comma" literals

# 4. Test mkdir + cd in one command
copilot "mkdir test-project && cd test-project && ls"

# 5. Check /usage output for BYOK rows
copilot /usage
```
