AmpCode **October 27** dropped the one thing mobile developers have been asking for since iOS launched: **a native Android app.**

Not a web wrapper. Not a companion. The full AmpCode experience — Threads, Orbs, Puck, Portals, Changes — in your pocket.

## The One-Line Summary

**Your coding agent just went mobile. Threads, Orbs, Puck, and Portals now run on Android. Download from ampcode.com/app or scan the QR code on their site.**

---

## What You Actually Get

### Threads — Your Coding Conversations, Mobile-First

Every thread you run on desktop syncs to your phone. Open the app → see your active threads → tap one → continue the conversation. The agent keeps working while you're on the train, in a meeting, or lying in bed.

**For beginners:** This is the "aha" moment. You ask Amp to refactor a module on desktop. It starts working. You close your laptop. On your phone, you see the diff appear in real-time. You approve it. The agent commits. You never sat at a desk.

### Orbs — Remote Compute You Can Check From Anywhere

Orbs are Amp's remote agent environments. Spin one up on your Mac, a cloud VM, or your self-hosted Kubernetes cluster. The Android app lets you:

- **See every running orb** with its status (spawning, running, paused, done)
- **Tap to open the orb's thread** and watch the agent work
- **Pause/resume/delete orbs** with a swipe
- **Get push notifications** when an orb finishes or needs input

**The use case:** You spin up an orb to do a massive refactor before bed. Wake up → check phone → orb is done → review diff → merge. Your laptop stayed closed.

### Puck — Your Meta-Agent, Now Parallel

Puck is Amp's meta-agent that manages other agents. On desktop you got "Many Pucks" (multiple parallel conversations) in early October. Now **all of them are on your phone**.

Open the app → see 3 Puck conversations running:
- Puck #1: Reviewing a PR
- Puck #2: Planning the auth rewrite
- Puck #3: Debugging the CI failure

Tap any one → see its full transcript → steer it → close → tap another. True multi-agent orchestration without a dashboard.

### Portals — Live Preview in Your Hand

Orbs can expose ports via Portals (added in September). Your Android app shows the Portal tab. Tap it → see the live app your agent is building. Swipe through changes. It's a browser tab, but for the agent's work.

### Changes Tab — Diffs That Make Sense on Mobile

Code review on a phone used to be painful. Amp's Changes tab renders diffs with:
- Syntax highlighting that works on small screens
- File tree navigation optimized for touch
- Inline comments from the agent explaining *why* it made each change
- One-tap "Approve" / "Request Changes" / "Merge"

## Honest Assessment: What's Still Missing

- **iOS app** — Released August 28 (iOS/macOS), Android took 2 more months. If you're on iPhone, you've had this since September.
- **Offline mode** — Still needs connectivity for auth/licensing. Agent compute runs on your orb (remote), so the app is a window, not the engine.
- **Native notifications for every event** — Currently: orb completion, input needed. Not yet: every tool call, every token.
- **Tablet/landscape optimization** — Works, but clearly phone-first. Foldables and tablets get the phone layout stretched.
