Cursor 3.29 dropped **November 5, 2026** — just two days after the massive 3.28 platform launch.

If 3.28 was "Cursor becomes a platform," 3.29 is **"that platform actually works reliably now."**

---

## The One-Line Summary

**Cursor 3.29 (Nov 5) → Stabilization release after 3.28's platform pivot. Fixes for Projects sync, Cloud Agent reliability, Remote Control reconnection, Origin Marketplace installs. No new flagship features — just "it works" energy.**

---

## Why This Release Exists

**3.28 changed everything:** Projects (multi-agent orchestration), Cloud Agents with Canvases, Origin App Marketplace (20+ integrations), Remote Control from iOS, Rollouts, Security Review, Grok Bot for GitHub issues — all graduated from beta to stable *simultaneously*.

That's a *lot* of moving parts. When you ship six major features at once, things break.

3.29 is the "we heard you" release. The Cursor team spent 48 hours fixing the rough edges developers hit on day one.

---

## What's Fixed (The Stuff You'll Actually Notice)

### Projects — Sync Issues Resolved

**The problem:** Some users reported Project context not persisting across sessions, or coordinator agents "forgetting" prior decisions after a restart.

**3.29 fix:** Project state serialization hardened. Coordinator memory now checkpoints more frequently. Subagent handoffs preserve context correctly.

```bash
# If you lost Project context in 3.28, try:
# Left nav → Projects → [your project] → "Resume" button
# Should now pick up exactly where you left off
```

### Cloud Agents — Fewer "Agent Disconnected" Errors

**The problem:** Cloud agents occasionally dropped mid-task, especially on larger repos (100+ files) or when Canvases were involved.

**3.29 fix:** 
- Environment startup timeout increased (was too aggressive for 300-repo environments)
- Canvas rendering now streams incrementally instead of blocking on full render
- Auto-reconnect logic improved for flaky connections

### Remote Control (iOS) — Stays Connected Longer

**The problem:** iOS app would lose connection to local agents after ~10 minutes of background time, requiring re-pairing.

**3.29 fix:**
- Background keep-alive interval adjusted
- "Keep this computer awake" now works more reliably on Windows (was macOS-first)
- Re-pairing flow simplified — no need to re-approve on desktop if session token valid

### Origin Marketplace — Install Flow Smoother

**The problem:** Some app installs hung at "Configuring..." or failed silently with cryptic errors.

**3.29 fix:**
- Better error messages with actionable next steps
- Retry logic for transient network failures during install
- App permissions preview before confirm (so you know what you're granting)

### Grok Bot — GitHub Issue Threading Fixed

**The problem:** Grok Bot sometimes created duplicate PRs or lost context when multiple `@grok` mentions happened in the same issue.

**3.29 fix:**
- Deduplication on `@grok` mentions within 5-minute window
- Session persistence improved — follow-ups in same issue thread resume correctly
- Rate limiting added to prevent API quota exhaustion

## For Beginners: Should You Update?

**Short answer: Yes.**

**Long answer:** If you're on 3.27 or earlier → **update immediately**. You're missing the entire platform (Projects, Cloud Agents, Origin, Remote Control, Rollouts, Security Review, Grok Bot).

If you're on 3.28 → **update today**. 3.28 was the "it compiles" release. 3.29 is the "it runs reliably" release. The fixes target exactly the friction points beginners hit hardest:
- "Why did my Project forget what we did yesterday?"
- "Why does Remote Control keep disconnecting?"
- "Why did the Cloud Agent die halfway through?"

## What's *Not* in 3.29 (Honest Assessment)

- **No new flagship features** — this is intentional. The team is stabilizing.
- **No Android Remote Control app** — still "coming soon" (iOS only for now)
- **No Rollouts/Security Review on Pro plan** — still Teams/Enterprise only
- **No fully offline/local Projects** — Projects require cloud compute
- **No Canvas embed/export** — still shareable link only
