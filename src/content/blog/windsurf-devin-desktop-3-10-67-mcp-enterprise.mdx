Devin Desktop **3.10.67 dropped October 12, 2026** — and it's a quiet but significant release for teams running agents at scale.

The headline: **MCP protocol 2026-07-28 support** (the new `server/discover` handshake without `initialize`), **enterprise marketplace lockdown**, and **large folder performance fixes** that stop the agent window from choking on monorepos.

Plus a private preview: **remote MCPs from Devin Cloud** (enterprise-only).

---

## The Headline Features (Ranked by Team Impact)

### 1. MCP Protocol 2026-07-28 — The New Handshake Standard

**What changed:** MCP servers can now negotiate protocol version 2026-07-28, which uses `server/discover` instead of the old `initialize` flow.

**Why it matters:** The old `initialize` handshake was a bottleneck — every MCP connection needed a full round-trip before tools were available. `server/discover` is lighter, faster, and designed for the multi-agent workloads Devin Desktop runs.

**For beginners:** If your MCP servers support the new protocol, they'll connect faster and more reliably. If they don't, they'll fall back to the old handshake. No config changes needed.

### 2. Enterprise Marketplace URL Lockdown

**What changed:** Enterprise admins can now set an **Extension marketplace URL** in team settings. When set, Devin Desktop **only searches and installs extensions from that marketplace**.

**Why it matters:** 
- No more accidental installs from public marketplace
- Enforce approved/internal-only MCP servers, skills, plugins
- Supply-chain security for agent tooling
- Audit trail: every extension comes from your vetted source

**Setup:**
```
Settings → Team → Extension Marketplace URL → [your internal registry]
```

**For teams:** This is the first real enterprise governance for agent tooling. You control what your agents can *reach*, not just what they can *do*.

### 3. Large Folder Performance — Monorepos Don't Freeze Anymore

**What changed:** Improved performance for **very large or deeply nested folders**.

**Why it matters:** If you've worked in a monorepo with 50k+ files, you know the pain: file search lags, agent context loading stalls, the whole window gets sluggish. This release targets those bottlenecks directly.

**For daily work:** File mentions (`@`), search, and agent context gathering should feel snappier on large codebases. Not "instant" — but "usable" instead of "wait, is it frozen?"

### 4. Model Picker Remembers Your Variant Per Model Family

**What changed:** The model picker now **remembers the variant you last used for each model family**, instead of resetting to the family default.

**Example:** You pick "Claude Opus 5.5 (thinking: high)" → switch to GPT-6 → switch back to Claude → **it remembers "thinking: high"**.

**Why it matters:** Small UX win, but compounds across dozens of model switches per day. You set your reasoning preference once per model family.

### 5. Private Preview: Remote MCPs from Devin Cloud (Enterprise)

**What changed:** Devin Desktop can now connect to **remote MCPs configured in Devin Cloud**. Only enterprise-level MCPs will be reached.

**Why it matters:** Centralize your MCP infrastructure in Devin Cloud. Agents on any desktop (local, remote, CI) pull the same MCP config. No more "which version of the MCP server is on this machine?"

**Access:** Private preview — enterprise plans only. Contact Cognition if you're interested.

## FAQ

**Does MCP 2026-07-28 break existing MCP servers?**
No — fallback to old `initialize` handshake is automatic. Servers supporting the new protocol get faster discovery; others work as before.

**Can I use the enterprise marketplace URL with a private npm registry?**
Yes — any registry implementing the Origin API spec works. See [Origin API docs](https://cursor.com/docs/api/origin).

**Is the remote MCP preview available on Pro plans?**
No — enterprise only for the preview. GA timeline TBD.

**What's the difference between "Devin Desktop" and "Windsurf"?**
Rebrand only. Same binary, same Cascade agent, same Wave numbers. Your config, sessions, and settings carry over.

**Are Arena Mode / Plan Mode in this release?**
Yes — they launched in **3.10.23 (Sep 10, Wave 14)**. If you're on 3.10.23+, you already have them. 3.10.67 adds enterprise/governance features.
