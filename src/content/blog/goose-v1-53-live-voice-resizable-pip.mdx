Goose **v1.53.0 dropped October 2**, hot on the heels of v1.52 (Sep 23) and v1.51 (Sep 17). Three releases in two weeks. The pace is relentless, and the desktop app is finally becoming the daily driver the 20K-star Rust agent promised.

If you've been watching Goose from the sidelines — **this is the version where the desktop app stops feeling like a demo.**

---

## 1. Resizable Picture-in-Picture for MCP Apps

**The headline feature:** MCP apps (the little web tools Goose can spawn — browsers, dashboards, databases) now run in a **resizable Picture-in-Picture window** instead of taking over your screen or cramming into a fixed pane.

- Drag to resize, position anywhere
- Stays on top while you code
- Multiple PiP windows supported
- Works with any MCP app that exposes a web UI

For beginners: this is how "agent uses tools" becomes "agent uses tools *while you watch*." You can have a browser MCP app open in a corner, a database admin panel in another, and your editor full-screen — all talking to the same Goose session.

---

## 2. Live Model Metadata from models.dev (With Bundled Fallback)

Goose now **fetches model metadata live from [models.dev](https://models.dev)** — the community-maintained model catalog — with a bundled fallback so you're never blocked if the API is down.

What this means:
- New models appear in Goose's picker **automatically** when added to models.dev
- Context windows, pricing, modalities (vision, audio, reasoning) always current
- No waiting for Goose releases to get the latest model specs
- Offline/air-gapped installs use the bundled catalog

This is the "one tool, every model" philosophy executed at the metadata layer.

---

## 3. Quoting Action — Selected Text → Composer

Highlight any text in the conversation (your previous prompt, an agent response, an error message) → **quote action** → it appends to your composer with context preserved.

No more copy-paste-edit. The workflow:
1. Agent gives you a plan
2. You highlight the step you want to refine
3. Quote → it's in your composer, ready to send back with your tweaks

Small UX, compounds daily.

---

## 4. Lean ACP-Only Binary

A new **`goose-acp` binary** (and npm package) that speaks *only* the Agent Communication Protocol — no TUI, no desktop, no CLI chat. Just ACP.

Why this matters:
- Embed Goose in your own tools/editors/CI without the full binary weight
- Pair with external frontends (VS Code extensions, custom UIs, web apps)
- Smaller attack surface, faster startup
- The same agent core, stripped to the protocol layer

If you're building on ACP, this is the distribution you've been waiting for.

---

## 5. GDK Agent Loop Runs on WASM (wasm32)

The **Goose Development Kit (GDK)** — the library for building custom agents on Goose's core — now compiles its agent loop to **WebAssembly (wasm32)**.

This unlocks:
- Goose agents running in browsers (no server required)
- Edge deployments (Cloudflare Workers, Fastly Compute, Vercel Edge)
- Plugin architectures where the agent *is* the plugin
- Sandboxed execution environments with deterministic behavior

The GDK is how Goose becomes a platform, not just an app. WASM is the universal runtime.

---

## 6. Model Discovery API for GDK Provider

Programmatic model discovery for custom GDK providers. Instead of hardcoding model lists, your provider can now implement a discovery endpoint and Goose will fetch available models dynamically.

Combined with models.dev live metadata — **your custom provider's models get the same first-class treatment as first-party ones.**

---

## 7. Meta Muse Code Provider

Native support for **Meta's Muse Code** models (the open-weight coding family). Added as a declarative provider — works out of the box, no config wrestling.

---

## 8. Opus 5.5, GPT-6 Sol, GPT-6 Luna Support

Frontier model support lands within days of release:
- **Claude Opus 5.5** — Anthropic's latest Opus
- **GPT-6 Sol** — OpenAI's reasoning-optimized variant
- **GPT-6 Luna** — OpenAI's speed-optimized variant

Goose's provider system means these work the same way as every other model: pick from picker, go.

---

## 9. Session Rename Command in CLI

`goose session rename <new-name>` — finally. Your session list stops being a wall of timestamps.

---

## 10. Show Working Directory in Session Remove

`goose session remove` now shows the working directory so you know *which* project you're deleting. Small safety win.

## How to Update

```bash
# macOS/Linux (install script)
curl -fsSL https://github.com/block/goose/releases/download/v1.53.0/goose_v1.53.0_darwin_arm64.tar.gz | tar -xz && sudo mv goose /usr/local/bin/

# Or via Homebrew (when updated)
brew upgrade goose

# Windows (scoop)
scoop update goose

# Cargo (if you build from source)
cargo install --git https://github.com/block/goose --tag v1.53.0 goose

# Verify
goose --version
# Should show 1.53.0
```

For the ACP-only binary:
```bash
# npm
npm install -g @block/goose-acp@1.53.0

# Or download from releases
```
