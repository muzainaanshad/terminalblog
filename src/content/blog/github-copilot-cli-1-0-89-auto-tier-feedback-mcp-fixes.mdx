GitHub Copilot CLI **1.0.89** dropped September 25, and it's the kind of release that doesn't make headlines but **removes the friction you feel every time you switch models**.

The headline feature: **Automatic routing tier selection with instant switching**. No more digging through `/model` menus to find the right tier — Copilot now suggests the best one and lets you switch with a shortcut or click. Plus: instant feedback prompts when you manually override, so the system learns your preferences.

---

## 1. Auto Tier Selection — The Model Picker Finally Gets Smart

`/model` now **auto-suggests a routing tier** (Balance, Speed, Quality) based on your task. You see the recommendation, hit a shortcut or click, and you're on the right model for the job.

**No more:**
- Memorizing which model lives in which tier
- Cycling through tiers manually
- Accidentally staying on "Fast" (now unsupported) when you wanted "Balance"

**What changed:**
- Fast profile removed — stored/exported/resumed Fast preferences now fall back to Balance
- Tier cycling in `/model` works correctly
- One-click/shortcut switching from the suggestion

For beginners: this is the "just work" model selection you expected from day one. You code, Copilot picks the tier, you override if you disagree. Done.

---

## 2. Quick Feedback Prompts — Your Manual Overrides Teach the System

Switch away from the auto-suggested tier? **A quick feedback prompt appears instantly**. Tap why (too slow, wrong capability, cost, other) and Copilot learns.

This isn't telemetry theater — it's a **preference loop that tightens every session**. The more you use it, the less you need to override.

---

## 3. Direct Plugin Installs Can Now Be Enabled/Disabled

`copilot plugin enable <name>` / `copilot plugin disable <name>` now work on directly installed plugins (not just marketplace). A disabled plugin **stops loading entirely** — no more editing config files to test without it.

---

## 4. Fixes You'll Feel Daily

| Fix | Why It Matters |
|-----|----------------|
| **Sandboxed `gh`/`git` commands run correctly** (`timeout 60 gh ...`) | Wrapped commands in sandboxed sessions no longer break |
| **ACP sessions stay connected** when clients pause reading large responses | Long outputs no longer drop your session |
| **Gemini models no longer 400 on MCP tools** with `anyOf` schemas (nullable discriminated unions) | MCP servers with complex tool schemas now work with Gemini |
| **GitHub MCP tools connect on first CLI startup** after sign-in | No more "sign in, restart, try again" dance |

---

## 5. What This Means for Your Terminal Workflow

**If you're new to Copilot CLI:** 1.0.89 is the version where model switching stops being a chore. Install, code, the tier picker guides you. When you override, it learns. The MCP fixes mean your tool servers just connect.

**If you're on 1.0.80 (AHP release):** The shared-session architecture is stable. 1.0.89 polishes the daily interactions on top of it — model picker, plugins, MCP reliability.

**If you're comparing terminal agents:** Copilot CLI's differentiator remains **GitHub-native PR/issue integration** + **ACP shared sessions**. This release makes the model experience competitive with Claude Code's `/model` and Zed's picker.
