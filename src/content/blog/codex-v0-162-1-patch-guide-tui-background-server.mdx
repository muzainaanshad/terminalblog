**Codex v0.162.1 dropped October 9** — 13 hours ago as of this writing. It's a **two-fix patch release** on the stable channel. No new features. Just the crashes that were biting people daily.

If you've had the TUI crash when an async question wraps multiple lines, or seen startup fail because your background server's feature flags drifted from CLI defaults — this is your update.

---

## The Two Fixes

### 1. TUI Crash on Multi-Line Async Questions (Fixed)

**The bug:** When an asynchronous question from the agent contained multiple lines (like a long prompt with embedded hyperlinks), the TUI would crash trying to render it. Line breaks and complete hyperlink destinations were lost — then the whole UI went down.

**The fix:** PR [#51866](https://github.com/openai/codex/pull/51866) — multi-line async questions now preserve line breaks and full hyperlink destinations. The TUI stays up.

**Who this hits:** Anyone using the TUI (`codex` in terminal) with agents that ask multi-step questions or present options with links. Common in code review flows and multi-file refactors.

---

### 2. Background Server Feature Drift (Fixed)

**The bug:** You start a background server (`codex app-server start`). Later, you run `codex` CLI with different feature flags. The compatibility check would fail on **explicit command-line feature overrides** — even when they were intentional. Startup would refuse to connect.

**The fix:** PR [#52648](https://github.com/openai/codex/pull/52648) — compatibility checks now apply **only to explicit command-line feature overrides**. Implicit/default settings no longer block connection.

**Who this hits:** Teams sharing a background server, CI pipelines, anyone running `codex` with `--feature` flags that differ from the server's config.
