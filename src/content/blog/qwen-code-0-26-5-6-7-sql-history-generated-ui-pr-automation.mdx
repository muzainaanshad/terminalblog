If you're on 0.26.x — this is the update that makes the Web Shell feel like a real platform.

## The Features You'll Actually Notice

### 1. Generated UI — Now ON by Default, With Context Cards That Stick

**What it is:** Agents can now render **interactive UI cards** (charts, forms, tables, dashboards) directly in the chat. You continue the conversation *with the card's values attached as removable context* above the composer.

**Why it matters:** Before: agent shows a chart → you ask a follow-up → context lost. Now: the chart's data **stays attached**. You say "filter this by region" and the agent sees the exact values.

```bash
# In Web Shell or Desktop:
# Agent renders a Generated UI card (e.g., a sales dashboard)
# Card shows: "Revenue by Region" with interactive filters
# You click "APAC" → value attaches above composer as context chip
# You type: "show me quarterly trend for this region"
# Agent has the filtered data — no re-explanation needed
```

**For beginners:** This is the moment the chat becomes a **workspace**. The agent's output isn't read-only — it's a living artifact you build on.

---

### 2. SQL History Pagination — Finally Searchable

**What it is:** Managed local H2 and Hosted MySQL now support **bounded, paged SQL history queries** (#15839, #15865). You get:
- Recent messages (latest 100 live, then paged upward)
- Journal transactions
- Exact operation or command lookups

**Why it matters:** Your agent session history was a black box. Now you can **query it like a database** — "show me the last 50 tool calls," "find the transaction where I deleted the users table," "page back to yesterday's debugging session."

---

### 3. Web Shell Keyboard Shortcuts — Split View, Session Overview

**What it is:** Web Shell now has **keyboard shortcuts** for Session Overview and Split View (#14179). Plus "Add to Split View" in sidebar session menus (#15956).

**Why it matters:** You're comparing two agent sessions side by side. Old way: open new tab → navigate → resize. New way: `Ctrl+Shift+S` (or menu) → instant split. Session Overview gives you a bird's-eye view of all running work.

---

### 4. PR Automation That Knows When to Stop

**What it is:** `/autofix-pr` now has a **retry budget** (#15985). After **three fix pushes** on a failing check, it hands off to a human and shows the blockage in `/autofix-pr status`. Also: posts a PR comment when blocked (#15978) stating what was attempted, what blocks it, and what human action is needed.

**Why it matters:** No more infinite retry loops burning API credits. The agent tries, learns, and **escalates cleanly**.

```bash
# Workflow:
/autofix-pr 123
# Round 1: pushes fix → CI still fails
# Round 2: pushes fix → CI still fails  
# Round 3: pushes fix → CI still fails
# → Agent stops, posts comment: "Blocked: X needs human review"
# → Shows in /autofix-pr status with exact blockage
```

---

### 5. One-Command Helm Deployment for Managed Agent

**What it is:** Experimental Helm chart deploys **Managed Agent + Hosted Harness + MySQL + local execution + authenticated gateway** in one command (#15492).

**Why it matters:** Teams wanting self-hosted Qwen Code infrastructure had to wire 5+ components. Now: `helm install qwen-code ./chart` — done.

---

### 6. Context Memory Files Clickable in Usage Panel

**What it is:** Files in the Context Usage panel (like `AGENTS.md`) are now **clickable → open read-only preview** (#15932).

**Why it matters:** You see "AGENTS.md (2.3MB)" in the panel. Click → read it. No more guessing what's eating your context window.

---

### 7. Background Agent Count in Status Bar

**What it is:** Web Shell and Desktop now show **active background agent counts** in the status-bar task pill (#14002).

**Why it matters:** You fire off a background task. The pill shows "2 agents running." You know at a glance — no need to hunt for a process list.

---

### 8. Remote Access Toggle Without Restart

**What it is:** Enable remote access from Settings → takes effect **without restarting** the server (#15887).

**Why it matters:** You're in a session, realize you need to share it. Toggle → share URL works. No "wait for restart" friction.

---

### 9. Anthropic Transport Timeout Honored

**What it is:** Core now respects **Anthropic's configured transport timeout** instead of using its own (#16193).

**Why it matters:** Long-running Claude requests (large file reads, complex reasoning) no longer get cut off by a mismatch between Qwen Code's timeout and Anthropic's.

---

### 10. Explicit Trust for Project Frontmatter & LSP

**What it is:** Project frontmatter and LSP configurations now require **explicit trust** (#16182). No more silent execution of untrusted config.

**Why it matters:** Security hardening. You clone a repo → Qwen Code asks before running its `.qwen/` config or LSP settings. Supply chain attack surface reduced.
