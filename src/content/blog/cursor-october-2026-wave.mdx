## The Headline Features (And Why They're Not Just Marketing)

### 1. Projects — Multi-Agent Orchestration That Actually Works
**September 10**: Projects lets you take on larger bodies of work — a feature, a migration, a full app — and maintains context over months of work. The coordinator agent doesn't write code itself; it plans the work, delegates to subagents that implement it, and brings finished work back to you.

```bash
# Access from left-hand nav in Cursor
# Create a project → describe the goal → coordinator spins up agents
```

**What this means**: You don't onboard an agent every time you start a task. Each Project maintains shared context files that sync across every cloud and local machine its agents use. If one agent figures out how to test a service, every future agent uses those instructions.

**For beginners**: This is **multi-agent orchestration without writing YAML**. You describe the outcome; Cursor handles the agent choreography.

### 2. Cloud Agents with Canvases — Interactive Artifacts, Not Just Text
**October 16**: Cloud agents can now build **interactive canvases** as part of their work. Think: live dashboards, architecture diagrams, test reports, API explorers — not just code diffs.

**Environments API (beta)**: Programmatically create and manage the cloud environments your agents run in.

**Larger, faster environments**: Cloud agent environments now support up to **300 repositories** and load **5x faster**.

### 3. Origin App Marketplace — 20+ Integrations, Open to Public Submissions
**October 13**: Origin (Cursor's code hosting layer) now integrates with over 20 apps across deployments, CI, code review, security, monitoring, and project management.

| Category | Partners |
|----------|----------|
| Deployments | Cloudflare, Netlify, Render, Spacelift, Vercel |
| CI | Buildkite, CircleCI, CloudBees, Depot, EngFlow, Namespace, RWX |
| Code Review | CodeRabbit, Greptile, Tenki |
| Security | Artemis, Semgrep, Socket Security, Upwind |
| Monitoring | Sentry |
| Project Management | Linear |

**The kicker**: The marketplace is open to public submissions. Any team building developer tools can publish an app for Origin.

### 4. Remote Control from iOS — Your Local Agents, In Your Pocket
**October 6**: You can now see and reply to local agents running on your computer from the Cursor iOS app.

- Remote Control is on by default (except Enterprise orgs)
- Agents keep running on your computer — the app just connects to it
- "Keep this computer awake" setting prevents sleep while you're away
- **No cloud agents required** — works with your local setup

### 5. Rollouts & Security Review — Two Bots for the Last Mile of Shipping
**September 23**: Two new bots available on Teams and Enterprise plans.

**Rollouts** (deployment monitoring):
- Attaches a monitor to every PR, watches the change as it deploys
- Reports change health per environment: verified healthy, regression detected, inconclusive
- Writes a monitoring plan as a PR comment (risks, intended effect, signals, instrumentation gaps)
- Can open revert PRs or hand findings to a cloud agent for a fix
- Integrates with Origin/GitHub, your CD system, Datadog and other telemetry

**Security Review** (exploitable bug detection):
- Reads every PR in context of the codebase
- Posts one review comment reporting exploitable bugs (SQL/command/template injection, auth bypasses, secrets, SSRF, unsafe deserialization, vulnerable dependencies)
- Each finding carries severity, attack path, and proposed fix
- Team rules let you enforce codebase-specific policies (e.g., "external calls must go through this client")

## What This Means for a Beginner

You don't need all five updates. You need to understand **three shifts**:

| Old Cursor | New Cursor |
|------------|------------|
| Single-file AI edits | **Multi-agent Projects with shared context** |
| Local editor only | **Cloud agents + iOS remote control + local agents** |
| Just code completion | **Canvases, deployment monitoring, security review** |

**If you're new to AI coding**: Start with **Projects**. Create one for a real task you're avoiding (migration, refactor, new feature). Let the coordinator agent break it down. You'll see the shared context accumulate — that's the compounding value.

**If you're evaluating for a team**: The **Origin Marketplace + Rollouts + Security Review** combo means you can enforce standards, monitor deployments, and catch security issues automatically — all inside Cursor. That's CI/CD/security tooling you don't have to stitch together.

## What's Still Missing (Honest Assessment)

- **Windows runner parity for Remote Control**: iOS app works, but the "keep computer awake" logic is macOS-first
- **Local-first air-gapped Projects**: Projects run on cloud compute; no fully offline mode
- **Marketplace discovery**: 20+ apps is a start, but no central registry with reviews/ratings yet
- **Rollouts/Security Review on Pro plan**: Currently Teams/Enterprise only
- **Canvas export/embedding**: Canvases are shareable via link but not embeddable in Notion/Confluence/etc.

## FAQ

**What are Cursor Projects and how do they differ from regular chat?**
Projects maintain shared context across months of work. A coordinator agent plans and delegates to subagents. Regular chat is single-threaded; Projects are multi-agent with persistent memory.

**How does Remote Control work?**
Install Cursor iOS app, sign in, pair with desktop (approve in desktop app). Your local agents appear in the app. Your computer must stay on and online.

**What does Security Review actually catch?**
Injection (SQL/command/template), auth bypasses, secrets in source, SSRF, unsafe deserialization, vulnerable dependencies. It traces user input through the codebase.

**Can I use Rollouts without Origin?**
Yes — Rollouts connects to GitHub for source control, your CD system for deploy events, and Datadog/telemetry for signals. Origin is optional.

**Is the Origin Marketplace only for Enterprise?**
Apps are available to all Origin users. Publishing requires review. Some apps may have plan restrictions.

**Do I need cloud agents for any of this?**
Projects and Cloud Agents use cloud compute. Remote Control, Rollouts, Security Review, and Origin Marketplace work with your local setup.
