**Cursor November 5** dropped **Build Live Apps** — your cloud agent can now build a full web app, spin up a Postgres database, configure authentication, deploy it, and hand you a live URL. All from one chat thread.

---

## The One-Line Summary

**Your Cursor cloud agent just became a full-stack developer. Describe an app → it scaffolds, databases, auths, deploys → you get a live link. Zero infra work.**

---

## What "Build Live Apps" Actually Means

You kick off a **cloud agent** and say:

> *"Build me a dashboard for the sales team showing pipeline by region, with filters for quarter and rep. Use our Postgres data warehouse."*

The agent:
1. **Scaffolds the web app** (React/Next.js, TypeScript, Tailwind)
2. **Spins up a Postgres database** if needed
3. **Configures authentication** behind Cursor SSO (your team signs in with their Cursor account)
4. **Provisions hosting** on Cursor's infrastructure
5. **Asks for secrets** only if the app needs to connect to your systems (data warehouse API keys, etc.)
6. **You pick a domain** → Cursor gives you a live `your-app.cursor.app` link
7. **Share with specific people, groups, or your whole team** — all behind Cursor sign-in

## How It Works (Step by Step)

```bash
# 1. Open Cursor → start a Cloud Agent (paid plan required)
# 2. In the agent chat:
"Build a tool for the support team to look up customer tickets by email,
show recent orders, and let them issue refunds with one click.
Connect to our Shopify API (I'll give you the key)."

# 3. Agent works:
# - Scaffolds Next.js app with TypeScript + Tailwind
# - Creates Postgres tables for ticket cache
# - Sets up Cursor SSO auth (support@company.com signs in)
# - Asks for Shopify API key → stores as secret
# - Builds UI: search bar, customer card, refund button
# - Runs tests, fixes lint errors

# 4. You review → click "Publish" → pick subdomain:
# support-tools.yourcompany.cursor.app

# 5. Share link with support team → they sign in with Cursor → done
```

## Controls & Guardrails (It's Not Wild West)

| Guardrail | What It Does |
|-----------|--------------|
| **Security scan on publish** | Deterministic + agentic checks for secrets, exposed creds, common vulns |
| **Agent tells you what to fix** | If scan fails, agent explains the issue and suggests the fix |
| **Explicit publish required** | Nothing goes live until *you* click Publish |
| **Team admin oversight** | Admins see every app, every secret, can add custom rules, can unpublish |
| **Per-app permissions** | Share with specific people, groups, or whole team (individual plans: public too) |
| **API keys for scripts** | Provision a Cursor API key if you want Grok Bot or CI to call your app |
