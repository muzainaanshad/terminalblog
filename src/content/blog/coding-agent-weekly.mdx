## The Pattern: Agents Are Becoming Platforms

Qwen Code adding Goals/Pause/Resume, Hermes adding Pantheon, Cursor adding Projects/Rollouts — these aren't feature updates. They're platform moves. The winners won't be the ones with the best model; they'll be the ones with the best *orchestration layer*. Model access is commoditizing (OpenRouter, aiFiesta, local models). The moat is the workflow: planning, delegation, review, rollback, audit.

## Security Posture (Post-Aug-31)

Three major agents, three critical findings in one week. Cursor's worktree RCE, Claude Code's NTLM leak, Hermes' 6 HIGH audit findings — **agent security is the bottleneck, not model capability**. Every new integration surface (Git, filesystem, network, subprocess, inter-agent) is an attack vector.

|-------|---------------------------|-------------------|-----------------|
| **Cursor** | Worktree CLI | Config injection → RCE | Hours (public PoC) |

| **Hermes** | Pantheon message bus | Inter-agent spoofing | Weeks (requires access) |

## Operator Hardening Checklist

- [ ] **Pin agent versions** — don't auto-update; test in staging first
- [ ] **Isolate worktrees** — run agent worktrees in containers/VMs, not host FS
- [ ] **Network egress controls** — block agent processes from arbitrary outbound connections
- [ ] **Credential hygiene** — rotate tokens used by agents weekly; use short-lived creds
- [ ] **Audit logging** — capture all agent CLI invocations with args, working dir, exit code
- [ ] **Incident runbook** — define "agent went rogue" response: kill, isolate, audit, rotate
- [ ] **Service accounts for agents** — never share your credentials; least privilege, separate audit trails
