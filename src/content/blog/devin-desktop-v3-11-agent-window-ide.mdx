**Devin Desktop v3.11.212 dropped October 23** — and it's not an update. It's a **full replacement of the editor experience**.

The new **Agent Window** now matches `app.devin.ai` feature-for-feature: sessions sidebar, session view, Automations, Review, Wiki, settings, Command Palette (⌘K), and theming. You can drag sessions to split view (up to 8 side-by-side), group by workspace, spawn child sessions, and every session gets a file tree, changes tab, and **a real terminal**.

If you've been waiting for the agent-native editor to feel like a *real IDE* — this is it.

---

## The Headline: Agent Window = Web App, But Local

**What it is:** The entire Devin Desktop interface has been rewritten to mirror the cloud web app. Sessions sidebar, session view, Automations, Review, Wiki, settings, Command Palette — all identical, all following your Desktop theme.

**Why it matters:** No more context-switching penalty between local and cloud. Muscle memory transfers. Workflows transfer. The only difference is *where the compute runs*.

---

## Sessions: Drag, Split, Group, Spawn

| Feature | What It Does |
|---------|--------------|
| **Drag to split** | Drag a session from sidebar onto an open session → side-by-side view (up to 8 panes) |
| **Group by workspace** | Sessions auto-group by folder; "+" on each group starts a new session in that folder |
| **Child sessions** | Right-click any session → "Start child session" — inherits context, runs in parallel |
| **Spaces support** | Sessions grouped into Spaces appear under a parent session in the sidebar |

**For daily work:** You're debugging a frontend bug in one pane, watching the backend logs in another, and the test runner in a third. All same window. All same agent context.

---

## Every Session Gets: Files, Changes, Terminal

This is the big one. **Every session tab now has:**

- **Files view** — Local session's working directory OR cloud session's machine as a file tree next to the editor
- **Changes tab** — Per-file diffs with "Since last seen" scope (works for local sessions now too)
- **Terminal** — In the add-tab menu: opens a terminal on the session's machine (cloud) or local shell in the session's folder
- **Quick open** — `Cmd/Ctrl+O` opens local files in the Agent Window
- **Search** — `Cmd/Ctrl+Shift+F` searches the text of the session's files
- **Code actions** — Files opened in the Agent Window's editor support code actions and rename
- **Quote to chat** — Select code → `Cmd/Ctrl+L` → quoted into the composer

**Translation:** You no longer need a separate VS Code window to see your files, diffs, or run commands. It's all inside the agent session.

## Cloud Sessions: Remote IDE, Previews, Dev Containers

| Feature | What It Does |
|---------|--------------|
| **IDE button** | Top-right → opens Remote SSH window on the session's machine |
| **App previews** | Preview tab with URL bar, port switching, device sizes, element picker |
| **Unsaved edits sync** | Cloud sessions connected to your machine read unsaved edits from open editors |
| **Code scan badge** | Scan sessions show a badge and open Findings view beside the chat |

### Dev Containers: Finally First-Class

Devin Desktop v3.11 **fully supports `devcontainer.json`**:

- `onCreateCommand`, `updateContentCommand`, `postCreateCommand`, `postStartCommand`, `postAttachCommand` — all run
- Features and image metadata supported
- Dotfiles installed from `remote.devinDevContainers.dotfiles.*`
- `remoteEnv`, `customizations.vscode.settings`, extensions, `forwardPorts`, `shutdownAction` — all apply
- **New commands:** "Dev Containers: Rebuild Container" and "Rebuild Container Without Cache"
- **Auto-prompt:** Rebuild when `devcontainer.json`, Dockerfile, or Compose file changes
- **Reopen in Container** prompt when opening a folder with Dev Container config
- **Slim images work** — no `curl`, `wget`, `procps` required
- **Trust model:** Dev Container window is trusted when its host folder is trusted

**For enterprise teams:** This is the "we can standardize on Devin Desktop" release. Dev Containers + agent = consistent, reproducible, agent-ready environments.

- Settings UI identical to Devin Cloud
- Preferences → Appearance: pick interface font, code font, sizes
- Plugins declare `platforms: [cloud]` or `platforms: [local]` — Desktop only activates local-applicable plugins
- Enterprise admins: Extension marketplace URL in team settings (forces installs from that marketplace only)

## Behavior Changes (Read These)

| Change | Impact |
|--------|--------|
| **Enter while working** | Steers the running turn; `Cmd/Ctrl+Enter` queues until turn ends |
| **MCP @-mention** | Configured MCP servers can be @-mentioned in chat |
| **Command palette searches content** | Searches content of Local sessions, not just titles |
| **Windows: WSL distros as remote hosts** | WSL distros appear alongside SSH hosts in Cloud/Local picker |
| **Auto-open edited files OFF by default** | Turn back on in Settings → Editor → UI if you want it |
| **Agent diff zones OFF by default** | Agent edits apply directly; re-enable in Settings → Editor → UI |
| **Agent edits save without format-on-save** | Enable "Run save actions on agent edits" to restore old behavior |
| **Worktrees not auto-deleted after 19** | No more surprise cleanup |
