Zed **v1.25.2 stable dropped October 20, 2026** — and it's not just a pre-release anymore. The headlines: **33% smaller macOS binaries, 28% smaller Windows, 7% smaller Linux**, **a critical fix for secrets leaking to local process lists**, **GPT-6 Astra, Claude Fable 5.1, and Claude Opus 5.5 on Amazon Bedrock**, plus the quality-of-life features from v1.25.0-pre: **automatic unfolding when jumping to folded code**, **double-click inlay hints to apply edits**, **context compaction for external agents**, and **Gemini 4 Argon**.

**v1.25.3 dropped October 23, 2026** — a security patch updating dependencies to address recent software ecosystem vulnerabilities ([#66023](https://github.com/zed-industries/zed/pull/66023), [#65963](https://github.com/zed-industries/zed/pull/65963)).

If you've been on v1.24 — this is the stable release you've been waiting for.

---

## 1. The Security Fix You Need to Know

**Fixed:** Environment variables, **including secrets**, passed to external agents and MCP servers in remote projects were visible in the **local machine's process list** ([#65174](https://github.com/zed-industries/zed/pull/65174)).

This is a **CVE-grade issue** if you use remote development with external agents or MCP servers. Your API keys, database passwords, and tokens could appear in `ps` output on the host machine. Update immediately if you use remote projects with agents.

## 4. Automatic Unfolding — Never Lose Your Place Again

**New in v1.25.0-pre:** When you jump to a location (Go to Definition, Find References, diagnostics, search results), Zed now **automatically unfolds folded code** at the target ([#65217](https://github.com/zed-industries/zed/pull/65217)).

Before: you `Cmd+Click` a function → land inside a folded block → see nothing → manually unfold → lose your train of thought. Now: the editor unfolds just enough to show you the target, then keeps surrounding context folded.

**For beginners:** This is the "I clicked go-to-definition and saw a blank screen" problem, solved. The editor assumes you want to *see* what you jumped to.

---

## 5. Double-Click Inlay Hints — Apply Edits Without Typing

**New in v1.25.0-pre:** Inlay hints (type hints, parameter names, etc.) can now be **applied with a double-click** ([#64789](https://github.com/zed-industries/zed/pull/64789)).

Hover an inlay hint → see the edit preview → double-click → the edit applies in-place. No more copying the hint, finding the line, typing the change.

**Why it matters:** Inlay hints are already context-aware suggestions. Making them one-click applicable turns "that's a good suggestion" into "done" without breaking flow.

---

## 6. Context Compaction for External Agents — Your Token Budget Survives Longer

**New in v1.25.0-pre:** When external agents (ACP clients, custom integrations) send context to Zed, the editor now **compacts it intelligently** — preserving the most relevant parts while staying within token limits ([#65414](https://github.com/zed-industries/zed/pull/65414)).

**Why it matters:** If you're building on Zed's ACP protocol or running agents that feed context back to the editor, your sessions no longer hit hard token walls. The compaction prioritizes recent + relevant context automatically.

**For beginners:** You don't manage this directly. But if you use tools that integrate with Zed via ACP, your agent conversations stay coherent longer.
