Zed **v1.25.0-pre dropped October 14**, and it's the release that finally fixes the "where am I?" moments. The headlines: **automatic unfolding when jumping to folded code**, **double-click inlay hints to apply edits**, **context compaction for external agents**, and **Gemini 4 Argon + Amazon Bedrock models** join the BYOK party.

If you've been on v1.24 pre-releases — this is the quality-of-life jump that makes daily navigation feel telepathic.

---

## 1. Automatic Unfolding — Never Lose Your Place Again

**New:** When you jump to a location (Go to Definition, Find References, diagnostics, search results), Zed now **automatically unfolds folded code** at the target.

Before: you `Cmd+Click` a function → land inside a folded block → see nothing → manually unfold → lose your train of thought. Now: the editor unfolds just enough to show you the target, then keeps surrounding context folded.

**For beginners:** This is the "I clicked go-to-definition and saw a blank screen" problem, solved. The editor assumes you want to *see* what you jumped to.

---

## 2. Double-Click Inlay Hints — Apply Edits Without Typing

**New:** Inlay hints (type hints, parameter names, etc.) can now be **applied with a double-click**.

Hover an inlay hint → see the edit preview → double-click → the edit applies in-place. No more copying the hint, finding the line, typing the change.

**Why it matters:** Inlay hints are already context-aware suggestions. Making them one-click applicable turns "that's a good suggestion" into "done" without breaking flow.

---

## 3. Context Compaction for External Agents — Your Token Budget Survives Longer

**New:** When external agents (ACP clients, custom integrations) send context to Zed, the editor now **compacts it intelligently** — preserving the most relevant parts while staying within token limits.

**Why it matters:** If you're building on Zed's ACP protocol or running agents that feed context back to the editor, your sessions no longer hit hard token walls. The compaction prioritizes recent + relevant context automatically.

**For beginners:** You don't manage this directly. But if you use tools that integrate with Zed via ACP, your agent conversations stay coherent longer.

---

## 4. New Models: Gemini 4 Argon + Amazon Bedrock Expansion

### Gemini 4 Argon (`gemini-4-argon`)
Google's latest model — available via Google AI provider. Optimized for coding with improved reasoning and tool use.

### Amazon Bedrock — More Models, Better Config
- Additional Bedrock model IDs supported
- Configurable tool use, images, and reasoning per model (builds on v1.24's BYOK work)
- GovCloud regions via Bedrock Mantle

**For beginners:** More model choice without leaving the editor. If you have AWS/GCP access, you get frontier models at your provider's pricing.
