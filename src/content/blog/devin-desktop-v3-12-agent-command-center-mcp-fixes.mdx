**Devin Desktop v3.12.17 dropped November 6** — just a week after the massive v3.11 Agent Window overhaul. This isn't a feature splash. It's the **polish wave that makes v3.11 feel finished**. MCP controls in the session header. Local agent rejections that give you a second try. Chromium security fixes. Markdown that actually renders in the Command Center.

If you updated to v3.11 and hit rough edges — this is the release that sands them down.

---

## The Feature You'll Use Daily: MCP Controls in the Session Header

### The Problem: MCP Management Was Buried

You're in a session. Need to toggle an MCP server. Re-authenticate one. Check which servers are active.

**Before v3.12:** Settings → MCP → find the server → toggle → back to session. Context lost. Flow broken.

### The Fix: Three Dots, One Click

**v3.12 adds an MCP menu to the session header** (the "…" menu in each session tab):

- **See all MCP servers for that session** — no guessing
- **Turn one on/off** — instant, no settings detour
- **Re-authenticate** — expired tokens fixed in place

```markdown
# Real workflow
Session header → "…" → MCP Servers → [github] → Toggle off
Session header → "…" → MCP Servers → [slack] → Re-authenticate
# Back to coding in 2 seconds
```

**Why it matters:** MCP servers are per-session infrastructure. Managing them *in the session* — not in a global settings panel — is how it should have worked from day one.

---

## The Feature That Saves Your Prompt: Local Agent Rejection Recovery

### The Problem: "Rejected" Meant "Retype Everything"

Local agent rejects your first prompt (permission denied, tool unavailable, sandbox violation). The prompt vanishes. You retype from memory. Frustration compounds.

### The Fix: Prompt Returns to Composer with the Reason

**v3.12: If a local agent rejects the first prompt, Desktop puts the text back in the composer and shows *why* it was rejected.**

```markdown
You: "Refactor the auth module to use OAuth 2.1"
Agent: [Rejected] "Permission denied: cannot write to src/auth/legacy/"
Composer: "Refactor the auth module to use OAuth 2.1"  ← YOUR PROMPT IS BACK
          ↑ "Permission denied: cannot write to src/auth/legacy/"
You: [Edit prompt to target allowed paths] → Resend
```

**You correct and resend without retyping.** The rejection becomes a hint, not a wall.

## The Security Baseline: VS Code 1.141 + Electron 43.8 + Chromium Fixes

**v3.12.17 updates the editor foundation:**

- **VS Code 1.141.2** — upstream editor fixes and improvements
- **Electron 43.8.3** — **Chromium security patches** (CVE fixes from October/November)
- **Node.js** updated accordingly

**Why it matters for beginners:** You're running an agent that executes code, reads files, and talks to the network. The Electron/Chromium layer is your sandbox boundary. Keeping it current isn't optional — it's hygiene. v3.12 does it automatically.

---

## The IDE Mode Polish: Settings Opens in an Editor Tab

### The Problem: Settings Ejected You from Your Workflow

In IDE mode, opening settings **switched modes** — you left your session, landed in a separate settings view, lost your place.

### The Fix: Settings Opens as an Editor Tab

**v3.12: In IDE mode, opening Devin settings opens an editor tab instead of switching modes.**

```markdown
# Before
Cmd+, → Mode switch → Settings view → Lose session context → Cmd+W to return

# After
Cmd+, → New tab in editor → Settings → Edit → Close tab → Back to session
```

**Muscle memory preserved.** Settings is just another file now.

---

## The Visual Polish: Chat Diffs + Code Blocks Use Your Theme

### Chat Diffs Match Your Editor Colors

**Before:** Hardcoded diff colors (green/red) that clashed with your theme.

**Now:** Chat diffs use **your editor theme's diff colors**. Dracula diffs look like Dracula. GitHub Dark diffs look like GitHub Dark.

### Shell Commands + Code Blocks Get Syntax Highlighting

**Before:** Plain text in transcript.

**Now:** Shell commands and code blocks use **your editor's syntax highlighting**.

```bash
# Before: Monochrome wall of text
npm run build
# > webpack 5.94.0 compiled with 3 errors

# After: Highlighted like your terminal
npm run build
# > webpack 5.94.0 compiled with 3 errors
```

**Small change. Big readability win** when you're scanning a 200-turn transcript.

## The Fixes You'll Actually Notice (Scannable)

### Local Sessions
- **Reopened Local session keeps working directory** — no more "wait, where was I?"
- **Closing tab no longer removes session from Past Conversations** — history preserved
- **Click filename on Local plan approval card** → read full plan before approving
- **Windows: local edits save even with different filename capitalization** — `Auth.ts` vs `auth.ts` no longer loses writes

### ACP / Third-Party Agents
- **Permission requests from third-party ACP agents no longer crash conversation view** — was a hard blocker for Claude Agent, OpenCode, etc.
- **Sessions with pending ACP requests reopen correctly** — no more stuck states

### Remote / SSH
- **Remote SSH connects to hosts defined ONLY in custom `remote.devinSSH.configFile`** — respects your SSH config isolation

### Agent Command Center
- **Markdown previews now supported** — Wiki, Review, Automations render properly instead of raw markdown
