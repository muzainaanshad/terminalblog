Zed **v1.27.0-pre dropped October 28** — the first pre-release on the 1.27 line, promoting v1.26.2's stability with new capabilities. The highlights: **Go 1.27 generic method syntax highlighting**, **AI commit messages that learn your repo's style**, **30% less agent panel memory**, **Solargraph crash fixes**, plus **macOS Catalina/Big Sur dropped** and **agent checkpoints removed**.

If you write Go, want commits that sound like you, or hit agent memory issues — this pre-release is worth the upgrade.

---

## The Headline Features

### 1. Go 1.27 Generic Methods — Syntax Highlighting Day One

**New:** Zed now highlights **Go 1.27 generic methods** ([#64562](https://github.com/zed-industries/zed/pull/64562)).

```go
// Go 1.27 — generic methods on non-generic types
func (s *Server) Handle[T any](ctx context.Context, req *Request[T]) (*Response[T], error) {
    return s.process(ctx, req)
}
```

**Why it matters:** Go 1.27 (released August 2026) added generic methods. Zed v1.27.0-pre supports them on day one of the pre-release cycle. No waiting for stable.

---

### 2. AI Commit Messages That Sound Like *You*

**New:** AI commit message generation now uses **your last 3 repository commits as style examples** ([#61528](https://github.com/zed-industries/zed/pull/61528)).

Before: Generic "Fix bug in auth module"

After: Your actual style — "fix(auth): handle nil token in middleware" or "feat: add JWT validation to login flow"

```json
// No config needed — just works
// Zed reads your git history and mimics the pattern
```

**Why it matters:** Commit messages become consistent without templates. The agent learns from *your* history, not a generic dataset.

---

### 3. Agent Panel Memory Usage — 30% Less RAM

**Fixed:** Agent Panel now loads **tool-call diffs and thread Markdown only when first viewed**, not when loading a thread ([#65444](https://github.com/zed-industries/zed/pull/65444), [#65470](https://github.com/zed-industries/zed/pull/65470)).

- **CPU usage and disk reads** during agent work also improved, especially with long thread histories ([#66015](https://github.com/zed-industries/zed/pull/66015))
- Large sessions stay responsive instead of freezing the UI

**Why it matters:** If you run long agent sessions (hours, hundreds of turns), the panel used to balloon to 1-2GB. Now it scales with *what you're looking at*, not *what exists*.

---

### 4. Solargraph Crash Fix — Ruby Devs, This One's For You

**Fixed:** **Solargraph completions no longer crash Zed** in certain cases ([#66157](https://github.com/zed-industries/zed/pull/66157)).

This was a hard crash — editor gone, unsaved work at risk. Now fixed.

---

### 5. OpenCode Compatibility Improvements

**Improved:** OpenCode integration now properly handles:
- **DeepSeek reasoning replay** — reasoning blocks render correctly
- **Google models thinking disable** — `thinking: false` actually works ([#65922](https://github.com/zed-industries/zed/pull/65922))
- **Thinking controls explain when thinking can't be disabled** at selected effort level ([#62480](https://github.com/zed-industries/zed/pull/62480))

If you use OpenCode via Zed's ACP support, these were daily paper cuts. Now fixed.

---

## Breaking Changes (Read Before Upgrading)

### macOS Catalina (10.15) and Big Sur (11) Dropped

**Removed:** Support for macOS Catalina and Big Sur. Zed now requires **macOS 12.0 (Monterey) or later** ([#65994](https://github.com/zed-industries/zed/pull/65994)).

If you're on older macOS — you're stuck on v1.26.x. Plan your upgrade.

---

### Agent Checkpoints Removed

**Removed:** Agent checkpoints and the "Restore Checkpoint" button ([#65989](https://github.com/zed-industries/zed/pull/65989)).

**Why:** Taking a checkpoint before every message made the agent slow or hang in large Git repos.

**What to do instead:** Reject the agent's edits, or use Git (`git checkout`, `git restore`, `git reset`).
