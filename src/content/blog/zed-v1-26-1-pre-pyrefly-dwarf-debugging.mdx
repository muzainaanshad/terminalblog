Zed **v1.26.1-pre dropped October 21, 2026** — the first pre-release on the 1.26 line, hot on the heels of v1.25.2 stable. The highlights: **Pyrefly as optional Python LSP**, **DWARF debugging for WebAssembly**, **expandable variable hovers in the debugger**, **OpenCode reasoning compatibility**, and **Display P3 color space on macOS**.

If you live in Python, debug WASM, or want wider-gamut colors on Mac — this pre-release is for you.

---

## The Headline Features

### 1. Pyrefly — Optional Built-in Python Language Server

**New:** Pyrefly (from Meta/Instagram) is now available as an **optional built-in Python language server** — enable it in `language_servers` setting for Python ([#44262](https://github.com/zed-industries/zed/pull/44262)).

```json
{
  "language_servers": {
    "python": {
      "settings": {
        "language_server": "pyrefly"
      }
    }
  }
}
```

**Why it matters:** Pyrefly is fast, type-aware, and designed for large codebases. Previously you needed external setup. Now it's one setting flip.

**For beginners:** If Pyright/Pylance felt slow or Jedi missed types — try Pyrefly. No install, no config file, just works.

---

### 2. DWARF Debugging for WebAssembly (JS Debugger)

**New:** The JavaScript debugger now supports **DWARF debugging for WebAssembly sources** ([#65371](https://github.com/zed-industries/zed/pull/65371)).

- Step through `.wasm` files with source maps
- Inspect WASM locals and stack frames
- Works with Rust→WASM, C++→WASM, AssemblyScript, any DWARF-emitting toolchain

**Why it matters:** WASM debugging used to mean `console.log` in the browser. Now it's a first-class Zed debugger experience — breakpoints, watches, call stacks, the works.

---

### 3. Expandable, Keyboard-Accessible Variable Tree in Debugger Hovers

**New:** Debugger hovers now show an **expandable, keyboard-accessible variable tree** ([#53198](https://github.com/zed-industries/zed/pull/53198)).

Before: hover a variable → see truncated value → click to expand in side panel.

Now: hover → **nested tree appears inline** → arrow keys navigate → `Enter` expands/collapses → `Escape` dismisses.

**Why it matters:** Deeply nested objects (React props, GraphQL responses, config trees) are now explorable without leaving the editor or reaching for the mouse.

---

### 4. Improved OpenCode Compatibility

**Fixed:** OpenCode integration now properly handles:
- **DeepSeek reasoning replay** — reasoning blocks render correctly
- **Google models thinking disable** — `thinking: false` actually works ([#65922](https://github.com/zed-industries/zed/pull/65922))
- **Thinking controls explain when thinking can't be disabled** at selected effort level ([#62480](https://github.com/zed-industries/zed/pull/62480))

If you use OpenCode via Zed's ACP support, these were daily paper cuts. Now fixed.

---

### 5. Display P3 Color Space on macOS

**New:** `use_display_p3` setting enables **Display P3 wide color gamut** on supported Macs ([#64394](https://github.com/zed-industries/zed/pull/64394)).

```json
{
  "use_display_p3": true
}
```

**Why it matters:** P3 covers ~45% more colors than sRGB. If you do UI work, design tokens, or just want your syntax highlighting to pop on M-series Macs — toggle it on.

## Breaking Change Notice

> **ACP configuration defaults now apply only to new conversations** — existing conversations preserve their session settings when reopened ([#65850](https://github.com/zed-industries/zed/pull/65850)).

If you tweak ACP agent config mid-session, your changes stick to *that* session. New sessions get the updated defaults. Sensible.
