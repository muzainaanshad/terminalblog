Hermes Agent **v0.22.4 dropped October 21** — a patch release that does something rare: **removes a feature that annoyed users.**

The **suggestion pills** that appeared above the desktop composer for "no clear reason" (mostly nudging MCP setup) are **gone**. The helpers that only they used? Also gone.

Plus: plugins with zero dependencies skip the consent prompt, WhatsApp re-pairs safely after logout, and the approval-mode chip finally follows your active profile.

---

## The One Thing You'll Notice: The Pills Are Gone

**Before v0.22.4:** Open Hermes Desktop → see suggestion pills above the composer → "Set up MCP servers!" → "Try skills!" → "Configure providers!" → every. single. time.

**After v0.22.4:** Clean composer. No pills. No nagging.

The pills "appeared for no clear reason" — the release notes' words, not mine. They were a well-intentioned onboarding nudge that became UI clutter. Removing them is the kind of user-respecting decision that builds trust.

**For beginners:** You still discover features — they're in the menu, the docs, the command palette. You just don't get nagged about them every session.

---

## The Other Fixes You'll Actually Feel

### Plugins That Install Nothing: No More Empty Consent Prompts

**Fixed:** A plugin that declares no dependencies, or whose `pyproject.toml` installs nothing, **now enables without an empty consent prompt**.

Before: install a lightweight plugin → "This plugin wants to install 0 packages. Allow?" → click Allow → wonder why you were asked.

After: install a lightweight plugin → it just works. Consent only appears when there's something to consent *to*.

### WhatsApp: Safe Re-Pairing After Logout

**Fixed:** WhatsApp can now be **safely re-paired after logging out**.

Before: logout → try to pair again → unclear state, potential duplicate sessions, manual cleanup needed.

After: logout → pair again → works cleanly. The pairing flow handles re-connection properly.

### Desktop Approval-Mode Chip: Finally Follows Your Profile

**Fixed:** The approval-mode chip in Desktop **now follows the active profile's mode**.

Before: switch profiles → chip shows old profile's mode → confusion about which rules apply.

After: switch profiles → chip updates instantly → you always know what mode you're in.

### Release Builds: Pre-Build Check Gets Time on Slow Storage

**Fixed:** Desktop bundle's pre-build verification **gets enough time to verify archived inputs when storage is slow**.

Before: slow disk / network storage → pre-build check times out → false failure → wasted CI minutes.

After: verification waits appropriately → slow storage no longer blocks releases.

## The Bigger Picture: Hermes Removes Friction, Not Just Adds Features

| Release Wave | Philosophy |
|--------------|------------|
| v0.20.x | "80% faster" — performance foundation |
| v0.21.x | "Pantheon bots" — multi-agent orchestration |
| **v0.22.x** | **"Threshold" — remove what doesn't serve the operator** |

v0.22.4 continues the v0.22 theme: **threshold**. Not "add more" — "remove what's in the way."

- Suggestion pills → removed
- Empty consent prompts → removed  
- WhatsApp re-pair friction → removed
- Profile-mode mismatch → removed
- Slow-storage build failures → removed

This is the Hermes thesis: **the agent that grows with you grows by shedding what you don't need.**
