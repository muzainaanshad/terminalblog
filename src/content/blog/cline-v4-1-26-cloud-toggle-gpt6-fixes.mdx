## 1. Local/Cloud Model Toggle — Finally, Separate Settings

**What it is:** Settings → API Configuration now shows a **Local | Cloud toggle** when cloud sessions are enabled. Cloud tasks get their own model setting, saved separately from your local models.

**Why it matters:** You want Opus 5.5 locally for deep reasoning. You want Gemini 4 Argon in the cloud for speed and cost. Before: one model setting ruled both. Now: **cloud picks the cloud model, local picks the local model**.

```bash
# In Cline settings:
# 1. Enable Cline Cloud
# 2. See "Local | Cloud" toggle appear in API Configuration
# 3. Set cloud model (e.g., Gemini 4 Argon)
# 4. Set local model (e.g., Claude Opus 5.5)
# 5. Click model label in cloud session composer → opens cloud model picker
```

**For beginners:** This is the "it remembers my preference" moment. No more switching models every time you flip between local and cloud.

---

## 2. Cloud Sandbox Progress Cards — You Can See It Starting

**What it is:** Starting or resuming a cloud sandbox now shows a **progress card** with the repo, branch, and steps: *start sandbox → clone repository → start agent*. It collapses once the agent starts.

**Why it matters:** Before: you clicked "run cloud task" and... waited. No feedback. Blank screen. Was it working? Frozen? Now: **you see every step**. If it stalls on "clone repository," you know exactly where.

**For beginners:** This turns "did it work?" into "oh, it's cloning now." Visibility = confidence.

---

## 3. Claude Sonnet 5.5 Is Back as Default (Cline Provider)

**What it is:** With no model chosen, the Cline provider now uses **Claude Sonnet 5.5** again — back at the top of the recommended list.

**Catalog refresh details:**
- **Added providers:** CommandCode, Reflection, Liquid Inference, Munito AI
- **Dropped providers:** CrofAI, iFlow, Llama
- **Free list changes:** Added Reflection Beam, Nemotron 3.5 Lightning, Laguna S 2.1. Dropped Mimo V2.6 Flash, Muse Spark 1.3 Contributor
- **ClinePass defaults:** Kimi K3.1 Pro + MiniMax M3.1 Flash + DeepSeek V4.1 Flash 1017
- **Most other providers:** Defaults shifted to Kimi K3.1 Pro, MiniMax M3.1 Flash, or DeepSeek V4.1 Flash 1017

**What you should do:** **Pin your models** if you want stability. Provider defaults shift with every catalog refresh.

---

## 4. GPT-6 Finally Works on OpenAI, Azure, and SAP AI Core

**The bug:** GPT-6 models (`gpt-6-sol`, `gpt-6.1-sol`) sent `max_tokens` parameter. OpenAI-compatible endpoints (including Azure and SAP AI Core) rejected with "Unsupported parameter: 'max_tokens'".

**The fix:** v4.1.26 sends `max_completion_tokens` for GPT-6 models on OpenAI, Azure OpenAI-compatible, and SAP AI Core endpoints.

**Why it matters:** If you've been blocked from using GPT-6 on your enterprise Azure deployment — **it works now**. No workarounds, no proxy hacks.

---

## 5. Gemini Free Tier: No More 429 Quota Errors Every Turn

**The bug:** Gemini API keys (the `gemini` provider) were sending native Google Search with every request. Free-tier keys hit 429 quota errors on Gemini 3+ *every single turn*. On Gemini 2.x, every Cline tool was dropped.

**The fix:** Gemini provider **no longer sends native Google Search**. Your free-tier key works. Tools work. No more "quota exceeded" spam.

**For beginners:** If you use the free Gemini tier, **this release unbreaks your workflow entirely**.
