## The Headline Features (Ranked by Daily Impact)

### 1. Fable 5.2 Is Now the Default Fable Model — 1M Context, Cheaper

**What it is:** **Claude Fable 5.2 (`claude-fable-5-2`) replaces Fable 5.1 as the default Fable model.** You get:

| Spec | Fable 5.1 | **Fable 5.2 (New Default)** |
|------|-----------|-----------------------------|
| Context Window | 200K | **1,000,000 (1M)** |
| Input Cost | $15/Mtok | **$8/Mtok** |
| Output Cost | $75/Mtok | **$40/Mtok** |
| Cache Read | $1.50/Mtok | **$0.20/Mtok** |

**Why it matters:** Your agent can now hold **5x more context** (entire codebases, massive logs, full conversation histories) at **~half the price**. Cache reads are **7.5x cheaper** — meaning compacted sessions cost pennies.

```bash
# Check your model
/model
# Should show: claude-fable-5-2 (default)

# Want old Fable 5.1 back?
/model claude-fable-5-1
```

**For beginners:** You don't need to do anything. Next session, you're on Fable 5.2. Your agent just got smarter and cheaper automatically.

### 2. `--settings <file>` for `claude remote-control` — Persistent Config Across Sessions

**What it is:** You can now pass a settings file to `claude remote-control` that applies to **every session it starts**. If the file changes, the setting takes effect on the next session (no restart needed unless you're mid-session).

```bash
# Start remote control with custom settings
claude remote-control --settings ./my-team-settings.json
```

**Why it matters:** Teams can version-control their agent configuration. One file controls permissions, model, hooks, MCP servers — every session inherits it. Change the file → new sessions pick it up.

```json
// my-team-settings.json
{
  "permissions": {
    "allow": ["Bash", "Read", "Write", "Edit"],
    "deny": ["Bash:rm -rf *", "Bash:sudo *"]
  },
  "model": "claude-fable-5-2",
  "mcp": {
    "servers": {
      "github": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"] }
    }
  }
}
```

### 3. MCP OAuth Secret Leak Patched — Refresh Tokens No Longer Follow Redirects

**What it was:** When an MCP server redirected an OAuth request, **Claude Code followed the redirect with your refresh token** — sending secrets to an unexpected host.

**What it is now:** **Fixed.** Redirects during OAuth no longer carry credentials. Your tokens stay where they belong.

```bash
# This attack vector is closed
# Before: MCP server redirects → refresh token sent to attacker.com
# After:  MCP server redirects → redirect followed WITHOUT credentials
```

**For beginners:** If you use MCP servers with OAuth (GitHub, Slack, Notion, etc.), this was a real risk. It's now fixed. Update and you're protected.

---

### 4. Network Path Editing Finally Works (WSL, UNC Shares, /net Mounts)

**What was broken:** Editing files on network paths — WSL folders (`/mnt/c/...`), UNC shares (`\\server\share`), `/net` mounts — caused:
- `NotebookEdit` deleting/overwriting the first cell
- `Edit` changing the first match, replacing whole file on empty `old_string`, editing notebooks as text

**What it is now:** **Fixed.** Network paths behave like local paths. Your WSL workflows, mounted network drives, and shared folders just work.

```bash
# These now work correctly:
claude edit /mnt/c/Users/you/project/src/auth.ts
claude edit //server/share/project/src/auth.ts
claude edit /net/server/share/project/src/auth.ts
```

---

### 5. `/config` Now Shows Auto as Default (Not Manual) + Space Saves Don't Ask

**What it was:** `/config` showed "Manual" as the default permission mode even when new sessions started in auto mode. Pressing Space on "Auto (default)" saved "Don't Ask" instead of "Plan."

**What it is now:** **Fixed.** UI matches reality. Space on "Auto (default)" → saves "Plan" (the actual default).

# Verify
