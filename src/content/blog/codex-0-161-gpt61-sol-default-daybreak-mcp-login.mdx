Codex v0.161.0 dropped October 7, 2026. It's a **stable** release — not alpha, not beta — and it ships the kind of quiet upgrades that make you realize the agent has been getting better while you weren't looking.

**GPT-6.1 Sol is now the default.** `/mcp login` works from inside a running session. Daybreak (Cyber access) is opt-in by design. You can pick your microphone and speaker for voice. Windows sandbox finally preserves PowerShell relative paths. SQLite corruption gets detected at startup with automatic backup preservation.

This is the release you put on your daily driver machine.

---

## 1. GPT-6.1 Sol Is the New Default — Everywhere

**Bundled catalog:** GPT-6.1 Sol is now the default model when you open Codex.
**Amazon Bedrock catalog:** Same — GPT-6.1 Sol is default, and Bedrock now supports multi-agent V2 and Ultra reasoning on compatible models. GovCloud regions work too.

For beginners: you don't need to hunt for model IDs anymore. Open Codex, start coding, you're on the latest flagship. If you *were* pinning a model, your pin still wins — defaults only apply when you haven't chosen.

---

## 2. `/mcp login <name>` — Authenticate MCP Servers Without Leaving Your Session

This is the workflow fix MCP users have been waiting for. You're in a Codex session. You need an MCP server that requires auth. Before: leave the terminal, run a separate auth flow, come back. Now:

```bash
/mcp login github
# Opens browser, you approve, done — server is live in this session
```

No restart. No config file editing. The auth persists for that server in that session.

---

## 3. Daybreak (Cyber Access) Is Now Explicitly Opt-In

Daybreak — the Cyber access program routing — **requires explicit enablement**:

```bash
# CLI flag
codex --enable cli_daybreak

# Or in config
features.cli_daybreak=true
```

`daybreak=true` alone is **insufficient**. By default, controls are hidden, `/daybreak` is unavailable, and automatic Cyber routing is omitted — even for saved Daybreak threads. Your saved preferences remain intact; they just don't activate until you opt in.

This is a deliberate design choice: Cyber access changes routing behavior, and the team wants you to choose it consciously.

**Per-turn override:** `codex exec --cyber-access-program` or the TypeScript SDK's `cyberAccessProgram` option lets you pick a program for a single turn without changing your saved setting.

---

## 4. Voice Conversations — Pick Your Actual Microphone and Speaker

Voice (from the v0.162-alpha wave) now lets you **choose specific audio devices**:

- Microphone input device
- Speaker output device  
- Microphone input channels

Preferences save locally. No more "it picked the wrong mic" frustration.

---

## 5. Windows Gets Serious: Elevated Sessions + PowerShell Path Preservation

Two Windows fixes that matter if you're not on macOS/Linux:

| Before v0.161 | After v0.161 |
|---------------|--------------|
| Elevated terminal sessions couldn't use embedded server | **Embedded server works in elevated sessions** |
| Sandboxed PowerShell lost relative paths under protected profiles | **Relative paths preserved beneath protected user profiles** |

If you've run Codex on Windows and hit "access denied" or path weirdness in admin terminals — this release targets those paper cuts directly.

---

## 6. Enter Key Finally Behaves After Paste (Including Vim Insert Mode)

Paste detection used to eat your Enter key. Now: **Enter correctly submits buffered input after paste detection expires** — even in Vim insert mode.

Small fix. Feels huge when you hit it ten times a day.

---

## 7. Thread Resume + SQLite Corruption Protection

- **Thread resume includes the latest committed history** — no more "where did my last turn go?"
- **Startup detects recoverable SQLite corruption earlier** and preserves damaged databases as backups instead of silently failing

Your local history is safer. The database that powers your session memory now has a safety net.

---

## 8. Network Resilience: Retries Honor Server Guidance

Responses retries and WebSocket-to-HTTP fallback now **honor server retry guidance**. During overload, you get fewer premature failures — the client backs off the way the server asks it to.

---

## 9. Auth Documentation Catches Up to Reality

Authentication guidance now **accounts for keyring storage** instead of implying credentials always live in `auth.json`. If you've been confused about where your tokens actually are — the docs now match the implementation.

---

## 10. Chore: Alpha Tags Don't Move Backward Anymore

Publishing an older alpha or hotfix **no longer moves npm alpha tags backward**. Version ordering stays sane.

## How to Update

```bash
# Stable (v0.161.0) — RECOMMENDED for daily use
npm install -g @openai/codex@0.161.0

# Or via the installer (auto-updates to latest stable)
# macOS/Linux
curl -fsSL https://codex.openai.com/install | bash

# Windows (scoop)
scoop update codex

# Verify
codex --version
# Should show 0.161.0
```

**To enable Daybreak (if you want Cyber access):**
```bash
codex --enable cli_daybreak
# Or add to config: features.cli_daybreak=true
```

**To use MCP login in a session:**
```bash
/mcp login <server-name>
```
