## The Headline Fixes (What You'll Actually Feel)

### 1. Linux Sandbox: Background Commands Can't Leak Write Denies Anymore
**Before:** A background command outliving your session could lift sandbox write denies — the agent could write outside the sandbox after you thought it was done.
**Now:** Write denies persist correctly. The sandbox boundary holds even when processes linger.

### 2. macOS Sandbox: Symlink-Aware DenyWrite Glob Patterns
**Before:** `denyWrite` glob patterns didn't apply at a path's *real* location when reached through a symlink.
**Now:** The sandbox resolves symlinks before checking patterns. Your `denyWrite: ["**/.env*"]` actually protects `.env` files even behind symlinks.

### 3. Windows: Hooks No Longer Fail Open Without Git Bash
**Before:** `PreToolUse` and `PermissionRequest` hooks with only quoted strings (like a quoted path) would **let the tool call through** if Git Bash wasn't installed. Silent security bypass.
**Now:** Hooks run correctly regardless of Git Bash presence. The security gate holds.

### 4. Compaction That Doesn't Choke on Dense Content
**Before:** After a "Prompt is too long" error, compaction kept too much dense text (base64, SVG, minified JS), so the *next* request failed again immediately.
**Now:** Compaction recognizes dense content and trims it first. Your session survives the compaction instead of looping into repeated failures.

### 5. VS Code Panel: Self-Healing From Cached Corruption
**Before:** The Claude panel stayed blank after VS Code cached an incomplete copy of its files. You had to reload the window or reinstall.
**Now:** The panel detects the corruption, recovers automatically, or tells you exactly what went wrong and how to fix it.

### 6. Hook `once` Removal Bug Fixed
**Before:** A skill's `once` hook running would *also* remove another skill's identical hook — cross-contamination between skills.
**Now:** Each skill's hooks are isolated. Your custom skills don't step on each other.

### 7. Subagent Runaway Prevention
**Before:** A plugin could keep a headless run going past `--max-turns`, Stop, or ended input by spawning subagents or re-running finished ones.
**Now:** The turn limit is enforced even when plugins try to extend the session via subagents.

Enterprise orgs can now grant **Cloud Sessions** and **Remote Control** access per custom role — not just org-wide on/off.

## The "You Didn't Know You Needed This" Fixes

### File Read Permission Prompts Show Symlink Targets
**Before:** Permission prompt showed the symlink path. You had no idea where it actually led.
**Now:** Prompt shows the resolved destination. You approve the *real* file, not the link.

### Auto Mode Prompt Explains Shell Command Blocking
**Before:** Auto mode blocked reads outside working dirs with a cryptic prompt.
**Now:** Prompt says "blocking these reads will make shell commands ask for permission" — you understand the *consequence* before deciding.

### Non-Interactive Session Memory During Compaction
**Before:** Large transcript files in `-p`/SDK sessions caused memory pressure during compaction.
**Now:** Memory use improved — large transcripts compact without OOM risk.

### Mod Image Rendering in tmux/kitty/Ghostty/iTerm2
**Before:** Mod `Image` with `allow-passthrough` + `focus-events` showed only `alt` text in modern terminals.
**Now:** Fullscreen rendering works. Your agent's diagrams/charts actually display.

### Linux Sandbox Startup Warning Names AppArmor
**Before:** Sandbox failed to start with a generic error on Ubuntu.
**Now:** Warning explicitly names Ubuntu's AppArmor restriction on user namespaces and tells you how to lift it.

### MCP Tool Timeout Error Tells Claude Not to Retry
**Before:** MCP tool timeout in non-interactive session left Claude thinking "maybe retry?"
**Now:** Error explicitly says "no answer came, don't repeat the call" — saves tokens and time.
