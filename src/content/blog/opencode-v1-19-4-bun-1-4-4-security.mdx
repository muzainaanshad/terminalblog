OpenCode **v1.19.4 dropped October 22** — and it's the release you run if you're on the stable v1.x line and want your agent's network stack patched *now*.

No new features. No MCP forms. No background compaction. No voice models.

**Just one thing:** the bundled Bun runtime upgraded from 1.4.x to **1.4.4**, which patches security vulnerabilities across the entire network stack your coding agent uses every single session.

---

## The One-Line Summary

**v1.x stable line gets Bun 1.4.4: Brotli, TLS, HTTP/1.1, HTTP/2, HTTP/3, WebSocket, and fetch vulnerabilities patched. Root certs updated to NSS 3.131.1. Run `opencode update` — zero config changes, zero breaking changes.**

---

## Why This Matters (Even If It's "Just a Runtime Update")

Your coding agent makes **hundreds of network calls per session**:

- Model API endpoints (Anthropic, OpenAI, OpenRouter, Ollama, etc.)
- MCP server definitions and tool calls
- GitHub/GitLab repo fetches
- Package registry requests (npm, PyPI, Cargo, etc.)
- Documentation lookups
- Web searches

Every one of those calls travels through **Bun's network stack**. When that stack has vulnerabilities, your agent's entire communication layer is exposed.

### What Bun 1.4.4 Actually Fixed

| Component | Vulnerabilities Patched |
|-----------|------------------------|
| **Brotli** | Decompression vulnerabilities that could crash or exploit the parser |
| **TLS** | Certificate validation edge cases — your agent might accept a bad cert |
| **HTTP/1.1** | Request smuggling / parsing issues — proxy confusion, header injection |
| **HTTP/2** | Header handling / flow control bugs — DoS or request manipulation |
| **HTTP/3** | QUIC transport vulnerabilities — connection hijacking, data corruption |
| **WebSocket** | Frame parsing / memory safety — remote code execution paths |
| **fetch** | Redirect / origin validation flaws — SSRF, credential leakage |

**Plus:** Root certificates updated to **NSS 3.131.1** — your agent now trusts the *current* CA bundle, not one from months ago. Expired or compromised roots? Gone.

## v1.19.4 vs v2.1.4 — Which One Are You On?

| If You... | You Want |
|-----------|----------|
| **Never migrated to v2** — your config works, you're productive | **v1.19.4** — security only, zero disruption |
| **Want MCP forms, background compaction, voice models** | **v2.1.4** — feature release (also has Bun 1.4.4) |
| **Are on v2.1.3 or earlier** | **v2.1.4** — features + security |
| **Are on v1.19.3 or earlier** | **v1.19.4** — security only |

**Both lines are supported.** The v1.x line isn't abandoned — it's the stable track. v2.x is where new features land first.

## How to Update (30 Seconds)

```bash
# Standard update — works for both v1.x and v2.x
opencode update

# Verify
opencode --version
# v1.x users: should show 1.19.4
# v2.x users: should show 2.1.4 (already has Bun 1.4.4)
```

**That's it.** No config migration. No session loss. No plugin updates. The update swaps the Bun binary, restarts the server, and you're patched.
