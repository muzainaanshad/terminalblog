## 1. Corporate Proxies & Gateways: Beta Headers No Longer Break You

**The problem:** Proxies/gateways that reject one of Claude Code's beta headers with anything other than 400 — or with a second beta header — would kill the request entirely.

**The fix:** Requests now handle non-400 rejections and multi-header rejections gracefully. If you're behind a corporate proxy or using a gateway that strips unknown headers, **this release unbreaks your connection.**

---

## 2. WebFetch: The 100k Character Ceiling Is Gone

**Before:** `WebFetch` silently dropped page text past 100,000 characters. You'd get partial content with zero warning.

**Now:** It tells you how much was unread and takes an `offset` parameter to continue reading.

```bash
# Fetch the next chunk
/fetch https://example.com/huge-page --offset 100000
```

For anyone scraping docs, reading long specifications, or pulling API references — **this removes a silent data-loss bug.**

---

## 3. Terminal Freeze on Massive Outputs: Fixed

**Before:** 10,000+ line outputs (test suites, build logs, `grep -r` on large repos) would freeze the terminal interface completely.

**Now:** The rendering pipeline handles large outputs without locking. You can scroll, search, and interrupt normally.

This was one of the most reported "daily driver" annoyances. **Gone.**

---

## 4. Resumed Subagents Keep Their Brains

**The bug:** When a subagent received a message mid-run (via teammates, background sessions, or Cowork), it lost its earlier thinking and prompt cache. Context gone.

**The fix:** Resumed subagents and teammates now **preserve their thinking and prompt cache** after receiving a message mid-run.

Your background agents maintain continuity. They don't "forget" what they were doing just because you sent them a note.

---

## 5. Hooks: `onFailure: "block"` Now Has Teeth Everywhere

v2.1.295 introduced `onFailure: "block"`. v2.1.296 **enforces it comprehensively**:

- Command hooks that fail to start, time out, or crash → **block the tool call**
- HTTP hooks that return non-2xx, timeout, or network error → **block the tool call**
- No silent pass-through. No "well the hook failed but we ran it anyway."

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "./security-check.sh",
        "onFailure": "block"
      }]
    }]
  }
}
```

If your security check crashes, the Bash call **dies**. This is the permission model you've been asking for.

---

## 6. Mods Get Native Notifications: `$.ui.notify`

Mod authors — you can now raise **system-level notifications** from your mods:

```javascript
// In your mod
$.ui.notify({
  title: "Security Review",
  body: "Found 3 issues in the last PR",
  channel: "security-review"
})
```

Users see a **native OS notification** (macOS/Windows/Linux) with your custom channel name. No more polling the UI for mod status. No more "did it run?" uncertainty.

## 8. Gateway Sign-In: The Deny Button

**Before:** Gateway sign-in approval page had no Deny button. If you walked away, the terminal waited... indefinitely.

**Now:** **Deny button ends the pending sign-in immediately.** The waiting terminal stops within seconds.

Small UX fix. Massive quality-of-life for gateway users.

## 9. Session Attach/Logs by Partial Name

```bash
# Before: needed full session ID
claude attach abc123-def456-ghi789

# Now: partial name works
claude attach morning-debug
claude logs morning-debug
```

If you run multiple sessions, this saves you `claude agents` → copy ID → paste every time.
