**Codex v0.163.0 dropped October 15** — and it's the first stable release that makes the open-source terminal agent feel like a workspace you *live in*, not just a chat loop you visit.

The headline: **a real `/config` UI**, **instant interrupt with follow-up steering**, **parallel read-only tools**, and **Daybreak enabled by default**. If v0.162.0 gave you worktrees (multi-tasking), v0.163.0 gives you *control*.

---

## The Headline Features (Ranked by Daily Impact)

### 1. `/config` — Finally, a Preferences UI That Doesn't Require Memorizing Flags

**What it is:** Type `/config` and you get a searchable interface across all categories. Change supported settings immediately. See which changes need a restart. No more `codex config set <obscure.flag> true` guesswork.

**Why it matters:** Before this, configuring Codex meant reading docs, memorizing dot-notation paths, and restarting to verify. Now you search "sandbox" and toggle. Search "model" and switch. Search "key" and rebind.

**For beginners:** This is the difference between "I hope this setting works" and "I can see exactly what's on, what's off, and what needs a restart."

```bash
# In Codex, just type:
/config
# Search, toggle, done. Restart only when it says so.
```

---

### 2. Instant Interrupt + Follow-Up Steering — Stop, Redirect, Continue

**What it is:** Send a follow-up *while Codex is responding* to steer it immediately. Interrupting a turn also stops active Code Mode cells and their nested tool calls.

**Why it matters:** Your agent starts writing a 200-line refactor. You realize halfway through it's going the wrong direction. Before: wait for it to finish, then explain why it's wrong, then wait again. Now: type your correction *mid-stream*. Codex stops, incorporates your steer, continues.

**For beginners:** It's like grabbing the wheel when your GPS tries to drive you into a lake — except the car actually listens.

```bash
# While Codex is streaming a response:
# Type your follow-up → Enter
# Codex interrupts, re-plans, continues with your direction
```

---

### 3. Leader Key in `/keymap` — Your Terminal, Your Shortcuts

**What it is:** Configure a leader key in `/keymap`. Default is `Ctrl+X`. Shortcut hints stay open until you choose or cancel. Voice mute moves to `F9`.

**Why it matters:** Muscle memory matters. If you live in `Ctrl+A` for tmux/screen, or `Ctrl+Space` for your IDE, you can now make Codex match your brain instead of forcing your brain to match Codex.

**For beginners:** Set it once. Never fight your own shortcuts again.

```bash
# In Codex:
/keymap
# Set leader to whatever your fingers expect
```

---

### 4. Managed Daemon Restart from `/daemon` — Background Server, Under Control

**What it is:** Restart the managed background server from `/daemon`. Codex warns about work the restart could interrupt, then reconnects automatically.

**Why it matters:** The daemon manages your long-running state. When it gets stuck (it happens), you used to kill the process and lose context. Now: `/daemon` → restart → it reconnects with your sessions intact.

**For beginners:** It's the "turn it off and on again" button that actually preserves your work.

---

### 5. Parallel Read-Only Tools — Skill, Memory, History Lookups at Once

**What it is:** Codex can now run independent read-only tools in parallel — skill lookups, memory searches, conversation-history retrieval all happen concurrently instead of sequentially.

**Why it matters:** Your agent needs to check a skill, search memory, and read past conversation context. Before: three sequential round-trips. Now: one parallel batch. Feels snappier because it *is* snappier.

**For beginners:** You won't see this directly. You'll just notice the agent "thinks faster" when it needs context.

---

### 6. Daybreak Enabled by Default — GPT-6.1 Sol for Eligible Accounts

**What it is:** Daybreak (OpenAI's newest model tier) is enabled by default for eligible accounts. `codex exec` can also select it with an OpenAI API key when the server offers access.

**Why it matters:** If you have access, you get the latest model without config. If you're on `codex exec` with your own key, you can opt in when available.

**For beginners:** Better model, zero config. Just works.
