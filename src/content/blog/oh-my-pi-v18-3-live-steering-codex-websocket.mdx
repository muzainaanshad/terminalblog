Oh My Pi **v18.3.0** (Sep 24) and **v18.3.1** (Sep 25) just shipped — and v18.3.1 drops a feature that changes how you work with agents: **live steering for Codex WebSocket transports**.

Translation: you no longer have to watch your agent type the wrong thing for three paragraphs before you can stop it. You can now jump in *while it's still responding* and nudge it back on track.

## The headline: live steering mid-response

This is the big one. Oh My Pi's Codex WebSocket transport now supports **interruptible streaming** — you can provide input while a response is in progress. The agent actually *listens* and adjusts.

**Before:** Agent starts a long answer → you realize it misunderstood → you wait for it to finish → you correct it → it starts over.

**After:** Agent starts → you see it going sideways → you type "stop, use TypeScript not Python" → it pivots mid-stream.

For beginners, this is the difference between a passenger and a co-pilot. You stay in the driver's seat without breaking flow.

## Passive tool-call context — agents that remember what they just did

v18.3.0 added `TOOL_INTERRUPT_ABORT_REASON` so interruptible tools can distinguish between:
- Queued steering (you nudging it)
- Peer messages (other agents talking)
- Background completions
- A full run abort

Plus **passive tool-call context support** — hooks and tools can now supply additional context for subsequent model processing without you manually threading it. The agent builds its own context chain as it works.

## The daily release cadence is the real feature

Oh My Pi releases **every single day**. v18.3.0 dropped September 24. v18.3.1 dropped September 25. While other agents batch features into monthly drops, Oh My Pi ships fixes and improvements within 24 hours.

What this means for you:
- Bug you found yesterday? Fixed in tonight's build.
- New model drops? Provider support often lands same week.
- Provider API breaks? Patched before you hit it.

The tradeoff: you update frequently (`npm update -g @oh-my-pi/pi-agent` or let the desktop auto-updater handle it). The payoff: the tool evolves *with* the ecosystem instead of lagging behind.

## What this looks like in practice

**Scenario:** You ask Oh My Pi to refactor a React component to use the new compiler.

1. Agent starts writing the old pattern
2. You notice and type: "use the new compiler API, not the legacy one"
3. Agent pivots mid-response, rewrites using the new API
4. You get the right code on the first try — no iteration loop

**Scenario:** Agent starts a long file search
1. You realize it's searching the wrong directory
2. You steer: "only check src/components"
3. Agent narrows scope instantly, returns relevant results

## How to get it

```bash
npm update -g @oh-my-pi/pi-agent
# or if you use the desktop app, it auto-updates
```

Confirm with `pi --version` — you want `18.3.1` or later.

## The bottom line

Oh My Pi v18.3 isn't a feature parade — it's a **control upgrade**. Live steering means you stop being a spectator to your own agent. Passive context means the agent stops dropping the thread between tool calls. And the daily cadence means the tool you use tomorrow is already better than the one you used today.

If you've been frustrated by agents that run away with the wrong assumption and you have to wait for them to finish before correcting — this is the release that fixes that.
