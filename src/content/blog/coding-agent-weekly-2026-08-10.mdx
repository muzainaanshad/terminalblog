LangChain's terminal agent dcode has exactly three approval modes: Manual, classifier-backed Auto, and YOLO. Here's what each gates, how to enable them, how the Auto classifier works, and when each mode is safe to run.

### [Gitlawb Zero Just Gave Its Agents Eyes — Screenshots Are No Longer a Lie](https://terminalblog.com/blog/gitlawb-zero-v0-7-0-vision-readonly-plan-mode/)

### [Gitlawb Zero Cross-Session Messaging: Make Two Agents Talk (Safely)](https://terminalblog.com/blog/gitlawb-zero-cross-session-messaging/)

### [Qwen Code v0.21.8 Fixes a Trust Bug, Shares Prompt Cache, and Brings Back Fork Autofix](https://terminalblog.com/blog/qwen-code-v0-21-8-trust-cache-fork-autofix/)

### [What Developers Think About Approving Every AI Agent Command — From 177 HN Comments](https://terminalblog.com/blog/hn-agent-approval-fatigue-humans-in-the-loop-debate/)

### [Beware: Claude Code Silently Drops Its Sandbox in Nested Project Folders](https://terminalblog.com/blog/beware-claude-code-nested-project-sandbox-drop/)

Claude Code issue #83035: when a session or subagent runs inside a nested project directory, the workspace's sandbox settings are silently discarded — network restrictions and unsandboxed-command policies stop applying. No warning, no error. Here's how to check if you're affected.

### [OpenClaw v2026.6.34: Your Coding Agent's Browser and Network Access Just Got Safer](https://terminalblog.com/blog/openclaw-v2026-6-34-safer-browser-network/)
