Cline **v4.1.25 dropped October 16**, and it brings the feature that changes **where your agent runs**.

**Cline Cloud sessions** (rolling out gradually): run a task in a **hosted sandbox on a GitHub repo and branch you pick**. Turn it on in Settings. Cloud tasks show in Recent and History with status, notify you when they finish, and **keep running after you close your editor**.

Plus: **Gemini 4 Argon** becomes the new default model, model catalog refresh with new providers, and **local models no longer timeout after 5 minutes** of silence.

---

## The Feature That Changes Everything: Cloud Sessions

### What It Is

You pick a GitHub repo + branch. Cline spins up a hosted sandbox. Your agent runs the task there. You get a notification when it's done. The session **persists after you close VS Code / JetBrains / the desktop app**.

```text
Your laptop: closed
Cline Cloud: running your task on github.com/your-org/your-repo@feature-branch
You: get notified → open result → merge / iterate
```

### Why This Is Huge

| Before | After |
|--------|-------|
| Agent runs on *your* machine | Agent runs in *hosted sandbox* |
| Close editor → task dies | Close editor → task **keeps running** |
| Local resources consumed | Zero local CPU/RAM during task |
| One task at a time | Queue multiple cloud tasks |
| No history if editor crashes | Full history in Recent/History panel |

**For beginners:** This is "GitHub Actions for your coding agent" — but you don't write YAML. You just say "fix the auth bug on the `login-refactor` branch" and Cline Cloud does it.

### How to Enable

1. Open Cline Settings
2. Toggle **Cline Cloud sessions**
3. Pick a GitHub repo + branch
4. Start a task → it runs in the cloud

**Rolling out gradually** — if you don't see it yet, check back in a few days.

## Gemini 4 Argon: The New Default Model

**Changed:** With no model chosen, the Cline provider now uses **Gemini 4 Argon** — the new first model in Cline's recommended list.

**OpenRouter stays on Claude Sonnet 5.5** (unchanged).

| Provider | Old Default | New Default |
|----------|-------------|-------------|
| Cline (built-in) | Claude Sonnet 5.5 | **Gemini 4 Argon** |
| OpenRouter | Claude Sonnet 5.5 | Claude Sonnet 5.5 |

**Why it matters:** Gemini 4 Argon is Google's latest coding-optimized model. If you use Cline's built-in provider (no API keys needed for free tier), you just got a model upgrade for free.

**For beginners:** Don't overthink it. If you haven't picked a model, you're now on a better one. If you *have* picked a model, nothing changes.

## Model Catalog Refresh: New Providers, New Defaults

**Refreshed catalog:** 6,952 → 7,041 models. Adds **Boundless** and **Standard Compute** providers. **SambaNova** now comes from catalog with **MiniMax M3** as default.

**Cline recommended list:** Adds **Gemini 4 Argon**, drops **Grok 4.7**.

**Cline free list:** Replaces **Step 5 Preview** with **Nemotron 3.5 Super VL**.

**OpenCode Go:** Keeps its `https://opencode.ai/inference/go/v1` base URL (now pinned) because models.dev moved its provider-level URL to OpenAI-only path.

**Default model changes for 20+ providers** — if you use one without pinning a model, expect a different default. Check the [full changelog](https://github.com/cline/cline/compare/v4.1.24...v4.1.25) for the complete list.

## The Fix That Saves Local Model Users: No More 5-Minute Timeout

**Fixed:** Long requests to local models (LM Studio, Ollama) **no longer fail after 5 minutes of silence** with `terminated: BodyTimeoutError` while the server is still processing.

**Before:** Send large prompt to local model → wait 5 minutes → **error** → model was actually still thinking → wasted time.

**After:** Request waits until the server responds. No arbitrary timeout.

**Why this matters:** Local models on consumer hardware *are* slow on large contexts. A 32K context prompt can take 10+ minutes on a 24GB GPU. The 5-minute timeout made local models unusable for real work. **Fixed.**

## The Bigger Picture: Cline Goes Remote

| Era | What Cline Was |
|-----|----------------|
| v3.x | Local IDE extension |
| v4.0.x | Local IDE + Desktop + CLI + SDK |
| **v4.1.25+** | **Local + Remote (Cloud sessions)** |

Cloud sessions aren't just "run elsewhere" — they're **persistent, queueable, notify-able, history-tracked remote execution**. This is the infrastructure for "agent as a service" without the service lock-in.

You still own the agent. You still pick the model. You still control the repo. **Cline just handles the compute.**
