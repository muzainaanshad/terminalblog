Codex 0.157.0 landed on September 25, and it's the kind of release that changes how you *feel* using the tool — not just what it can do.

The headliners: **GPT-6 Sol and Luna** are now first-class models (including Amazon Bedrock), **fullscreen transcripts are on by default**, and the **background server starts itself** so your sessions don't stall when you step away.

But the real story is in the details that remove friction you've been tolerating for months.

---

## 1. GPT-6 Sol and Luna — The New Frontier Models, Ready to Use

OpenAI's newest model family — **GPT-6 Sol** (the reasoning powerhouse) and **GPT-6 Luna** (the speed-optimized sibling) — are now in the Codex model picker. If you have Bedrock access, they work there too. Migration prompts for older models are included, so switching doesn't mean rewriting your prompts.

For beginners: this is the model tier you've been reading about. Sol thinks longer and deeper. Luna gets you there faster. Both are available *inside* Codex without juggling API keys or separate dashboards.

---

## 2. Fullscreen Transcripts by Default — Finally

Remember when you had to toggle fullscreen mode every session? **It's now the default.** The transcript takes the full terminal height, and **Shift-click extends text selections** — so you can grab a code block, a stack trace, or a long reasoning trace without fighting the UI.

This sounds small. It's not. It means your mental model of "where am I in this conversation" stays intact instead of resetting every time you open a session.

---

## 3. Background Server Starts Itself — No More "Wait, Is It Running?"

Codex now **automatically starts the background server** for eligible interactive sessions. If your settings are incompatible, it gives you recovery choices instead of silently failing.

What this means: you open Codex, start a task, walk away for coffee, come back — and the agent is still working. The server recovered. The session didn't die. This was the #1 "silent killer" of long-running tasks. Fixed.

---

## 4. The `f` Shortcut — Fork Conversations Without Losing Your Place

Press **`f`** in the TUI and the current conversation forks open in another app. Your drafts, queued prompts, and context all come with it.

This is huge for parallel workflows: keep the main thread exploring option A, fork to test option B, compare results side by side. No copy-paste. No "wait, which window had the working version?"

---

## 5. `/import` Works Everywhere Now

The `/import` command (bringing external context into your session) now works in **remote sessions and local background-server sessions**. Before, it was local-only. Now it's universal — your research, docs, and specs follow you wherever the agent runs.

---

## 6. Terminal Rendering Got a Serious Upgrade

- **Unicode bullets and checkboxes** — task lists actually look like task lists
- **Aligned equations and optimization notation** — math renders cleanly in the transcript
- **Optimization notation** — mathematical expressions don't break across lines

If you've ever squinted at a garbled table or a split equation in your terminal, this is the release where that stops happening.

---

## What This Means for Beginners

If you're new to Codex (the OpenAI coding agent that runs in your terminal, free with ChatGPT Plus/Pro), here's the practical takeaway:

1. **You get the newest models immediately** — GPT-6 Sol/Luna are in the picker today
