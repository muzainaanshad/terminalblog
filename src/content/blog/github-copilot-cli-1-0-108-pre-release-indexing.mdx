**GitHub Copilot CLI v1.0.108-0 dropped 7 hours ago** (Nov 7, 00:25 UTC). It's a pre-release, but the feature that matters — **managed shared tgrep indexing** — is enabled by default for eligible repositories. Your agent just got a search index it didn't have yesterday.

## The Headline Feature: `/index` Commands + Shared tgrep (Default-On)

### What It Is

**tgrep** (tree grep) is GitHub's semantic code search index. Until now, you had to set it up manually. **v1.0.108 makes it managed and shared** — the CLI builds the index, shares it across your sessions, and keeps it fresh. Enabled by default for repositories that qualify.

```bash
# New /index commands
/index status      # Shows index health, coverage, last updated
/index build       # Force a full rebuild
/index watch       # Live tail of index updates
/index pause       # Pause background indexing
/index resume      # Resume paused indexing
```

### Why It Matters for Beginners

**Before:** Agent searches with `grep`/`glob`/`rg` — scans files every time. Slow on large repos. Misses semantic context.

**After:** Agent queries a **pre-built semantic index**. Finds "the auth middleware" not by filename but by *what it does*. Cross-file references work. 10-100x faster on large codebases.

```markdown
# Real difference
You: "Where's the JWT validation?"
# Old: rg "jwt" → 200 matches, you scroll
# New: Agent queries index → "src/auth/validate.ts:42 — validates JWT in middleware chain"
```

### Eligibility (Default-On)

- Repository has a `.git` directory
- Not a bare repo
- Under 500k files (soft limit)
- Not explicitly opted out via `settings.json`

```json
// Opt out if needed
{
  "indexing": {
    "managed": false
  }
}
```

## Windows: Enumerate-Only Directory Grants

New setting: `sandbox.userPolicy.filesystem.enumeratePaths`

```json
{
  "sandbox": {
    "userPolicy": {
      "filesystem": {
        "enumeratePaths": ["C:\\Projects\\secret-repo"]
      }
    }
  }
}
```

**What it does:** Grants the agent permission to *list* directory contents (see file names, structure) without read/write access to file contents. Useful for:
- Letting the agent explore a repo structure before you grant full access
- Security-sensitive directories where you want visibility but not content access
- CI/CD scenarios where the agent maps the repo first

## 50+ Fixes You'll Actually Notice (Scannable)

### Agent Behavior
- **Autopilot + Assisted Permissions**: Since 1.0.106, agent no longer stops on permission prompts — tries another approach, reports what it couldn't do
- **Ctrl+C stops `/compact`** — same as Esc Esc, instead of only arming exit hint
- **Interactive Autopilot waits for MCP input/consent** — no longer auto-declines
- **`/mcp enable` respects repo settings** that disable an MCP server

### Session & Resume
- **`copilot --resume` / `/resume` find sessions with accented names** — precomposed or decomposed Unicode, matches either
- **Headless runs error on resume conflict** — keeps history intact instead of corrupting
- **Auto-updates no longer skipped** when sign-in takes >1 second

### Search & Navigation
- **`/search` keeps match in view** when opening, no more jump to bottom
- **Up/Down/Enter in `/search`** bring single match back after scroll-away
- **Shorter terminals** no longer leave current match off-screen

### MCP & Tools
- **MCP deny rules block by advertised name** (e.g., `server(weather.lookup)`) not just sanitized name — works with `--allow-all-tools`
- **MCP form validation errors** show beside inputs, focus first invalid field, better screen-reader labels
- **Pasted image path re-attaches** after clearing `[image: ...]` label with Ctrl+U/K/W or Up-arrow history

### Input & Editing
- **Backspace/arrow/Ctrl+U/Shift+Enter after paste** act on pasted text, not text before it
- **Tab chars in replies/errors/agent names** show as spaces (not dropped) — tab-separated words stay readable

### Windows/Linux Fixes
- **Language servers on Linux** no longer told files deleted when directory renamed away-and-back
- **Language servers on Linux** now notified of directory renames (old deleted, new created) during package installs
- **Reduce CPU during builds** in large worktrees when language servers watch files

### Accessibility
- **`/help` describes `ctrl+d`** (exits only on empty prompt), `ctrl+z` on Windows, `ctrl+j/v/y` and voice keys
- **Screen reader labels improved** across MCP forms, `/config` help, `/model` list

### SDK / Headless
- **SDK sessions include start/resume/model-change events** in `-p --output-format json`
- **Turn ending with unwritable event log** still ends with `session.idle` — `sendAndWait` won't timeout
- **grep/glob tools return matches found** even when some paths unreadable — note names what was skipped
