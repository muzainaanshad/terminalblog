Less than two weeks after [Codex made GPT-6 Astra its default](/blog/codex-0-154-gpt6-astra-worktrees-windows-daemon/), OpenAI shipped **0.156.0** (Sept 22) and **0.156.1** (Sept 23) — a release pair that genuinely changes how the terminal feels to use.

The headline features: **an experimental fullscreen TUI with transcript search and mouse selection**, **voice conversations enabled by default** with bundled audio runtimes for Linux and Windows, **a `/usage` analytics dashboard**, **worktrees enabled by default**, and **six new themes with Mermaid diagram rendering**. Then 0.156.1 dropped GPT-6 Sol and Luna into the model catalog.

If you're not reading every changelog, here's what actually matters for daily use.

## 1. The Fullscreen TUI — `/tui` Changes Everything

Run `codex /tui` (or add `/tui` to your next launch) and you get an **alternate-screen terminal UI** with:

- **Transcript search** — find anything in your conversation history instantly
- **Mouse selection and right-click copy** — no more keyboard gymnastics to grab output
- **Per-activity detail controls** — expand/collapse tool calls, reasoning, and results
- **Compact transcript browsing** — navigate prompts without scrolling through walls of text

This is Codex's answer to the "terminal agents feel like REPLs" complaint. The TUI makes history navigable, not just scrollable. It's experimental (feature-flagged), but the interaction polish is already ahead of most terminal UIs.

**For beginners:** this is the first time a coding agent feels like a *native terminal app* instead of a chat window bolted onto a shell.

## 2. Voice Conversations — On by Default

No more opt-in flags. Voice is now **enabled out of the box** with:

- **F8 toggle** — one key to start/stop dictation
- **`/voice settings` picker** — choose your voice
- **Bundled audio runtimes** for Linux and Windows — no external dependencies, no `pip install` nightmares

The audio pipeline preserves captions across speaker updates and handoffs, and voice meter history survives quiet samples. If you've ever wanted to talk to your agent while reading code, it now just works.

## 3. `/usage` Analytics Dashboard — Finally, Visibility

Type `/usage` and you get an **account-level analytics dashboard** inside the terminal:

- Token totals and credit formatting
- Top chats by usage
- Plan usage history (gated)
- Plugin and skill activity breakdown
- Stacked chart primitives for navigation

For teams and solo devs alike: you can finally answer "how much did that refactor cost?" without leaving the terminal.

## 4. Worktrees Enabled by Default

The experimental worktree support from 0.154 is now **on by default**. From the agent command center:

- Filter tasks by status
- Create worktree sessions — isolated checkouts where the agent experiments without touching your working copy
- Browse and resume worktrees later

This is the isolation pattern Claude Code and Qwen Code have been pushing: **dangerous experiments in a side copy, review the diff, then merge**. The scariest part of agent coding ("what if it breaks my branch?") gets a native answer.

## 5. Six New Themes + Mermaid Diagrams + Display Math

The TUI got a proper theming system:

- Six bundled themes with theme-aware accents
- **Mermaid diagrams render as diagrams** in the TUI (not raw code blocks)
- **Display equations render as Unicode** — `$$E=mc^2$$` actually looks like math
- Inline TeX math renders as Unicode
- System reduced-motion preferences respected

For anyone reading architecture diagrams or math-heavy docs in the terminal: this is a quality-of-life leap.

## 6. Daemon Lifecycle Commands (`/daemon` and `--no-daemon`)

The background server that keeps sessions alive across window closes now has **user-facing controls**:

- `/daemon` menu — update the local background server from inside Codex
- `--no-daemon` flag — bypass the shared server entirely

Windows users especially: this is the "sessions survive window closes" feature with a UI to manage it.

## 7. GPT-6 Sol and Luna Land (0.156.1)

The hotfix 0.156.1 adds **GPT-6 Sol and GPT-6 Luna** to the model catalog. The rate-limit switch prompt now recommends Luna. If you're on a plan with access, they're available in the model picker immediately.

## 8. The Safety Fixes You Didn't See

The changelog is long, but these matter for unattended runs:

- **Streamed answers and plans preserved** when turns fail, are interrupted, or receive subagent completion events
- **Clipboard forwarding fixed in tmux and SSH** — tabs preserved when terminals send pasted text as keystrokes
- **Plan mode restored on session resume** — thread identity and settings preserved when editing earlier prompts
- **Login recovers through system proxies** — MCP credentials refresh when OAuth discovery returns 503
- **Sandbox isolation gaps closed**: inbound Windows connections, privileged Linux/macOS sockets, writes through read-only macOS file handles
- **OpenSSL 3.6.4** for Linux musl builds (bundled TLS deps updated)

## What to Actually Do

1. **Update**: `codex update` — or let the managed updater run in the desktop app
2. **Try the TUI**: run `codex /tui` and search your transcript with `/`, select with mouse, right-click to copy
3. **Try voice**: hit F8, talk, hit F8 again — it's that simple now
4. **Check `/usage`**: see your token spend, top chats, plugin activity
5. **Use worktrees for scary refactors**: create a worktree session from the agent command center, let it experiment, review the diff
6. **Windows users**: explore `/daemon` for background session management
