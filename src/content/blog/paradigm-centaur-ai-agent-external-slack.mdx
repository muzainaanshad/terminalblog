Paradigm unlocked Centaur, its AI-powered security agent, for external Slack channels. The move lets the agent participate in conversations that span beyond an organization's internal workspace — meaning Centaur can join shared channels with partners, contractors, or open-source communities where vulnerabilities are discussed.

Centaur was initially scoped as an internal tool for auditing smart contracts and detecting exploit patterns inside Paradigm's portfolio. Opening it to external channels changes the surface area: the agent can now monitor, flag, and respond to security-related discussions in real time across organizational boundaries. For teams that coordinate incident response across multiple companies, that is a practical shift.

The feature reflects a broader trend in agent deployment boundaries. Most coding and security agents still operate inside a single workspace or repo. Moving into cross-org Slack channels means the agent is trusted to handle sensitive context outside the firewall — a step forward in agent autonomy and a new vector for access-control design.

Centaur on external channels means security agents are no longer confined to internal chat. They are joining the conversation where the threats get discussed.
