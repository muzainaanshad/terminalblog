Hermes Agent v0.21.5 dropped September 24. Since then, **main has absorbed 5,635 commits across 300 files**.

That's not a typo. In 8 days, the project has moved more code than many agents ship in a quarter.

The last release notes explicitly said: *"Full curated release notes for this window ship with v0.22.0, which will document everything from v0.21.0 onward — highlights, feature areas, and complete contributor credits. Nothing in this window is skipped."*

Everything since Pantheon (v0.21.0, August 31) is sitting on main, waiting for v0.22.0 to land. That's ~2,260 PRs from v0.21.0→v0.21.4, another 460 from v0.21.4→v0.21.5, and now 5,635 commits on top.

## What's Actually in Those 5,635 Commits

The diff isn't just bug fixes. The top changed files tell the story:

| File | Changes | What It Signals |
|------|---------|-----------------|
| `COMPAT_MANIFEST.md` | −3,858 lines | Massive compatibility matrix overhaul |
| `.github/workflows/desktop-bundled-release.yml` | +2,548 lines | **New desktop bundling/release pipeline** |
| `.github/workflows/stable-release.yml` | +634 lines | **Stable release automation** |
| `agent/context_compressor.py` | +711 lines | Context compression rewrite |
| `agent/chat_completion_helpers.py` | +608 lines | Core LLM interaction layer |
| `.github/workflows/docker.yml` | +599 lines | Docker publishing overhaul |

This is **infrastructure work** — the kind that doesn't make flashy release notes but makes every future release faster, more reliable, and shippable to more platforms.

## The Desktop Bundling Overhaul

The new `desktop-bundled-release.yml` workflow (2,548 lines, brand new) is the biggest signal. It handles:

- Multi-platform desktop builds (macOS, Windows, Linux)
- Code signing and notarization
- Installer generation (DMG, MSI, AppImage, DEB, RPM)
- Auto-update manifest publishing
- Plugin catalog bundling

This means v0.22.0 will likely ship **proper desktop installers for every platform** — not just "run the binary" but signed, notarized, auto-updating applications.

## Stable Release Pipeline

The new `stable-release.yml` (634 lines) automates what used to be manual: tagging stable releases, publishing Docker images, updating Homebrew/Scoop/AUR formulas, and triggering Hermes Cloud deployments.

The project is building **release engineering as code** — so future stable tags (like the v2026.9.21 and v2026.9.24 patches) happen automatically, not by maintainer intervention.

## The Velocity Is the Feature

```
v0.21.0 "Pantheon"        Aug 31
    ↓ ~2,260 PRs in 3 weeks
v0.21.4                   Sep 21
    ↓ 460 PRs in 3 days
v0.21.5 "v2026.9.24"      Sep 24
    ↓ 5,635 commits in 8 days

```

This isn't a project that ships once a quarter. It's a project that **ships continuously and tags stable releases for production**.

The tags exist so your deployments don't have to choose between "latest features" and "stable baseline." You pin to `v2026.9.24` for production, track main for the bleeding edge, and v0.22.0 will be the next curated milestone with full release notes for the entire v0.21 cycle.

## What This Means for You

### If you run Hermes in production
Stay on `v2026.9.24` (Docker: `nousresearch/hermes-agent:v2026.9.24`). It's the current stable tag. The main branch is for testing, not production.

### If you're evaluating agents
The architecture was already best-in-class (background delegation, multi-model routing, cron, memory, skills, dashboard, credential guard). Now the **release engineering matches**. This is what "production-ready open source" looks like.

### If you're already on Hermes
You're benefiting from the performance work already — the model picker is instant, config loads faster, tool invocation is snappier. The 5,635 commits on main will land in v0.22.0 with full documentation.

### If you're building plugins or integrations
The Desktop plugin SDK surface stabilized in v0.21.4. Build against that. The new bundling pipeline means your plugins will be discoverable in the catalog and installable via the Connectors page — no manual config needed.

## The Bottom Line

Most open-source agents have a GitHub repo and a README. Hermes has:

- **Background task delegation** that actually works
- **Multi-model routing** across 15+ providers
- **Cron jobs with persistent memory**
- **Bot Mode** where agents talk to each other
- **Credential guard** that isolates secrets
- **Real-time console dashboard**
- **Skill system** for reusable capabilities
- **Now**: automated desktop bundling, stable release pipeline, and 5,635 commits of polish since the last tag

The "underrated" window closed months ago. The project is now building the **release infrastructure to match its feature velocity**.

v0.22.0 will be the first release where the curated notes cover the *entire* v0.21 cycle — Pantheon through the current main. When it drops, it won't be a feature release. It'll be a **capability milestone** documenting everything this agent can now do.

Watch the tags. The next stable one is coming.
