## 1. Memory That Survives Everything (The Big One)

**What it does:** OpenClaw 2026.10.1 preserves **usage across registry changes**, **delivers worker attachments from remote workspaces**, **prevents queued cancellations from stalling active turns**, **keeps continuation signatures aligned**, and **migrates embedding caches in bounded batches with oversized-row reporting**.

**In English:** Your agent's memory — what it learned, what it's working on, what files it touched — **survives the infrastructure events that used to wipe it.**

| Before 2026.10.1 | After 2026.10.1 |
|------------------|-----------------|
| Registry change → memory gone | Registry change → memory preserved |
| Gateway restart → context lost | Gateway restart → context kept |
| Model switch → reasoning tail cut off | Model switch → answers survive |
| Background job → chat stalls | Background job → chat responsive |

**Why beginners care:** You spend hours teaching an agent your codebase. Then a Gateway restart or model switch wipes it. Now: **the context sticks.** This is the difference between "toy" and "tool."

## 2. Claude Haiku 5.5 Is Now Native

**What it does:** Added native support for **Claude Haiku 5.5** (#166706).

**Why it matters:** Haiku 5.5 is Anthropic's **fast, cheap, smart** model — perfect for high-volume coding tasks (edits, refactors, tests). Before today, getting it in OpenClaw meant config hacking. Now it's **just in the model picker**.

**Cost context:** Haiku 5.5 is ~1/10th the cost of Opus 5.5 for similar coding performance on routine tasks. If you're cost-conscious, this is your daily driver.

## 3. Workboard Sidebar: Personal Kanban Inside Your Agent

**What it does:** Added **Workboard sidebar navigation and personal board pinning** (#164604).

**What you get:**
- A sidebar panel for personal task boards
- Pin your most-used boards (they stay top)
- Navigate between boards without leaving the agent

**Why beginners care:** You're debugging auth → need to track "check JWT expiry," "verify refresh flow," "test logout." Instead of a separate Notion/Trello/Linear tab, **the board lives where the agent works.** Context stays unified.

---

## 4. MCP Apps That Don't Die When You Look Away

**What it does:** MCP Apps can now **call their tools while their views remain open**, with **inline message confirmations** and **synchronized forms/files/context** (#164496, #164493, #164277).

**Before:** Open MCP browser tool → switch to chat → browser tool disconnects → lose your place.

**Now:** Browser/DB/Figma/terminal stays **alive and interactive** while you chat with the agent. Inline confirmations appear in the chat. Forms, files, context stay **synchronized**.

**Why it matters:** MCP is becoming the standard for agent-tool integration. This makes it **usable for real workflows** — not just demos.

---

## 5. Sealed Immutable Installations: Deploy Like Git Tags

**What it does:** Adopted **sealed immutable installation generations with activation and recovery support** (#163799, #164306).

**What it means:**
- Prepare a sealed generation (like `git tag v1.2.3`)
- **Activate** it → becomes live
- **Recover** to previous generation if something breaks
- `--no-restart` stays preparation-only (safe)
- Existing installations **not converted automatically** (opt-in)

**Why it matters:** Production OpenClaw deployments can now do **zero-downtime, rollback-safe updates** — the same discipline you expect from Kubernetes, now for your agent runtime.

---

## 6. Windows Worktrees Finally Work

**What it does:** Fixed **empty and nested Windows worktree creation**, improved **Linux Chromium discovery**, and **automatically starts Playwright Chromium on ARM64** (#164202, #164249, #163510, #163281).

**If you've ever:** Created a worktree on Windows → empty folder → "why is nothing here?" → **Fixed.**

**Also:** Nested worktrees (worktree inside worktree) now create correctly. Playwright Chromium auto-starts on ARM64 Linux (no manual install).

---

## 7. Background Work Stops Blocking Your Chat

**What it does:** Recovered interrupted database workers and Doctor migrations. **Kept background CLI replies from hanging**. Preserved automatic chat following as new content arrives (#163258, #165854, #167091).

**The experience:** You kick off a long Skill Workshop review or cron job. **Your chat stays responsive.** New messages appear. You keep working. The background job reports when done.

**Why it matters:** OpenClaw is becoming a **platform that runs background automation while you use it interactively** — not "one or the other."

---

## 8. Gateway Startup With Large Plugins: No More Multi-Minute Stalls

**What it does:** Valid startups no longer capture/discard plugin Doctor modules on every config read. **Windows plugin captures use fast pinned-descriptor copy** again. Catalog updates don't recapture plugins. Model changes don't freeze Gateway. Windows launchers keep working after pnpm updates (#168017, #167544, #161267, #167905).

**If you run:** OpenClaw with many plugins on Windows → **Gateway starts in seconds, not minutes.**

---

## 9. Security & Privacy Hardening

**What it does:** Rejected NUL execution arguments before startup. **Failed closed on unresolved peer credentials**. Prevented stale Codex sessions and foreign live owners from mutating successor workspaces. **Kept private runtime context out of replies and saved conversations** (#164770, #165021, #164197, #164203, #163471, #164561).

**Translation:** Multiple attack vectors closed. Your agent's private context (secrets, internal reasoning) **stays private** — not leaked into saved conversations or replies.
