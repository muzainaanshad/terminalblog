GitHub Copilot CLI 1.0.97 dropped on October 13, and it's the kind of stable release that makes you realize how much friction you've been tolerating. This isn't a patch — it's a proper feature drop that touches sandbox, authentication, model selection, agent extensibility, and session visibility all at once.

## The Big Three Changes

### 1. Agent-Scoped Declarative Hooks (Custom Agents Just Got Real)

You can now define **declarative hooks for custom agents** — not just global ones. This means your specialized agents (code reviewer, test writer, security auditor) can each have their own pre/post tool hooks without polluting the global namespace.

```json
// .copilot/agents/code-reviewer.json
{
  "name": "code-reviewer",
  "hooks": {
    "preToolUse": [
      { "matcher": "Edit|Write", "command": "echo 'Reviewing change...'" }
    ],
    "postToolUse": [
      { "matcher": "Edit|Write", "command": "npm run lint --if-present" }
    ]
  }
}
```

**Why this matters**: Before, hooks were global. Now each agent carries its own behavior. Your security auditor can block `rm -rf` while your test writer auto-runs the test suite. No more one-size-fits-all.

### 2. Interactive Sandbox Settings (Finally)

Sandbox configuration used to be a "edit JSON, hope it works" experience. Now you get a guided interactive setup:

```bash
copilot sandbox
```

This opens a flow that **detects common secrets (API keys, tokens) and prompts you to mask them** before saving. No more accidentally leaking credentials in transcripts.

**What you get**:
- Environment secret suggestions based on your project
- Masking hosts for sensitive domains
- Visual confirmation before anything writes to config

### 3. Timeline Now Shows WHO Made Each Permission Decision

This is huge for debugging. Every permission prompt in your timeline now shows exactly what decided it:

| Source | Meaning |
|--------|---------|
| **You** | Manual approval |
| **Assisted Permissions** | AI judge said yes |
| **Policy** | Org policy allowed it |
| **Unattended Fallback** | Auto-approved because nobody was watching |

```bash
# See it in action
copilot timeline
```

## Authentication That Actually Works

### Entra (Azure AD) Broker Auth on macOS
If your org uses Microsoft Entra ID, the CLI now uses the **native broker** instead of forcing browser fallback. Falls back gracefully if broker isn't available.

### `/user list` Shows Auth Source
You can now see which account uses which authentication method at a glance.

### Remote Session Resume Uses Your Configured GitHub Auth
No more re-authenticating when reconnecting to cloud sessions.

## What This Means for Beginners

### You Stop Fighting the Tool

**Before 1.0.97**: Configure sandbox via JSON → leak a secret → wonder why auth broke → manually fix timeline gaps → curse at case-sensitive model IDs.

**After 1.0.97**: Run `copilot sandbox` → guided setup masks secrets → auth just works (Entra broker on Mac) → timeline tells you exactly why that command ran → model IDs work however you type them.

### Custom Agents Become Maintainable

Agent-scoped hooks mean you can build a **library of specialized agents** (reviewer, tester, documenter, migrator) each with their own guardrails. Share them with your team. Version them. They don't step on each other's toes.

### Debugging Permission Issues Becomes Trivial

Open `copilot timeline` → see "Unattended Fallback" on that 2 AM deploy → realize your org policy needs tightening. No more guessing.
