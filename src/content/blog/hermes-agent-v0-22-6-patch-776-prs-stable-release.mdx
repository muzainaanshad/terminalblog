**Hermes Agent v0.22.6 dropped November 2, 2026** — and it's the biggest patch drop since the Threshold release. **776 merged PRs. 3,448 non-merge commits. 385 closed issues.** All rolled into one stable tag for the GitHub release, Microsoft Store, Docker, and Hermes Cloud.

If you've been on v0.22.5, you're 776 PRs behind. Here's what that actually means for your daily workflow.

## The One-Line Summary

**v0.22.6 (Nov 2) → 776 PRs, 3,448 commits, 385 issues closed. Webapp on gateway listener, per-skill locks, prepared compaction, cron cancel/stop, OS-keychain vault, Telegram video notes, resumable downloads. Full curated notes ship with v0.23.0.**

---

## The Headline Features (Ranked by Daily Impact)

### 1. Webapp on Gateway Listener — `hermes webapp`

**What it is:** The Webapp now runs on the gateway's own listener. Run `hermes webapp` and you get a **Desktop Web Access pane** — open it on your network, or behind your own URL with Nous sign-in.

**Why it matters:** No more separate web server. The gateway *is* the web server. Desktop plugins also load in a browser tab now — your plugin UI works in the browser, not just the native app.

```bash
# Start the webapp
hermes webapp
# Opens Desktop Web Access pane → pick network URL or custom domain with Nous sign-in
```

**For beginners:** This is the moment Hermes becomes a **web-first agent**. Your skills, plugins, cron jobs, memory — all accessible from a browser tab on any device on your network.

---

### 2. Per-Skill Locks Against Autonomous Writes

**What it is:** Skills can now be **locked** from the Desktop Capabilities pane. A locked skill refuses autonomous writes — the agent can read it, but won't modify it without explicit permission.

**Why it matters:** You have a skill that manages production infra. You want the agent to *read* it for context, but *never* auto-edit it. Lock it. Done.

```bash
# In Desktop → Capabilities → find skill → toggle "Lock"
# Or via CLI (coming in v0.23.0 tooling)
```

**For teams:** This is the "trust but verify" control. Junior devs can use powerful skills. Senior devs lock the dangerous ones.

---

### 3. Prepared Compaction (`compression.prepare_ahead`)

**What it is:** Opt-in **prepared compaction**. When enabled, Hermes compresses conversation history *ahead* of the context window limit — not reactively when you hit it.

**Why it matters:** No more "context window full" mid-task pauses. Compaction happens in the background. Your session stays fluid.

```json
// In hermes.json or profile config
{
  "compression": {
    "prepare_ahead": true
  }
}
```

---

### 4. Cron Cancel + Missed-Run Policy + Stop Button

**What it is:** Three cron upgrades that actually matter:
- `hermes cron cancel` — cancel a running cron job
- Per-job **missed-run policy** — what happens if the machine was asleep/offline when a cron was scheduled
- **Stop button in Desktop cron editor** — click to kill a running job

**Why it matters:** Cron jobs are no longer "fire and forget." You control them mid-flight.

```bash
# Cancel a running cron
hermes cron cancel <job-id>

# Missed-run policies (per job):
# - "run_immediately" — run as soon as machine wakes
# - "skip" — skip this occurrence
# - "run_next_schedule" — wait for next scheduled time
```

---

### 5. OS-Keychain Vault Storage (Opt-In)

**What it is:** The vault encryption key can now be stored in your **OS keychain** (Windows Credential Manager, macOS Keychain, Linux Secret Service) instead of a file.

**Why it matters:** No more `vault.key` file sitting on disk. The OS protects it with your login credentials. Opt-in — you choose.

```bash
# Enable (one-time setup)
hermes vault migrate --keychain
# Vault key moves to OS keychain. File deleted.
```

---

### 6. Delegation Choices Saved Per Session

**What it is:** `/delegation` choices (which agent handles which task) are now **persisted for the next session**.

**Why it matters:** You set up your agent team once. Next session, they remember their roles. No re-configuration.

---

### 7. Telegram Video Notes + Slack Emoji Reactions

**What it is:** Telegram integration now supports **video notes** (the round video messages). Slack gets **emoji reactions in thread context** — reactions show which thread they belong to.

**Why it matters:** Richer notifications. Video notes for quick demos. Thread-aware reactions for team coordination.

---

### 8. Resumable Downloads in Package Manager

**What it is:** Plugin/skill downloads **resume on interruption**. Network blip? Docker layer fails? It picks up where it left off.

**Why it matters:** Large plugins (looking at you, browser automation) don't fail on flaky WiFi. Just works.

---

### 9. `/model reset` — Clear Model Pin Without Losing History

**What it is:** New slash command: `/model reset` clears the session's **pinned model** but **keeps all history**.

**Why it matters:** You pinned Opus 5.5 for a deep task. Task done. `/model reset` → back to default routing. History intact.

---

### 10. Agent-Picked ElevenLabs Voices in `text_to_speech`

**What it is:** The `text_to_speech` skill now lets the **agent pick the ElevenLabs voice** per utterance — not a static config.

**Why it matters:** Agent says "this is urgent" → picks a serious voice. "Here's a fun fact" → picks a playful voice. Dynamic TTS personality.

---

### 11. `pre_llm_call` Hook — Block a Turn Before Inference

**What it is:** New hook: `pre_llm_call` fires **before the LLM request**. Can **block the turn entirely**.

**Why it matters:** Hard guardrails. Budget enforcement. Content filtering. Custom routing logic. The agent *asks permission* before every inference call.

---

### 12. Desktop Group Chat: Rename, Disband, Mentions, Attachment Paste

**What it is:** Group chats in Desktop get:
- **Rename** — give your agent team a real name
- **Disband** — clean shutdown
- **Mentions** — `@agent-name` to direct a message
- **Attachment paste** — drag/drop images, files into group chat

**Why it matters:** Group chat becomes a **collaboration workspace**, not just a demo feature.

---

### 13. Every Profile as a Desktop Sidebar Section

**What it is:** Each Hermes profile now appears as its **own sidebar section** in Desktop. Switch profiles → switch sidebar context instantly.

**Why it matters:** Work profile, personal profile, experiment profile — each has its own skills, plugins, cron, memory. Visual separation.

---

### 14. Migrate Grok Bot / OpenBot Users

**What it is:** `hermes migrate` now moves **Grok Bot and OpenBot users** into Hermes profiles.

**Why it matters:** If you were on Grok Bot or OpenBot, one command brings your config, history, and habits over.

---

### 15. Catalog `requires_hermes` Enforced at Install

**What it is:** Plugins declare `requires_hermes: ">=0.22.0"` in their manifest. Hermes **enforces it at install/update time**.

**Why it matters:** No more "plugin installed but crashes because it needs newer Hermes." Version mismatch caught *before* you waste time debugging.
