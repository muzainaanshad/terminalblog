**Codex v0.166.0 dropped October 29** — just two days after v0.165.0's Vertex AI and Memory v2 release. The October velocity is relentless: four stable releases in three weeks, each adding a layer that compounds.

This one isn't just fixes. It gives you **keyboard-native transcript navigation**, **consistent Markdown everywhere**, **Terra on every major cloud**, **queue resume for background work**, and a **network doctor** for when corporate proxies eat your connection.

## The Headline Features (Ranked by Daily Impact)

### 1. Keyboard-Driven Transcript Selection — Vim Motions for Your Chat History

**What it is:** Navigate, select, search, and copy from your transcript using keyboard motions — word (`w`/`b`), line (`j`/`k`), page (`Ctrl+f`/`Ctrl+b`), integrated search (`/`), and configurable shortcuts.

**Why it matters:** You're in a deep debugging session. The agent printed a 200-line stack trace 40 messages ago. Before: scroll, hunt, mouse-select, copy. Now: `/error` → `n` → `v` → `y` → done. Your hands never leave the keyboard.

```bash
# In Codex TUI:
/search-term    # Jump to matches
v               # Visual selection mode
w / b           # Word forward/backward
j / k           # Line down/up
Ctrl+f / Ctrl+b # Page down/up
y               # Yank (copy) selection
```

**For beginners:** This is Vim keybindings applied to your conversation history. If you know Vim, you already know this. If you don't, the basics (`/`, `n`, `v`, `y`) get you 90% of the value in 5 minutes.

---

### 2. Consistent Markdown Rendering Everywhere

**What it is:** Async questions, choices, answers, and transcript replies now all render Markdown the same way. No more "why does this look different in the prompt vs the reply?"

**Why it matters:** Tables, code blocks, lists, links — they render identically whether the agent is asking you a question, showing a choice, or streaming a response. Mental model stays consistent.

---

### 3. GPT-6.1 Terra Now in Bundled, Vertex AI, and Bedrock Catalogs

**What it is:** OpenAI's flagship reasoning model (Terra) is now available not just via OpenAI's API, but natively through **Google Cloud Vertex AI** and **Amazon Bedrock**.

**Why it matters:** Enterprises on GCP or AWS can use Terra with their existing cloud quotas, VPC perimeters, and IAM policies. No data leaves your cloud project. One model, three cloud paths.

```json
// Works on all three now:
{
  "model": "gpt-6.1-terra",
  "model_provider": "openai"  // or "gcp" or "bedrock"
}
```

**For beginners:** Terra is the model you reach for when the problem is "understand this legacy system and refactor it" not "write a quick function." Now it's available wherever your cloud lives.

---

### 4. `codex queue --resume` — Background Work That Survives

**What it is:** Queue a message for an unloaded thread, and Codex resumes the thread automatically. The agent picks up where it left off.

**Why it matters:** You started a long refactor, closed the terminal, came back tomorrow. Before: find the session, resume manually, re-send the prompt. Now: `codex queue --resume "continue the auth refactor"` and it just works.

```bash
# Queue a follow-up for a background thread
codex queue --resume "add refresh token rotation to the JWT implementation"
# Thread loads, context restores, agent continues
```

---

### 5. Clearer Safety-Block Explanations + Selectable Safer Follow-Ups

**What it is:** When Guardian (Codex's safety system) blocks a tool call, you now get:
- **Clearer explanation** of what triggered the block
- **Selectable safer follow-up prompts** in the TUI — click to retry with a safer approach

**Why it matters:** Safety blocks used to be dead ends. Now they're decision points. "This command was blocked because it writes outside the workspace. Try: 'write to ./output instead' → click → agent retries safely."

---

### 6. `codex doctor --network-only` — Connectivity Diagnostics That Don't Waste Time

**What it is:** A focused diagnostic that checks only configuration, connectivity, and WebSocket health. Skips the full doctor suite (model checks, auth, disk, etc.).

**Why it matters:** You're behind a corporate proxy. `codex doctor` takes 2 minutes and tells you 50 things you don't care about. `codex doctor --network-only` takes 10 seconds and tells you: "WebSocket upgrade failed at proxy hop 2 — check `HTTPS_PROXY` config."

```bash
codex doctor --network-only
# Output focuses on:
# - Config resolution
# - DNS resolution
# - TLS handshake
# - WebSocket upgrade
# - Proxy detection
```
