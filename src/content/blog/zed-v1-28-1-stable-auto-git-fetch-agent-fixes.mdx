## 1. Auto Git Fetch — Now Stable, Off By Default

### What it is
`git.auto_fetch.enabled` (default `false`) fetches your current branch's upstream and the default branch's remote on a configurable interval (60s default).

```json
// settings.json
{
  "git.auto_fetch.enabled": true,
  "git.auto_fetch.interval_secs": 60
}
```

### Why it matters
- **No more stale branches**: Your branch picker, Git panel, and graph reflect reality
- **CI/CD stays green**: Fetch failures surface immediately, not at push time
- **Remote workspaces**: Finally usable over high-latency connections

### The catch
It's **opt-in**. The team made it default-off because aggressive fetching on large monorepos can spike bandwidth. Enable it per-project or globally — your call.

---

## 2. Agent Compaction Fixed — No More Context Window Explosions

### The bug
Auto-compaction ran **once per agent turn**. On long turns with many tool calls, the thread could exceed the model's context window before compaction triggered again.

### The fix
Compaction now runs **continuously** during long turns. It also reuses the prompt cache for ChatGPT subscription models — so you're not paying for tokens you've already sent.

### What this means for you
- **Long refactoring sessions** don't silently truncate history
- **ChatGPT subscribers** see lower bills (cached input is cheaper)
- **Claude users** get the same reliability — compaction respects provider limits

---

## 3. Mouse-Wheel Font Zoom — Finally in Diffs and Terminals

Hold `Cmd` (Mac) or `Ctrl` (Linux/Windows) + scroll in:
- **Diff views** — zoom the diff, not the whole editor
- **Terminal panes** — zoom terminal output independently

Enabled via `mouse_wheel_zoom` setting (default on). Tiny UX win, massive daily quality-of-life.

## 5. AI-Specific Improvements

### Edit prediction button toggle
New setting: `edit_predictions.button` — hide the status bar button if you don't use it.

### ACP agent config ordering
The first option an ACP agent provides now appears **next to the send button** — less hunting for the right tool.
