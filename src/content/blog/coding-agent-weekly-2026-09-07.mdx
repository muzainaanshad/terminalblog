### [Qwen Code v0.23.1 — Goals, Pause, Stuck Worktree Tasks](https://terminalblog.com/blog/qwen-code-v0-23-1-goals-pause-stuck-worktree-tasks/)

Qwen Code v0.23.1 introduces Goals for task planning, Pause/Resume for long-running tasks, and fixes for stuck worktree tasks. Major UX improvements for managed runtime users. Goals let you define high-level objectives that the agent breaks down into steps. Pause/Resume is critical for long-running tasks — you can stop an agent mid-task and resume later without losing context. The worktree fixes address a class of bugs where agents would hang on Git operations.

### [Hermes Agent v0.21 — Pantheon Bots That Talk to Each Other](https://terminalblog.com/blog/hermes-agent-v0-21-pantheon-bots-that-talk-to-each-other/)

Hermes v0.21 introduces Pantheon — a multi-agent coordination system where bots communicate and delegate tasks. Plus skills system improvements and cron stability fixes. Pantheon is the most ambitious multi-agent feature in any coding agent to date — it lets you spawn specialized sub-agents that coordinate via a message bus. One agent plans, another writes code, a third reviews, a fourth tests. The skills system now supports versioned skill packs.

### [What Developers Think: AI Code Review Validity (HN)](https://terminalblog.com/blog/what-developers-think-ai-code-review-validity-hn/)

HN discussion on whether AI code reviews are actually useful or just noise. Split opinions: some catch real bugs, others generate false positives that waste reviewer time. The thread revealed a key divide: teams using AI review as a *filter* (catch obvious issues before human review) see value; teams using it as a *replacement* for human review get burned.

## The Pattern: Agents Are Becoming Platforms

Qwen Code adding Goals/Pause/Resume, Hermes adding Pantheon multi-agent coordination — these aren't feature updates. They're platform moves. The winners in this space won't be the ones with the best model; they'll be the ones with the best *orchestration layer*. Model access is commoditizing (see: OpenRouter, aiFiesta, local models). The moat is the workflow: planning, delegation, review, rollback, audit.
