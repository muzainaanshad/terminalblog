## Pros & Cons

### Codebuff
**Pros:**
- Terminal-native code generation
- Multi-model support
- Open source

**Cons:**

- No vision

### GitHub Copilot CLI
**Pros:**
- Deep GitHub integration
- Multi-model (Claude Sonnet 4.5, GPT-5)
- MCP server built-in

**Cons:**
- Requires Copilot subscription
- GitHub ecosystem dependent
