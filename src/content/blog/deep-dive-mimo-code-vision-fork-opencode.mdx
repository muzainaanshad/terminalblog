Mimo Code is a fork of OpenCode that adds vision support, reasoning model integration, and a polished terminal UI.

## What Mimo Adds

**Vision Support** — Process screenshots, diagrams, UI mockups, and whiteboard photos as input. Enables bug report analysis from screenshots, UI diff comparison, architecture diagram understanding, and document OCR.

**Reasoning Models** — Support for reasoning-enhanced models that show chain-of-thought, useful for complex debugging and architectural analysis.

**Enhanced Terminal UI** — Better output formatting, collapsible sections, and progress indicators for long-running tasks.

## Why Fork vs Contributing

Vision support required significant architectural changes to OpenCode's tool execution pipeline. The fork has since developed its own community while maintaining compatibility with OpenCode's skill format.
