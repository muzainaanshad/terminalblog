## What Zero Is, in One Paragraph

Gitlawb Zero (MIT-licensed, npm package `@gitlawb/zero`, ~1,200 GitHub stars) is a terminal coding agent for people who want to **own their tooling**. You start it in a project folder, ask for something in plain English, and it plans, edits files, runs commands, and commits — but every permission stays on your machine, and you can point it at any model provider you like (OpenAI, Anthropic, Ollama, OpenRouter, local models via LM Studio, and more).

If you're new to it, our [Gitlawb Zero deep dive](/blog/deep-dive-gitlawb-zero-agent/) covers the architecture. This article covers what v0.9.0 through v0.13.0 change.

## v0.9.0 (Sep 15) — The ACP & TUI Foundation

### 1. ACP Standard Session List and Resume — The Headline

**ACP (Agent Communication Protocol)** now supports listing and resuming sessions natively ([Twigpine/zero#914](https://github.com/Twigpine/zero/issues/914)). This isn't a custom format — it's the emerging standard for agent interoperability.

**What this means for you:**
- `zero acp session list` — shows all sessions with metadata (model, working directory, last activity, message count)
- `zero acp session resume <id>` — picks up exactly where you left off: conversation history, tool state, working directory, permissions
- Works across restarts, across machines, across ACP-compatible tools

**Why beginners care:** You stop treating agent sessions as disposable. A session becomes a *project artifact* — you can resume it tomorrow, hand it to a teammate, or fork it for a different approach.

---

### 2. Richer TUI — Interactive Terminal Attach and Mid-Run Model Escalation

The TUI got two features that change daily workflows:

#### Interactive Terminal Attach for TTY Exec Sessions ([Twigpine/zero#1055](https://github.com/Twigpine/zero/pull/1055))

When Zero runs a command in a TTY (interactive CLI, `vim`, `htop`, `psql`), you can now **attach to that terminal live** from the TUI. See the output, send keystrokes, detach and reattach — the command keeps running.

No more "I wish I could see what that long-running command is doing right now."

#### Mid-Run Model Escalation Behind `--allow-escalation` ([Twigpine/zero#1019](https://github.com/Twigpine/zero/pull/1019))

Start a task with a fast/cheap model (GPT-6 Luna, Haiku). Hit a complex reasoning wall. **Escalate mid-run to Opus 5.5 or GPT-6 Sol** without losing context.

```bash
zero --allow-escalation
# In TUI: /model escalate claude-opus-5-5
```

The conversation history, tool results, and working state all transfer. You pay for expensive reasoning *only when you need it*.

---

### 3. Richer `/resume` Session Browser ([Twigpine/zero#1047](https://github.com/Twigpine/zero/issues/1047))

The session picker now shows:
- Preview of the last few messages
- Tool calls made in the session
- Working directory and git branch
- Model and provider used
- Token usage estimate

Pick the right session to resume without guessing.

---

### 4. ACP: Structured File Changes in Tool Updates ([Twigpine/zero#999](https://github.com/Twigpine/zero/issues/999))

Tool results now emit **structured file changes** (create, modify, delete, rename) through ACP. Other ACP-compatible tools can parse what Zero changed without scraping text output.

This is how agents start talking to each other *about code* — not just text.

---

### 5. ACP: Safe Browser Tool Metadata ([Twigpine/zero#1000](https://github.com/Twigpine/zero/issues/1000))

Browser tools (`browser_screenshot`, `browser_pdf`, `browser_click`) now surface safe metadata through ACP: URLs visited, element selectors used, viewport dimensions — without exposing raw DOM or credentials.

---

### 6. Default Headless Runs to Turn-Budget Ceiling ([Twigpine/zero#1049](https://github.com/Twigpine/zero/pull/1049))

Headless runs (`zero run --headless`) now default to the maximum turn budget instead of a conservative limit. Your CI/CD agents stop hitting arbitrary ceilings mid-task.

---

## v0.11.0 (Oct 16) — Provider Expansion & Git Safety

### 1. Concentrate Provider Preset ([#1147](https://github.com/Twigpine/zero/issues/1147))

Added **Concentrate** as a new provider preset — a unified API gateway for multiple model providers with intelligent routing.

---

### 2. CLI: Providers Subcommands Run Without Active Provider ([#1143](https://github.com/Twigpine/zero/issues/1143))

You can now run `zero providers list`, `zero providers add`, etc. without having an active provider configured. Removes a common friction point for new users.

---

### 3. Git Config Isolation — Your Repo's Git Config Can't Run Code in Zero ([#1133](https://github.com/Twigpine/zero/issues/1133))

**Critical security fix:** A repository's `.git/config` could previously execute arbitrary commands during Zero's own git operations. Now Zero uses `gitsafe` for all internal git calls — your repo's config stays in your repo.

---

### 4. NPM Publish Reliability ([#1145](https://github.com/Twigpine/zero/issues/1145))

NPM publishing now waits for each publish to apply and drops the one-time `@gitlawb/zero` steps. More reliable releases.

---

### 5. Workspace Index: Skip Git-Ignored & Build-Cache Dirs in Scan ([#1117](https://github.com/Twigpine/zero/issues/1117))

Scan is faster and cleaner — ignores `.gitignore` patterns and common build directories (`node_modules`, `.next`, `dist`, `target`, etc.).

---

### 6. Redaction Fast-Path — Eliminates Regex Allocations on Clean Strings ([#945](https://github.com/Twigpine/zero/issues/945))

Credential redaction now has a fast byte-check path that avoids regex overhead on strings that don't contain secrets. Measurable performance win.

---

## v0.12.0 (Nov 2) — Sandbox, Skills, Security, Sessions

### 1. Self-Exec Sandbox — Eliminated Separate Helper Binary ([#946](https://github.com/Twigpine/zero/issues/946))

**Major architectural change:** The sandbox no longer needs a separate helper binary. It uses a **self-exec pattern** — the Zero binary re-executes itself with a sandbox flag. This means:
- Fewer moving parts
- No binary sync issues between updates
- Simpler installation and distribution
- Same security guarantees

---

### 2. MiniMax-M3.1-Flash Added to Provider Catalog ([#1180](https://github.com/Twigpine/zero/issues/1180))

New model provider: **MiniMax M3.1 Flash** — fast, capable, and now natively supported.

---

### 3. Skills: Install Bundled Files & Point Tools at Them ([#1167](https://github.com/Twigpine/zero/issues/1167))

Skills can now ship with **bundled assets** (scripts, templates, configs) and the skill tool automatically points at them. This makes skills **self-contained distributable units** — no more "download this extra file" instructions.

---

### 4. Agent: Headless Guardrail Stops Marked Incomplete ([#1182](https://github.com/Twigpine/zero/issues/1182))

When a headless run hits the guardrail, the session is now explicitly marked `incomplete` — not "success" or "failed." You know exactly what happened.

---

### 5. Go 1.26.10 — Security Update for GO-2026-6809 ([#1168](https://github.com/Twigpine/zero/issues/1168))

Underlying Go toolchain updated for a security advisory.

---

### 6. ChatGPT Provider: Subscription Defaults & Compatibility Version Refreshed ([#1179](https://github.com/Twigpine/zero/issues/1179))

ChatGPT provider now correctly detects subscription tier and uses the right compatibility version.

---

### 7. OAuth: Crash-Safe Secret Store & Encrypted Publication Sync ([#1165](https://github.com/Twigpine/zero/issues/1165))

OAuth tokens now use the same crash-safe secret store as the rest of Zero. Encrypted publications sync correctly across machines.

---

### 8. Redaction: Greedy Span Swallowing Fixed ([#1158](https://github.com/Twigpine/zero/issues/1158))

Fixed a bug where credential redaction could miss secrets if a greedy regex span swallowed the trigger pattern.

---

### 9. Sessions: Capture Freeform `apply_patch` Checkpoints ([#1183](https://github.com/Twigpine/zero/issues/1183))

Freeform patch applications now create proper checkpoints. Resume works even after manual patch edits.

---

### 10. Sessions: Preserve Image Attachment Summaries on Resume ([#1152](https://github.com/Twigpine/zero/issues/1152), closes [#1135](https://github.com/Twigpine/zero/issues/1135))

**Image attachments now survive session resume.** Their summaries (what the image was, what the agent saw) persist across restarts. No more "what was that screenshot?" after resuming.

---

### 11. Tools: Grep Stops at File's Actual Line Breaks ([#1160](https://github.com/Twigpine/zero/issues/1160))

Grep no longer reads past where a file's line breaks end. Fixes edge cases with truncated or binary files.

---

### 12. WorkspaceIndex: GitSafe Integration ([#1153](https://github.com/Twigpine/zero/issues/1153), [#1149](https://github.com/Twigpine/zero/issues/1149))

Workspace index now runs all git calls through `gitsafe` — same isolation as the agent's git operations.

---

### 13. Dependencies: Hono 4.13.13 ([#1171](https://github.com/Twigpine/zero/issues/1171))

Web framework dependency refreshed.

## v0.13.0 (Nov 9) — AI/ML API, Plugin Control, TUI Reasoning, Performance

### 1. AI/ML API as Opt-In Built-In MCP Server ([#1193](https://github.com/Twigpine/zero/issues/1193))

**New provider integration:** AI/ML API now available as a built-in MCP server. Enable it and get access to their model catalog through Zero's standard MCP interface.

---

### 2. Plugin Enable/Disable via CLI ([#1202](https://github.com/Twigpine/zero/issues/1202))

**Plugin management just got real:** `zero plugin enable <name>` and `zero plugin disable <name>` work directly on `plugin.json`. No more hand-editing config files to toggle plugins.

---

### 3. OpenGateway Points to api.twigpine.com with Live Model List ([#1208](https://github.com/Twigpine/zero/issues/1208))

OpenGateway now hits the official Twigpine API for its live model catalog. New models appear automatically — no Zero update needed.

---

### 4. Web-Fetch: AI/ML API Toolbox Scraping Backend (Opt-In) ([#1192](https://github.com/Twigpine/zero/issues/1192))

Web fetching can now use AI/ML API's Toolbox as a scraping backend. Opt-in for better extraction on complex pages.

---

### 5. Web-Search: AI/ML API Toolbox as Opt-In Backend ([#1189](https://github.com/Twigpine/zero/issues/1189))

Web search gets the same AI/ML API Toolbox backend option. More search providers = better results.

---

### 6. Hooks: Specialist Start/Stop Lifecycle Hooks Dispatched ([#1204](https://github.com/Twigpine/zero/issues/1204))

Specialist agents (subagents with specific roles) now emit `specialistStart` and `specialistStop` lifecycle hooks. Build tooling that reacts to subagent boundaries.

---

### 7. TUI: Reasoning Stream Rendering Made Linear ([#1198](https://github.com/Twigpine/zero/issues/1198))

**Big UX fix:** Reasoning/thinking blocks in the TUI now render with **coalesced deltas, O(1) append, and tail-bounded preview**. No more janky, jumping reasoning output. It streams smoothly like a proper terminal should.

---

### 8. TUI: Bounded File Read, LRU Rendering Cache, Size Caps ([#1203](https://github.com/Twigpine/zero/issues/1203))

Full-file view in the TUI now has:
- Bounded reads (won't OOM on huge files)
- LRU rendering cache (scrolling stays fast)
- Size caps (auto-truncates massive files with notice)

## What This Means for You

### If You're New to Coding Agents

**v0.9–v0.13 changes the "first run" entirely.**

1. Install Zero → `zero --plan` → explore a repo safely (read-only planning mode from v0.7.0)
2. `zero acp session list` → your sessions are portable artifacts, not disposable
3. Attach to live TTY commands in the TUI → see what long-running commands are doing
4. Escalate models mid-run when reasoning gets hard → pay for Opus only when needed
5. Plugins enable/disable via CLI → capabilities are toggles, not config surgery
6. Self-exec sandbox → no helper binary, same security
7. Image attachments survive resume → your visual context persists

The learning curve just got a ladder, and the safety rails are real.

---

### If You Run Zero in Production (CI, Cron, Automation)

- **Headless defaults to max turn budget** → CI agents don't hit arbitrary ceilings
- **ACP session resume** → failed runs can be inspected and continued
- **GitSafe isolation** → repo git config can't hijack your automation
- **OAuth crash-safe store** → tokens survive machine crashes
- **Self-exec sandbox** → fewer deployment moving parts
- **Structured file changes via ACP** → your tooling can parse what Zero changed

---

### If You Build on Zero (Plugins, Integrations, Skills)

- **Skills with bundled files** → ship complete capabilities, not instructions
- **Plugin CLI enable/disable** → your users toggle features without config editing
- **ACP structured changes + browser metadata** → build tooling that understands code changes
- **Specialist lifecycle hooks** → react to subagent boundaries programmatically
- **OpenGateway live model list** → your integration sees new models automatically

---

## What's Still Missing (Honest Assessment)

- **Multi-user gateway** — Single-user per gateway; team workspaces = multiple gateways
- **Visual trace viewer** — W3C trace context emitted; no built-in UI to explore it
- **Plugin marketplace** — No centralized discovery/install beyond GitHub/npm
- **ACP authentication standard** — ACP transport auth still evolving
- **Mobile/remote UI** — TUI is terminal-only; no web/mobile client yet

## How to Upgrade

```bash
# Global install (recommended)
npm install -g @gitlawb/zero

# Verify
zero --version
# Should show 0.13.0

# First things to try after update:
# 1. List and resume a session via ACP
zero acp session list
zero acp session resume <id>

# 2. Attach to a live TTY command
# Run: zero run "start a long build"
# In TUI: attach to the TTY session → send keystrokes, detach, reattach

# 3. Escalate mid-run (if you have --allow-escalation)
zero --allow-escalation
# In TUI during a run: /model escalate claude-opus-5-5

# 4. Toggle a plugin
zero plugin enable <name>
zero plugin disable <name>

# 5. Try the self-exec sandbox
zero run --sandbox "write a test file"
# No helper binary needed

# 6. Check image attachment persistence
# Paste an image → resume session → summary still there
```

**v0.7.0 got newcomers through the door. v0.9–v0.13 built the house they live in.**

- **ACP sessions** = your work is portable, not disposable
- **TTY attach** = you see what the agent sees, live
- **Model escalation** = expensive reasoning only when you need it
