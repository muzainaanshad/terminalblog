## Feature 1: Keyboard-Driven Transcript Navigation — Finally, Edit-Mode for Conversations

**What it is:** Full keyboard navigation of your transcript with:
- **Word motions** — `Ctrl+Left/Right` (or `Option+Left/Right` on Mac)
- **Line motions** — `Up/Down` with context awareness
- **Page motions** — `Page Up/Down` for fast scanning
- **Integrated search** — `/` to search transcript, `n`/`N` for next/prev
- **Configurable shortcuts** — remap to your muscle memory

```bash
# In Codex TUI:
/search-term        # Search transcript
n / N               # Next / previous match
Ctrl+Left/Right     # Word-by-word
Page Up/Down        # Page-by-page
```

**Why it matters:** Before 0.166, long transcripts meant mouse scrolling or `j`/`k` line-by-line. Now: **navigate like Vim, search like less, jump like a pro**.

**For beginners:** This turns "where was that error message from 3 hours ago?" into `/error` → `n` → found. Muscle memory builds in one session.

## Feature 2: Consistent Markdown Rendering in Async UI

**What it is:** Async questions, choices, answers, and transcript replies now **all render Markdown consistently**. No more "why does this look different in the approval dialog vs the main chat?"

```markdown
# This heading
**This bold**
`This code`
- This list
> This quote
```

Renders identically whether it's a permission prompt, a choice dialog, an async answer, or the main transcript.

**Why it matters:** Visual consistency = cognitive load reduction. Your brain stops parsing formatting differences and starts reading content.

## Feature 3: GPT-6.1 Terra — Now on Vertex AI AND Amazon Bedrock

## Feature 4: `codex queue --resume` — Background Work That Survives Restarts

**What it is:** Queue a message, unload the thread, resume later with results intact.

```bash
# Queue a long-running task
codex queue "Refactor the entire auth module to use JWT"

# Thread unloads (saves resources)
# ... later ...
codex queue --resume  # Picks up where it left off
```

**Why it matters:** Long tasks (big refactors, test generation, doc writing) no longer block your session. Queue → walk away → resume with results.

**For teams:** This is the primitive for "agent as background worker" patterns. CI can queue, agent processes, results appear on resume.

## Feature 5: Clearer Safety Blocks + Selectable Safer Follow-Ups

**What it is:** When Guardian (Codex's safety system) blocks something, you now get:
- **Clear explanations** — why it was blocked, not just "blocked"
- **Selectable safer follow-ups** — one-click alternatives that avoid the issue

```bash
# Before: "Request blocked by safety system"
# After:
# "This request was blocked because it may generate credentials.
#  [Try: 'Show me how to rotate API keys securely']
#  [Try: 'Explain OAuth 2.0 flow for this API']
#  [Try: 'Generate a .env.example template']"
```

**Why it matters:** Safety blocks used to be dead ends. Now they're **teaching moments with escape hatches**.

## Feature 6: `codex doctor --network-only` — Focused Network Triage

**What it is:** A targeted diagnostic that checks only:
- Configuration validity
- Connectivity (DNS, TLS, proxy)
- WebSocket health

```bash
codex doctor --network-only
# Skips: disk, memory, plugin, marketplace checks
# Returns: network health in seconds, not minutes
```

**Why it matters:** Full `codex doctor` is comprehensive but slow. When you're debugging "why can't I connect?", you want **network answers now**.
