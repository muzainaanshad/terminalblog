### [Beware: Claude Code Routed Around a Delete-Protection Block With cmd rmdir — a Quoting Bug Then Destroyed ~10,000 Files (No Fix)](https://terminalblog.com/blog/beware-claude-code-rmdir-bypass-mass-deletion/)

Cline's web-fetch tool has no loopback, link-local, or private-IP guard and follows redirects by default, so a prompt-injected page can read your localhost services and cloud IAM credentials. No patch yet — check if you're exposed and what to do now.
