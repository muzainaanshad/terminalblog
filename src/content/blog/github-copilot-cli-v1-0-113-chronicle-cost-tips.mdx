**GitHub Copilot CLI v1.0.113 dropped November 16** — and it's the release that doesn't make headlines but makes you wonder how you lived without it. 100+ fixes. Chronicle cost tips that actually work. Session limit dialogs that don't wander. Vim mode that respects your paste. This is craft at scale.

---

## The One-Line Summary

**100+ fixes + Chronicle with real model recommendations + session dialogs that stay put + Vim paste fixed = the most polished terminal agent you're not using yet.**

---

## 1. Chronicle Cost Tips — Now With Real Evidence

### What changed
`/chronicle cost-tips` now:
- **Includes Copilot App sessions** (not just CLI)
- **Recommends cheaper models** based on *your actual usage patterns*
- **Suggests reasoning settings** that save money without quality loss
- **Reports sooner** when local usage data is available

### Why this matters
Before: generic advice like "try a smaller model."  
After: "You spent 40% of credits on `claude-sonnet-4` for simple edits — switch to `gpt-4.1-mini` for those and save ~$15/mo."

This is **personalized optimization**, not generic tips. Run it weekly. Watch the numbers drop.

---

## 2. Session Limit Dialogs Stay With Their Session

### The bug
Hit the AI credit limit in one session → limit dialog appears → switch to another session → dialog follows you, blocking input everywhere.

### The fix
**Dialogs now stay attached to their session.** Other sessions remain free for typing. Switch away, keep working, come back when ready.

Small fix. Massive flow preservation.

---

## 3. Vim Mode Paste Finally Works

### The paper cuts fixed
- **Pasted text position preserved** on `Esc` or `Ctrl+C` — no more cursor jumping to line start
- **Undo/repeat scoped to current draft** — `u` doesn't reach into previous messages
- **`Ctrl+Y` accepts completion** in popups (alongside `Tab`) — muscle memory respected

If you live in Vim mode, this release feels like someone finally *tested it*.

---

## 4. macOS Sandbox TCP Reality — Finally Documented

`copilot help sandbox` now tells the truth:

> **On macOS, sandbox host rules block direct TCP connections to local ports** (like a build client reaching its daemon). Localhost stays reachable **only through the local proxy** — HTTP or a CONNECT tunnel from a proxy-aware client.

No more guessing why your local server isn't reachable. The docs match the behavior.

---

## 5. Compact Failures Show Real Errors

A failed `/compact` now surfaces the **model provider's actual error message** — no more internal host-rethrow prefixes. Debugging context window issues just went from "guess" to "read the error."

---

## 6. Microsoft 365 Accounts Can Run Workflows

`copilot workflow run --help` now lists **Microsoft 365 accounts** alongside:
- Usage-based billing
- BYOK (custom model provider while signed out of GitHub)

Enterprise teams on M365: you're first-class citizens for workflow automation now.

---

## 7. The 100+ Invisible Fixes (Polish That Compounds)

| Area | What Got Fixed |
|------|----------------|
| **Sessions sidebar** | No more creating/switching sessions during CLI exit; exit summary resume commands stay valid |
| **Narrow terminals** | Settings editors, permission prompts, model picker, diff search — all keep content visible |
| **Copy/paste** | `/copy` keeps formatting in Word/Outlook/Teams; multi-message responses keep paragraph structure |
| **Unicode/emoji** | Paths, variable names, search cursors, LSP logs — all handle emoji and CJK correctly |
| **MCP** | Inspection commands warn when workspace config skipped; `copilot mcp get` reports unconfigured servers correctly |
| **Plugin manager** | Skips plugins with file-path catalogs (warning instead of killing all MCP servers) |

| **Subagent model picker** | Reopens for same agent after switching away; arrows visible in narrow terminals; no escape sequences in view |
| **Pasted text survival** | Policy-load delays no longer eat your paste — press Enter again, it sends correctly |
