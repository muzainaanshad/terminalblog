Zed **v1.24.1-pre dropped October 7**, and it's the kind of release that doesn't need a flashy blog post — it just removes friction you've been living with for months.

The headlines: **Git tag creation from the UI** (finally), **drag Terminal tabs into the Agent Panel** (so your terminal context travels with the agent), **Amazon Bedrock BYOK with configurable tool use**, **JSONL/NDJSON table previews**, **23% smaller Linux binaries**, and **faster startup**. Plus a mountain of bug fixes that stop paper cuts you hit daily.

If you've been on Zed stable (v1.22/v1.23) — this pre-release is the one to jump to. The Guild tests these internally before tagging. v1.24.1-pre is stable enough for daily use.

---

## 1. Git Tags Without Leaving the Editor

**New:** `git: create tag at head` command + **Create Tag…** context menu in Git History and Git Graph.

You've always been able to see tags. Now you can **create them locally** on any commit — lightweight or annotated — without dropping to the terminal. Tags don't push automatically (intentional), so you control when they go remote.

For beginners: this is the "I want to mark this commit as v1.0 before I push" workflow, now two clicks instead of `git tag -a v1.0 -m "Release"` + `git push origin v1.0`.

---

## 2. Terminal Tabs → Agent Panel: Context That Moves With You

**New:** Drag a Terminal tab directly into the Agent Panel.

Before: you ran a command, saw output, wanted the agent to act on it → copy/paste or retell the story. Now: **drag the tab**. The agent inherits the terminal's working directory, environment, and recent output as context.

This is the "agent as teammate" moment Zed has been building toward. Your terminal isn't a separate tool anymore — it's a context source for the agent.

---

## 3. Amazon Bedrock BYOK — With Configurable Tool Use

**New:** Custom Bedrock models now support configurable tool use, images, and thinking.

You bring your AWS credentials. Zed handles the rest. If your Bedrock model supports tools, images, or reasoning tokens — you toggle them on per-model. No more "Bedrock model X doesn't support tools in Zed" dead ends.

GovCloud regions work too (via Bedrock Mantle).

---

## 4. JSONL/NDJSON → Sortable, Filterable Tables

**New:** Open `.jsonl` or `.ndjson` files → **rendered as tables** with sortable columns, resizable columns, value-based filtering, right-click copy as JSON/CSV/TSV, virtualized rendering for millions of rows.

Your LLM streaming outputs, application logs, analytics exports, and dataset files just became browsable. Same engine that powers CSV/TSV/PSV/SSV previews — now extended to the JSON Lines formats every AI workflow produces.

---

## 5. Linux Binary: 23% Smaller, macOS: Finder Knows It's a Dev Tool

**Linux:** Release binary down ~23% on x86_64 (stripped debug symbols). Faster downloads, less disk, faster cold starts.

**macOS:** Finder now identifies Zed as a **developer tool** — proper grouping in Get Info, better Spotlight integration, the small platform polish that makes it feel native.

## 10. Breaking Changes (Know Before You Update)

- **Title-bar menus on Linux/Windows now require a click** (hover no longer opens). Enable `title_bar.open_menus_on_hover` to restore old behavior.
- **Close dock shortcut changed** from `cmd-w`/`ctrl-w` → `ctrl-alt-w` on all platforms (was closing active pane item by accident).
- **`terminal.path_hyphlink_regexes` inheritance changed** — top-level `"..."` now inserts inherited regexes. To keep old three-char regex, use `["..."]`.
- **Stopped importing VS Code `files.watcherInclude`** as `file_scan_inclusions` — watch roots ≠ Git-ignore overrides.
