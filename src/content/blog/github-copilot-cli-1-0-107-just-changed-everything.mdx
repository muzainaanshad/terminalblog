**GitHub Copilot CLI v1.0.107 landed November 6** — and this isn't just another patch. It's the biggest feature drop in weeks: **inline images in Rex terminals, a `/code` command to jump straight to VS Code, Fusion tier configuration, a unified settings dashboard with global search, opt-in session management tools, GPT-6.1 Terra model access, sandbox extensions, and over 100 fixes that remove daily friction.**

If you've been on v1.0.106, this is the update you've been waiting for.

---

## The Five Features You'll Actually Use

### 1. Rex Terminals: Inline Images Finally Work

**What it is:** Rex terminals (the modern terminal renderer) now display inline images using **Kitty direct placements**. No more "image saved to file" — you see the chart, diagram, or screenshot right in your terminal.

**Why it matters:** When your agent generates a Mermaid diagram, a chart, or analyzes an image, you see it instantly. No context switching. No file opening. It's just *there*.

```bash
# Before: "Image saved to /tmp/chart.png"
# After: The chart renders inline in your terminal
```

**For beginners:** If you use a modern terminal (Ghostty, WezTerm, Kitty, iTerm2, Windows Terminal), this just works. Your agent becomes visual.

---

### 2. `/code` Command — Open Any Session in VS Code Instantly

**What it is:** Type `/code` in any Copilot CLI session and it **opens that exact session in VS Code** with full context.

**Why it matters:** You're deep in a terminal session, need the full IDE power — debugging, multi-file editing, git UI. One command. No copy-paste. No "what was the file path?"

```bash
/code
# Opens VS Code at the session's working directory with the conversation context
```

**For teams:** Pair programming just got smoother. Terminal person types `/code`, VS Code person takes over. Same session. Same context.

---

### 3. Fusion Tier Setting in `copilot config`

**What it is:** You can now configure your **Fusion tier** (the model routing that picks the best model per task) directly in `copilot config` — no more environment variable juggling.

```bash
copilot config set fusion.tier high
# or: copilot config set fusion.tier max
```

**Why it matters:** Fusion High/Max gives you access to more capable models for complex tasks. Now it's a first-class config option, not a hidden env var.

---

### 4. Unified Settings Dashboard with Global Search (`/settings`)

**What it is:** `/settings` now opens a **unified dashboard for ALL users** (not just some) with **global search across settings AND local resources**.

**Why it matters:** 
- **Before:** Settings scattered across files, env vars, CLI flags. Finding "that one timeout setting" took 10 minutes.
- **After:** One dashboard. Search "timeout" → finds every timeout setting across sandbox, MCP, network, session. Search "github" → finds GitHub-related settings across auth, MCP, PR tools.

```bash
/settings
# Search box at top → type anything → instant results across ALL settings
```

**For beginners:** This is the "I don't need to memorize config paths" moment. The dashboard teaches you what's configurable.

---

### 5. Opt-In Session Management Tools + `@mentions` for Local Sessions

**What it is:** New opt-in tools let agents **manage sessions programmatically** — create, list, switch, delete — and `@mention` local sessions in prompts.

**Why it matters:** Your agent can now say "remember that debugging session from yesterday?" and actually pull it up. Session management becomes part of the agent's toolkit, not a manual CLI chore.

```json
// Enable in settings.json
{
  "sessionManagement": {
    "enabled": true
  }
}
```

---

## The Model News: GPT-6.1 Terra

**What it is:** **GPT-6.1 Terra** is now available as a selectable model under "New models" when your account has access.

**Why it matters:** Terra is optimized for coding — larger context, better reasoning on code tasks. If you have access, it appears in `/model` picker automatically.

---

## Sandbox Extensions — Run Extensions Inside the Sandbox

**What it is:** New setting: `sandbox.extensions` — run extension processes **inside the sandbox** instead of on the host.

**Why it matters:** Security. Extensions (linters, formatters, custom tools) now respect the same filesystem/network boundaries as the agent. No more "extension read my .env file" surprises.

```json
{
  "sandbox": {
    "extensions": true
  }
}
```

## The 100+ Fixes You'll Feel (Scannable)

### Session & Resume
- **No more 30-second stall** reopening recently closed local sessions — instant resume
- **`Ctrl+C` writes shutdown record before exit** — usage totals, code-change counts preserved
- **`/resume` foregrounds running background sessions** instead of duplicating them
- **Session picker closes immediately** after `/resume` commits
- **Resumed sessions keep unique shell IDs** — bash tool calls target correctly

### Input & Paste (Quality of Life)
- **Multi-line paste after `/ask`, `/clear`, `/delegate`, `/diagnose` keeps formatting** — indentation, line breaks intact
- **WSL clipboard copy fixed** — `clip.exe` now works with compatible cmd.exe arguments
- **Pasted Unicode separators (NEL, paragraph) fill separate prompt lines** — no more cutoff rows
- **Ctrl+V/Alt+V/Super+V paste when no attachment detected** — muscle memory works

### web_fetch & Encoding
- **web_fetch decodes declared charsets** (ISO-8859-1, windows-1252, XML declarations) — legacy pages render correctly
- **RSS/Atom/XML feeds decode via XML declaration** when server sends no charset

### MCP & Tools
- **Symlinked `mcp-config.json` preserved** on save — dotfile management intact
- **Hung HTTP MCP servers timeout once, not three times** — faster failure detection
- **Sandboxed local MCP servers respect relative permissions** from session directory
- **MCP Entra auth falls back to VS Code registration** when CLI preauth unavailable
- **Remote MCP servers showing bare 401 appear in auth picker** — you can sign in

### Windows & PowerShell
- **PowerShell works in long directory paths** — no more "path too long" crashes
- **Sandboxed sessions in nested Git dirs can write at repo root** on Windows
- **Keep winget launcher symlinks intact** on `copilot update`

### Accessibility
- **Screen reader mode: "Error:"/"Warning:" prefixes** on failed tool calls, unknown commands
- **Keypad arrows, Home, End, PgUp/PgDn work in Kitty protocol terminals** (Windows Terminal NumLock off)

### Agent Behavior
- **Autopilot stops implementing after review/analysis requests** — does what you asked, not what it guessed
- **Model request 404 under load retries** instead of "Execution failed: 404"
- **ACP clients can switch `--yolo` sessions out of autopilot** — allow-all stays on
- **Agent no longer suggests Shift+Tab to leave plan mode in `-p --plan`** — includes key points in reply instead

### Search & Navigation
- **`/search` keeps match in view** when opening — no jump to bottom
- **Up/Down/Enter in `/search`** bring single match back after scroll-away
- **Shorter terminals** no longer leave current match off-screen
- **@ file picker underlines Unicode matches** (İstanbul.txt with/without dotted I, decomposed accents)

### Configuration & Help
- **`copilot help config` lists EVERY setting** — including previously missing `askUser`, `effortLevel`, `planModel`, `toolSearch`, `worktreeBaseRef`
- **`copilot help billing` explains footer AI credits** and statusline items
- **`copilot help permissions` documents glob patterns** in write/read rules, lists read/memory kinds
- **`copilot config warns on wrong-type values** instead of silently ignoring settings.json
