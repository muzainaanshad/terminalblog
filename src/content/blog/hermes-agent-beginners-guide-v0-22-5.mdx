---

## Wait, What Is Hermes Agent?

Hermes is an **AI coding agent that runs fully local** on your machine. Built by Nous Research. No cloud dependency, no subscription, no data leaving your computer unless you explicitly configure it to.

Think: Claude Code or Cursor, but:
- Runs 100% offline (models run locally via Ollama, LM Studio, or your own endpoints)
- Plugin system that's actually extensible (not "here's 3 blessed integrations")
- You own the config, the data, the everything
- Free. MIT licensed.

It has a **Desktop app** (Windows/macOS/Linux), a **CLI**, and a **TUI**. Microsoft Store version exists. Docker images for servers.

## The 8 Things That Actually Change Your Daily Workflow

### 1. Sign-In No Longer Confuses You

**Before:** Free tier → guest mode → "wait, which account am I?" → connectors open guest sessions anyway.

**Now:** Every sign-in is the plain device login. Free tier hands over to your actual account cleanly. You see exactly who signed in. Connectors offer sign-in instead of opening a guest.

**Why it matters:** If you've ever lost work because you were in the wrong session — this eliminates that entire class of problem.

### 2. `hermes update` Finally Just Works

**Before (CLI):** `hermes update` would refuse a stable release it had already downloaded, or on Windows, get stuck on the old launcher after a Python version bump.

**Now:** It updates. Period. Windows launcher stays current.

**Why it matters:** Updating should be invisible. You run one command, you get the latest. No debugging the updater.

### 3. Windows Desktop: Drag-to-Pin + One-Click Plugin Installs

- Drag any chat to pin it in the sidebar (stays at top)
- Plugin installs are one click with tier badges (official / community / labs)
- Electron 44 under the hood = faster, more stable

**Why it matters:** Pinning your 3 active work chats saves ~10 clicks per session. Plugin discovery used to mean reading GitHub READMEs — now it's a catalog with badges.

### 4. Pluggable Delegation Backends = "Send Cheap Tasks to Cheap Models"

You can now configure: "Route subagent tasks matching *pattern* to *model/profile*." Switchable per session.

**Example:**
```
Main agent: Claude Sonnet 4 (smart, expensive)
Subagents for file edits: Gemma 2 9B (fast, cheap, local)
Subagents for research: Llama 3.1 70B (good reasoning, local)
```

**Why it matters:** Cost control without babysitting. Set the rules once. Hermes routes automatically.

### 5. Plugin Slash Commands Can Now Ask You Questions

Interactive prompts inside slash commands. No more editing YAML config files to change a parameter.

**Before:** Edit `.hermes/plugins/my-plugin/config.yaml` → restart Hermes → test.

**Now:** Type `/my-plugin` → it asks "Which model?" → you pick → it runs.

**Why it matters:** Plugins become usable for people who don't write TypeScript.

### 6. `hermes import-agent` Now Supports Cursor

Point Hermes at another agent's config directory. It imports: model settings, MCP servers, custom commands, keybindings. Cursor joins the existing importers.

**Why it matters:** Switching agents used to mean rebuilding your workflow from scratch. Now it's:
```bash
hermes import-agent --from cursor
```

### 7. `hermes mcp serve` — Hermes Becomes an MCP Server

Hermes can now *expose its tools* to other agents via MCP (Model Context Protocol). The Singularity backend moved out of core into a plugin.

**Why it matters:** You can run Hermes locally, then connect Claude Code / Cursor / Goose to it as an MCP server. Your local tools become available to cloud agents. The ecosystem connects.

### 8. Usage-Window Plan Support (Claude Daily Limits, etc.)

Plan gauges, limit cards, and **model-switch recovery** for window-based plans.

**Before:** You hit Claude's daily limit → error → you manually switch models.

**Now:** Hermes shows the gauge. When you hit the limit, it can auto-switch to your configured fallback model and keep working.

**Why it matters:** You stay in flow. The agent handles the quota management.

## How to Get Started (If You're New)

| Platform | Easiest Path |
|----------|--------------|
| **Windows** | Microsoft Store → search "Hermes Agent" → Install |
| **Windows (CLI)** | `irm nousresearch.com/hermes/install.ps1 \| iex` |
| **macOS/Linux** | `curl -fsSL nousresearch.com/hermes/install.sh \| bash` |

## Should You Switch from Cursor / Claude Code / Goose?

**Stay where you are if:**
- You're happy with your current workflow
- You need cloud sync across machines (Hermes is local-first; cloud sync is on the roadmap)
- Your team standardizes on a specific tool

**Try Hermes if:**
- You want **zero data leaving your machine** (privacy / compliance / air-gapped)
- You want to **run models 100% free locally** (Ollama + Gemma/Llama/Qwen = $0/month)
- You like **tinkering** — the plugin system lets you build custom tools, not just use blessed ones
- You want **one agent that can import the others' configs** — not start from zero
