Your agent can now **click, type, take screenshots, and drive browsers**. Not "generate code that clicks." Actually click. Actually type. Actually navigate a website and scrape what it sees.

## How to Get Started (5 Minutes)

### Option A: Copilot CLI (Terminal)
```bash
# 1. Update to latest
npm install -g @github/copilot-cli@latest
# Verify: copilot --version (should be 1.0.105+)

# 2. Start a session
copilot

# 3. Try a computer-use task
# "Open github.com in browser and take a screenshot of the homepage"
# "Go to my Linear board and move ticket ABC-123 to Done"

```

### Option B: Copilot App (Desktop GUI)
1. Download from [github.com/features/ai/github-app](https://github.com/features/ai/github-app)
2. Sign in with your Copilot account
3. Settings → **Computer Use** → Enable
4. Start a chat → ask it to do something on your desktop

## The Safety Model: Local Sandboxing (GA Since Oct 5)

Computer Use sounds scary — "the agent controls my mouse?" GitHub solved this with **local sandboxing**, now generally available:

| Protection | What It Does |
|------------|--------------|
| **File access limits** | Agent only reads/writes folders you approve |
| **Network controls** | Agent only reaches domains you allow |
| **Credential isolation** | Agent never sees your tokens, SSH keys, AWS creds |
| **Per-action approval** | You approve each click/type/screenshot before it happens |
| **Session scoping** | Sandbox resets between tasks — no persistent agent state |

```bash
# Configure sandbox in ~/.copilot/settings.json
{
  "sandbox": {
    "files": { "allow": ["~/projects/**"], "deny": ["~/.ssh/**", "~/.aws/**"] },
    "network": { "allow": ["github.com", "linear.app"], "deny": ["*"] },
    "developerTools": true  # allows npm, git, docker inside sandbox
  }
}
```

**You stay in control. The agent just has hands now.**

## The Catch (Honest Assessment)

- **macOS and Windows only** — no Linux support yet (WSL2 works)
- **Public preview** — expect rough edges, API changes
- **Not fully autonomous** — you approve each action (by design)
- **Screen resolution matters** — very high DPI can cause coordinate issues
- **No Android/iOS** — desktop only for now
- **Enterprise policies** — org admins can disable Computer Use entirely
