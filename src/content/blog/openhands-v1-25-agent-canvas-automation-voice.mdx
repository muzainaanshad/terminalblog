**OpenHands v1.25 dropped October 6.** The changelog reads like a greatest-hits album: voice dictation, native Git for automations, bulk LLM profiles, model router intelligence, Canvas app updates — plus 30+ fixes that plug the leaks you've been working around.

If you've been waiting for OpenHands to feel less like a demo and more like infrastructure — **this is the version.**

---

## 1. Your Agent Just Got a Voice

**New:** Microphone icon in the chat composer. Click, speak, done.

No more typing out "refactor this auth module to use the new middleware pattern" — say it. The browser handles speech-to-text, OpenHands handles the rest.

<details>
<summary>Why this matters for beginners</summary>

Voice input changes the *kind* of prompts you write. You naturally give more context when speaking ("Hey, can you look at the user service and add rate limiting like we discussed yesterday?") vs. typing ("add rate limiting to user service"). More context = better agent output.
</details>

Works in local and Cloud sessions. Requires browser mic permission (one-time).

---

## 2. Automations Finally Get Native Git

**Before:** Automations used issue-to-PR templates. You configured a template, the automation filled it, you got a PR. Rigid.

**Now:** Native Git integrations (GitHub, GitLab, Bitbucket) are offered *first* — before templates.

```
Automation runs → Detects repo → Offers "Create PR on GitHub" / "Push to GitLab" / "Sync to Bitbucket"
```

Plus:
- **Filter automations dashboard by creator** — see only *your* runs, or your team's
- **Templates shown on cloud backends** — parity between local and Cloud
- **Built-in integration offered before templates** — the happy path is now native

For teams running CI/CD automations — this removes the "which template?" decision fatigue.

---

## 3. Bulk LLM Profiles — Stop Adding Models One by One

**New in Settings → LLM Profiles:**
- **Bulk-add provider models** — select a provider, pick multiple models, create profiles in one shot
- **Per-connection bulk add** — if you have multiple API keys for the same provider (personal + team), bulk-add per connection
- **Model Router "Run at conversation start" toggle** — router classifies *before* the first message, not after

```yaml
# What this unlocks in practice:
# Before: Add GPT-4o → save → add GPT-4o-mini → save → add Claude-3.5 → save...
# After: Select OpenAI → check GPT-4o, GPT-4o-mini, o1-preview → "Create 3 profiles" → done
```

Credit: **@georgeglarson, @juanmichelini** across 3 PRs (#16426, #17723, #17797)

---

## 4. Canvas Apps Get Update Actions

Canvas (the agent UI framework) now has **Update action for installed apps**.

```bash
# User sees in Canvas:
# "Update available for Code Review Agent v2.1 → v2.3"
# One click → updated, no re-install, config preserved
```

Also:
- **Streaming slots retired** — event-id-based reconciliation replaces text-matching (faster, fewer glitches)
- **SVG icons from manifest** — your custom agents show their actual icon, not a generic puzzle piece
- **Real tab semantics in conversation drawer** — keyboard navigation works properly

Credit: **@VascoSch92** across 4 PRs (#17465, #17736, #17877, #17612)

---

## 5. Model Router Gets Smart Defaults

- **Auto-enable "Run on first message"** when first router created — no manual toggle hunting
- **Preselect router classifier model** so it's created even when no profiles exist
- **Flash template prompt completed** + model table injected
- **Default routers renamed:** "OpenHands Router Pro" / "OpenHands Router Flash" (clearer than generic names)

The router now *works out of the box* instead of requiring a setup ritual.

---

## 6. Settings Search + Per-Conversation Prompt History

**Settings search:** `Ctrl+F` (`Cmd+F` Mac) in left rail → filters every setting, grouped by category, jump-to-tab. The shortcut shows as a keycap.

**Per-conversation prompt history (experimental):** Each conversation keeps its own input history. Up-arrow in chat A doesn't show prompts from chat B.

Small UX wins that compound daily.
