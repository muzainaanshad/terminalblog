Plus: the model catalog got a full refresh with **Claude Haiku 5.5 as the new default** across most providers.

## 1. SSH Remotes: The v0.0.38 Regression Is Fixed

**The bug:** Since v0.0.38 (late August), connecting to an SSH environment failed with:

```
SyntaxError: Invalid character
```

**The fix:** v0.0.45 restores SSH remote connections. If you've been stuck on v0.0.37 or using workarounds — **update now**. Your remote dev workflows work again.

---

## 2. Git Branch Label: From Fork Bomb to Reasonable

**The bug:** The git branch label in the UI would open **two new SSH logins every 5 seconds** just to check the branch. On a remote server, this meant dozens of orphaned SSH sessions piling up.

**The fix:** Polling interval changed from **5 seconds → 30 seconds**. Switching branches from the picker still updates immediately. Your SSH server (and your session limit) will thank you.

---

Cline refreshed the entire model catalog. The big change: **Claude Haiku 5.5 is now the default model** for:

- DevPass (LLM Gateway)
- Eden AI
- GitHub Copilot
- LLM Gateway

- OpenCode Go
- Requesty
- Vivgrid

**Why beginners care:** Haiku 5.5 gives you **1M context at Haiku prices** ($0.10/$0.50 per M tokens). For everyday coding — file edits, quick refactors, test generation — it's faster than Sonnet, cheaper than Opus, and capable enough for most tasks. You get more context for less money without changing a setting.

---

## 4. Reasoning Toggle: No More 400 Errors on New Models

**Before:** Turning reasoning **off** on GPT-6 Astra, GPT-6.1 Sol, Claude Fable 5, or Claude Opus 5.5 threw a `400 Bad Request`.

**Now:** The reasoning toggle works correctly on all new models. You can disable reasoning for faster/cheaper responses without hitting API errors.

---

## 5. Background Service: Stops Crashing When MCP Servers Quit Early

**The bug:** If an MCP server or hook quit before reading all its input (stdin), the background service would crash ~3 seconds later. This took down your agent session silently.

**The fix:** The background service now handles early MCP/hook exits gracefully. No more "why did my agent just disappear?" moments when a tool misbehaves.

---

## 6. VS Code Settings Migration: Clean Provider List

**Before:** Migrating settings from the VS Code extension added an **empty "SAP AI Core" provider** to your list — clutter you didn't ask for.

**Now:** Migration skips empty providers. Your provider list stays clean.
