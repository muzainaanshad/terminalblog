Zed v1.21.0 landed September 23, and it's the release that finally answers the question everyone's been asking: **"Can I use the newest frontier models without juggling API keys?"**

The answer is now **yes**. BYOK (Bring Your Own Key) support for **GPT-6 Astra, GPT-6 Sol, GPT-6 Luna** and **Claude Opus 5.5** means you paste your Anthropic or OpenAI key once, and the newest models just work — inside the editor you already use.

Plus: **SuperGrok sign-in** lets Grok subscribers use Grok models directly. No API key dance.

---

## 1. GPT-6 Astra, Sol, and Luna — First-Class, Zero Friction

OpenAI's newest model family is now in Zed's model picker:

| Model | What It's For |
|-------|---------------|
| **GPT-6 Astra** | The flagship — reasoning + coding + everything |
| **GPT-6 Sol** | Deep reasoning, complex problem solving |
| **GPT-6 Luna** | Speed-optimized, everyday coding |

If you have a **ChatGPT Plus/Pro subscription**, you already have access. Paste your OpenAI API key in Settings → AI → Providers, and all three appear instantly. No separate dashboard, no waitlist, no "contact sales."

**For beginners:** this is huge. You've been reading about GPT-6 Astra in [Codex 0.154](/blog/codex-0-154-gpt6-astra-worktrees-windows-daemon/) and [Goose v1.50](/blog/goose-v1-50-gpt6-astra-web-search-security-wave/). Now you can use it in a *real editor* with inline diffs, multi-file context, and the language server integration Zed is known for.

---

## 2. Claude Opus 5.5 — 1M Context, BYOK Ready

Anthropic's latest flagship — **1 million token context window** — is now a first-class option in Zed.

Same flow: Settings → AI → Providers → paste your Anthropic key → Opus 5.5 appears alongside Sonnet and Haiku.

This matters because Zed's agent panel can now feed *entire codebases* into Opus 5.5's context window. The "which files do I include?" dance disappears when the model can hold your whole project.

---

## 3. SuperGrok Sign-In — Grok Models Without API Keys

If you're a **SuperGrok subscriber** (X Premium+), you can now sign in directly and use Grok models in the Agent Panel. No API key generation, no separate billing, no "wait, which key goes where?"

Just click "Sign in with SuperGrok" and you're live. This is the first major editor to ship native Grok integration for subscribers.

---

## 4. The Quiet Features You'll Use Daily

### `agent.prevent_idle_sleep` (enabled by default)
Your agent is running a long task. You step away. Your laptop tries to sleep. **Zed now keeps the system awake** while agent threads are running. No more coming back to a stalled session because the OS decided to nap.

### Language Server Command Picker
Language servers can now open files and URLs via `showDocument` requests. Run a "Go to Definition" from an LSP result, and Zed opens it. Run a code action that links to docs, and it opens in your browser. The LSP ↔ editor handshake finally works the way the spec intended.

### Markdown Code Block Rendering — Actually Fast
Rendering performance for Markdown code blocks in the Agent Panel, hover popovers, and Markdown preview got a serious optimization pass. If you've ever hovered over a code block and watched the UI stutter, that's fixed.

### Agent Thread Rename Action
Right-click any agent thread → "Rename." Finally. Your "debug auth flow" thread no longer sits next to "refactor user service" with the same generic name.

- **macOS traffic light animation** fixed when exiting fullscreen

- **Font suggestions stop listing unavailable fallbacks**
