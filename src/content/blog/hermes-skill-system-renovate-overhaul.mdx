Hermes's skill system just got a major overhaul. The `skills-renovate` branch touches nearly every part of the skill infrastructure — loading, caching, validation, dependency resolution, and cross-skill references.

## What Changed

The skill system is how Hermes extends its capabilities. Skills are SKILL.md packages that bundle instructions, scripts, templates, and capabilities. The renovation makes them:

**Faster to load** — Skill compilation is now cached. Previously, every skill was parsed from scratch on each load. Now compiled skill artifacts persist, making subsequent loads near-instant. Cold start for a profile with 20+ skills dropped from ~2.3s to ~400ms in local benchmarks.

**Validated on install** — Skills now go through a validation pipeline: frontmatter parsing, script existence checks, template verification, and capability declaration validation. Bad skills fail early with clear error messages instead of cryptic runtime crashes.

**Dependency-aware** — Skills can now declare dependencies on other skills. The resolver handles transitive dependencies, deduplication, and version constraints. This means a "React debugging" skill can depend on a "TypeScript utilities" skill, and Hermes handles the wiring.

**Cross-referenced** — Skills can reference tools, hooks, and types from other skills. This enables composable skill workflows where one skill builds on another. For example, a code-review skill can invoke the linting skill's tools directly.

## Why This Matters

The skill system is Hermes's answer to extensibility. While OpenCode and Mimo also use SKILL.md, Hermes's skill system is more sophisticated — it has hooks, lifecycle events, and now dependency management. This renovation makes it production-grade.

With the old system, skills were isolated packages that couldn't reference each other. The renovation transforms skills from standalone scripts into a composable ecosystem. Third-party skills can now build on community foundations.

## Technical Details

The renovation touched these core files:
- `packages/skills/src/skill-loader.ts` — caching layer with content-addressable storage
- `packages/skills/src/validator.ts` — multi-stage validation pipeline
- `packages/skills/src/resolver.ts` — dependency graph resolution with cycle detection
- `packages/skills/src/registry.ts` — cross-skill reference resolution

Migration is automatic for existing skills — the new loader detects legacy formats and upgrades them on first load.

## What's Next

The foundation is laid for a skill registry where users can discover, install, and publish skills. Renovate is phase 1 — the plumbing. Phase 2 will be the marketplace experience with search, ratings, and dependency-aware installation.
