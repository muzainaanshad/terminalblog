Codex shipped **two major milestones in two weeks**: **v0.155.0 stable (Sep 17)** — the first stable release since v0.99.0 in February — followed by the **v0.162.0-alpha wave (Sep 18–Oct 2)** with seven alpha releases. Together, they form the biggest feature wave since the Rust rewrite.

If you've been waiting for Codex to feel like a daily driver — **this is the release cycle.**

---

## 1. Guardian Review — The Agent That Actually Listens (v0.155.0)

**Guardian** is a new opt-in capability that lets the agent **retrieve earlier user instructions and context from agent handoffs**.

In practice: you're in a session. You explain your project structure, your coding standards, your "don't touch this file" rules. The agent acknowledges. Three turns later, it forgets half of it. With Guardian enabled, it can pull that context back when it matters.

**For beginners:** this is the first time a terminal agent treats conversation history as a *first-class retrieval target* — not just a scrolling log you have to read yourself.

Enable it in Settings → Guardian → "Retrieve conversation history." It's opt-in because it sends relevant history snippets to the model — you control when that happens.

---

## 2. Agent Command Center — Browse Older Tasks Without Scrolling Forever (v0.155.0)

The TUI's agent command center (the dashboard you get with `Ctrl+A` or the sidebar) now has a **keyboard-accessible "Show more" action** for browsing older tasks.

Before: you scrolled. And scrolled. And scrolled.
Now: paginated history, keyboard navigation, and you can actually find that task from Tuesday without RSI.

---

## 3. TUI Finally Remembers Your Settings (v0.155.0)

Three persistent annoyances, fixed in one release:

| What Used to Happen | What Happens Now |
|---------------------|------------------|
| Provider reset to default on restart | **Server provider preserved** across sessions |
| Reasoning summary lost | **Reasoning-summary setting persists** |
| Verbosity reset every launch | **Verbosity setting persists** |
| Resume/fork history showed wrong sessions | **Correct sessions shown** in resume and fork history |

For beginners: you configure your workflow *once*. It sticks. This is table-stakes UX that terminal agents have been missing.

---

## 4. Windows Sandbox — PowerShell Fallbacks and No More Ghost Console Windows (v0.155.0)

If you run Codex on Windows, v0.155.0 is the release that makes the sandbox **actually usable**:

- **Compatible PowerShell fallback** for the MXC sandbox — no more "raw mode not supported" crashes when input is piped
- **Long-path permission repairs** — Windows paths >260 chars no longer break sandbox operations
- **Background console windows suppressed** — those annoying flash windows from helper processes are gone
- **Windows sandbox ACL repair for long runtime paths** — the sandbox now understands actual Windows filesystem semantics

The net effect: `codex` on Windows feels like a first-class citizen, not a port with paper cuts.

---

## 5. SQLite Background Reclamation — Your Disk Space Thanks You (v0.155.0)

Codex's local log database (SQLite) now **reclaims unused space in the background** automatically.

If you've been running Codex for months, your `~/.codex` directory probably grew silently. This release adds a background vacuum that shrinks the database without you doing anything.

---

## 6. Subagents Keep Their Environment (Even While Starting) (v0.155.0)

Subagents now **retain environments that are still starting** and receive their configuration or preparation failure instead of silently inheriting a broken state.

Translation: when you spawn a subagent for a parallel task, it won't start with a half-initialized environment and then fail mysteriously. It waits for readiness or tells you exactly why it couldn't start.

---

## 7. Experimental Voice Conversations — Talk to Your Agent (v0.162.0-alpha)

**v0.162.0-alpha.9.2 (Sep 18)** adds experimental `/voice` conversations with **live transcripts and microphone controls** on supported builds, enabled through `/experimental`.

This is full-duplex audio streaming — you speak, the agent replies in real time. Not a text-to-speech gimmick. The TUI shows live reasoning summaries in the status row and completion timestamps after successful turns.

For beginners: this is the first open-source terminal agent with native voice. If you've used ChatGPT's voice mode and wished your coding agent had it — Codex now does.

---

## 8. Task Hiding, Archiving, and Deletion in Agents Overview (v0.162.0-alpha)

The agents overview now supports:
- **Hide** tasks you don't need to see
- **Archive** completed work (keeps history, clears active view)
- **Delete** clean managed worktrees with confirmed deletion
- **Worktree ownership details** shown per task

Your agent dashboard is now manageable, not a graveyard of every session you've ever run.

---

## 9. Touch ID Verification for MCP Requests (v0.162.0-alpha)

On supported Macs, **MCP requests can now use Touch ID** for verification in local TUI sessions.

No more typing passwords or approving in a separate window. Finger on sensor → request approved. This is the UX that makes MCP feel native on macOS.

---

## 10. Configurable Daemon Update Schedules (v0.162.0-alpha)

- **Daemon update schedules** are now configurable
- **`codex app-server daemon update`** command for manual trigger
- **Saved threads and active goals can recover after daemon restarts**

If you run Codex as a background service (CI, remote server, always-on daemon), this is the ops feature you've been waiting for.

---

## 11. Amazon Bedrock Credential Commands (v0.162.0-alpha)

Bedrock can now obtain AWS credentials from **configured commands**, with:
- Caching
- Expiration-based refresh
- Authentication recovery

No more manual `aws configure` juggling for Bedrock users.

## How to Update

```bash
# Stable (v0.155.0)
npm install -g @openai/codex@0.155.0

# Alpha (v0.162.0-alpha.8) — for voice, task mgmt, Touch ID
npm install -g @openai/codex@0.162.0-alpha.8

# Or via the installer (auto-updates)
# macOS/Linux
curl -fsSL https://codex.openai.com/install | bash

# Windows (scoop)
scoop update codex

# Verify
codex --version
# Should show 0.155.0 (stable) or 0.162.0-alpha.8 (alpha)
```

**To enable Guardian:** Settings → Guardian → "Retrieve conversation history"
**To enable Voice (alpha):** `/experimental` → enable voice → `/voice`
