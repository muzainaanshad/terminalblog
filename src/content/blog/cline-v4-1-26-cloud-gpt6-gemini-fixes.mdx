## The Cloud Workflow Upgrades (The Headline)

### 1. Local | Cloud Model Toggle in Settings

**What it is:** When **cloud sessions are enabled**, **Settings > API Configuration** now shows a **Local | Cloud toggle**.

**Why it matters:** Cloud tasks run on a **different model than your local work**. You pick the cloud model *once*, saved separately. Your local model stays whatever you want.

```bash
# Before: One model for everything. Cloud used your local pick.
# After: Toggle → Cloud model picker → saved independently
# Local: Claude Sonnet 5.5 (your daily driver)
# Cloud: Kimi K3.1 Pro (cheap, fast, good enough for sandbox tasks)
```

**Click the model label in a cloud session's composer** → opens the cloud model picker right there. No context switching.

---

### 2. Cloud Sandbox Progress Card

**What it is:** Starting or resuming a **cloud sandbox shows a progress card** with:
- Repository
- Branch
- Steps: **Start sandbox → Clone repository → Start agent**

**Why it matters:** You *see* what's happening. No more "is it stuck?" guessing. Card collapses once the agent starts.

---

### 3. Cloud Sessions Hide Plan/Act Toggle & Auto-Approve Bar

**What it is:** In cloud sessions, the **Plan/Act toggle and auto-approve bar are hidden** (not shown disabled).

**Why it matters:** Cloud tasks run autonomously. The UI doesn't tease you with controls that don't apply. Cleaner mental model.

## The Model Compatibility Fixes (The "It Finally Works" Features)

### 4. GPT-6 Models Work on OpenAI / Azure / SAP AI Core

**What it is:** **GPT-6 models (`gpt-6-sol`, `gpt-6.1-sol`)** now work on:
- **OpenAI** endpoints
- **Azure OpenAI-compatible** endpoints
- **SAP AI Core** — no longer rejects with `"Unsupported parameter: 'max_tokens'"`

**Why it matters:** Both now use **`max_completion_tokens`** (the new parameter). If you've been blocked on GPT-6 because your endpoint rejected `max_tokens` — unblocked.

```bash
# Before: SAP AI Core → 400 "Unsupported parameter: 'max_tokens'"
# After:  max_completion_tokens sent → works
# Azure OpenAI: same fix
```

---

### 5. Gemini Provider: Native Google Search Disabled (Stops 429 Quota Errors)

**What it is:** **Gemini API keys (the `gemini` provider) no longer send native Google Search.**

**Why it matters:** This was a **silent killer**:
- **Free-tier keys:** Every turn → 429 quota error on Gemini 3+
- **Gemini 2.x:** Every Cline tool call → dropped because Search quota exhausted

**v4.1.26 fix:** Native Search disabled for `gemini` provider. You get the model. You don't get the hidden Search calls eating your quota.

```bash
# Before: gemini provider → every turn includes Search → 429 on free tier
# After:  gemini provider → no Search → quota lasts, tools work
# Note: If you WANT Search, use a provider that supports it explicitly (e.g., Vertex AI with Search enabled)
```

---

### 6. Kimi K3 Gets `max` Reasoning for Extra High / Max

**What it is:** **Kimi K3** now gets **`max` reasoning** for **Extra High** and **Max** effort levels (instead of `xhigh` which it rejected).

**Why it matters:** Kimi K3's reasoning levels are particular. `xhigh` = rejected. `max` = accepted. Now mapped correctly.

## The UX Bug Fixes (The "Stop Annoying Me" Features)

### 7. Plan/Act Toggle Race Condition Fixed

**What it is:** **Toggling Plan/Act while a task is starting** no longer:
- Drops your first prompt
- Keeps the session running with the other mode's tools

**Why it matters:** You click Plan → Act → Plan fast while Cline spins up. Old behavior: prompt lost, wrong tools active. New behavior: **toggle waits for task start to settle.**

---

### 8. Disabled Rules Stay Disabled

**What it is:** **Disabled rules stay disabled.** Period.

**Why it matters:** You disable a rule (e.g., "always run tests"). It used to re-enable silently. Now: **off means off.**

---

### 9. Starting a Command No Longer Steals Keyboard Focus

**What it is:** **Starting a command no longer moves keyboard focus into the terminal.**

**Why it matters:** You're typing in chat. Cline starts a terminal command. **Your typing stays in chat.** No more "why is my message in the shell?"

---

### 10. Cancelling Task During Question No Longer Hijacks Next Message

**What it is:** **Cancelling a task or opening another one while Cline is asking a question** no longer lets **your next message get taken as the answer to the old question.**

**Why it matters:** Cline asks "Continue?" You cancel. You type "new task." Old behavior: "new task" sent as answer to "Continue?" New behavior: **question context cleared on cancel.**

---

### 11. Connection Drop After Reasoning-Only Stream → Retry, Not End Task

**What it is:** A turn whose **connection drops after the model has streamed only reasoning** is now **retried instead of ending the task.**

**Why it matters:** Reasoning streams can be long. Network blip at minute 3? Old: task dead. New: **retry from where it left off.**

---

### 12. Auto-Compaction Loops Fixed

**What it is:** Two auto-compaction fixes:
- **No longer runs for models with unknown context limit** (was crashing/looping)
- **No longer runs again every few tool calls after first compaction** (was re-compacting aggressively)

**Why it matters:** Auto-compaction used to go rogue on unknown models or after first run. Now: **once, correctly, or not at all.**

---

### 13. `ask_question`: Model Keeps Going, Empty Answers Rejected

**What it is:** `ask_question` tool behavior fixed:
- **Model keeps going after you pick an option** (doesn't stall waiting for more input)
- **Empty answers are rejected** (no more blank submissions)

---

### 14. `run_commands`: Empty List = Error, PowerShell Gets Quote Guidance

**What it is:** `run_commands` with **empty command list returns an error** (not silent success).

**PowerShell bonus:** Tool tells the model **how quote escaping works** and **to confirm recursive deletes first.**

---

### 15. Task Header Badges Wrap (Close Button Visible), GitHub Check Stops Flashing, Toggle Padding Fixed

**What it is:** Three UI polish fixes:
- **Task header badges wrap** → close button never hidden
- **GitHub connection check** no longer flashes loading indicator
- **Local/Cloud toggle padding** fixed
