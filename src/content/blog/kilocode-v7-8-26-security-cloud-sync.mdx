## Agent Manager: Continue Local Worktrees in the Cloud

The headline feature: **Agent Manager now bridges local ↔ cloud seamlessly.**

### How It Works

1. You're working in a local worktree (git worktree, not just a branch)
2. Open Agent Manager → see the worktree listed
3. Click **"Continue in Cloud"**
4. Kilo:
   - Validates the branch
   - Syncs open conversations
   - Opens a cloud workspace in browser (or gives you the link)
   - Retries balance/partial-creation failures automatically

```markdown
# Real scenario

You're on a plane, working in a local worktree `feature/payment-refactor`.
Landing → open laptop → click "Continue in Cloud" → 
full conversation history, open files, agent context → 
pick up exactly where you left off on a cloud GPU instance.
```

### Why Worktrees (Not Just Branches)

Git worktrees = **isolated working directories** sharing the same `.git`. Each worktree:
- Has its own checked-out files
- Runs its own agent sessions
- Maintains independent conversation history

Agent Manager now treats each worktree as a **first-class sync unit** — not just "the repo."

## OpenShell-Ready Docker Image: `ghcr.io/kilo-org/kilocode:<version>-openshell`

For teams running **OpenShell** (the open-source sandbox/orchestration layer):

- Kilo's own sandbox **disabled** (OpenShell handles it)
- Model catalog fetch **skipped** (OpenShell blocks it)
- Cloud session upload/presence **disabled**
- Drop-in replacement for OpenShell workloads

```dockerfile
# Your Dockerfile
FROM ghcr.io/kilo-org/kilocode:v7.8.27-openshell
# No Kilo sandbox config needed
# No model catalog config needed
# Just works inside OpenShell
```

## Quick Start: Try the Cloud Worktree Sync

```bash
# 1. Update Kilo
kilocode update  # or your package manager

# 2. Create a worktree for a feature
git worktree add ../my-feature-worktree feature/payment-refactor
cd ../my-feature-worktree

# 3. Open Kilo, do some agent work
kilocode

# 4. Open Agent Manager (Cmd/Ctrl+Shift+P → "Kilo: Open Agent Manager")
# 5. Click "Continue in Cloud" on your worktree
# 6. Opens browser → cloud workspace with full conversation history
```
