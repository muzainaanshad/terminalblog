OpenClaw **v2026.8.33** landed September 29, and it's not the flashy flagship release — it's the **gateway-only `extended-stable`** line. Think of it as OpenClaw's LTS: the version you run in production when you want the bleeding edge to settle down.

The current latest is [v2026.9.6](/blog/openclaw-v2026-9-6-massive-release-2614-prs/) (2,614 PRs, 351 contributors). v2026.8.33 is the *stable* branch — end of August 2026 code, plus critical security updates, reliability fixes, and flagship model support backported.

## 1. What "Extended Stable" Actually Means

OpenClaw has two release tracks:

| Track | Cadence | Purpose |
|-------|---------|---------|
| **Mainline** (e.g., v2026.9.6) | Monthly-ish | Latest features, newest models, fastest iteration |
| **Extended Stable** (e.g., v2026.8.33) | As needed | Hardened build for production, backported security, LTS support |

v2026.8.33 normalizes OpenClaw, all publishable plugins, and native version metadata to 2026.8.33 while retaining the release-line-compatible publication workflows from 2026.8.2.

**For beginners:** If you're running OpenClaw in a team, on a server, or anywhere "it just works" matters more than "I have the absolute newest model today" — this is your track.

## 2. Flagship Models Backported — You Don't Lose the New Stuff

The extended-stable line doesn't mean "old models." v2026.8.33 adds:

| Model | Provider | Why It Matters |
|-------|----------|----------------|
| **Meta Muse Spark 1.3** | Meta | Latest open-weight reasoning model |
| **Anthropic Fable 5.1** | Anthropic | 1M context, deepest reasoning tier |
| **OpenAI GPT-6 Astra** | OpenAI | New default for ChatGPT subscribers |
| **OpenAI/fal GPT Image 2.5** | OpenAI/fal | Image generation/editing in-agent |

**Complete GPT-5.6 family preserved:** Sol, Terra, and Luna catalog, routing, migration, image, vision, and thinking behavior — including Ultra reasoning across model-runtime boundaries and Bedrock tool-result images.

You get the models *and* the stability. That's the pitch.

## 3. Extended-Stable Security Rollup — The Quiet Work That Matters

This is the part most release notes skip but production teams read first:

- **Reconciled all repository advisories** affecting 2026.8.2
- **Hardened Prometheus metrics authorization** — reject metric scrapes lacking configured operator-read scope
- **Discord asset/voice ownership hardened** — preserve speaker and playback ownership across voice lifecycle transitions
- **Cleared production Nodemailer advisory gate** — override IMAP dependency graph to Nodemailer 9.1.1, clearing address-parser denial-of-service

**Anthropic reasoning continuity** preserved through model switches and runtime events — your Fable 5.1 thinking blocks don't evaporate mid-session.

**OpenAI discovery** now requires successful model discovery before offering GPT-6 Astra through OAuth — no more phantom models in the picker.

**Doctor skill state** preserves explicitly enabled skills during automatic updates.

**Generated media** retains generated images when a later tool call fails — your artifacts survive agent hiccups.

**Matrix verification** refreshes verification state before reporting device trust.

**Discord media policy** enforces sender media policy for guild asset uploads.

**Discord consult cancellation** records host-cancelled realtime consults as cancellation, suppresses generic error fallback, keeps voice session ready.

## 4. The macOS Crash Context — Why This Track Exists

Remember the v2026.9.6 macOS crash? The initial DMG hard-crashed on launch (#156861). The team rebuilt and notarized a fixed DMG within hours.

**Extended stable exists so that doesn't happen to you.** The mainline moves fast; things break. Extended stable is where the dust settles.

If you installed the earlier 2026.9.6 DMG and it doesn't launch — delete it and download the current one. The npm package (`npm i -g openclaw`) was never affected.

## How to Update

**Extended Stable (this release):**
```bash
npm i -g openclaw@extended-stable
# or specify version
npm i -g openclaw@v2026.8.33
```

**Mainline (latest):**
```bash
npm i -g openclaw@latest
# or
openclaw upgrade
```

**Docker:**
```bash
# Extended stable
docker pull openclaw/openclaw:v2026.8.33

# Mainline
docker pull openclaw/openclaw:v2026.9.6
```

**macOS Desktop (Extended Stable):**
Download from [GitHub Releases](https://github.com/openclaw/openclaw/releases/tag/v2026.8.33) — look for the `extended-stable` tag.

That's the release worth paying attention to if you run agents in anger.
