Hermes Agent **v0.23.1** landed today (Nov 10). It's a patch release, but it fixes something that affected **every plugin user** since November 9.

## The Bug That Broke Plugin Installs

Since the plugin catalog's site deploy on Nov 9, the published `plugin-catalog.json` exceeded the **2 MiB cap** that clients accept. 

Result: every `hermes plugins install <name>` silently fell back to the catalog your release shipped with. You couldn't find plugins added since your last update. You got the pinned version instead of the current one. Newer `removed` entries were missed entirely.

**v0.23.1 raises the cap to 16 MiB** — the live catalog works again. ([#151860](https://github.com/NousResearch/hermes-agent/pull/151860), fixes [#151856](https://github.com/NousResearch/hermes-agent/issues/151856))

> If you're on v0.23.0 or older: you're still falling back. Update to get the live catalog.

## What Else Is in This Patch

This rolls up **~618 PRs** (2,578 commits, 2,781 files changed) since v0.23.0. Full curated notes ship with v0.24.0, but highlights from the window:

**Plugin system:**
- Auto-update switch (CLI, chat, Desktop, dashboard) — held-back updates that would break your setup
- Catalog grew from ~600 to **1,050+ entries** (~270 new listings)
- Verified tier for vendor-built plugins
- `hermes plugins update` updates everything at once

**Desktop & Webapp:**
- Your full Desktop workspace now opens in a browser tab (served by your gateway)
- Every machine you run Hermes on connects in one Desktop window
- Group Chats with bot routing, scheduled jobs, shared notes

**Terminal:**
- Inline images in CLI/TUI (real pixels in Kitty/Ghostty, colored blocks elsewhere)
- Rewind conversations: press Esc twice or `/rewind`, pick a message, edit and resend or fork

**Core:**
- One gateway owns every conversation — CLI, TUI, Desktop, editors, bots, cron all attach as clients
- Pluggable delegation (install `advanced-delegation` to route subagents to specific models/profiles)
- Price tags + spend limits for paid MCP tools
- Leaner built-in skills (58 → 44, Office merged into one)
- `hermes curator lock` stops the agent from rewriting your curated skills
- Password managers + keychain vault key

## Upgrading

```bash
# CLI
hermes update

# Or re-run the installer one-liner

# Docker / Hermes Cloud
docker pull nousresearch/hermes-agent:stable
```

Microsoft Store app updates through the Store. Desktop installer (.exe/.dmg) updates with the next bundled release.

## Why This Matters

v0.23.0 ("Hearth Release") was massive — 10K commits, 1,950 PRs, 850 issues closed, 666 contributors. v0.23.1 is the first patch on top of it, and it fixes the one thing that broke for everyone: **plugin discovery**.

If you use Hermes plugins at all, update today.
