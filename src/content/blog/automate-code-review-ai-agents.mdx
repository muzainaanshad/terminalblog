## FAQ

**Which AI coding agents can run automated code review on a schedule?**
Hermes Agent has native cron support and is the most capable for scheduled automation. Alternatives include CodeRabbit (hosted GitHub App, free tier available), PR-Agent by Codium (open source, runs via GitHub Actions or CLI), and Claude Code's `/review` command (manual invocation only). The key difference: Hermes runs on your infrastructure with full control; CodeRabbit is hosted; PR-Agent requires more setup but is self-hosted.

**Will automated code review replace human reviewers?**
No — and it shouldn't try to. Automated review catches the obvious issues (security, test coverage, functionality) so humans can focus on architectural decisions, design tradeoffs, and context-dependent judgment. In practice, automation catches ~30% of issues that would require a human re-review cycle; the remaining 70% genuinely benefit from human discussion.

**What's the false positive rate for AI code review?**
With a well-tuned prompt (including "if the code looks clean, say so"), false positive rates drop to ~8-10%. Without that instruction, agents tend to find issues everywhere (~40% false positive rate). Severity labeling (critical/warning/nit) and easy dismissal tracking are essential — if the same pattern gets dismissed repeatedly, remove it from the checklist.

**Can I run this on private repositories without sending code to a third party?**
Yes, if you use Hermes Agent (self-hosted) or PR-Agent (self-hosted via GitHub Actions). CodeRabbit sends diffs to their service. For regulated environments or proprietary codebases, self-hosted options keep your code on your infrastructure. Hermes with local models via Ollama is fully air-gapped.

**How long does it take to set up automated code review?**
An afternoon for the initial setup with Hermes or PR-Agent. CodeRabbit integrates in minutes. Plan 1-2 weeks of tuning the prompt on your own PRs before rolling out to the team — most teams need this tuning period to get the signal-to-noise ratio right.
