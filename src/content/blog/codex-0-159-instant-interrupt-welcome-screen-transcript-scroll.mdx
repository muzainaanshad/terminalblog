Codex 0.159.0 landed September 29, and it fixes the one thing that made terminal agents feel sluggish: **you couldn't interrupt them mid-thought**.

Until now, if Codex started generating a long response or running a code-mode task, you had to wait. Ctrl+C would kill the whole thing. Now there's an opt-in `instant_interrupt` flag that lets new input steer the agent *during* model responses or long-running calls. You type, it listens, it adjusts. The conversation finally flows both ways.

Plus: a compact welcome screen for new sessions, scrollable transcripts while reviewing plans, and warning dismissal that actually sticks. This is the release where Codex stops feeling like a demo and starts feeling like a daily driver.

---

## 1. Instant Interrupt — The Feature You've Been Waiting For

**`instant_interrupt` (opt-in)** lets you send new input while Codex is still generating a response or executing a code-mode call. The agent receives your input *immediately* and adjusts its behavior — no more waiting for a 500-token explanation to finish before you can say "actually, do it this way instead."

```bash
# Enable it in your config or pass as flag
codex --instant-interrupt
```

**Why this changes daily work:**
- You spot a misunderstanding in the *first paragraph* of a response → interrupt → correct it → agent pivots
- Long-running code-mode task going off track? Send a new instruction mid-execution
- The "wait for it to finish" friction that made you reach for a GUI agent? Gone.

This is opt-in because it changes the turn-taking contract. If you prefer the classic "agent speaks, you listen, you speak" rhythm, nothing changes. But once you try interrupt-driven flow, the old way feels like using a walkie-talkie in a phone call.

---

## 2. Welcome Screen That Doesn't Waste Your Time

New sessions now open with a **compact welcome screen** — consistent headers, occasional contextual tips during and after turns, and zero fluff. You see what you need (model, context, quick actions) and get out of the way.

**What's gone:** The verbose onboarding wall that appeared every session.  
**What's there:** Model pill, context indicator, and tips that appear *when relevant* (e.g., "press `k` to keep this warning" shows up *on* a warning, not in a help menu).

For beginners: this means your first session teaches you the tool *in context*, not in a tutorial. For veterans: it means less visual noise every time you `codex` in a new directory.

---

## 3. Scroll the Transcript While Deciding on a Plan

This one's small but compounds: **you can now scroll the transcript while the plan implementation dialog is open.**

Previously, the plan review modal blocked transcript access. You'd see "implement this plan?" but couldn't scroll up to remember *what* the plan was responding to. Now you scroll, read context, decide, confirm. The mental model stays intact.

---

## 4. Warning Dismissal That Remembers

Warnings viewer now **dismisses reviewed warnings when closed**. Press `k` on any warning to keep it for later. No more re-reading the same "unused variable" notice every session because you closed the panel to focus.

---

## 5. Native Mermaid Rendering (Finally)

Mermaid diagrams in transcripts now render natively — no more raw markup or copy-pasting to a viewer. Architecture diagrams, flowcharts, sequence diagrams: they just show up.
