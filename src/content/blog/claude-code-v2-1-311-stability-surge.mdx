Claude Code **v2.1.311 dropped October 26** — and if you've been living with daily paper cuts (startup freezes, MCP timeouts, compaction weirdness, subagent ghost runs), this is the release that finally sands them down.

**80+ fixes. Zero new features. Pure stability.**

The changelog reads like a greatest-hits album of "that annoying thing that happens every third session" — and they're all gone.

---

## The Headline: What You'll Actually Notice

### 1. Startup Freezes — Gone

**Fixed:** Long freezes at startup and after reading/editing files when a `CLAUDE.md` file holds a very long list item.

**What this means:** If your project has a massive `CLAUDE.md` with sprawling lists, Claude Code no longer hangs for seconds parsing it. Startup is snappy again.

---

### 2. Write/Edit Stalling on Large Files — Fixed

**Fixed:** Write and Edit tools stalling for up to **5 seconds** after they ran, reporting "0 lines changed" when changing thousands of lines.

**What this means:** Large refactors, generated file writes, bulk edits — they complete and report correctly now. No more staring at a spinner wondering if it worked.

---

### 3. MCP Hangs During Interrupts — Fixed

**Fixed:** Interrupting Claude not taking effect until a timeout while an MCP server hadn't answered a resource read or a skill was still downloading.

**What this means:** Hit `Ctrl+C` and it *actually stops* now. No more waiting for a stalled MCP server to time out before you regain control.

---

### 4. Compaction "Usage Credits" False Alarm — Fixed

**Fixed:** Standard-context sessions stopping with "Usage credits required for 1M context" when a request ran over 200K tokens; Claude Code now compacts the conversation and continues.

**What this means:** You hit the context ceiling → it compacts → you keep working. No more false "out of credits" errors mid-session.

---

### 5. Subagent MCP Tools Finally Work

**Fixed:** Subagents being unable to use MCP tools from servers that finish connecting *after* the subagent starts.

**Fixed:** `SubagentStop` hooks running about **twice a minute** for each running subagent instead of once when it finishes.

**What this means:** Delegated tasks can now use your full MCP toolkit. And your hooks fire correctly — no more phantom double-runs polluting logs or triggering side effects.

---

### 6. Stale CLAUDE.md/MEMORY.md After Compaction — Fixed

**Fixed:** Claude seeing stale `MEMORY.md` and `CLAUDE.md` content right after automatic compaction when those files were edited earlier in the session.

**What this means:** Your agent's memory stays fresh. Edits to context files are respected immediately after compaction.

---

### 7. Transcript Order & Message Duplication — Fixed

**Fixed:** `claude -p` and SDK sessions saving transcript messages out of order or keeping messages that were taken back.

**Fixed:** `↑` in an agent's chat tab recalling a message still waiting to be delivered, so resending sent a second copy.

**What this means:** Your session history is clean. Up-arrow recall works. Programmatic transcripts are reliable.

---

### 8. Remote Control & Cloud Sessions — Major Fixes

| Fixed | Impact |
|-------|--------|
| Remote Control sessions stuck on "Connecting" for ~2 min behind proxy | Starts fast behind corporate networks |
| Messages sent over Remote Control appearing as *your* message in mobile apps | Attribution is correct now |
| File attachments failing silently (disk full, >20 attachments) | You get told *why* it failed |
| WebFetch/WebSearch hanging on stalled response in Cowork | 300s timeout, then fails cleanly |
| Background sessions not restarting after crash while attached/pinned/scheduled | They actually recover now |
| "Background service did not respond" suggesting disabled `claude daemon restart` | Now suggests `claude daemon stop --any` |

---

### 9. VS Code Extension — 4 Critical Fixes

| Fixed | Impact |
|-------|--------|
| Custom skills/slash commands from panel missing open file/selected lines | Your context is included again |
| Extension host freezing on macOS/Linux reading PATH from login shell | No more frozen VS Code on startup |
| Voice dictation continuing after Send button | Send stops dictation (like Enter always did) |
| Clicking image in tool result *also* opening text in editor | One click = one action |

---

### 10. MCP Command UX — Fixed

- `claude mcp add/remove` and `/mcp` now name the **project entry in `~/.claude.json`** (not the current folder) when run below a repo root
- `claude mcp list/get` no longer shows error code twice (`ENOENT: ENOENT: …`)
- `--plugin-dir` folder no longer loads as one plugin when empty `.mcp.json` sits at its top
