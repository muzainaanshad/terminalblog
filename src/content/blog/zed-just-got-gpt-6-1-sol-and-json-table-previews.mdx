## 2. JSONL/NDJSON Files → Sortable, Filterable Tables

This is the feature you didn't know you needed until you use it once.

**Before:** Open a `.jsonl` or `.ndjson` file → raw text, one JSON object per line, scroll horizontally to find fields, good luck finding the error in line 4,847.

**After:** Open the same file → **rendered as a table** with:
- **Sortable columns** — click any header
- **Resizable columns** — drag to fit
- **Value-based row filtering** — type in the filter box, rows narrow instantly
- **Right-click copy** — copy cell, row, or column as JSON/CSV/TSV
- **Handles millions of rows** — virtualized rendering, no UI freeze

Your LLM streaming outputs, application logs, analytics exports, and dataset files just became browsable. This is the same table engine that powers Zed's CSV/TSV/PSV/SSV previews — now extended to the JSON Lines formats every AI workflow produces.

---

## 3. `agent.max_idle_retained_threads` — Stop the RAM Bleed

Long-running agent sessions used to accumulate idle threads in memory. Each completed subagent thread stayed loaded "just in case." A day of heavy agent work = gigabytes of retained context you weren't using.

**New setting:** `agent.max_idle_retained_threads` (default: sensible limit)

Controls how many idle agent threads remain loaded after completing their work. Older threads get unloaded first. Your active threads stay snappy; your memory stays bounded.

For beginners: this is the "don't let the agent eat my laptop" setting. If you run multi-agent workflows or leave sessions open overnight, this is the fix.
