## v1.51 — EUrouter, GPT-live API, Gateway Pairing, and More (Sep 17)

Just nine days after v1.50, v1.51 dropped with a feature set that feels like a second wave:

- **EUrouter as a declarative provider** — Route requests through EU-based inference for data residency compliance. Critical for teams in Europe or with EU customers.
- **GPT-live API support** — Real-time audio streaming with OpenAI's Realtime API. Goose can now speak and listen in live conversations.
- **Operator allowlist for gateway pairing** — Control which operators can pair with your gateway. Security for shared infrastructure.
- **Desktop routed to state-machine loop via ACP prompt meta** — Cleaner architecture for the desktop app's conversation handling.
- **Connect external backend ACP socket to redirect-resolved backend URL** — Better support for remote/bridged backends.
- **Opt-in terminal bell** — Get an audible ping when a turn finishes or approval is needed. Great for multitasking.
- **Real cause reporting for external backend connection failures** — No more "connection failed" — you get the actual error.
- **Scope Toolshim to custom providers** — Cleaner provider isolation.

Bug fixes in v1.51 include auto-compact handling, MCP retry logic, preserved-thinking compliance for Anthropic, bound image responses, session storage permissions, and recipe validation.

**What is a coding agent?** A coding agent is an AI-powered tool that can autonomously write, edit, and reason about code across multiple files in a codebase. Unlike simple autocomplete (GitHub Copilot), agents can execute terminal commands, navigate project structure, run tests, and complete multi-step tasks from a high-level prompt.



## v1.52 — Live Voice Conversations, Decisions Provider, Z.AI Plan (Sep 23)

Just six days after v1.51, **v1.52.0** drops with the most user-visible feature wave yet:

- **Live voice conversations in the desktop app** — Talk to Goose and hear it reply in real time. This is full duplex audio streaming via OpenAI's Realtime API, not a text-to-speech gimmick. You can have a genuine back-and-forth conversation while coding.
- **Decisions provider crate with OpenRouter and Jev implementations** — A new provider abstraction for "decisions" (planning/routing) that separates model selection from execution. OpenRouter and Jev are the first implementations, letting you route different task types to different models automatically.
- **Z.AI Coding Plan provider with streaming tool calls** — Native support for Z.AI's coding-specific model family with full streaming tool call support.
- **Route Desktop to state-machine loop via ACP prompt meta** — Cleaner conversation handling architecture continues to mature.
- **EUrouter as a declarative provider** — Now stable and documented for production EU data residency requirements.
- **Connect external backend ACP socket to redirect-resolved backend URL** — Better support for remote/bridged backend deployments.

Bug fixes include auto-compact handling improvements, MCP retry logic, preserved-thinking compliance for Anthropic, bound image responses, session storage permissions, and recipe validation.
