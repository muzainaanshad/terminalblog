**Cline v4.1.23 dropped October 7** — and it's the kind of release that fixes the things that made you silently curse at your terminal.

The headlines: **Claude through custom Anthropic base URLs (Azure AI Foundry, corporate gateways) works again**, **Generate Commit Message now follows your `.clinerules`**, **MCP tool output that exceeds context is now pageable**, and **Kimi K3 and other picky models no longer reject requests**. Plus a model catalog refresh adding GPT-6.1 Sol.

If you're on Azure, behind a corporate gateway, or just want commit messages that match your project conventions — this is your update.

---

## 1. The Azure / Corporate Gateway 400 Error: Fixed

**The bug:** Since v4.1.22, using Claude through a custom Anthropic base URL (Azure AI Foundry, corporate proxies, self-hosted gateways) threw a **400 error**. Cline started sending an option that only Anthropic's own API accepts.

**The fix:** v4.1.23 strips that option for non-Anthropic endpoints. Your Azure / corporate / self-hosted Claude just works again.

**Who this hits:** Anyone on Azure AI Foundry, corporate Anthropic gateways, or any non-official Anthropic endpoint. If you saw "400 Bad Request" when calling Claude — update and it's gone.

---

## 2. Generate Commit Message Finally Respects `.clinerules`

**Before:** You spent hours crafting `.clinerules` with your commit conventions — language, format, ticket references, conventional commits style. Then you hit "Generate Commit Message" and got generic garbage that ignored all of it.

**Now:** **Generate Commit Message reads and follows your `.clinerules`.** Your conventions apply to commit messages too.

```markdown
# .clinerules example
- Commits: conventional format (feat/fix/chore: scope - description)
- Reference Jira ticket: PROJ-123
- Language: English, imperative mood
```

Now when Cline generates a commit message, you get:
```
feat(auth): add OAuth2 refresh token rotation - PROJ-456
```

Instead of:
```
update auth files
```

---

## 3. MCP Tool Output That Exceeds Context: Now Pageable

**The problem:** An MCP tool returns more output than fits in context. The overflow was just... gone. Lost. You knew there was more but couldn't reach it.

**The fix:** Cline now returns a **preview + a link it can page through with `read_files`**. The output past the cutoff is no longer lost.

```text
[MCP Tool Result]
Preview (first 50KB): {...}
⚠️ Output truncated. Use read_files to page through the rest.
Link: mcp://tool-result/abc123/page/2
```

**Why it matters:** Database queries, log dumps, large file reads — you can now page through results instead of hitting a hard wall. The agent can fetch page 2, page 3, etc., using the same tool.

---

## 4. Kimi K3 and Picky Models: Reasoning Level Auto-Negotiation

**The bug:** Models like Kimi K3 that only accept certain reasoning levels would **reject the request entirely**. You'd get an error instead of a response.

**The fix:** Cline now **picks the closest reasoning level the model supports**. You ask for "high" → model only supports "medium" → Cline sends "medium" automatically. No error, no manual tweaking.

## 6. Approve/Reject on Tool Approvals: Race Condition Fixed

**Before:** You click "Approve" on a tool call while the panel is still updating → a late update failure rejects a *later, unrelated* approval. You approve one thing, something else gets rejected. Chaos.

**Now:** Approve/Reject work **right away**, even while the panel updates. A late update failure no longer poisons subsequent approvals.

---

## 7. Focus Chain Cleanup on Task Reopen

**Fixed:** Old tasks no longer show leftover Focus Chain checklist rows when reopened. Clean slate every time.
