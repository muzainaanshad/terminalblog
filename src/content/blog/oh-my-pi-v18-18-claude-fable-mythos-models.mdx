### 2. Fixed the "Text-Only" Misclassification Bug

Before this release, **Fable and Mythos were showing as text-only, non-reasoning models** — which meant:
- Agents wouldn't use them for coding tasks
- Reasoning features were disabled
- Tool calling didn't work
- You got worse results without knowing why

**v18.18.5 fixes this completely.** The models now correctly report as full-capability reasoning models with vision, tools, and computer-use.

### 3. Fixed the Pricing Hallucination

The catalog was **mispricing Fable/Mythos before models.dev caught up** — showing wrong costs that made agents avoid them or budget incorrectly. Now pricing matches Anthropic's official API.

## What v18.18.6 Added (The Proxy Fix)

### LiteLLM Proxy Now Only Lists Models Your Key Can Actually Call

This is a **huge operational fix** for anyone running Oh My Pi as a shared gateway:

> **Before:** Proxy's `/v1/models` returned *every model the proxy serves* — even if your API key couldn't access them. Agents saw models they couldn't use, tried to call them, got 401s, and failed silently.

> **After:** Proxy queries its authenticated `/v1/models` endpoint and **only returns models your specific key can call**. If the proxy's model list fails, it returns empty instead of hallucinating access.

```bash
# What this means for you:
# - No more "model not found" errors from phantom models
# - Agents only see what they can actually use
# - Team gateways: each key sees only its entitled models
# - Safer multi-tenant setups
```

### Hyperspace AI / Gemini Gateway Compatibility

Added `base64SkipThoughtSignature` compat flag so **Gemini gateways that decode `thoughtSignature` as base64** (like Hyperspace AI LLM proxy) can receive the unsigned-tool-call bypass sentinel without rejecting with 400.

## What This Means for You

### If You're New to Coding Agents + Model Routing

**Oh My Pi is the router that sits between your agent and 100+ model providers.** You configure it once, and every agent (Claude Code, Cursor, Cline, Goose, OpenCode, Kilo, Hermes, Zed, etc.) gets access to *every model* with unified pricing, caching, and fallbacks.

**v18.18.5/6 means:** You now get Anthropic's newest, best-priced models **automatically** — no config, no wait for upstream catalog updates.

```bash
# Quick start (if you don't have Oh My Pi yet):
# 1. Install
npm install -g @oh-my-pi/pi

# 2. Add your Anthropic key
pi auth add anthropic --key sk-ant-...

# 3. Pick Fable 5.2 as your daily driver
pi model use claude-fable-5-2-20261109

# 4. Point your agent to the local proxy
# In your agent config: base_url = "http://localhost:4000/v1"
```

### If You Run a Shared Gateway / Team Setup

**v18.18.6 is the release you've been waiting for.** The LiteLLM proxy now respects per-key entitlements. Your teammates only see models their keys can access. No more accidental 401s, no more "why can't I use Opus?" confusion.

