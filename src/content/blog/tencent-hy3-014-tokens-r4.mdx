Tencent has launched **Hy3**, a coding-focused AI model priced at **$0.14 per million input tokens** — a number that should make every team paying premium rates for code generation take a second look. In a market where the big-name models charge multiples of that for similar work, Hy3 is positioning itself as the budget engine for developers who burn through tokens by the billion.

## The Pricing Math

Let's put $0.14/1M tokens in context:

| Model | Input Price | Output Price | Category |
|-------|------------|-------------|----------|
| **Tencent Hy3** | **$0.14** | TBD | Budget coding |
| GPT-4o | $2.50 | $10.00 | Flagship |
| Claude Sonnet 4 | $3.00 | $15.00 | Flagship |
| Gemini 2.5 Flash | $0.15 | $0.60 | Budget reasoning |
| DeepSeek V3 | $0.27 | $1.10 | Value coding |
| Llama 4 Maverick (via API) | $0.19 | $0.85 | Open-weight |

Hy3's input price undercuts almost every option on the market. At $0.14 per million tokens, a coding agent session that processes 500K input tokens costs roughly $0.07 — less than a penny. Run that 1,000 times a day across a team, and the monthly input bill lands around $210. Compare that to Claude Sonnet 4 at the same volume: $1,500/month just for input.

## What Hy3 Is Actually Good At

The model targets the bread-and-butter of software work: writing functions, refactoring modules, explaining unfamiliar code, and turning natural-language specs into working pull requests. Tencent is betting that for most coding tasks, raw flagship performance is overkill, and a lean model at a fraction of the cost wins on total bill rather than leaderboard bragging rights.

Where Hy3 makes sense in a multi-model routing setup:

- **Lint and format passes** — straightforward transformations where accuracy is easy to verify
- **Boilerplate generation** — scaffolding controllers, test stubs, config files
- **Code explanation and documentation** — summarizing what a module does for a new contributor
- **Simple bug fixes** — typo corrections, missing imports, one-liner patches

Where it probably doesn't replace a flagship model:

- Complex architectural decisions across multiple files
- Subtle concurrency bugs or race conditions
- Security-sensitive code review
- Tasks that require deep understanding of business logic

## The Multi-Model Routing Angle

For teams already running multi-model orchestrators — where a router picks the cheapest adequate model per subtask — Hy3 slots in as the new cost floor. The routing logic becomes simpler: anything that doesn't require deep reasoning gets routed to Hy3, everything else goes to a premium model.

This is the same playbook Meta is running with Muse Spark 1.1, and it's the same logic that made DeepSeek V3 popular: cheap tokens that are good enough for the boring 80% of agent work. The difference is that Hy3 is specifically tuned for code, which means the quality bar on coding tasks may be higher than a general-purpose budget model at a similar price point.

If you're evaluating which free coding agent to pair with your API budget, the math changes when input costs drop this low. Agents like Oh My Pi and OpenCode that let you BYO keys become even more attractive when the key they're using costs almost nothing.

## The Catch

Cheap tokens are worthless if the model fumbles architecture or subtle bugs. Hy3 hasn't been through the same round of independent benchmarking that established models have, so real-world performance on hard problems is still unknown. The smart move is to route your low-stakes calls to Hy3 now, track the quality metrics, and promote it to higher-stakes tasks only if the output proves reliable.

For cost-conscious shops, the calculus just shifted. At $0.14 per million input tokens, the risk of trying Hy3 is nearly zero — and the upside is a dramatically lower API bill.
