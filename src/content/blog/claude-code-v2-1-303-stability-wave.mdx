Claude Code v2.1.303 landed **October 17, 2026** — and it's not a feature release. It's a **100+ bug fix dump** that quietly resolves the paper cuts that have been biting teams for weeks.

If you've hit worktree corruption on git 2.56+, Windows file write refusals on exFAT/FAT32, plugin startup slowness, cloud session flakiness, or MCP protocol issues — this is the release you've been waiting for.

---

## The Headline Fixes (Ranked by Daily Pain)

### 1. Worktree Isolation Fixed for Git 2.56+ — Stops Repo Corruption
**The bug**: Worktree isolation refused to create or resume worktrees under git 2.56 or later when a stray `.git` file pointed at a directory that doesn't exist. This silently corrupted repos.

**The fix**: Worktree isolation now handles git 2.56's reftable format correctly. If you use worktrees (and you should — they're the safest way to run agents in parallel), **upgrade immediately**.

### 2. Windows exFAT/FAT32 File Writes — Every Write Was Refused
**The bug**: Every file write was refused or prompted for projects on exFAT or FAT32 drives — including sessions started with `--plugin-dir`. This made Claude Code unusable on external drives and some Windows setups.

**The fix**: File writes on exFAT/FAT32 now work without permission prompts.

### 3. Idle Compaction Controls — You Can Finally Turn It Off
**The bug**: Idle compaction ran automatically with no way to disable it. Long-running sessions would compact mid-task, losing context.

**The fix**: 
- Added `CLAUDE_CODE_AUTO_MODE_MODEL` to choose the model for client-side auto mode classifier
- Added an "Idle compaction" row to `/config` for turning it off or back on
- Notices after idle compaction now say how to turn it off

### 4. Plugin Performance — Startup Is Now Fast with Many Plugins
**The bug**: Plugin command and agent files took excessive file system calls to load, especially on Windows. Startup with 20+ plugins was painfully slow.

**The fix**: Plugin loading now takes far fewer file system calls. Most improvement on Windows. If you run many plugins, you'll notice the difference immediately.

### 5. Cloud Session Reliability — Stops Losing Your Work
**The bug cluster**: 
- Cost/usage restarting from zero after session resume in new process
- Scheduled routine runs failing partway, then repeating work (posting same report twice)
- Open cloud sessions not showing messages from other devices until reload
- "Rewind to here" failing on every message except newest
- Diff view missing changes after repo rename/move

**The fix**: All addressed. Cloud sessions now persist state correctly across process boundaries, device switches, and repo operations.

## The Full Fix List (Categorized)

### Worktree & Git
- Worktree isolation for git 2.56+ (reftable format)
- Self-hosted runner: git fetches failing with "bad object refs/heads" in reftable checkouts
- Stray `.git` file pointing at non-existent directory no longer blocks worktrees

### Windows & Filesystem
- exFAT/FAT32 file write refusals fixed
- Plugin startup performance (fewer fs calls, especially Windows)
- PowerShell tool finding commands in plugin `bin/` folders
- PowerShell search piped to `Select-Object`/formatting cmdlets no longer errors

### Idle Compaction & Auto Mode
- `/config` now shows "Idle compaction" toggle
- Notices explain how to disable idle compaction
- Auto mode with server-side classifier: long conversations compact instead of denying every tool call
- `CLAUDE_CODE_AUTO_MODE_MODEL` env var for client-side classifier model

### Plugin System
- Plugin marketplaces no longer re-clone on every refresh
- Newly installed git plugins no longer show version "unknown"
- `claude plugin` subcommands no longer exit before queued config writes finish (no more `.tmp` files left behind)
- `claude plugin details <name>@builtin` points to `/plugin` instead of `claude plugin list`
- Improved startup with many plugins enabled

### MCP (Model Context Protocol)
- MCP servers negotiating protocol version 2026-07-28 but omitting `resultType`, `ttlMs`, or `cacheScope` no longer show no tools or fail every call
- MCP server sign-in from VS Code panel no longer opens broken auth page when server URL has query string

### Cloud Sessions
- Cost/usage persists across process resume
- Routine runs: failed partway → re-run from start (fixed duplicate reports)
- Messages from other devices appear without reload
- "Rewind to here" works on all messages
- Diff view works after repo rename/move
- PR status bar no longer flips conflicted PRs to ready
- Routine run states: Completed/Cancelled/Failed now accurate
- Error messages: "Connection lost" or "Server error" instead of "Something went wrong"
- Banner on routine page explains why last run didn't start (concurrent limit, etc.)

### Remote Control
- Subagent pane no longer spins forever when computer goes offline — shows "Remote Control disconnected"

## What's NOT Fixed (Still Watching)

- **No new features** — this is purely a stability release
- **Auto mode model selection** — server-side classifier model still not configurable (only client-side via `CLAUDE_CODE_AUTO_MODE_MODEL`)
- **Fully offline mode** — cloud sessions still require connectivity
- **Android Remote Control** — iOS only for now
