Hermes Agent **v0.22.5 dropped October 22** — a patch release that rolled up **81 PRs** and **231 commits** since v0.22.4. On paper it's a "patch." In practice, it fixes the things that made you sigh every time you opened the app.

---

## The One Thing You'll Notice Immediately: Sign-In Just Works

**Before v0.22.5:** You clicked sign-in → got a guest session → had to figure out how to attach your real account → connectors opened confusing guest flows.

**After v0.22.5:** Every sign-in is now a **plain device login**. The free-tier guest automatically hands over to your account. The result shows *who signed in*. Connectors offer sign-in instead of opening a guest.

No more "wait, am I signed in as me or a ghost session?" The sign-in flow finally respects the user.

---

## Windows Users: `hermes update` Is No Longer Stuck

If you're on Windows, you know the pain: `hermes update` would hang on the old launcher after a Python repin. You'd kill it, re-run the installer, wonder if you broke something.

**Fixed.** Windows `hermes update` now recovers properly after a Python repin. It also **recovers paused gateways after a damaged `.git`** — so a corrupted repo doesn't mean a dead install.

---

## Pluggable Delegation Backends — Route Subagents Your Way

This one's for power users who run multi-agent workflows.

You can now **route subagents by model map or profile**, and switch the delegation backend **per session**. Want your coding subagent on Claude Opus 5.5 but your research subagent on a local Qwen? Define a model map. Want to swap the whole routing logic for a specific project? Swap the backend.

No more hardcoded delegation. The agent orchestration layer is now pluggable.

---

## Plugin Slash Commands That Ask You to Pick

Plugin authors can now write slash commands that **prompt you for options** instead of guessing.

```bash
# Before: plugin guesses or fails
/hermes-github create-issue

# After: plugin asks
/hermes-github create-issue
→ Pick repository: [dropdown]
→ Pick label: [multi-select]
→ Confirm? [y/n]
```

This turns plugins from "rigid tools" into "interactive workflows." Huge for team-shared plugins.

---

## `hermes import-agent` — Cursor Migration Now Official

The `hermes import-agent` command now includes **Cursor** in its supported importers. Setup detects another agent on your machine and offers the importer automatically.

If you've been Curious about Hermes but locked into Cursor's workflow, the switching cost just dropped.

---

## Singularity Backend Moves to Plugins — Core Gets Leaner

The Singularity/Apptainer container backend (for HPC/scientific workloads) **moved out of core into a plugin**.

This is the architectural direction: **core stays minimal, capabilities live in plugins**. You don't pay for container runtime overhead unless you install the plugin. The plugin catalog now handles it with one-click install and tier badges.

## Experimental: Webhook-Mode MCP Events Client

For builders: an experimental **webhook-mode MCP events client** landed. This lets you receive MCP server events via webhook instead of long-lived connections — useful for serverless, edge, or intermittent connectivity scenarios.

Marked experimental. API may change. But the direction is clear: MCP integration is becoming a first-class platform capability, not just a client feature.

## The Bigger Picture: Hermes Fixes the Boring Stuff

| Release Wave | Philosophy |
|--------------|------------|
| v0.20.x | "80% faster" — performance foundation |
| v0.21.x | "Pantheon bots" — multi-agent orchestration |
| **v0.22.x** | **"Threshold" — remove what doesn't serve the operator** |

v0.22.5 continues the v0.22 theme: **threshold**. Not "add more" — "remove what's in the way."

- Confusing sign-in flow → replaced with plain device login
- Windows update hanging → fixed at the launcher level
- Hardcoded subagent routing → pluggable backends
- Rigid plugin commands → interactive pickers
- Core bloat (Singularity) → moved to plugin

This is the Hermes thesis: **the agent that grows with you grows by shedding what you don't need.**
