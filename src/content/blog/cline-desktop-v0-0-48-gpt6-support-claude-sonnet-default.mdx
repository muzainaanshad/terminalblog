**Cline Desktop v0.0.48 dropped October 17** — and it fixes the silent failure that made GPT-6 models unusable on OpenAI and Azure since they launched.

If you tried `gpt-6-sol` or `gpt-6.1-sol` and got rejected requests with no clear error — **this update fixes it**. Plus: **Claude Sonnet 5.5 is back as the Cline provider default** after a brief Gemini 4 Argon experiment, and the model catalog got two new providers (CommandCode, Reflection) plus default model shifts across 8+ services.

---

## The Headline Fix: GPT-6 Models Now Actually Work on OpenAI/Azure

**The bug:** Since GPT-6 models launched, Cline sent `max_tokens` for every request. OpenAI and Azure **require `max_completion_tokens` for GPT-6 models** — they reject `max_tokens` with a 400 error. Every GPT-6 request silently failed.

**The fix:** v0.0.48 detects GPT-6 model IDs (`gpt-6-sol`, `gpt-6.1-sol`, `gpt-6-1-sol`, and the gpt-5 through gpt-9 family) and automatically sends `max_completion_tokens`. Azure's `gpt-35-turbo` keeps `max_tokens` — the logic is model-aware.

**For beginners:** You don't need to change anything. Select `gpt-6-sol` in the model picker → it works. No config, no flags, no debugging why your frontier model calls return 400.

---

## The Default Model Flip: Sonnet 5.5 Is Back

**What happened:** v0.0.46 switched the Cline provider default to **Gemini 4 Argon** (it was top of the recommended list). v0.0.48 switches back to **Claude Sonnet 5.5** — it's #1 on the recommended list again.

**Why it matters:** Sonnet 5.5 is widely considered the best all-round coding model. The default flip means new users get the strongest model out of the box, without knowing they need to pick it.

**OpenRouter stays on Sonnet 5.5** — only the Cline provider default changed.

## OpenCode Go Endpoint Pinned

OpenCode Go's base URL is now **pinned to `https://opencode.ai/inference/go/v1`** — it won't drift if models.dev changes its provider-level URL (which it did, moving to an OpenAI-only path). Stability for OpenCode Go users.
