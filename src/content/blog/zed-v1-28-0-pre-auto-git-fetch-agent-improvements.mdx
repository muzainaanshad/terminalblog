**Zed v1.28.1 stable dropped November 11** — the pre-release features from v1.28.0-pre are now on the stable channel, plus 30+ additional bug fixes. If you waited for stable, this is your update.

---

## Headline Features (Now Stable)

### Optional Automatic Git Fetch
```json
// settings.json
{
  "git.auto_fetch.enabled": true,
  "git.auto_fetch.interval_secs": 60  // default
}
```
Fetches the current branch's upstream remote and the default branch's remote automatically. Disabled by default. ([#53089](https://github.com/zed-industries/zed/pull/53089))

### AI Commit Messages That Match Your Style
Zed now uses the **three most recent repository commit messages** as style examples when generating commit messages. No more generic "fix: updated code" — it learns your project's conventions. ([#61528](https://github.com/zed-industries/zed/pull/61528))

### Resizable Refs Column in Git Graph
Toggle a resizable "Refs" column from the column header's context menu. ([#66260](https://github.com/zed-industries/zed/pull/66260))

### Drag Git Panel Files to Terminal/Editor
Drag files from the Git Panel directly into terminal and editor panes. ([#66423](https://github.com/zed-industries/zed/pull/66423))

### Mouse-Wheel Font Zoom in Diff Views & Terminals
- **macOS**: `cmd` + scroll
- **Linux/Windows**: `ctrl` + scroll
Enable with `mouse_wheel_zoom: true`. ([#66296](https://github.com/zed-industries/zed/pull/66296))

## AI & Agent Improvements

- **Edit prediction button toggle** — `edit_predictions.button` setting to show/hide the button in status bar
- **Improved ACP compatibility** — handles missing sessions, plan updates, diff formats, permission request cancellation
- **Truncated `read_file` tool output** — lines >2000 chars truncated to prevent context overflow
- **Subagent cards** — full screen opens finished subagent run at its start
- **Agent Panel memory** — tool-call diffs and thread Markdown loaded only when first viewed (not at thread load)
- **CPU/disk usage** — improved while agent works, especially with long thread history

## Agent Context Compaction Fixes (Critical)

- Fixed compaction **unnecessarily using uncached input tokens** with supported providers (OpenAI, xAI)
- Fixed auto-compaction **only running once** during long agent turns — could exceed context window
- Fixed compaction **not reusing prompt cache** for ChatGPT subscription models

These are the kinds of fixes that prevent "context window exceeded" surprises mid-task.
