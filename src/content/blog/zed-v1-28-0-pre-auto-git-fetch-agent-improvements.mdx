## The AI Agent Fixes (Why You're Here)

### 1. Auto-Compaction No Longer Runs Once and Quits

**What it was:** During a long agent turn, auto-compaction ran **once** — then stopped. Your thread could blow past the model's context window silently. Next thing you know: truncated context, lost reasoning, broken task.

**What it is now:** Auto-compaction **repeats as needed** throughout long turns. It respects the context window continuously.

```bash
# Before: One compaction at turn start → hope it lasts
# After:  Compaction triggers whenever context grows too large → stays in bounds
```

**Why it matters:** You can run hour-long refactors without babysitting the context window.

---

### 2. Prompt Cache Finally Reused for ChatGPT Subscriptions

**What it was:** ChatGPT subscription models (via OpenAI) **never reused the prompt cache** during compaction. Every compaction = full reprocess = slower, more expensive.

**What it is now:** Prompt cache **works for ChatGPT subs** during compaction. Compaction is faster, cheaper, and doesn't reset the model's "memory" of your project.

---

### 3. Agent `read_file` Output Truncated at 2,000 Chars/Line

**What it was:** Agent reads a minified file or huge log line → 50,000 character line → context window explosion.

**What it is now:** Lines >2,000 chars **auto-truncated** in `read_file` output. You get the signal, not the noise.

---

### 4. Agent Client Protocol (ACP) Compatibility Improved

**What it is:** Better handling of:
- Missing sessions (no more crashes)
- Plan updates from agents
- Diff format variations
- Cancellation of permission requests

**Why it matters:** If you use external agents (Claude Agent, OpenCode, etc.) via ACP — they integrate more reliably.

## The Git Workflow Upgrades (Daily Driver Stuff)

### 5. Optional Automatic Git Fetching

```json
// settings.json
{
  "git.auto_fetch.enabled": true,
  "git.auto_fetch.interval_secs": 60  // default
}
```

**What it does:** Every 60 seconds (configurable), Zed fetches:
- Current branch's upstream remote
- Default branch's remote

**Why it matters:** Your Git Graph, branch list, and status **stay current without you pressing Fetch**. No more "wait, my colleague pushed 20 minutes ago and I'm looking at stale branches."

**Default: OFF.** Enable it if you want it.

---

### 6. Resizable "Refs" Column in Git Graph

**What it is:** The Git Graph now has a **resizable Refs column** (toggle from column header context menu). Branch names, tags, remotes — all visible, sized how you want.

---

### 7. Drag Git Panel Files → Terminal / Editor

**What it is:** Drag a file from the **Git Panel** (staged/unstaged changes) directly into:
- A terminal pane → path pasted, ready to run
- An editor pane → file opens

**Why it matters:** "Copy path → cd → open" becomes **drag → drop → done**.

---

### 8. Search by Branch Name in Worktree Picker

**What it is:** Worktree picker now has **branch name search**. Type "feat-auth" → see matching branches instantly.
