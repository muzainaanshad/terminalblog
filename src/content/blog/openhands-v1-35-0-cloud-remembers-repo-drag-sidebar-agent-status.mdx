## The Cloud Workflow Upgrades (You'll Feel These Daily)

### 1. Cloud Remembers Your Repository Selection

**What it is:** When you pick a repository for a cloud conversation, **OpenHands remembers it**. Next cloud conversation → same repo pre-selected.

**Why it matters:** Before: every cloud task = repo picker → scroll → find → select. Now: **pick once, it sticks**. Your workflow: *open cloud → pick repo once → every subsequent cloud task starts there*.

```bash
# Before: Cloud conversation → "Select repository" → scroll list → pick → start
# After:  First cloud conversation → pick repo
#         Second cloud conversation → repo already selected → start
```

**PR:** [#19053](https://github.com/OpenHands/OpenHands/pull/19053) by @tofarr

---

### 2. Drag the Sidebar Edge to Resize — Finally

**What it is:** The sidebar in Agent Canvas is now **draggable from the edge**. Make it narrow for code, wide for reading automations, whatever fits your screen.

**Why it matters:** You've been asking for this since v1.0. Fixed sidebar width forced horizontal scrolling on automation names, truncated conversation titles. Now: **your layout, your rules**.

**Bonus:** Sidebar text is **one size larger** — readable at a glance, no squinting.

**PRs:** [#19097](https://github.com/OpenHands/OpenHands/pull/19097), [#19113](https://github.com/OpenHands/OpenHands/pull/19113) by @ak684

---

### 3. Live Agent Status in Chat — Know What It's Doing

**What it is:** The chat now shows **real-time agent status**: *thinking*, *running tool*, *waiting for input*, *compacting*, *done*.

**Why it matters:** Before: you send a message → spinner → wait → wonder if it crashed. Now: **you see the agent's state live**. Long tool call? You see "running tool: bash" with the command. Compacting? You see "compacting context". No more guessing.

**PR:** [#19130](https://github.com/OpenHands/OpenHands/pull/19130) by @ak684

---

### 4. Download Button in Files Tab

**What it is:** The **Files tab now has a Download button** (OHE-3834). Click → file downloads. No more "how do I get this file out of the sandbox?"

**Why it matters:** You're in a cloud sandbox, agent generated a report, you need it locally. **One click. Downloaded.**

**PR:** [#19076](https://github.com/OpenHands/OpenHands/pull/19076) by @hieptl

---

### 5. Hooks & Reasoning Grouped with Tool Calls — Readable Transcripts

**What it is:** In the chat, **hooks, reasoning, and tool calls are now grouped** — and each group says *what it did*.

**Why it matters:** Before: flat stream of tool calls, hooks, reasoning blocks — hard to follow. Now: **logical groups**. *Agent decided to search → ran grep → hook validated → reasoning summarized*. You read the story, not the raw log.

**PR:** [#19084](https://github.com/OpenHands/OpenHands/pull/19084) by @ak684

---

### 6. Compact Timestamps on Hover — Clean Chat, Precision When Needed

**What it is:** Message timestamps are **compact by default**, full timestamp on **hover**.

**Why it matters:** Chat stays clean. You need exact time? Hover. You don't? Clean UI.

**PR:** [#19227](https://github.com/OpenHands/OpenHands/pull/19227) by @ak684

---

### 7. Startup Progress Visible — No More "Is It Loading?"

**What it is:** Starting or resuming a cloud conversation shows **inline startup progress**: *starting sandbox → cloning repo → starting agent*. Collapses once agent starts.

**Why it matters:** Cloud cold starts take 30-60 seconds. Before: blank screen, spinner. Now: **you see exactly which step it's on**.

**PR:** [#19155](https://github.com/OpenHands/OpenHands/pull/19155) by @ak684

---

## The Automation Upgrades (If You Run Scheduled Work)

### 8. Events Webhook Sources View

**What it is:** New **Events webhook sources view** in Automations — see all incoming webhook events, their sources, and trigger status.

**Why it matters:** You have 20 automations triggered by GitHub, GitLab, Bitbucket, custom webhooks. Now: **one view to debug "why didn't that automation fire?"**

**PR:** [#19034](https://github.com/OpenHands/OpenHands/pull/19034) by @malhotra5

---

### 9. Keep-Alive Edit on Automation Detail Page

**What it is:** Automation detail page now shows **keep_alive** setting — edit it inline.

**Why it matters:** Long-running automations (overnight refactors, weekly audits) need keep-alive. Before: buried in config. Now: **toggle on the detail page**.

**PR:** [#19125](https://github.com/OpenHands/OpenHands/pull/19125) by @tofarr

---

### 10. Template Suggestions Matched to Your Integrations

**What it is:** When creating an automation, **template suggestions now match your connected integrations** (GitHub connected → GitHub templates shown first).

**Why it matters:** You see relevant templates. No scrolling past Bitbucket templates if you only use GitHub.

**PR:** [#19101](https://github.com/OpenHands/OpenHands/pull/19101) by @ak684

---

### 11. Org Rows Grouped in Backend Picker (Stays in Sidebar)

**What it is:** Organization rows in the backend picker are **grouped** — and the picker **stays inside the sidebar** instead of overlaying.

**Why it matters:** Multi-org setups: you see org → workspaces → repos grouped. Picker doesn't cover your context.

**PR:** [#19102](https://github.com/OpenHands/OpenHands/pull/19102) by @ak684
