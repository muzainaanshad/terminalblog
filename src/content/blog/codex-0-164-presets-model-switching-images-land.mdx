**OpenAI Codex 0.164 dropped on October 23** and it's the first release in a while that feels like it was built for people who actually use this thing daily.

No marketing fluff. Three features that change how you work: **`/presets` for reusable prompts**, **inline `/model` switching**, and **fullscreen image preview** in your terminal.

Here's what you need to know.

---

## The One-Line Summary

**Codex 0.164 adds `/presets` (10 saved prompt slots with keyboard menu), `/model` and `/permissions` inline switching, and Kitty/Sixel image preview. Plus fixes for session resume, Windows proxy auth, and disk bloat. Run `npm install -g @openai/codex@latest` now.**

---

## Feature 1: `/presets` — Your Prompts Finally Stick

This is the one you'll use every session.

You get **10 numbered slots** (`/preset 1` through `/preset 10`). Save any prompt, slash command, or workflow template. Recall it with a keystroke.

```
# Save your standard "review this PR" workflow to slot 3
/preset 3 "Review this PR for security issues, performance regressions, and test coverage. Focus on auth changes."

# Later — one keystroke brings it back
/preset 3
```

**Keyboard menu:** Type `/preset` and you get a navigable list. No memorizing slot numbers.

**Why this matters:** Most developers have 3–5 prompts they use every day — code review, test generation, refactoring patterns, debug workflows. Before 0.164, you either re-typed them, kept a scratchpad, or used shell aliases that didn't carry context. Now they live *inside* Codex, context-aware and one keystroke away.

---

## Feature 2: Inline `/model` and `/permissions` Switching

Mid-session model switching without leaving the conversation.

```
/model gpt-5                    # Switch to GPT-5
/model o3-mini --reasoning high # o3-mini with high reasoning effort
/model gpt-5 --speed fast       # GPT-5 speed tier
/permissions read-only          # Drop to read-only for safe exploration
/permissions full               # Back to full access
```

**All in one command:**
```
/model gpt-5 --reasoning high --speed balanced --permissions full
```

**Why this matters:** Different tasks need different models. Code generation → GPT-5. Quick edits → o3-mini fast. Security audit → high reasoning. Before, you'd restart the session or use a separate terminal. Now it's one command, same context, same history.

---

## Feature 3: Fullscreen Image Preview (Kitty / Sixel)

If your terminal supports **Kitty graphics protocol** or **Sixel**, images now render *inside* Codex — fullscreen, zoomable, scrollable.

Supported terminals: **Ghostty, WezTerm, Kitty, iTerm2 (with imgcat), foot, konsole**.

```
# Generate a diagram, it renders inline
"Create a mermaid diagram of the auth flow"
# → Image appears in terminal, press Enter for fullscreen
```

**Why this matters:** No more "open this in a browser" for architecture diagrams, UI mockups, or generated charts. Your coding agent becomes a visual tool, not just a text tool.

---

## Enterprise MCP: Real Auth Support

Codex 0.164 adds **enterprise-grade MCP authentication**:

- **Account grants** — Use your eligible Codex account to authenticate MCP servers
- **Dedicated sign-in** — Separate OAuth flow for MCP connections
- **OAuth clients with secrets** — Full support for confidential clients

This matters if you're running Codex in a team/enterprise setting with private MCP servers (internal tools, private APIs, corporate data sources). No more workarounds with API keys in environment variables.

## The Fixes You'll Actually Notice

| Fix | Why You Care |
|-----|--------------|
| **Session resume restores compressed history + thread settings** | Stop losing your context when you reopen a session. Compaction failures no longer leave partial summaries. |
| **Windows HTTPS/WebSocket proxy auth (Negotiate/NTLM)** | Corporate proxy users: Codex now authenticates properly through Windows proxies. |
| **Config overrides preserved at multiple subcommand levels** | `codex -c config1.yaml subcommand -c config2.yaml` now works as expected. |
| **Queued prompts wait for permission resolution** | No more race conditions when you rapid-fire prompts during a permission prompt. |
| **Disk usage pruning** | Unused installations, abandoned marketplace checkouts, and unbounded daemon logs get cleaned automatically. |
| **Hardened macOS sandbox (case-variant paths, symlink resolution)** | Fewer "operation not permitted" surprises on macOS. |
