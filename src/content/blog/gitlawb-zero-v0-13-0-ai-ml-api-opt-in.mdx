## The Big Feature: AI/ML API — One Key, 200+ Models

### What It Is

AI/ML API (aimlapi.com) is a unified gateway that proxies requests to **200+ models** across OpenAI, Anthropic, Meta, Mistral, DeepSeek, Qwen, Google, Cohere, and more. You add **one API key** to Zero, and you get access to:

| Category | Models Available |
|----------|------------------|
| **GPT Family** | GPT-4o, GPT-4o-mini, GPT-4-turbo, o1-preview, o1-mini |
| **Claude Family** | Claude 3.5 Sonnet, Claude 3.5 Haiku, Claude 3 Opus, Claude 3 Sonnet |
| **Llama** | Llama 3.1 405B, 70B, 8B; Llama 3.2 90B, 11B, 3B, 1B |
| **Mistral** | Mistral Large 2, Nemo, 7B, Codestral |
| **DeepSeek** | DeepSeek V2.5, Coder V2, R1 |
| **Qwen** | Qwen 2.5 72B, 32B, 14B, 7B, 3B; Qwen 2.5 Coder |
| **Google** | Gemini 1.5 Pro, Flash, 1.5 Flash-8B |
| **Cohere** | Command R+, Command R |
| **Others** | Nemotron 3 Ultra, Phi-3, Yi, Gemma 2, and 100+ more |

### Why This Matters for Beginners

**Before v0.13.0:** You needed separate keys for OpenAI, Anthropic, Together, Fireworks, Groq... each with its own billing, rate limits, and config.

**After v0.13.0:** One key. One billing account. One endpoint. Zero config per model.

```bash
# Add AI/ML API key (one time)
zero config provider aimlapi --key your-aimlapi-key

# Now pick any model
zero --model gpt-4o
zero --model claude-3.5-sonnet
zero --model llama-3.1-405b
zero --model deepseek-r1
# All work immediately
```

### The Opt-In Design

This is **opt-in** — Zero doesn't auto-enable it. You explicitly add the provider. Your existing keys (OpenAI, Anthropic, etc.) keep working exactly as before. AI/ML API is just another provider in the catalog.

## The Quality-of-Life Features

### 2. Custom Keyboard Shortcuts

**What it is:** Define your own keybindings in `zero.json`. No more fighting defaults.

```json
{
  "keybindings": {
    "new-session": "ctrl+n",
    "toggle-sidebar": "ctrl+b",
    "copy-last-response": "ctrl+shift+c",
    "interrupt": "ctrl+c",
    "scroll-up": "pageup",
    "scroll-down": "pagedown"
  }
}
```

**Why it matters:** Muscle memory matters. If you come from VS Code, Cursor, or another editor — map Zero to match.

### 3. Subdirectory Git Branch Detection

**What it is:** Run `zero` from a subdirectory of a Git repo — it now correctly detects the branch instead of showing "detached" or the parent repo's branch.

**Why it matters:** Monorepos, nested projects, worktrees — Zero now knows *exactly* where you are.

### 4. Context Preservation Across Exec Prompts

**What it is:** When you interrupt an agent and redirect it (`zero --exec "actually, use TypeScript"`), it now remembers what it did *before* the interrupt. The context doesn't reset.

**Why it matters:** Iterative coding feels natural. "Do X" → interrupt → "actually do Y instead" → agent knows X happened.

## Security Hardening (The Stuff You Don't See But Should Care About)

| Fix | What It Prevents |
|-----|------------------|
| **Stale-lock DoS prevention** | Malicious repo can't freeze your agent by leaving a stale lock file |
| **Windows taskkill hijack prevention** | Canceling a model call on Windows kills the full process tree — no orphaned helpers |
| **Permission payload validation** | Sandbox can't be tricked into granting permissions it shouldn't |
| **Credential privacy** | Git credential stores (`~/.git-credentials`) are now blocked from agent reads unless explicitly approved |

These are the fixes that make Zero **safe to run unattended** — in CI, as a daemon, or overnight.

```bash
# Global npm install

# Verify

# Add AI/ML API (optional but recommended)
```
