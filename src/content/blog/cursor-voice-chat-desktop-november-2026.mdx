**Cursor dropped Voice Chat today (November 6, 2026)** — and it changes how you supervise agents. You don't type prompts anymore. You *talk* to your agent. It *talks back* with progress updates. You steer work while it runs, hands-free.

This isn't dictation. This is a **two-way voice conversation** with your coding agent.

## The One-Line Summary

**Your Cursor cloud agent just got a voice. Speak to it → it codes → it speaks progress updates → you steer out loud. Powered by Grok Voice. Works in IDE, web, and iOS. All paid plans.**

---

## What Voice Chat Actually Is

You start a Cloud Agent. Instead of typing, you click the **waveform button** (where Send usually sits) and say:

> *"Build a dashboard for the marketing team showing campaign ROI by channel. Pull from our Postgres warehouse. Make it filterable by quarter."*

The agent:
1. **Listens** to your full request
2. **Replies out loud** — *"Got it. I'll scaffold a Next.js app, connect to Postgres, build the dashboard..."*
3. **Starts working** — you hear short progress notes: *"Setting up database... writing queries... building UI components..."*
4. **Speaks the result** — *"Dashboard deployed at marketing-roi.yourcompany.cursor.app. Want me to add a date range picker?"*

You never touch the keyboard unless you want to.

---

## Voice Chat vs. Dictation (They're Different)

| Feature | Dictation (Old) | Voice Chat (New) |
|---------|-----------------|------------------|
| **Trigger** | Cmd+Shift+Space | Click waveform button |
| **Direction** | One-way (you → text) | Two-way (you ↔ agent voice) |
| **Agent replies** | Text only | **Spoken aloud** |
| **Progress updates** | Read in chat | **Heard in real-time** |
| **Use case** | Quick text input | **Supervising long-running work** |

**Dictation** = "type with your voice"
**Voice Chat** = "manage an agent with your voice"

## How to Start a Voice Call

```bash
# 1. Update Cursor to latest (3.29+)
# Cursor menu → About → check version

# 2. Open a Cloud Agent (paid plan required)
# Cmd/Ctrl+Shift+P → "Cursor: Create Cloud Agent"
# Or click the cloud icon in the agent panel

# 3. When agent is idle and chat input is empty:
# Click the WAVEFORM button (where Send button usually is)

# 4. Speak your request
# Agent replies out loud, works, speaks progress

# 5. Keep talking while it works
# "Actually, add a dark mode toggle"
# "Make the charts interactive"
# "Deploy to staging instead"
```

**On iOS:** Say *"Hey Siri, call Cursor"* to start a call with a new agent. Mute/hang up from Lock Screen with Live Activity.

## Why This Changes the Agent Loop

### Before: Keyboard Babysitting
1. Type prompt → wait → read response → type correction → wait → read → type...
2. Long tasks = you stare at spinner, wonder if it's stuck
3. Context switching: code review → Slack → back to agent → lost train of thought

### After: Voice Supervision
1. **Speak request** → agent acknowledges **out loud**
2. **Hear progress** while you do something else (coffee, walk, other code)
3. **Steer mid-flight** — *"Skip the tests for now, just get the UI working"*
4. **Hear completion** — *"Done. Live at staging-dashboard.cursor.app"*

**The agent becomes a colleague you talk to, not a terminal you watch.**

## Real Workflows That Just Got Easier

### Workflow 1: The "Walking Meeting" Refactor
```markdown
1. Start Cloud Agent: "Refactor the auth module to use JWT rotation"
2. Start Voice Chat
3. Walk to meeting / grab coffee / stretch
4. Agent: "Found 3 files using old token logic. Updating..."
5. You (via phone/headphones): "Also update the middleware tests"
6. Agent: "Tests updated. All passing. Ready for review."
7. You're back at desk → review diff → merge
```

### Workflow 2: Non-Technical Stakeholder Loop
```markdown
1. PM says: "Can the sales dashboard show quarterly comparison?"
2. You: *Voice Chat* "Add quarter-over-quarter comparison to sales dashboard"
3. Agent builds it, speaks progress
4. You hand phone to PM: "Talk to it directly"
5. PM: "Make the bars green for growth, red for decline"
6. Agent: "Done. Chart colors updated."
7. PM sees live preview → approves → you merge
```

### Workflow 3: Debugging Without Context Switching
```markdown
1. Test fails in CI
2. Voice Chat: "The payment integration test is flaky. Investigate and fix."
3. Agent: "Reading test... found race condition in webhook handler... fixing..."
4. You: *continue reviewing other PRs*
5. Agent: "Fixed. Added retry with exponential backoff. Tests passing."
6. You: "Push the fix"
7. Agent: "Pushed to fix/payment-flaky branch. CI running."
```

## Privacy & Voices

**Voices (Grok Voice):** Ara, Eve, Leo, Rex, Sal — pick in Voice Settings.

**Privacy Mode:** Toggle ON → **zero data retention**. Your voice never leaves the session. Grok Voice processes and discards immediately.

**Data handling without Privacy Mode:** Standard Grok Voice processing (xAI's voice model).
