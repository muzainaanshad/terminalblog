**You don't need an IDE anymore.** Bolt.new, Replit Agent, v0.dev, and Lovable all run in your browser. You type a prompt. They write code, spin up a dev server, and give you a live URL. No git, no terminal, no local setup.

This isn't "chat with an AI." This is **the browser becoming the IDE.**

## The One-Line Summary

**Bolt.new** = fastest zero-to-live for React/Next.js/Vue. **Replit Agent** = only one with real backend (DB, auth, secrets, scheduled jobs). **v0.dev** = best for designers who want shadcn/UI components that don't look like AI garbage. **Lovable** = best for non-technical founders who need a working SaaS skeleton yesterday. Pick your fight.

## Why Browser Agents Are a Different Category

Terminal agents (Cursor, Claude Code, Codex, Zed, OpenCode) assume **you own the environment**. You bring the repo, the terminal, the deployment pipeline. The agent helps you *inside* that world.

Browser agents **own the environment for you**. They give you:
- A file tree you can edit
- A running dev server (Vite/Next.js)
- A live preview that hot-reloads
- One-click deploy (Netlify, Vercel, Replit)
- Zero local dependencies

**The trade-off:** You lose git history, local debugging, offline work, and full control over the stack. You gain: *I have an idea → I have a URL in 3 minutes.*

## Bolt.new — The Speed Demon

**Best for:** "I need a working React app *right now* and I'll figure out the backend later."

### What It Does Well
- **Instant scaffold**: Prompt → file tree → live preview in ~30 seconds
- **Stack detection**: Infers Next.js, Vite+React, Vue, Svelte, Astro from your prompt
- **Iterative editing**: Click a file → tell it what to change → sees preview update
- **Netlify deploy**: One click → live URL with custom domain support
- **No auth required to start**: Anonymous sessions work (but don't persist)

### Where It Falls Short
| Gap | Reality |
|-----|---------|
| **No real backend** | Supabase/Firebase integration is manual — you paste keys, you write API routes |
| **No database** | You're on your own for Prisma, Drizzle, raw SQL |
| **No secrets management** | Env vars exist but no vault, no rotation, no team sharing |
| **Session fragility** | Refresh the tab? Hope you exported. No git, no recovery. |
| **Complex state** | Multi-page apps with auth + payments + webhooks = manual wiring |

### The Honest Verdict
**Use Bolt when:** You're prototyping a frontend, building a landing page, testing a UI concept, or need a disposable demo for a stakeholder meeting *today*.

**Don't use Bolt when:** You need user accounts, payments, webhooks, background jobs, or any backend that survives a browser refresh.

## Replit Agent — The Only One With a Real Backend

**Best for:** "I need a full-stack app with a database, auth, and scheduled jobs — and I don't want to manage infrastructure."

### What It Does Well
- **Real PostgreSQL**: Provisioned, managed, connection string injected automatically
- **Auth out of the box**: Clerk/Auth.js integration — login, signup, sessions, protected routes
- **Secrets vault**: Environment variables with team sharing, rotation, audit log
- **Scheduled jobs**: Cron-style tasks that actually run (not "deploy a Vercel cron and pray")
- **Always-on VM**: Your app stays warm. No cold starts. Webhooks receive 24/7.
- **Git sync**: Push to GitHub from the UI. Real commits. Real history.
- **Mobile app**: Edit/run on phone. Real file tree. Real terminal if you want it.

### Where It Falls Short
| Gap | Reality |
|-----|---------|
| **Slower first render** | 2-3 minutes to first preview (provisioning DB, installing deps) |
| **Opinionated stack** | Node/TypeScript/Postgres — Python/Go/Rust need manual setup |
| **Pricing scales fast** | Free tier = 1 always-on repl. Teams = $20/seat + compute. Production = $50-200/mo. |
| **Less design control** | You get shadcn/Tailwind but customizing design system = more work than v0 |
| **Agent can get stuck** | Complex multi-step tasks sometimes loop — need to intervene in terminal |

### The Honest Verdict
**Use Replit Agent when:** You're building a real SaaS — users, payments, webhooks, background jobs, admin dashboard — and you want *one platform* that handles infra so you don't.

**Don't use Replit Agent when:** You only need a frontend, you're optimizing for sub-minute iteration, or you need a stack Replit doesn't natively support.

## v0.dev — The Designer's Agent

**Best for:** "I know exactly what this should look like. Give me clean shadcn components I can drop into my real codebase."

### What It Does Well
- **shadcn/UI native**: Every component uses Radix + Tailwind + class-variance-authority — copy-paste ready
- **Design system awareness**: Understands "primary/secondary/destructive" variants, dark mode, responsive breakpoints
- **Component library, not apps**: Generates *pieces* (forms, tables, charts, navbars) not full routes
- **Code you'd write**: No weird abstractions. `cn()` utility. Proper TypeScript. Accessible markup.
- **v0 Blocks**: Save/reuse generated components across projects. Team sharing on paid plans.
- **Export to GitHub/CodeSandbox**: One click → real repo with your components.

### Where It Falls Short
| Gap | Reality |
|-----|---------|
| **No backend generation** | Zero. No API routes, no DB, no auth. You integrate into *your* Next.js app. |
| **No live preview of full app** | Preview is the component in isolation. No routing, no state management. |
| **No deployment** | You copy code → your repo → your Vercel. v0 doesn't host. |
| **Prompting is an art** | "Build a dashboard" gives generic. "Build a shadcn data table with column sorting, row selection, server-side pagination, and optimistic delete" works. |
| **Free tier = 10 generations/day** | Paid = $20/mo for 100 + Blocks + team. |

### The Honest Verdict
**Use v0 when:** You're a frontend dev/designer building a real Next.js app and need production-grade UI components *fast*. You have the backend. You need the frontend to not look like AI wrote it.

**Don't use v0 when:** You want a full app generated, you need backend code, or you're not using Next.js + Tailwind + shadcn.

## Lovable — The Non-Technical Founder's Agent

**Best for:** "I have a SaaS idea. I don't code. Give me something I can show investors by Friday."

### What It Does Well
- **Product-first prompting**: "SaaS for dog walkers with Stripe subscriptions, admin panel, email notifications" → full skeleton
- **Supabase integration**: Auth + DB + storage + edge functions — connected with one click (OAuth)
- **Stripe billing**: Subscription plans, checkout portal, webhook handling — generated, not stubbed
- **Admin panel**: Auto-generated from your data model. CRUD + search + filters + exports.
- **Email/resend**: Transactional emails (welcome, password reset, invoice) wired and working.
- **One-click deploy**: Vercel + Supabase + Stripe → live. Custom domain in settings.
- **Non-technical UI**: No file tree by default. Chat → preview → "make the button blue" → done.

### Where It Falls Short
| Gap | Reality |
|-----|---------|
| **Lock-in risk** | Your code lives in Lovable. Export = zip file. No git sync. No PR workflow. |
| **Custom logic = pain** | Anything beyond "standard SaaS patterns" requires the "Developer Mode" (beta) or manual Supabase/Edge Function work |
| **Pricing** | Free = 5 projects, 100 generations. Launch = $50/mo. Scale = $200/mo. Team = $400/mo. |
| **Debugging opacity** | When something breaks, you don't have a terminal. You have chat history. |
| **Design flexibility** | Opinionated design system. Custom branding = CSS overrides or Developer Mode. |

### The Honest Verdict
**Use Lovable when:** You're a non-technical founder (or PM) who needs a *working, billable SaaS* to validate demand. You'll hire engineers later to rewrite. You need it *now*.

**Don't use Lovable when:** You're a developer who wants control, you need git workflow, you're building something non-standard, or you plan to maintain this code long-term.

## The Workflow That Actually Works (Hybrid)

**Stop picking one. Chain them.**

```bash
# 1. v0.dev → Generate your design system
#    "shadcn dashboard layout: sidebar + topbar + data table + chart cards + dark mode"
#    → Export to GitHub → Clone locally

# 2. Cursor / Claude Code / Zed → Build the backend
#    Prisma schema → tRPC routers → Next.js API routes → Stripe webhooks → Cron jobs
#    → Push to GitHub → Vercel preview deploy

# 3. Bolt.new → Rapid prototype a specific flow
#    "Onboarding wizard: 3 steps, conditional fields, progress save to localStorage"
#    → Copy the component code → Paste into your real app

# 4. Replit Agent → Spin up a throwaway staging environment
#    "Deploy my full stack with test DB + test Stripe keys"
#    → Share URL with QA / designer / stakeholder
#    → Kill when done (no cloud bill)

# 5. Lovable → Validate a new product idea in 30 minutes
#    "Micro-SaaS: PDF invoice generator for freelancers, Stripe one-time payments"
#    → Live URL → Send to 10 potential users → If they pay, rebuild properly
```

**The browser agents are for *speed of validation*. The terminal agents are for *speed of execution*. You need both.**

## What the Vendors Won't Tell You

### 1. **None of them replace git.**
Bolt = no git. Lovable = no git. v0 = export only. Replit = git sync but it's a mirror, not your source of truth. **Your repo lives locally. Period.**

### 2. **The "AI wrote it" tax is real.**
Code generated by browser agents has patterns: over-fetching, missing error boundaries, no loading states, hardcoded strings, no tests. **You will rewrite 40-60% before production.** Budget for it.

### 3. **Vendor lock-in is a spectrum.**
- **Low**: v0 (components → your repo), Bolt (Netlify deploy → your DNS)
- **Medium**: Replit (git sync + always-on VM = convenient trap)
- **High**: Lovable (code only exports as zip, Supabase/Stripe tied to their OAuth)

### 4. **Free tiers are for learning, not production.**
All four hit hard limits (generations, compute, projects) within a week of real work. **Budget $50-200/mo if you're serious.**

### 5. **The model matters less than the harness.**
Bolt uses Anthropic. Replit uses custom + Anthropic. v0 uses Vercel's tuned models. Lovable uses OpenAI + custom. **The UX around the model (file tree, preview, deploy, secrets) determines your velocity more than which LLM is underneath.**

## The Bottom Line

**Browser agents didn't kill the terminal. They killed the "blank repository" phase.**

You used to spend Day 1 on: `npx create-next-app`, `npm i prisma @clerk/nextjs stripe`, `docker compose up -d`, `vercel env add`, `.env.local`, `git init`, first commit.

Now: **Prompt → Live URL → Iterate → Export → Real Repo.**

The winners in 2027 aren't the devs who pick *one* browser agent. They're the devs who **chain the right tool to the right phase** and never write boilerplate again.
