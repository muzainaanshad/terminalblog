Cline Desktop **v0.0.49 dropped October 26** — and it's the release that finally makes the app feel like a **real IDE**, not just a chat wrapper with a sidebar.

We're talking: **Changes panel with per-turn diffs**, **project file tree with git status**, **built-in terminal (Ctrl+\`)**, **Local Models page for Ollama/LM Studio**, **configurable keybindings**, **PR status in the header**, and a **hub startup screen with diagnostics** instead of cryptic errors.

If you've been using Cline Desktop and thinking \"this is nice but it's missing...\" — **this update adds most of what was missing.**

## Changes Panel: Finally, Per-Turn Diffs That Make Sense

This is the big one. **Every turn now shows what files changed.** Click the summary under a completed turn → opens the Changes pane scoped to that turn. Click the Changes button in the header → see the whole session's changes.

```text
Before: "The agent edited some files... good luck finding which ones"
After:  Turn 3 → 3 files changed → click → diff view → approve/revert
```

**For beginners:** This is how you *verify* what your agent did. No more scrolling through transcripts hunting for `edit_file` calls. The diff is right there.

---

## Project Files Panel: Your Codebase Beside the Conversation

The folder button in the session header opens a **file tree panel** with:

- **Git status letters** (M = modified, A = added, D = deleted) on every file
- **Read-only tabbed viewer** — click a file, it opens in a tab
- **Marker on files the session changed** — you know exactly what the agent touched
- **File/Diff toggle on agent-edited files** — see the diff inline
- **Works on local AND SSH environments** — your remote codebase is visible too

**This replaces the \"where am I?\" feeling** with a persistent spatial map of your project.

---

## Integrated Terminal: `Ctrl+\`` and You're In

Press `Ctrl+\`` (backtick) → terminal panel opens at the bottom. It runs in **your session's environment** — same working directory, same SSH connection, same everything.

```bash
# Quick test without leaving Cline
npm test
# or
git status
# or
python -c "print('hello from agent session')"
```

**For beginners:** This is the terminal you'd open anyway. Now it's *inside* the agent conversation. Run a quick command, see the output, continue chatting. No context switch.

## Local Models Page: Ollama & LM Studio Finally Have a Home

Settings → **Local Models** is a brand new page that gives you:

- **Setup guidance** for Ollama and LM Studio (no more Googling \"how do I connect my local model\")
- **Model details & storage** — see what's downloaded, how much space it uses
- **Memory usage chip in the composer** — shows how much RAM the loaded model consumes

**If you've wanted to run local models but the setup was opaque — this page solves it.** You see exactly what's available, what's loaded, and what it costs in memory.

---

## Configurable Keybindings (Including \"Don't Quit by Accident\")

**Every keybinding is now configurable** in Settings (also reachable from the app menu and Help menu).

The best default: **Quit requires holding the shortcut for 1 second (macOS)**. No more `Cmd+Q` muscle memory killing your session when you meant `Cmd+W`.

**For power users:** Remap everything. Make `Ctrl+K` open the terminal, `Ctrl+L` focus the composer, whatever fits your fingers.

---

## Hub Diagnostics: No More Silent Failures

**Before:** Hub fails to start → every action fails with \"desktop backend endpoint not ready\". You're stuck.

**Now:** Hub fails to start → **startup screen with Retry button and Export diagnostics**. You can actually *do something* — retry, grab logs, file a useful issue.

---

## Task Attachment: No More Duplicate Runs

**Open a task that's already running in another Cline app** → **attaches to that run** instead of starting a second one that couldn't be stopped.

**Requests waiting on an app that closed mid-task** → **fail with a clear message** instead of hanging forever.

This is the end of \"wait, did I already start this somewhere else?\"

---

## Large Transcript Recovery: 8MB+ Sessions Work Again

Sessions with transcripts over ~8MB **can be resumed again**. Before, the transcript was sent to the Hub twice, hitting the message size limit.

**If you have long-running sessions — they work now.**

---

## SSH & ProxyJump: Remote Environments Just Connect

- SSH remotes behind a **ProxyJump alias** now connect
- Connect budget: 10s → **30s**
- Per-command limit: **60s**
- Tunnel readiness: **40s**
- When ssh exits mid-upload → **real error reported** (not `EPIPE`)
- `LocalForward` on alias no longer collides with tunnel

**If you code on remote servers — this release respects your SSH config.**

---

## Model Retry Logic: Smarter, Fewer Retries

- Model requests retry **at most 3 times** (down from 5)
- Failed attempts recorded in Langfuse traces
- Cancelled requests no longer reported as Langfuse errors
- A turn whose connection drops after **only reasoning streamed** → **retried** (partial reasoning discarded)
- Turns with text, media, or tool calls → **never retried** (preserves correctness)

---

## Kimi K3 Gets `max` Reasoning (Fixed)

Kimi K3 now gets `max` reasoning for **Extra High and Max** effort levels — instead of an `xhigh` setting it rejects.

**First things to try after update:**

3. **Press `Ctrl+\`` → terminal opens at bottom**
4. **Settings → Local Models → see your Ollama/LM Studio models with memory chips**
