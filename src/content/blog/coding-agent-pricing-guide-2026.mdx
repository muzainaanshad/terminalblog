## Free Agents (9 agents)

These agents cost nothing to install. You bring your own API keys for the LLM.

**Actual cost:** $0 for the agent + ~$5-50/month in API usage depending on how much you code.

### API Cost Breakdown for Free Agents

When you use a free agent, you're paying for the LLM API calls. Here's what that looks like in practice:

**Light usage (1-2 hours/day):**
- OpenRouter free tier: $0
- Anthropic API (Claude 3.5 Sonnet): ~$10-20/month
- OpenAI API (GPT-4): ~$15-30/month

**Heavy usage (4+ hours/day):**
- OpenRouter paid: ~$20-50/month
- Anthropic API: ~$40-100/month
- OpenAI API: ~$50-120/month

**Cost optimization tips:**
1. Use OpenRouter's free models for simple tasks
2. Switch to paid models only for complex reasoning
3. Set token limits to prevent runaway costs
4. Use context caching to reduce redundant API calls

### What You're Actually Paying For

**Claude Code ($20-200/month):**
- $20 tier: Basic access, limited context window
- $100 tier: Full context, subagents, skills
- $200 tier: Priority access, longer context, custom tools
- Best for: Complex reasoning, multi-file refactors, architecture decisions

**Cursor ($20-200/month):**
- $20 tier: Basic editing, limited completions
- $100 tier: Full composer, background agents
- $200 tier: Priority model access, custom rules
- Best for: Fast editing, UI work, rapid prototyping

**Codex CLI ($20/month):**
- ChatGPT Plus subscription required
- Parallel execution in cloud sandbox
- Best for: Batch processing, CI/CD integration, automated testing

**Copilot CLI ($10-39/month):**
- $10: Basic completions
- $39: Advanced models, custom instructions
- Best for: GitHub-centric workflows, code review, PR automation

### AmpCode Pricing Deep Dive

AmpCode uses a credit system:
- **Free tier:** ~$10/day in credits (enough for 2-3 hours of coding)
- **Paid tier:** Variable based on usage
- **Risk:** Complex tasks can burn credits fast
- **Best for:** Occasional use, trying out before committing

**Cost comparison:** If you code 4 hours/day, AmpCode costs ~$200-300/month vs $20/month for a subscription.

## The Hidden Costs

1. **API tokens** — Free agents still need LLM access
2. **Context window waste** — Failed tasks burn tokens
3. **Multi-agent sprawl** — Two subscriptions × multiple tools
4. **Overage charges** — Usage-based billing beyond the base plan

## ROI Calculation

**Time savings:** Coding agents typically save 30-50% of coding time.

**Example:**
- Senior developer: $100/hour
- 4 hours/day coding = $400/day
- 30% time savings = $120/day saved
- Monthly savings: ~$2,400 (20 working days)
- Even at $400/month for agents, that's **6x ROI**

**Break-even point:**
- Free agents: Immediate ROI
- $20/month subscription: Break-even at 1 hour saved
- $200/month subscription: Break-even at 2 hours saved

## Recommendations by Use Case

**Solo developer, budget-conscious:**
- Start with: Free agent (Hermes or OpenCode) + OpenRouter free tier
- Upgrade to: $20/month subscription when you hit limits
- Avoid: Pay-as-you-go (costs add up fast)

**Startup, small team:**
- Start with: Claude Code $20 tier for lead developer
- Standardize on: One subscription agent for consistency
- Avoid: Multiple subscriptions (context switching kills productivity)

**Enterprise, compliance-heavy:**
- Start with: Self-hosted agents (Hermes, OpenCode)
- Add: Subscription agents for specific use cases
- Avoid: Pay-as-you-go (budget unpredictability)

**Student/hobbyist:**
- Start with: Free agents + free API tiers
- Maximize: OpenRouter free models, community resources
- Avoid: Paid subscriptions (budget for learning, not tools)

## Cost-per-task benchmarks (how to actually predict your bill)

Sticker prices are the easy part. The real bill is tokens, and the only way to predict it is per-task. These are realistic 2026 numbers from our cost-tracking coverage ([Oh My Pi usage reporting](/blog/oh-my-pi-usage-cli-reporting-cost-tracking/), [Codex cloud economics](/blog/codex-cloud-execution-economics/)):

| Task | Tokens | ~API cost (Claude Sonnet-tier) |
|------|--------|-------------------------------|
| One-file bug fix | 20–40K | $0.10–0.30 |
| Feature across 5–10 files | 100–200K | $1–3 |
| Refactor + full test suite | 300–600K | $5–12 |
| Long agentic session (tool loops) | 1–3M | $10–40 |

Multiply by your weekly session count and you get a real monthly number — the one most people skip, and the one that explains why a "free" agent still shows up on a credit-card statement. [Token overhead differences between harnesses](/blog/claude-code-vs-opencode-token-overhead/) can double or halve these figures, so measure your own with a usage CLI instead of trusting this table.

## Budget templates for 2026

- **Hobbyist ($0–10/mo):** free BYO agent + free-tier model + one API key; set a hard token cap and a monthly spend alert. See the [free-agent options](/blog/real-cost-of-ai-coding-agents/).
- **Solo professional ($20–60/mo):** one $20 subscription (Claude Code or Cursor) plus a BYO agent for overflow; stop at one subscription — the [pricing problem post](/blog/pricing-problem-ai-coding-tools/) explains why sprawl is the hidden tax.
- **Team ($30–80/seat/mo):** standardize on one subscription for consistency; add a second tool only for automation (e.g. a cron-capable free agent). **One subscription per seat is the rule.**
- **Enterprise ($50–200/seat/mo):** self-hosted/local agents for the sensitive repos + managed subscriptions for velocity; negotiate annual pricing at 20+ seats.

The [what developers say about coding agent pricing](/blog/what-devs-say-coding-agent-pricing/) thread shows most teams end up in the middle: one subscription, one BYO agent, and one automation twin. That convergence is a signal, not an accident — it is the shape that actually fits a work week.

## Verdict

**Free agents win on cost.** Subscription agents win on polish and benchmark scores. Most developers end up with one of each.

The best strategy:
1. Start free to learn what you need
2. Add one subscription when you hit limits
3. Avoid multi-agent sprawl (pick one primary tool)
4. Reevaluate quarterly as pricing changes
