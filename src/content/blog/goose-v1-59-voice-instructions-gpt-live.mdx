Block's Goose **v1.59.0** landed November 10. The headline for most users: **configurable voice instructions per session start** — your live-voice agent finally speaks the way you want it to.

---

## The Feature You'll Hear: Configurable Voice Instructions

**What it is:** When you start a live-voice session, you can now pass **custom voice instructions** that persist for that session. Not global config — *per-start*.

**Why it matters:** "Speak concisely." "Use technical terms." "Pretend you're a senior engineer reviewing my PR." The voice agent follows your style, not a generic preset.

**For beginners:** Start Goose with voice: `goose --voice --voice-instructions "Speak like a tired senior dev who's seen it all"`. It works.

---

## Configurable GPT-Live Endpoint, Model, and Key

**What it is:** Full control over the GPT-Live connection:
- Custom endpoint (not just OpenAI's)
- Custom model selection
- Custom API key per session

**Why it matters:** Enterprise proxy, self-hosted models, different providers — Goose's voice layer is now pluggable. You're not locked to OpenAI's Realtime API.

---

## Session Filtering by Client Tags (ACP)

**What it is:** Filter sessions/list by **client tags** — ACP clients (editors, IDEs) can tag their sessions. You see "VS Code sessions" vs "CLI sessions" vs "Custom integration sessions."

**Why it matters:** If you run Goose in VS Code, Cursor, and terminal simultaneously, you can now query "show me only my VS Code sessions." No more guessing which session belongs to which client.

---

## Resume Completed Delegates with Follow-Up (Subagents)

**What it is:** A completed subagent (delegate) can now be **resumed with a follow-up task**. The delegate picks up where it left off, context intact.

**Why it matters:** Subagents aren't fire-and-forget anymore. "That refactor you did — now add tests for it" works. The delegate remembers the codebase state.

---

## GDK: Stop, Approval, and Tool Hook Operations

**What it is:** The Goose Agent SDK (GDK) now exposes:
- **Stop operations** — programmatically halt an agent
- **Approval operations** — hook into the approval flow
- **Tool hook operations** — intercept/transform tool calls

**Why it matters:** Building on top of Goose? You now have the primitives for custom control planes, policy enforcement, and observability.
