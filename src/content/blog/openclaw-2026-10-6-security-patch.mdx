## The Security Fix: eMudhra Certificate Compromise

**What happened:** eMudhra (a certificate authority) had its signing keys compromised. The October 2026 Node.js security releases (24.22.1, 26.12.1) revoke trust in certificates signed by those keys.

**What OpenClaw did:** v2026.10.6 **requires** the patched Node versions. The installer validates this on startup.

| Node Line | Minimum Version | Why |
|-----------|-----------------|-----|
| **Node 24** | **24.22.1+** | Revokes eMudhra trust |
| **Node 26** | **26.12.1+** | Revokes eMudhra trust |

**If you use standalone installers** (npm global, Docker, desktop apps): They bundle the fixed runtime. Just update.

**If you manage Node manually** (nvm, fnm, system package manager): `nvm install 24.22.1` or `nvm install 26.12.1` before running OpenClaw.

## The Bottom Line

**2026.10.5 made the platform reliable. 2026.10.6 makes it secure.**

The eMudhra compromise was real — certificates signed by compromised keys could be used for MITM, impersonation, or trust bypass. Node.js revoked them. OpenClaw enforces the patched runtime.

Beyond security: **233 PRs of pure reliability.** Windows installs that don't lie about "offline maintenance." Updates that tell you exactly what's wrong and how to fix it. Gateways that shut down gracefully instead of leaving dead workers. Imports that survive encoding edge cases.

For a beginner: **update and forget.** The installer handles Node. The fixes prevent the weird failures that make you think "is it me or the tool?"
