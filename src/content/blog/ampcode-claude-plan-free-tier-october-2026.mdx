## What Actually Happened

**October 10**: AmpCode added a **"Claude Code" mode** to the Dial. When you create a new thread, pick **Mode → Claude Code**. It asks to link your Claude subscription if you haven't already. Done.

Under the hood, this mode uses the **Claude Agent SDK** instead of Amp's own agent. But Amp made it all work: orbs and runners, thread sharing, portals, multiplayer, thread-to-thread messaging and orchestration.

You're not just getting "Claude in a terminal." You're getting **Amp's full infrastructure** — shared runners, global skills, multi-Puck orchestration — running on *your* Claude plan.

## How to Set It Up (Takes 3 Minutes)

```bash
# 1. Install Amp (Mac app recommended for beginners)
# Download from https://ampcode.com/download

# 2. Auth + link your Claude plan
amp auth
amp dial --link-anthropic
# Opens browser → approve → done

# 3. Start a shared runner on your Mac (or any machine)
amp run --share

# 4. Create a workspace skill (now global!)
mkdir -p .amp/skills/my-team-linter
cat > .amp/skills/my-team-linter/skill.yaml << 'EOF'
name: "Team Linter"
description: "Enforces our internal patterns"
tools: ["edit", "bash"]
EOF

# 5. Use it everywhere — it's global now
amp --skill my-team-linter "review this PR for our patterns"

# 6. Try multiple Pucks
# Open ampcode.com → click "New Puck" → have parallel conversations
```

## FAQ

**What does "Use Your Claude Plan in Amp" actually mean?**
When creating a thread, pick Mode → Claude Code. Link your Claude Pro/Max subscription. Amp uses the Claude Agent SDK for model calls, but wraps it in Amp's orchestration (runners, orbs, skills, Pucks, portals). You pay Anthropic; Amp is free.

**Do I need a Claude Max plan, or does Pro work?**
Both work. Pro gets you Sonnet 5.5 / Haiku 5.5. Max gets you Opus 5.5. The Dial's "Claude Code" mode respects your plan's entitlements.

**Can I use this with my company's Anthropic Enterprise agreement?**
Yes. The Claude Agent SDK supports enterprise plans. Link your org's subscription the same way.

**Is there any catch?**
Amp's orchestration layer is free, but you need to bring compute (your Mac, a cloud VM) for runners. The Mac app handles this natively. For cloud runners, you provide the VM.

**Can I still use Amp's own models (GPT-6 Astra, Fable 5.1) without a Claude plan?**
Yes. The Free Agent tier lets you bring *any* model keys (OpenAI, Google, Anthropic, local/Ollama). Or use Amp's hosted models with a flat subscription if you prefer predictability.
