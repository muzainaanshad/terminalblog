You've been picking models based on benchmarks someone else ran on problems you don't have. **Windsurf Wave 14 just changed that.**

The new **Arena Mode** spins up two Cascade agents side-by-side on the *same task in your actual codebase* — model names hidden — and you vote on which output actually works. No more "GPT-5 beats Claude on SWE-bench." You see which model solves *your* refactor, *your* bug, *your* feature.

## The Headline: Arena Mode — Your Codebase, Your Vote

**Launched in Wave 14** (building on Wave 13's foundation). Open the model picker → select **Arena tab** → pick "Fast models vs Smart models" or choose specific models → start prompting.

What happens:
1. **Two Cascade agents launch side-by-side** on the exact same prompt
2. **Model names are hidden** — you see Agent A and Agent B
3. **Both run in your context** — your files, your MCP servers, your git history
4. **You vote** — which output is better? The Elo updates instantly
5. **Personal + global leaderboards** — your votes build your personal ranking; aggregated votes build the community one

**First week: all battle groups are FREE** (roughly 50% off inference since you're running double). After that, pricing normalizes to single-run cost.

## Why This Isn't Just "Chatbot Arena in Your Editor"

Chatbot Arena (lmarena.ai) changed model evaluation. But it has three blind spots Windsurf fixes:

| Chatbot Arena | Windsurf Arena Mode |
|---------------|---------------------|
| Blank slate — no codebase context | **Your actual repo** — agents see your files, imports, patterns |
| Single-turn tests | **Multi-turn workflows** — refactors, debugging, feature work |
| Strangers voting | **You voting** — on tasks you actually care about |

**The speed penalty problem:** Arena throttles to the slower model. Windsurf doesn't — fast models get credit for keeping you in flow. Three quick turns with a "fast" model often beats one long prompt with a "smart" one. You feel the difference immediately.

**Self-consistency bonus:** Even if you don't care about leaderboards, running two agents on the same task and picking the best is **Best-of-N** — research shows 20+ percentage point uplift on complex tasks. You're the judge. No LLM-as-judge bias.

## Plan Mode — Stop Hallucinations at the Source

**Also in Wave 14.** Toggle Cascade to **Plan Mode** (next to Code/Ask). The agent:
1. **Reads your request**
2. **Asks clarifying questions** (or you type "megaplan" for the advanced version)
3. **Produces a structured plan** — steps, files to touch, assumptions, risks
4. **Waits for your approval** before writing a single line

**Why it works:** Most AI code failures aren't model quality — they're *underspecified prompts*. Plan Mode forces the "what" before the "how." You catch the "I assumed you meant X" moment *before* it becomes 200 lines of wrong code.

**Pro tip:** Make Plan Mode default in your team config. Treat any agent output that skipped planning as requiring a higher review bar.

## FAQ

**Does Arena Mode work with self-hosted models?**
Yes — if you've configured custom models via OpenRouter or local providers, they can enter battle groups.

**Can I run more than 2 agents at once?**
Arena Mode is 1v1. For parallel multi-agent workflows, use Wave 13's Parallel Cascade Sessions (Git worktree isolation, multi-pane view).

**What happens to my votes?**
They build your **personal leaderboard** (only your votes) and feed the **global leaderboard** (aggregated across Windsurf users). Team/enterprise leaderboards coming for larger orgs.

**Is "Devin Desktop" the same as Windsurf?**
Yes — Windsurf was rebranded to Devin Desktop. Same product, same Cascade agent, same Wave releases. The `windsurf-stable.codeiumdata.com` download URLs confirm the lineage.

**Can I use Arena Mode on the free tier?**
Yes — all battle groups free for the first week, then standard pricing applies. Free tier has generous daily limits.
