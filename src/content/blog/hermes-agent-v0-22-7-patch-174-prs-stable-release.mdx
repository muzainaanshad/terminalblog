This patch is smaller (174 PRs, 581 commits, 29 issues) but it's the **polish layer** that makes the Threshold release feel complete: lead routing for group chats, cron-to-group-chat, Kanban boards as tabs, TeX/Mermaid rendering, Desktop update error reports, and more.

If you updated to v0.22.6 yesterday, this is the follow-up that sands down the edges you'll actually hit.

## The Headline Features (Ranked by Daily Impact)

### 1. Lead Routing for Desktop Group Chats — Opt-In, With a Badge

**What it is:** Group chats can now designate a **Lead agent**. The Lead gets a badge on the room header and routes messages — other agents defer to the Lead for decisions.

**Why it matters:** Before, group chats were flat — every agent equal, every message broadcast. Now: **one agent owns the thread**. You set up a reviewer Lead, a coder Lead, a planner Lead. The badge shows who's driving.

```bash
# In Desktop → Group Chat → Settings → toggle "Lead Routing"
# Pick Lead agent → badge appears on room header
# Messages route through Lead → cleaner coordination
```

**For beginners:** This is the moment group chats become **usable for real work** — not just demos. You get a team lead without the management overhead.

---

### 2. Cron Jobs That Post Into Group Chats

**What it is:** Your scheduled cron jobs can now **post their output directly into a Group Chat** — not just notifications, but full messages that agents in the chat can see and act on.

**Why it matters:** Cron jobs were isolated. Now: **a cron finishes → posts summary to group chat → Lead agent picks it up → delegates to coder agent → work continues**. The cron becomes a team member.

```bash
# Configure cron to post to group chat
hermes cron create --name "nightly-tests" \
  --schedule "0 2 * * *" \
  --command "run-tests" \
  --post-to-group-chat "team-alpha" \
  --as-agent "test-runner"
```

---

### 3. Room Purpose & Shared Notes — Context That Stays

**What it is:** Every group chat now has a **Purpose field** and **Shared Notes** — persistent context that every agent in the chat sees, survives restarts, and guides behavior.

**Why it matters:** You set the purpose once: *"This chat handles the payments refactor. Lead: payments-architect. Rules: no direct DB edits, all changes via migration files."* Every agent reads it. No re-explaining.

---

### 4. Pinned Kanban Boards as Quick-Switch Tabs

**What it is:** Kanban boards can now be **pinned as tabs** in the group chat column — one click switches between board view and chat view.

**Why it matters:** Your task board lives **beside** the conversation. Drag a card → chat about it → update status → all in one column. No tab switching, no context loss.

---

### 5. `$$TeX$$` Diagram Labels & Mermaid Rendered Through Pele

**What it is:** Mathematical notation (`$$E=mc^2$$`) and **Mermaid diagrams** now render inline through Pele — the same engine powering the webapp.

**Why it matters:** You ask an agent to *"diagram the auth flow as a sequence diagram"* → it outputs Mermaid → **renders instantly in chat**. No copy-paste to a viewer. The diagram *is* the message.

---

### 6. Desktop Update Error Box — Output + Report Link

**What it is:** When a Desktop update fails, you now get a **modal showing the actual error output** with a **one-click "Report Issue" link** that pre-fills a GitHub issue with the error.

**Why it matters:** Before: "Update failed. Try again." Now: **you see exactly why**, and the maintainers get a reproducible report. Faster fixes for everyone.

---

### 7. Web Access Step Clock — Know Where Start Is

**What it is:** Web Access (the browser automation skill) now shows **which step Start is on with a running clock** — live progress, not a spinner.

**Why it matters:** Long browser tasks (scraping, testing, form filling) are no longer a black box. You see: *"Step 3 of 12: filling checkout form — 0:47 elapsed."*

---

### 8. Telegram on Team Gateway — Link Account to Shared Bot

**What it is:** Team Gateway now supports **Telegram via a shared bot**. Link your account → the team bot handles messages → no per-user bot tokens needed.

**Why it matters:** One bot, whole team. Admin sets it up once. Everyone gets Telegram notifications, commands, group chat bridge — zero individual config.

---

### 9. Slack `thread_followup_silence` — Opt-In Quiet for Unaddressed Replies

**What it is:** New opt-in setting: if a thread reply isn't addressed to the bot (no mention, no DM), **silence the follow-up notification**.

**Why it matters:** Slack threads get noisy. This keeps the bot from pinging you on every side conversation. Only notifies when *you're actually needed*.

---

### 10. Daybreak Switch for Catalog-Listed ChatGPT Subscription Models

**What it is:** ChatGPT subscription models listed in the catalog now have a **Daybreak toggle** — flip it on/off without removing the model entry.

**Why it matters:** You use ChatGPT Plus for some tasks, API for others. Toggle the subscription model on when you want it, off when you don't. No re-configuration.

---

### 11. Batch of New Plugin-Catalog Entries

**What it is:** The plugin catalog grew — new entries for tools, integrations, and skills you can one-click install.

**Why it matters:** The ecosystem expands. Check the catalog in Desktop (`hermes plugin browse`) or CLI (`hermes plugin search`) for the latest.
