Hermes v2026.9.24 dropped September 24, and it's the kind of release that doesn't scream — it **settles**.

No flashy announcement. No new model. Just **460 merged PRs, 1,610 commits, 4,828 files changed** rolled into a stable tag so Docker images, Hermes Cloud, and hosted deployments finally have a solid baseline.

If you've been running Hermes from `main` or a nightly, **this is the version to pin**.

---

## What This Release Actually Is

Think of v2026.9.24 as **"everything since v0.21.4, stabilized."** The curated feature notes for this window are deferred to v0.22.0 (coming soon), but the work is **done and in this tag**.

Here's what landed that you'll actually feel:

---

## 1. Desktop Plugin SDK — Finally Real

The Desktop plugin system went from "experimental" to "here's the API surface":

- **Composer draft API** — plugins can read/write the composer draft
- **Session list & row decoration slots** — your plugin adds columns, badges, actions to the session list
- **Sidebar nav preferences** — plugins register their own sidebar tabs
- **Model-pill label providers** — custom badges on the model selector
- **Typed settings/skills/toolsets/profiles bridges** — no more JSON string parsing
- **Sandboxed embed primitive** — plugins embed webviews safely
- **Appearance settings slot** — plugins contribute theme options
- **Public event bridge** — plugin backends talk to the host without hacks

**For beginners:** this means the next wave of community plugins won't be fragile hacks. They'll be first-class citizens.

---

## 2. Connectors Page Replaces the MCP Tab

The MCP tab is gone. **Connectors** is the new page, and it does what you wanted:

- **"Connect now"** button for a freshly installed plugin's MCP servers
- Installed plugins' tools and skills go live in **every open chat immediately**
- Onboarding offers catalog plugins beside connectors

No more "install plugin → restart → wonder why tools don't show up."

---

## 3. Complete French, German, Spanish Desktop Catalogs + RTL/LTR

Full localization for three major languages, plus a **text direction setting** (RTL/LTR) that actually works across the UI.

If you've been waiting to recommend Hermes to non-English teams — **this is the version**.

---

## 4. Custom Model Entry From Composer & Settings Pickers

You no longer need to edit config files to add a model. Type the model ID in the composer or Settings model picker, and it's saved.

---

## 5. Per-Profile Gateway Control (`gateway.standalone`)

Run multiple Hermes profiles on one machine? **`gateway.standalone: true`** opts a profile out of the shared gateway multiplexer. Each profile gets its own gateway process.

Critical for:
- CI runners that need isolation
- Side-by-side stable/experimental profiles
- Teams sharing a box

---

## 6. Live Dock — Standing `/goal` and Queued Prompts Visible

The CLI and TUI now show a **live dock** with:
- The standing `/goal` (if set)
- Queued prompts waiting for their turn

You always know what the agent is doing and what's coming next. No more guessing.

---

## 7. Kanban Redesign — Two-Column Ticket Modal + Markdown Tasks

The kanban board got a design pass:
- Two-column ticket modal (details + activity)
- Markdown task text (not plain text)
- Cleaner drag targets

---

## 8. Webhook Deliveries Mirrored Into Target Chat Session

Incoming webhooks (GitHub, GitLab, custom) now **mirror their delivery into the chat session** you configured. You see the payload, the trigger, and the agent's response — all in one thread.

---

## 9. Bot Screen on Hosted `-desktop` Images

Hosted Docker images (`-desktop` tag) now include a **Bot Screen** — a persistent visual status for headless bot deployments. Useful for monitoring fleets.

---

## 10. Frontier Models in Catalogs — GPT-6 Sol/Terra/Luna + Opus 5.5

The Nous and OpenRouter catalogs now include:
- **GPT-6 Sol, Terra, Luna** (OpenAI)
- **Claude Opus 5.5** (Anthropic, 1M context)

One-click add. No manual config.

---

## 11. Hot-Path Performance — Config, Tool Registry, Gateway, Model Picker

A sustained performance pass across the critical path:
- Config loading: faster startup
- Tool registry: faster tool discovery
- Gateway message handling: lower latency per turn
- Model picker: instant open, no loading spinner

If Hermes felt "snappy but not instant" before — this is the release where it feels instant.

---

## 12. Official Blender Lab Integration + NVIDIA App/Broadcast Plugins

Community plugins that ship in the catalog:
- **Blender Lab** — 3D asset generation, scene inspection, render pipeline control
- **NVIDIA App / Broadcast** — GPU metrics, broadcast controls, DLSS tuning from chat

---

## 13. Simple/Advanced Interface Mode for Desktop

Desktop now has a **Simple/Advanced toggle**. Simple hides the plugin system, connectors, kanban, and advanced settings. Advanced shows everything.

Perfect for: onboarding juniors, non-technical stakeholders, or just days you want less UI.

---

## 14. Function-Key & Dictation Voice Shortcuts

Bind any action to a function key. Dictation (speech-to-text) now works as a shortcut trigger — hold a key, speak, release → prompt sent.

## How to Update

```bash
# Git installs
hermes update

# Or re-run the installer one-liner
curl -fsSL https://hermes-agent.nousresearch.com/install | bash

# Docker / Hermes Cloud
# Images build from this tag:
docker pull nousresearch/hermes-agent:v2026.9.24
```

Verify: `hermes --version` → should show `v2026.9.24` (or `v0.21.5`)
