## The "Finally!" Fixes (The Ones That Lived Rent-Free in Your Head)

### 1. The Permission Prompt Flood — **GONE**

Remember when reading a single file from a network share triggered 47 permission prompts because some PreToolUse hook decided to be helpful? 

**Fixed.** File reads from UNC paths no longer bypass the permission prompt via PreToolUse hooks or auto mode. The security boundary holds.

### 2. The Streaming Crash That Stole Your Work — **PATCHED**

You're in flow. Claude is streaming a beautiful refactor. Then — *poof* — the stream dies. Your work? Gone. The transcript? Truncated. Your mood? Ruined.

**Fixed.** The streaming crash that silently truncated output is resolved. Long bulleted/numbered replies now stream, resize, and re-open in the transcript (Ctrl+O) much faster.

### 3. Windows NTLM Credential Leak — **PLUGGED**

If you're on Windows, v2.1.233 and v2.1.234 started the fix. v2.1.292 finishes it. The NTLM leak that could expose credentials during git operations is fully addressed.

### 4. The Sandbox Escape That Shouldn't Exist — **CLOSED**

Sandboxed commands could read staged file copies of `/ultrareview` uploads under `~/.claude/seed-admin`. A managed sandbox read-deny path that appeared mid-session wouldn't drop project grants or end credential injection.

**All fixed.** The sandbox now actually sandboxes.

---

## The "Wait, That Was a Bug?" Fixes

### Subagents with `permissionMode: auto` entering auto mode when unavailable
If your settings disabled auto mode, or a circuit breaker tripped, or your model didn't support it — subagents would still try to enter auto mode and fail silently. Now they respect the actual availability.

### `NO_PROXY` being ignored when `HTTPS_PROXY` is set
Your proxy config works now. All of it. Including for sign-in, policy, feedback, and artifacts.

### MCP tools with names >128 characters breaking *everything*
One badly-named MCP tool would make every request fail. Now that tool is excluded and you get a clear MCP error naming the culprit.

### One-shot `claude -p` killing background commands 5 seconds after finishing
Background commands now wait properly. Scheduled wakeups aren't dropped. Your one-shots behave like citizens.

### Plan mode not restoring on session resume
`/resume` and `--resume` now actually restore plan mode. Because of course they should.

## For Plugin Authors: The Mod API Got Serious

- **Prompt caching** for `$.model.complete` — `prompt` and `system` blocks take `cache: true`
- **Workflow agents** exposed to `agent.spawn` hook with run and index
- **`prompt.autocomplete` event** — mods can add their own autocomplete rows
- **`--marketplace <source>`** flag for `claude plugin install`
- **`effort` parameter** on Agent tool — subagents run at the effort level you specify

And validation got stricter: `claude plugin validate` now catches matcher/state values read from elsewhere, top-level `var` reassignment, and served `$` methods restarting hook origins.
