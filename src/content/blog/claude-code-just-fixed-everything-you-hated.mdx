**Claude Code v2.1.300 dropped October 14** — the latest in a streak of stability-focused releases. It's not a feature drop. It's a **massive stability wave** with 80+ fixes targeting the exact pain points that made daily users frustrated.

If you've lost work to session resume bugs, fought worktree corruption, watched MCP servers fail to reconnect, or had the daemon refuse to die — this is your update.

---

## The Headline: Session Resume Finally Works

The biggest category of fixes (15+) targets **session resume and compaction** — the thing that silently ate your context.

| Bug | What Happened | Fixed |
|-----|---------------|-------|
| Compaction after output token limit | Lost recent messages the compaction *kept* | ✅ v2.1.300 |
| MCP tools missing after compaction | Claude didn't know about reconnected servers | ✅ v2.1.300 |
| Compaction summary lost on retry | Pre-compaction history came back, summary gone | ✅ v2.1.300 |
| Headless/SDK resume losing context | Background agents lost their thread | ✅ v2.1.300 |
| First transcript entry lost after crash | Cut-off last line = lost first new entry | ✅ v2.1.300 |

**Bottom line:** You can now trust `claude --resume` and background agents to actually pick up where they left off.

---

## Worktree & Git Fixes (10+)

Worktrees have been a minefield. This release cleans up the worst:

- **`--worktree` starting from wrong commit** — when a tag/branch looked like a commit SHA
- **Branch showing as `.invalid`** — reftable repositories couldn't reopen worktrees
- **`claude purge` skipping subfolder projects** — Unicode separators (U+2028, U+2029) broke it
- **Bare repository worktrees** — fallback base is now current HEAD, not origin's default branch
- **WorktreeCreate/Remove hooks not firing** — with `--worktree` flag (tmux still pending)

If you use `claude --worktree` for parallel tasks, these were daily annoyances. Gone.

---

## MCP & Background Agent Fixes (12+)

The "MCP servers reconnect but tools stay invisible" problem — **fixed**.

- Automatic tool search (`ENABLE_TOOL_SEARCH=auto`) turning off mid-conversation during MCP reconnect
- Subagents disappearing from `/tasks` after finishing — no way back to the conversation
- Parent agent dropping off breadcrumb while viewing child
- Background command output polling/sleeping instead of proper event handling
- Cloud sessions: "organization policy blocked host" false alarms
- Cloud sessions hanging 5 minutes when org policy unreadable — now fails fast with explanation

## Daemon & Process Reliability (8+)

The daemon has been the silent killer of background workflows:

| Symptom | Root Cause | Fixed |
|---------|------------|-------|
| `claude daemon stop --any` says "stopped" but service runs | No force-kill, no wait | ✅ Waits, force-kills, exits 1 if stuck |
| `claude daemon stop` silent exit, sessions listed as running | Telemetry off path | ✅ Proper output + cleanup |
| Runner/orchestrator freeze (no polls, no healthz, no SIGTERM) | Nobody reading output | ✅ Logs keep 256 KiB, count drops |
| Background commands left running after exit | 1.5s grace period ignored in fullscreen | ✅ Force-kill enforced |
| Remote-control servers giving up on sign-in errors | Locked keychain = permanent failure | ✅ Retries, warns to run `claude /login` |

## VS Code Integration (12+ Fixes)

If you use the VS Code extension, these were paper cuts:

- Chat font size changes needing window reload or undone by theme change
- "Resume session" opening empty conversation instead of worktree session
- ↑ then Enter on recalled slash command running without arguments
- Shift+drag file onto prompt inserting nothing in WSL/SSH/Dev Container
- Ctrl+Alt+F toggling Focus view instead of Find in Explorer
- macOS `ps` PATH search creating extra processes on session checks
- Windows: "still open somewhere else" after crash/restart (PID reuse)

## The "Wait, That Was a Bug?" Category

- **Secondary (dim) text = normal text** in dark ANSI theme and 16-color terminals
- **Claude naming files by bare filename** instead of full path in scratchpad
- **Artifact tool showing `Artifact("(unprintable path)")`** while input arrives — now "Waiting…"/"Running…"
- **`claude --help` naming a removed tool** in `--restricted` description
- **Login refused by `forceLoginOrgUUID` leaving token stored** — security issue
- **Feature flags stale behind TLS-inspecting proxy** with OS-trusted certs
- **`/sandbox` mode options reading "Sandbox BashTool"** — now "Sandbox commands"
- **Large requests to api.anthropic.com not gzipped** when telemetry disabled — now compressed (opt out: `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`)
