**Kilo Code v7.8.28 dropped November 7, 2026.** Two changes. Both save you time if you run hosted workspaces or use plugins.

---

## 1. Hosted Workspace Profile Defaults — Now Exposed via Session Host API

This is the one you'll actually use. The Session Host API now lets clients:

| What You Can Do | Why It Matters |
|-----------------|----------------|
| Create an empty hosted workspace **without an initial prompt or profile** | Spin up a clean environment instantly — no "what do you want to work on?" prompt blocking automation |
| List personal and organization profiles **with their default flags** | See exactly which profile is the default before you commit |
| Set or clear the **personal default profile** | Switch your go-to setup without UI clicking |

**Before:** You had to provide a prompt/profile at creation. No way to query defaults programmatically.

**After:**
```bash
# Create empty workspace — no prompt required
kilocode workspace create --empty

# List all profiles with default flags
kilocode profile list --show-defaults

# Set your personal default
kilocode profile set-default my-production-setup

# Clear it
kilocode profile clear-default
```

If you script Kilo Code (CI, automation, team onboarding), this removes a whole class of "interactive prompt" failures.

---

## 2. Plugin Tools with Invalid JSON Schema Args — No Longer Nuke Your Session

**The bug:** A plugin tool whose arguments couldn't convert to JSON Schema would fail **every single prompt** in the session. One bad plugin = entire session broken.

**The fix (v7.8.28):** Kilo now **skips** those tools instead of crashing the prompt loop.

```json
// Plugin declares a tool with args that can't become JSON Schema
// Before: Every prompt fails with schema conversion error
// After: Tool is silently skipped, other tools work normally
```

Thanks to [@zfralish](https://github.com/zfralish) for the fix ([#15921](https://github.com/Kilo-Org/kilocode/pull/15921)).

**What this means for you:** A misbehaving plugin no longer holds your session hostage. You keep working, the bad tool just disappears from the available set until the plugin author fixes it.
