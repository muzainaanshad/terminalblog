OpenHands v1.24.0 landed September 25, and it's the release that finally answers the question every developer has asked since AI coding agents appeared: **"Why does my agent forget everything when I close the tab?"**

The answer is **Agent Canvas** — a persistent, visual workspace where your agent's memory survives restarts, its automations run on schedule, and you can *see* the reasoning behind every change. Not a chat history. Not a log file. A canvas that remembers.

If you've tried OpenHands (formerly OpenDevin) before and walked away because it felt like a stateless demo — **this is the version to come back for**.

---

## 1. Agent Canvas: Your Agent Finally Gets a Desk

Think of Agent Canvas as a **persistent mission control** for your AI agent. Instead of a linear chat that vanishes when you refresh, you get:

- **Infinite canvas** — zoom out to see the entire project history, zoom in on a single file diff
- **Session persistence** — close the browser, come back tomorrow, the agent remembers what it was doing
- **Visual task graph** — every step the agent took, every file it touched, every decision it made, laid out spatially
- **Live collaboration** — multiple humans + multiple agents on the same canvas, simultaneously

For beginners: this solves the "context amnesia" problem. You don't re-explain the codebase. You don't re-state the goal. The canvas *is* the context.

---

## 2. Persistent Memory That Actually Works

The headline feature is **persistent memory across sessions**. Here's what that means in practice:

| Before v1.24 | After v1.24 |
|-------------|-------------|
| Agent forgets project structure on restart | Agent loads project map instantly |
| Re-upload files every session | Files stay indexed, searchable |
| Lose conversation context | Full transcript + reasoning preserved |
| Manual re-onboarding | "Continue where we left off" button |

The memory isn't just "chat history saved to disk." It's **structured knowledge** — the agent builds a semantic map of your codebase (symbols, dependencies, patterns) and reuses it. Next session, it doesn't re-read `auth.ts` — it *knows* `auth.ts` handles JWT validation.

---

## 3. Automations: Set It and Forget It

v1.24 introduces **Automations** — recurring, scheduled, or triggered workflows your agent runs without you babysitting:

- **Nightly code review** — Agent wakes up at 2 AM, reviews PRs opened today, posts comments
- **Dependency monitoring** — Checks for outdated packages weekly, opens PRs with updates
- **Test generation** — When you add a new API route, agent auto-generates integration tests
- **Documentation sync** — Keeps README/ARCHITECTURE.md in sync with actual code changes

You define automations in plain YAML. The agent executes them on the canvas, leaving a visible trail. You wake up to a summary: *"Reviewed 3 PRs, updated 12 dependencies, generated 8 tests — all green."*

---

## 4. Visual Diffs That Make Sense

Every change the agent makes appears as a **visual diff card** on the canvas — not buried in a terminal scrollback:

- Side-by-side or unified view
- Semantic highlighting (added function vs. changed logic vs. renamed variable)
- One-click revert or "explain this change"
- Links to the exact line in your IDE

For beginners: this is how you *trust* the agent. You don't read 500 lines of terminal output. You glance at a card, see "added input validation to `login()`," and move on.

---

## 5. Multi-Agent, Multi-Human — Real Collaboration

Agent Canvas isn't single-player. v1.24 supports:

- **Multiple agents** — One plans, one codes, one tests, one documents — all on the same canvas
- **Multiple humans** — Your teammate joins, sees the agent's reasoning, adds a comment, the agent adjusts
- **Handoffs** — "You take the frontend, I'll handle the API" — agents coordinate via the shared canvas state

This is the first open-source agent platform where **"agents as teammates"** isn't marketing — it's the default UX.

## What This Means for You

**If you're new to coding agents:** OpenHands v1.24 is the easiest entry point. No API key required for the hosted version (free tier available). The canvas *shows* you what the agent does — no blind trust needed. Start with "fix this bug" and watch the reasoning unfold visually.

**If you're evaluating agents for a team:** This is the first open-source platform where **persistent memory + scheduled automations + visual collaboration** work out of the box. Compare against commercial tools that charge per-seat for less.
