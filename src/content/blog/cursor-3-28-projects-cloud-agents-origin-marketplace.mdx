Cursor didn't just ship a version bump. **Version 3.28 (released November 3, 2026) is the moment Cursor stopped being "VS Code with AI" and became an AI development platform.**

Everything that was beta in the October wave — **Projects, Cloud Agents with Canvases, Origin App Marketplace, Remote Control from iOS, Rollouts, Security Review** — is now stable. Plus a new teammate: **Grok Bot**, an agent that lives in your GitHub issues.

## The One-Line Summary

**Cursor 3.28 (Nov 3) → Projects, Cloud Agents with Canvases, Origin Marketplace (20+ apps), Remote Control, Rollouts, Security Review all stable. New: Grok Bot for GitHub issues. The editor is now a platform.**

## The Five Pillars That Are Now Stable

### 1. Projects — Multi-Agent Orchestration That Stays

**What it is:** A Project maintains shared context across *months* of work. A coordinator agent plans, delegates to subagents, and brings finished work back to you.

```bash
# Left nav → Projects → New Project
# Describe: "Add user authentication with JWT to this Express API"
# Watch coordinator plan → delegate → implement
```

**Why it matters:** You don't re-onboard an agent every task. Each Project builds a knowledge base — test patterns, architecture decisions, team conventions — that compounds.

**For beginners:** This is **multi-agent orchestration without writing YAML**. You describe the outcome; Cursor handles the choreography.

---

### 2. Cloud Agents with Canvases — Interactive Artifacts, Not Just Text

**What it is:** Cloud agents now build **interactive canvases** — live dashboards, architecture diagrams, test reports, API explorers — as part of their work.

**Environments API (beta):** Programmatically create and manage cloud environments.

**Larger, faster:** Cloud environments now support **300 repositories** and load **5x faster**.

```bash
# Start a cloud agent task → ask for "a live dashboard of API latency"
# Share the canvas link with your team → they see real-time data
```

| Category | Partners |

| **CI** | Buildkite, CircleCI, CloudBees, Depot, EngFlow, Namespace, RWX |

**The kicker:** Marketplace is open to public submissions. Any team building dev tools can publish an app for Origin.

---

### 4. Remote Control from iOS — Your Local Agents, In Your Pocket

**What it is:** See and reply to local agents running on your computer from the Cursor iOS app.

- On by default (except Enterprise)
- Agents keep running on your computer — app just connects
- "Keep this computer awake" prevents sleep while away
- **No cloud agents required** — works with your local setup

---

### 5. Rollouts & Security Review — Two Bots for the Last Mile

**Rollouts** (deployment monitoring):
- Attaches a monitor to every PR, watches deployment health per environment
- Writes a monitoring plan as a PR comment (risks, intended effect, signals, gaps)
- Can open revert PRs or hand findings to a cloud agent for a fix
- Integrates with GitHub/Origin, your CD system, Datadog

**Security Review** (exploitable bug detection):
- Reads every PR in context of the codebase
- Reports: SQL/command/template injection, auth bypasses, secrets, SSRF, unsafe deserialization, vulnerable dependencies
- Each finding: severity, attack path, proposed fix
- Team rules enforce codebase-specific policies

*Both available on Teams and Enterprise plans.*

## The New Kid: Grok Bot — An Agent in Your Issues

**What it is:** Mention `@grok` in a GitHub issue. Grok Bot:
1. Plans the work
2. Writes the code
3. Opens a PR
4. Responds to review feedback
5. Updates the issue thread

**Channels:** Wakes on PR, comment, CI events (GitHub, GitLab, Bitbucket), Slack mentions/DMs, webhooks, cron.

**Each conversation keeps its own session and complete record.** Follow-ups on a PR or Slack thread resume the same session.

**For beginners:** This is **an AI teammate that lives where work happens** — GitHub issues. No context-switching to a separate tool.

## What's Still Missing (Honest Assessment)

- **Windows runner parity for Remote Control**: iOS app works, but "keep computer awake" logic is macOS-first
- **Local-first air-gapped Projects**: Projects run on cloud compute; no fully offline mode
- **Marketplace discovery**: 20+ apps is a start, but no central registry with reviews/ratings yet
- **Rollouts/Security Review on Pro plan**: Currently Teams/Enterprise only
- **Canvas export/embedding**: Canvases are shareable via link but not embeddable in Notion/Confluence/etc.

## FAQ

**What are Cursor Projects and how do they differ from regular chat?**
Projects maintain shared context across months of work. A coordinator agent plans and delegates to subagents. Regular chat is single-threaded; Projects are multi-agent with persistent memory.

**How does Remote Control work?**
Install Cursor iOS app, sign in, pair with desktop (approve in desktop app). Your local agents appear in the app. Your computer must stay on and online.

**What does Security Review actually catch?**
Injection (SQL/command/template), auth bypasses, secrets in source, SSRF, unsafe deserialization, vulnerable dependencies. It traces user input through the codebase.

**Can I use Rollouts without Origin?**
Yes — Rollouts connects to GitHub for source control, your CD system for deploy events, and Datadog/telemetry for signals. Origin is optional.

**Is the Origin Marketplace only for Enterprise?**
Apps are available to all Origin users. Publishing requires review. Some apps may have plan restrictions.

**Do I need cloud agents for any of this?**
Projects and Cloud Agents use cloud compute. Remote Control, Rollouts, Security Review, and Origin Marketplace work with your local setup.
