## What Happened: A Snapshot of How Developers Actually Use AI Coding Agents

On November 4, 2026, a Hacker News user asked a simple question: **"What's your current AI agentic setup?"** The thread exploded with **413 comments** from developers sharing their exact subscriptions, tools, and workflows. No marketing fluff—just practitioners describing what they pay for and what they actually use daily.

This is rare. Most content about AI coding agents comes from vendors or early adopters selling courses. This thread is different: it's hundreds of engineers comparing notes on what works in production, what's a waste of money, and where the industry is actually heading.

---

## The Numbers: What Developers Are Paying For

The most striking pattern? **Most serious developers pay for multiple subscriptions.**

- **Claude (Anthropic)**: The dominant choice. Many pay for **Max/Ultra tiers ($100–200/month)**. Several commenters run **two or three Claude accounts simultaneously** to bypass usage limits.
- **Codex (OpenAI)**: Common as a secondary or backup. The **$100/month plan** is standard for heavy users.
- **Cursor**: Still used but fading. Several switched to Claude Code or Codex after hitting limits.
- **OpenRouter / APIs**: Popular for model diversity—DeepSeek, Qwen, GLM, Kimi—especially for cost-sensitive workloads.
- **Local models**: A minority but growing. Strix Halo (128GB), Mac Studios (192GB+), and custom rigs running Qwen 3.8 Flash Next, DeepSeek V4.1 Flash, GLM 5.3.

**Typical monthly spend for power users: $200–400.** One commenter runs **Claude Ultra + Codex $200 + OpenRouter**. Another: **two $100 Anthropic accounts + $100 Gemini**.

> "I max out the Claude every week and the Kimi most weeks. GLM is my fallback and used for some of my simpler agents." — HN commenter running multiple production agents

## The Tooling Reality: Simplicity Wins

Here's the surprise: **the most sophisticated developers use the simplest harnesses.**

### The "Just Use Defaults" Camp

Many top commenters stick to **Claude Code CLI**, **Codex CLI**, or **Zed with ACP** (Agent Client Protocol). No custom orchestration, no swarm frameworks, no multi-agent platforms.

> "Since Opus 5.5 came out, I just use the Claude IDE. I got rid of all my skills and just set it to medium. Then I vaguely talk to it about very high-end things that I want, and it comes back with magic." — HN commenter

> "I firmly believe that those using out-of-the-box Claude Code or Codex are likely getting the most cutting edge features of agents anyways." — Another commenter

The reasoning: **the labs (Anthropic, OpenAI) ship features faster than third-party wrappers can keep up.** Built-in subagents, code review, parallel sessions—these now ship natively.

### The "I Built My Own Orchestrator" Camp

A vocal minority built custom systems. Common patterns:
- **Next.js / React UIs** launching headless Claude/Codex sessions
- **GitLab/Linear integration** — auto-addresses CI failures, rebases, reviews
- **Custom agents per task type** — planning, implementation, review, QA
- **Hivemind-style coordination layers** — resource locking, file reservations, desktop notifications

> "Building a custom orchestrator for my workflow was quite easy. Like 1-2 weeks of prompting and now my work mainly consists of refining linear tickets in a claude/codex cli and then reviewing the completed MR on the other side." — HN commenter

### The "Open Source Harness" Camp

**OpenCode, Pi, Aider, herdr/Rex** — developers who want model flexibility without vendor lock-in. OpenCode especially praised for multi-provider support (OpenRouter, local, APIs) and skill system.

> "I've been using OpenCode for over a year. I think it's an incredible tool and its wide support is a massive boon. It's really easy to pull in skills, tag the skills, and switch providers." — HN commenter

## The Controversial Takes

### 1. "Complex Orchestration Is Mostly Token Burn"

Multiple commenters argued that **multi-agent swarms, orchestration platforms (OpenClaw, Hermes, Dots, Muse), and agent frameworks add overhead without proportional value.**

> "I'm yet to find any value in complex software factories and multi agent harnesses. If you know what you're doing, you can just use Codex or Claude for the core research and development."

> "I haven't seen a lot of improvement by increasing the orchestration layers, honestly. Am I missing something?"

The consensus: **raw model intelligence (Opus 5.5, GPT-5 class) has made scaffolding less necessary.** The model *is* the orchestrator now.

### 2. "Claude Code Web / Desktop > Local CLI for Many"

A surprising number prefer **cloud-hosted agent UIs** (Claude Code Web, Codex Desktop) over local terminals:
- Real sandboxing
- Doesn't tie up local machine
- Remote control from phone
- Native GitHub PR creation

> "I actually prefer it now over claude CLI. Nicer UI than a terminal, real sandboxing, and it doesn't tie up my computer."

### 3. "Self-Hosted / Local Is the Endgame for Cost and Privacy"

**Revolut slashed AI coding costs 10x by going self-hosted** (separate HN story, 13 points). Developers are watching this closely. Local inference on Strix Halo, Mac Studios, or custom rigs running Qwen/DeepSeek/GLM is becoming viable for production workloads.

> "I'm currently using OpenRouter. It's good for quickly switching around and trying different models, but I currently have it constrained to just 3 models and 1 provider. Truthfully I could just use that provider directly, but I like retaining some flexibility."

### 4. "Agent Platforms (Dots, Muse, Grok Bot, Hermes) Are Mostly Toys"

With few exceptions, commenters who tried **OpenClaw, Hermes Agent, Dots, Muse, Grok Bot** abandoned them. The execution fell flat; the labs' native features (Claude Projects, Codex remote control) did it better.

> "Played with OpenClaw and Hermes in the past, cool ideas but execution fell flat. I currently use Dots and Duet for little things (mostly monitoring communications). Dots is much better than Duet today but I hope Duet gets better."

## The Real Insight: The Market Is Splitting

Three distinct tiers are emerging:

| Tier | Who | Setup | Monthly Cost |
|------|-----|-------|--------------|
| **Casual** | Side projects, learning | One subscription (Claude Pro / ChatGPT Plus), default CLI or web UI | $20–30 |
| **Power User** | Full-time AI-assisted dev | 2–3 subscriptions (Claude Max + Codex + OpenRouter), custom orchestrator or OpenCode/Pi | $200–400 |
| **Enterprise / Self-Hosted** | Teams, cost-sensitive, privacy-first | Self-hosted models (Qwen, DeepSeek, GLM), custom infra, OpenCode/herdr | Hardware + engineering time |

**The middle tier is where the action is.** These developers treat AI as a **production dependency**, not a toy. They optimize for:
- **Parallelism**: Running 3–5 concurrent agent sessions
- **Context management**: Keeping sessions alive, avoiding auto-compaction
- **Review workflows**: Human-in-the-loop for PRs, not full autonomy
- **Model diversity**: Fallback chains (Opus → GLM → Kimi → DeepSeek)

## What This Means for You

### If You're Just Starting

**Don't overthink the harness.** Start with **Claude Code** or **Codex CLI** (whichever subscription you have). Use the defaults. Learn to:
- Write clear task specs ("what complete looks like")
- Run multiple concurrent sessions
- Use built-in subagents for code review, testing, research

> "The biggest trick is just to tell it what complete looks like. Be very specific about what you want it to come back with once it's done."

### If You're Hitting Limits

**Add a second provider before adding complexity.** OpenRouter + a cheap model (DeepSeek V4.1 Flash, GLM 5.3 Flash, Qwen 3.8 Flash Next) gives you fallback when Claude/Codex hit limits. Cost: pennies per million tokens.

### If You're Building a Team Workflow

**Invest in a custom orchestrator, not a platform.** The commenters who succeeded built thin layers over Claude/Codex APIs:
- Ticket → agent → PR → review → merge
- CI failure → auto-fix agent
- Shared context via Git/wiki, not proprietary platforms

> "My approach is to build the builder rather than the feature. So if something is off in the output I try to address it through the orchestrator."

### If You Care About Cost / Privacy

**Self-hosted is real now.** Qwen 3.8 Flash Next (MoE, 6B active), DeepSeek V4.1 Flash, GLM 5.3 Flash run on consumer hardware (Mac Studio M5 Ultra, Strix Halo, 2× 4090s). Quality is "SOTA for the price." Revolut proved the 10x savings.
