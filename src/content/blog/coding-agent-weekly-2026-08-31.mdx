### [Cursor 3 Just Replaced Your Code Editor With an Agent Command Center — Here's the Honest Truth](/blog/cursor-3-glass-agents-window-review/)

Cursor 3 'Glass' shipped the Agents Window, Composer 2, cloud agents, and a marketplace. But early adopters hit hard walls: no VS Code extensions, broken diffs, no WSL. Here's what actually works and what doesn't. The Agents Window is Cursor's new command center for managing multiple agent sessions, but it shipped without VS Code extension support — a dealbreaker for many. Composer 2 adds multi-file editing but diffs are unreliable. Cloud agents promise parallel execution but require a separate subscription.

### [Claude Code v2.1.233 — NTLM Leak Fixed + 50 Other Fixes](/blog/claude-code-v2-1-233-security-fix-windows-ntlm-leak/)

Claude Code patched a Windows NTLM hash leak (CVE-2026-33068) that could expose credentials on shared networks. Plus 50 other fixes including streaming crash fixes, subagent improvements, and MCP stability. The NTLM leak was critical — any Windows user on a corporate network could have their NTLM hash captured. The streaming crashes affected long-running sessions. Subagent improvements include better context isolation.

### [Beware: Cursor CLI Worktree Pre-Trust RCE](/blog/beware-cursor-cli-worktree-pre-trust-rce/)

Cursor's new CLI worktree feature had a pre-trust RCE vulnerability. If you used `cursor --worktree` on untrusted repos, attackers could execute arbitrary code. Patched in latest release — update immediately. The worktree feature was designed to let agents spin up isolated workspaces, but the pre-trust model meant any repo could execute code during the initial clone phase.

## What This Week Tells Us About Agent Security

Three major agents, three critical security findings in one week. Cursor's worktree RCE, Claude Code's NTLM leak, and Hermes' audit findings (covered next week) all point to the same reality: **agent security is the bottleneck, not model capability**. Every new integration surface — Git, filesystem, network, subprocess — is an attack vector. The agents shipping fastest are the ones with the most untested attack surface.
