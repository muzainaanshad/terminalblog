Groq Code CLI is the **fastest terminal coding agent you can run locally** — not because of clever architecture, but because it runs on **Groq's LPU (Language Processing Unit) inference hardware**. Models that take seconds on GPUs respond in milliseconds.

If you've ever sat waiting for a 70B model to think, Groq Code changes that dynamic entirely.

---

## What Groq Code Actually Is

**Groq Code CLI** (about 9K GitHub stars, MIT-licensed, npm package `@groq/code`) is a terminal-based coding agent that:

- Runs on **Groq's ultra-fast inference** — sub-second responses on 70B+ models
- **Free with BYO API keys** — you bring your own Groq, OpenAI, Anthropic, or OpenRouter keys
- **Skills-driven execution** — runs `.skill.md` files for repeatable coding tasks (like OpenCode/Hermes)
- **MCP support** — connects to Model Context Protocol servers for tools
- **ACP IDE integration** — works with VS Code, JetBrains via Agent Communication Protocol
- **Open source** — full control, no vendor lock-in

The project is actively maintained with regular releases.

## Why Speed Changes How You Code

Most agents feel the same: you type, wait 5-30 seconds, get a response. With Groq Code on LPU:

| Model | Typical GPU | Groq LPU |
|-------|-------------|----------|
| Llama 3.1 70B | ~8s | **~400ms** |
| Mixtral 8x7B | ~12s | **~600ms** |
| Gemma 2 27B | ~6s | **~300ms** |

**Practical impact:** You stay in flow. The agent becomes a *collaborator* not a *batch processor*. You can iterate 10x faster on the same task.

## Skills System: Repeatable Coding Tasks

Like OpenCode and Hermes, Groq Code uses **`.skill.md` files** — markdown files that define repeatable workflows:

```markdown
---
name: "refactor-to-typescript"
description: "Convert JavaScript files to TypeScript with strict types"
---

## Instructions
1. Find all `.js` files in the target directory
2. Add explicit type annotations
3. Fix any `any` types
4. Run `tsc --noEmit` to verify
```

Run with: `groq-code skill run refactor-to-typescript`

This means **you codify your workflow once, run it forever**. No more re-explaining the same refactoring pattern.

## MCP Integration: Your Tools, Your Way

Groq Code connects to **MCP (Model Context Protocol)** servers — the emerging standard for agent tooling. This means:

- Your existing MCP servers (filesystem, GitHub, database, browser) work out of the box
- You can write custom MCP servers for your internal tools
- Tools are discoverable and typed, not string-matching hacks

---

## ACP: Works in Your IDE

Via **Agent Communication Protocol**, Groq Code integrates with:
- **VS Code** (extension)
- **JetBrains IDEs** (plugin)
- Any ACP-compatible client

You get the same agent in your terminal *and* your editor — shared session, shared context.

## Getting Started

```bash
# Install
npm install -g @groq/code

# Configure your API key (Groq, OpenAI, Anthropic, or OpenRouter)
groq-code config set apiKey YOUR_KEY

# Start coding
groq-code
# Or in a project:
cd your-project && groq-code
```

First run walks you through model selection and skill discovery.
