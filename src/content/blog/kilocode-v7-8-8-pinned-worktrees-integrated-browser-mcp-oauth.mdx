## 1. Pinned Worktrees: Your Most Important Context Stays Put

**What it does:** In Agent Manager, Shift+click a worktree (or use the context menu) to **pin it**. Pinned worktrees:
- Stay at the top of the list
- Get the first jump shortcuts (1, 2, 3...)
- Keep their section when you unpin them

**Why beginners care:** You probably have 3–5 active worktrees — main, feature/auth, feature/api, hotfix, experiment. Before v7.8.8, the one you *actually* need right now could slide down the list. Now it's **anchored**. Your mental model matches the UI.

**The flow:**
1. Open Agent Manager sidebar
2. Shift+click the worktree running your main task
3. It jumps to top, gets shortcut `1`
4. `Ctrl+Alt+1` (or `Cmd+Alt+1`) jumps straight to it

---

## 2. Integrated Browser: One Tab Per Session, No More Chaos

**What it does:** When the experimental **Integrated Browser** is enabled:
- Sidebar chats open links in a **browser tab inside the editor**
- Agent Manager uses its **browser panel**
- Links show a browser icon
- **No more links opening in two browsers at once**

**Choose "System browser" under "Open links in" to opt out.**

**Why beginners care:** You're debugging a PR, click a GitHub link, it opens in your system Chrome *and* the integrated preview. Now you have two tabs, neither focused. v7.8.8: **one link → one tab → inside your session**. Context stays where you are.

**Also fixed:**
- Page loads and SPA route changes keep current page visible until next paint (no blank flash)
- Resize the panel → preview updates live, no stretch
- Clear warning when browser opened without active session, address bar disabled until session selected

---

## 3. MCP OAuth: Tokens That Stay Loyal

**What it does:** MCP OAuth credentials (refresh tokens, client secrets) are now **bound to the authorization server that issued them**.

**Before:** If an MCP server switched auth servers (common in enterprise rotations), it could receive stored tokens meant for the old server. Security risk. Confusing failures.

**Now:** Token ↔ auth server binding is enforced. A server that switches auth servers **cannot** receive old credentials.

**Why it matters:** MCP is becoming the standard for agent-tool integration. OAuth is how enterprise MCP servers auth. This fix makes Kilo **enterprise-ready for MCP** — not just "works on my machine."

---

## 4. Session Tab Shortcuts: Muscle Memory Finally Works

**What it does:** `Cmd+Alt+Left/Right` (Mac) / `Ctrl+Alt+Left/Right` (Win/Linux) switches between **session tabs in the sidebar AND Kilo editor tabs**.

Shortcut hints appear on the tabs and in the prompt.

**Why it matters:** You have 4 sessions open. You're in session 3, need to check session 1. Old way: mouse → sidebar → click. New way: `Ctrl+Alt+Left` ×2. **Your fingers never leave the keyboard.**

---

## 5. Settings Search: Find Anything in Seconds

**What it does:** A search field at the top of the Settings left rail (`Ctrl+F` / `Cmd+F` to focus):
- Filters **every setting** in real-time
- Results **grouped by category** so matching settings stay visible
- Click a result → jumps to its tab AND setting

**Why beginners care:** Kilo has *hundreds* of settings. Finding "that one MCP timeout setting" used to mean clicking through 8 tabs. Now: type "mcp timeout" → jump → done.
