Hermes Agent v0.21.6 landed today — October 8, 2026. The numbers are absurd: **8,867 commits**, **2,106 merged PRs**, **3,027 closed issues**, across **8,342 changed files**.

But the release notes bury the lede. This is the **first stable release cut by their new pipeline** — one attempt, tested Docker image, receipt tag at publish. No more guessing which Docker tag is safe.

Here's what a beginner actually needs to know.

## The Big Picture: This Is a Stability Release

v0.21.6 doesn't add flashy new features. It **locks in everything since v0.21.5** (the "Pantheon" release from late September) into a tagged, tested, Docker-ready artifact.

If you've been running `hermes update` on the CLI or pulling `:latest` Docker images, you've already been getting these changes incrementally. This tag just means: *this specific combination is verified.*

> **What changed since v0.21.5:** Live transcription while you speak (CLI, TUI, Desktop). Spoken voice turns routed to their own model with reasoning off by default. Third-party plugins running in isolated plugin hosts. Favorite and pinned models at the top of the Desktop picker. Local models in `hermes model` plus llama.cpp CUDA on Linux. Pluggable language packs. A summary-first `hermes status`. Review-pane diff scope selector. Cron and doctor warnings when the cron store goes unwritable. Approval flags for credential uploads and invisible Unicode in terminal commands. Discord bot setup that checks the token and prints the invite. GPT-6.1 Sol and Claude Sonnet 5.5 / Haiku 5.5 in the catalogs. Dozens of community plugins.

**None of that is documented in this release.** Full curated notes ship with v0.22.0.

## How to Update (Beginner Steps)

**Docker / Hermes Cloud:**
```bash
docker pull nousresearch/hermes-agent:stable
# or
docker pull nousresearch/hermes-agent:latest
```

**CLI (git installs):**
```bash
hermes update
# or re-run the installer one-liner from the repo
```

**Desktop app and Termux:** No change in this release — they update with the next bundled release.

## Why This Release Matters Even If You Don't See New Buttons

The new release pipeline is the real story. Before this, cutting a stable release was manual, error-prone, and slow. Now:

- One ref → tested Docker image → receipt tag at publish
- The tag **is** the quality gate
- No more "which Docker tag do I use?" confusion

For beginners, this means: **`nousresearch/hermes-agent:stable` is now a promise, not a guess.**

## What's Coming in v0.22.0

The team explicitly says: *full curated release notes for this window ship with v0.22.0 — highlights, feature areas, complete contributor credits. Nothing in this window is skipped.*

So if you want the human-readable changelog for all 2,106 PRs, watch for v0.22.0. It'll cover everything from v0.21.0 onward.
