## The Headline Features (The Ones You'll Actually Notice)

### Sessions & Memory: Finally Preserved Across Registry Changes

The nightmare scenario: you change your plugin registry, and *poof* — session history gone. Worker attachments from remote workspaces? Lost. Continuation signatures misaligned? Yep.

**Fixed.** 
- Usage preserved across registry changes
- Worker attachments delivered from remote workspaces
- Queued cancellations and transcript aliases no longer stall active turns
- Continuation signatures kept aligned
- Embedding caches migrated in bounded batches with oversized-row reporting

Credit: **@vincentkoc** across 8 PRs (#164217, #164219, #163708, #164230, #164251, #164289, #164287, #164303)

### Replies & Media: Local Videos Play Again

Inline playback for local videos: **restored.** Rejected media links now show useful errors instead of silent failures. Telegram progress updates stay clean (no preview card spam). Speech-only replies when reasoning is enabled: **fixed.**

Credit: **@ivan-magda, @obviyus, @Twilight-Networks**

### Updates & Doctor: Recovery Guidance That Helps

- Serving-verdict recovery guidance improved
- Repairs work with read-only managed config
- Repeated config/backup/metadata/pnpm-root probes removed
- Successful cleanup reported as progress without corrupting JSON output
- Still-starting Gateway treated as warning (not error)

Credit: **@DonnieFi, @JD8855122, @Patrick-Erichsen, @waynegault**

### Windows Workspaces & Browser: First-Class Citizens

- Empty and nested Windows worktree creation: **fixed**
- Linux Chromium discovery improved
- Playwright Chromium auto-starts on ARM64

Credit: **@ly85206559, @jesse-merhi, @obviyus**

If you've fought Windows worktrees in any coding agent, you know this isn't trivial. OpenClaw just made it work.

### Cloud Workers & Crabbox: The Infrastructure Hardening

- Real cloud-worker failures surfaced (no more mystery hangs)
- Linux leases enforced
- Worker-bundle downloads overlapped with bootstrap
- Unrelated warm-image cleanup waits removed
- Slow reads/unsupported backends no longer strand workers

This is the "boring" infrastructure work that separates toys from platforms.

### Plugins, Codex, MCP: The Integration Layer Hardens

- Bun package-import capture preserved
- Prerelease metadata requests reduced
- Expired remote-exec approvals no longer poison auth profiles
- Node policy hooks restored
- MCP forms/files/context synchronized
- Background skill reviews routed through Workshop proposals

## The Deprecation Wave: 30+ SDK Migrations Active

This is where plugin authors need to pay attention. **30+ deprecation warnings** are now active, most starting October 1–3, 2026:

| Deprecation | Warning Since | Migration Target |
|-------------|---------------|------------------|
| `channel-webhook-listener-config-inputs` | 2026-09-26 | `legacyWebhook` |
| `session-manager-sync-persistence` | 2026-10-01 | Async SessionManager methods |
| `extension-session-sync-persistence` | 2026-10-01 | Async ExtensionAPI/AgentSession |
| `provider-replay-sync-persistence` | 2026-10-01 | Async replay sanitizer |
| `memory-session-sync-inventory` | 2026-10-01 | `loadArchivedSessionsAsync`, `resolveMemorySessionTargetsAsync` |
| `workspace-mutation-guard-callback` | 2026-10-02 | `guard.assertHost` (SQL-free) |
| `gateway-placement-sync-results` | 2026-10-02 | Async Gateway placement readers |
| `watched-sessions-sync-harness-context` | 2026-10-03 | `prepareWatchedSessionsHarnessContext` |

**And 20+ more** — media understanding, memory host, channel setup, runtime barrels, provider helpers, message presentation, agent harness, official plugin exports, memory cache/FTS, plugin runtime API, plugin provider manifest.

**Bottom line:** If you maintain OpenClaw plugins, schedule migration time. The async suffix isn't optional — it's the new contract.

## What This Means for the Ecosystem

### For Users: Stability You Can Feel

- Sessions survive registry changes
- Windows worktrees work
- Cloud workers don't strand
- Local videos play
- Doctor gives actionable guidance

### For Plugin Authors: Migration Season

The SDK is moving to async-first, focused subpaths, and host-owned capabilities. The broad barrels are deprecated. The compatibility aliases are on the chopping block.

**Migration guide:** `/plugins/sdk-migration/how-to-migrate`

### For the Industry: A Signal

OpenClaw's daily release cycle (v2026.9.6 → v2026.9.7 → v2026.9.8 → v2026.10.1) with 2,600+ PRs in September alone shows a velocity that proprietary tools can't match.

The "beta" label is honest about SDK flux. The code quality is not beta.
