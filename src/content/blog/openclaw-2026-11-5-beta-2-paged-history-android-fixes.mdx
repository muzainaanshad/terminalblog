**OpenClaw v2026.11.5-beta.2 dropped November 12, 2026** — the second beta in the 2026.11.5 train. This one tackles large conversation browsing, macOS secret preservation, Android Talk fixes, and ships 95 PRs of security and reliability hardening.

If you run OpenClaw with long conversations, on macOS, or on Android — this update matters.

---

## The Headline Features

### 1. Large Conversations Stay Browsable — Paged History in Both Directions

**What it is:** Large conversations now remain browsable with **paged history in both directions**, visible history boundaries, and bounded archive reads.

**Why it matters:** Before, scrolling through a massive conversation could freeze the UI or load everything into memory. Now:
- History loads in pages (forward and backward)
- You see clear boundaries of what's loaded
- Archive reads are bounded — no more OOM on massive sessions

**PRs:** [#188450](https://github.com/openclaw/openclaw/pull/188450), [#188483](https://github.com/openclaw/openclaw/pull/188483), [#188557](https://github.com/openclaw/openclaw/pull/188557), [#188372](https://github.com/openclaw/openclaw/pull/188372), [#190690](https://github.com/openclaw/openclaw/pull/190690)

---

### 2. macOS App Preserves Secrets When Config Saves Fail

**What it is:** The macOS app now **preserves saved secrets and Gateway authentication** when configuration saves fail or Tailscale exposure is turned off.

**Why it matters:** Before, a config save failure (disk full, permissions, Tailscale toggle) could wipe your saved credentials and Gateway auth. Now they survive the failure.

**PRs:** [#187734](https://github.com/openclaw/openclaw/pull/187734), [#187664](https://github.com/openclaw/openclaw/pull/187664)

---

### 3. Android Talk No Longer Cancels Accepted Gateway Work

**What it is:** Ending Talk on Android **no longer cancels work the Gateway has already accepted**.

**Why it matters:** You start a voice session, the Gateway accepts the work, you end Talk — before, that canceled the in-flight work. Now the Gateway continues processing.

**PR:** [#188798](https://github.com/openclaw/openclaw/pull/188798)

---

### 4. Google Gemini Flash Uses Interactions API

**What it is:** Google provider now uses the **Interactions API for Gemini Flash models** on the official endpoint while retaining custom endpoint overrides.

**Why it matters:** Better compatibility and feature support for Gemini Flash on Google's official infrastructure.

**PR:** [#189395](https://github.com/openclaw/openclaw/pull/189395)
