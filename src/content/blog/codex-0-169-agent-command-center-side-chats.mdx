**Codex 0.169.0 dropped November 13, 2026** - two releases after 0.167's command center debut. This one solves the multi-context problem: **multiple side-chat tabs** in the terminal workspace, **searchable task history** from the agent command center, and **collapsible turn details** in full-screen transcripts.

If you've ever wanted to juggle two refactors at once, or search through last week's agent runs without scrolling forever - this is the release.

---

## The One-Line Summary

**Codex 0.169.0 (Nov 13) → Multiple side-chat tabs in terminal workspace (switch with keyboard/mouse, persist across restarts), search older tasks by name/prompt/directory from command center, collapse turn details in full-screen transcript to fold completed activity. Run `npm install -g @openai/codex@latest`.**

---

## Feature 1: Multiple Side-Chat Tabs - Your Multi-Context Workspace

**What it is:** The opt-in terminal workspace now supports **multiple side-chat tabs**. Switch between them with keyboard or mouse. Reopen saved local side chats after restarting Codex.

```
# In Codex TUI (terminal workspace):
# 1. Open a new side chat: Ctrl+Shift+N (or menu)
# 2. Switch tabs: Ctrl+Tab / Ctrl+Shift+Tab
# 3. Each tab = independent conversation context
# 4. Restart Codex → your side chats are still there
```

**Why it matters:** Before 0.169, you had *one* conversation context. Working on a frontend bug and a backend refactor meant: finish one → clear context → start the other → lose the first thread. Now: **tab 1 = frontend bug, tab 2 = backend refactor**. Switch instantly. Context preserved.

**For beginners:** Think of it like browser tabs but for AI conversations. Each tab remembers its own files, its own context, its own history. You're not "starting over" when you switch - you're picking up where you left off.

---

## Feature 2: Search Older Tasks from the Command Center

**What it is:** The agent command center (`codex agents --no-daemon`) now lets you **search older tasks by name, prompt preview, or working directory**.

```
# Open command center
codex agents --no-daemon

# Search box at top - type to filter:
# - Task name: "auth refactor"
# - Prompt preview: "fix the login flow"
# - Working directory: "/projects/api"
# Arrow keys to navigate, Enter to resume
```

**Why it matters:** 0.167 gave you the command center with unread markers. 0.169 makes it *searchable*. You ran 50 agent tasks this month. Finding "that one where I fixed the OAuth callback" used to mean scrolling. Now: **type "OAuth" → instant match → resume**.

---

## Feature 3: Collapsible Turn Details in Full-Screen Transcript

**What it is:** New **Collapse turn details** toggle in the full-screen transcript view. Folds completed activity beneath each prompt while keeping answers visible and tool output searchable.

```
# In full-screen transcript:
# 1. Toggle "Collapse turn details" (top right or key binding)
# 2. Each turn shows: your prompt + AI answer (expanded)
# 3. Tool calls, file edits,思考过程 folded under ▼
# 4. Click ▼ to expand any turn's details
# 5. Search still works across folded content
```

**Why it matters:** Long agent sessions = transcript overload. A 20-turn session with file edits, shell commands, and thinking tokens becomes unreadable. **Collapse = see the conversation flow, expand only what you need.** Answers stay visible. Tool output stays searchable.
