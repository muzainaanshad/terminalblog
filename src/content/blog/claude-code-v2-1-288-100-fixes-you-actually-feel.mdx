Claude Code v2.1.288 dropped October 2, and it's the kind of release that doesn't make headlines — it **makes your day better**.

No new model. No flashy feature. Just **100+ fixes** for the paper cuts that made you sigh, swear, or restart your session. If you've ever lost a draft to Ctrl+C, watched auto-compact fail, fought MCP OAuth loops, or had your Windows keyboard die after a restart — **this is the version you've been waiting for**.

---

## The "Finally" Fixes (You'll Feel These Immediately)

### 1. Ctrl+C Recovery — Your Draft Comes Back
Press `Ctrl+C` by accident? **Press Up on the empty prompt** — your entire draft (including pasted text and images) returns. No more rewriting that 500-word context dump.

### 2. Auto-Compact That Actually Compacts
Long conversations used to fail with *"Prompt is too long"* instead of compacting. **Fixed.** When the last reply reports zero token usage, it now compacts properly instead of crashing.

### 3. Session Resume — Actually Works Now
- `--resume` dropping files that compaction just restored → **fixed**
- Resumed session not saving the last response → **fixed**
- Transcript cut short during load → **fixed**
- Resuming pre-2.1.286 conversations dropping model thinking → **fixed**

### 4. MCP Re-Auth Prompt — No More Silent Failures
When an MCP server needs more OAuth scope during a tool call, **you now get a re-authenticate prompt**. No more wondering why the tool silently failed.

### 5. `/code-review` — You Control the Noise
Added `--max-findings <n>|all` to report more or fewer findings. Your choice persists until you pass `--max-findings default`.

---

## The "Oh Thank God" Fixes (Plugins, MCP, Cloud)

### 6. Plugin LSP Servers — Placeholders Finally Substituted
Plugins loaded with `--plugin-dir` now show **"Configure options"** in `/plugin`. LSP servers receive **actual substituted values** instead of literal `${user_config.*}` and `${CLAUDE_PLUGIN_ROOT}` placeholders.

### 6. Plugin Pane — Diffs That Don't Parse Won't Blank the UI
One `Code` element holding an unparseable diff used to make the whole pane show nothing. **Now it draws as plain code.**

### 7. `git-subdir` Plugin Installs — Works on Old Git (Ubuntu 22.04)
Fixed installs failing or caching incomplete plugins on git before 2.39.

### 8. Background Sessions — Survive Plugin Reload/Disable
Timers and reads no longer kill the session when a plugin reloads or disables mid-operation.

### 9. Sandboxed Heredocs — Auto-Allow Works
`python3 <<EOF` (unquoted delimiter) no longer asks for approval on every run under sandbox auto-allow when the body holds only plain text and simple `$VAR` references.

### 10. Bash Permission Check — Catches `BASHPID` Arithmetic
Prompts before a `BASHPID` assignment whose value the shell would evaluate as arithmetic, instead of allowing it silently.

---

## The "Windows Users, We See You" Fixes

### 11. Keyboard Works After Self-Restart
First sign-in to a Claude apps gateway, provider setup, or `/tui` — **the keyboard now works** after Claude Code restarts itself.

### 12. Windows Crash on Credential Read — Fixed
Crash when reading a stored credential that has no username → **fixed**.

### 13. `rm /` Protection — Even in `bash -c`
A dangerous `rm` (like `/` or home directory) inside `bash -c` or `sh -c` **now prompts** even in `bypassPermissions` mode or under a shell allow rule.

---

## The "Cloud & Cowork" Fixes

### 14. Cloud Sessions — New Conversation Doesn't Wait for Idle MCP
First turn no longer waits for a stdio MCP server with `alwaysLoad: false`.

### 15. Cowork Cloud — Phone Join Shows Prompt Suggestions
Fixed prompt suggestions not appearing on a phone joining a session started on another device.

### 16. Self-Hosted Runner — `gh api` Built-In Works
Refused `gh` command prints its `gh api` equivalent, `--paginate` follows every page, nested `claude` no longer removes it.

### 17. Remote Control — Survives Credential Renewal
Sessions stay connected during renewal and are kept if it gives up after a server outage.

---

## The "Screen Reader / Accessibility" Fixes

### 18. Screen Reader Mode — Short Announcements Stay Visible
Short announcements (like a deleted word) now stay on screen until your next key press or until something above them changes.

### 19. Answered Questions Say "Answered"
In question dialogs, answered questions now show "answered" beside their box.

### 20. `/permissions` — Typing a Rule Number Picks It
In screen reader mode, typing a rule's number now selects it instead of opening the search box.

---

## The "Agent & Subagent" Fixes

### 21. Subagents Get Their Own Tools (Not Defaults)
A plugin-defined agent spawned by name now runs with **its own prompt, tools, disallowedTools, and effort** instead of inheriting defaults.

### 22. Agent Teams — `tools:` with Many `Agent(...)` Entries No Longer Stalls
Fixed stall when launching an agent whose `tools:` lists very many `Agent(...)` entries.

### 23. Subagents in Claude Desktop Code Tab — Get MCP `memory` Tools
Fixed subagents getting **none of the tools** of a user-configured MCP server named `memory`.

### 24. Headless Sessions — Respect SIGTERM with SIGCONT
Fixed `-p` / SDK sessions occasionally ignoring SIGTERM when a supervisor sends SIGCONT alongside it.

---

## The "Model & Provider" Fixes

### 25. Full Model Output Limit for Claude Sonnet/Opus/Aliases
Prevents responses ending early during long reasoning. Uses the **full model output limit**.

### 26. Provider Context-Limit Errors → Auto-Compact + Retry
When the provider reports the request exceeded the model's context length, it now compacts and retries.

### 27. Custom OpenAI-Compatible Providers — No More `prompt_cache_breakpoint` 400s
Stopped sending `prompt_cache_breakpoint` to custom providers and first-party IDs rerouted through custom endpoints — both reject it with HTTP 400.

### 28. Kilo Gateway Models Without Supported Parameters — Now Visible
Models like Jev Router that don't report supported parameters now show up.

### 29. Auto Mode — Compacts Instead of Prompting/Failing Every Tool Call
When a conversation grows too long for the client-side safety classifier, it **compacts** instead of prompting for or failing every tool call.

### 30. Auto Mode Classifier — Ignores `ANTHROPIC_DEFAULT_SONNET_MODEL` Pin
If the pin names Sonnet 5.5 or Opus 5.5, it uses Sonnet 5 instead.

---

## The "MCP & Tool Call" Fixes

### 31. MCP Tool Calls Over 16 MB — No Longer Run Twice
Fixed remote server results over 16 MB or unparsable results causing duplicate execution.

### 32. MCP URL Prompts — Wait for "I'm Done, Continue"
Servers that can't report when you're done now wait for explicit confirmation before continuing the tool call.

### 33. `sandbox.credentials.files` on Git Config — Works with Block Reads
Entries on git config files now take effect while `permissions.blockReadsOutsideWorkingDirectories` is on.

### 34. LSP Tool Calls — 60s Timeout (Per-Server `requestTimeout`)
Fixed hanging indefinitely when a language server uses dynamic capability registration or stops responding.

### 35. PreToolUse / PermissionRequest Hooks — Blocked on Serialization Failure
When matching fails or input can't serialize to JSON, the call is **now blocked** (was skipped).

---

## The "VS Code Extension" Fixes

### 36. claude.ai Connector — "Needs Authentication" Fixed
MCP servers dialog now offers **Check connection** after you authorize.

### 37. New Conversation Shortcut (Cmd/Ctrl+N) — Only Starts in Active View
Fixed starting a conversation in **every visible Claude view** instead of just the one you're in.

### 38. Chat View — Archives Current Session → Starts New (Not Resume Next)
Fixed resuming the next saved session after archiving the current one.
