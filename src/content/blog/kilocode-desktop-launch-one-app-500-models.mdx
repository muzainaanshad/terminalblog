## What Kilo Desktop Actually Is

**One app. Everything you need to build.**

Not a plugin. Not a terminal tool. A native desktop application (Windows, macOS, Linux) that bundles:

- **Workspaces** — named groups of folders so the agent sees your whole project (frontend + API + analysis) at once
- **Agent modes** — Code (writes), Plan (reads + returns step-by-step plan), Ask (answers without editing), Debug (finds + fixes)
- **Editable notebooks** — the agent's cursor moves through cells as it writes; you review live
- **Conda management** — 19,000+ Anaconda packages, environments created inside the app
- **500+ models** — every frontier lab, open-source leaders, auto-routers that pick the cheapest capable model
- **Local models** — run open models on your hardware; prompts stay local
- **Skills + MCP + custom agents** — marketplace installs, workspace-scoped or global
- **Team controls** — admin guardrails for models, providers, geographies, agent permissions, skills

## The Workspace Problem It Solves

Real projects don't live in one folder. Your frontend is in `repo-a`, your API in `repo-b`, your data pipeline in `repo-c`. Most coding agents see **one** folder at a time. You copy context between them manually.

**Kilo Desktop workspaces** are named groups of folders from your machine. The agent reads across all of them simultaneously. It uses the analysis notebook to write the service, checks the API while updating the frontend — no file copying, no context gaps.

For beginners: this is the first agent setup where **"open my project" actually means your whole project**.

## Four Agent Modes (Not One Chatbot)

| Mode | What It Does | When to Use |
|------|--------------|-------------|
| **Code** | Writes and edits files | Daily implementation |
| **Plan** | Reads project, returns step-by-step plan (no edits) | Before touching code on complex tasks |
| **Ask** | Answers questions about your code, no changes | Understanding unfamiliar codebases |
| **Debug** | Finds what broke and fixes it | Failing tests, regressions, mysterious bugs |

**The workflow:** You prompt in **Plan** → get a structured implementation plan → approve → **Code** takes over, splits the plan into subtasks, runs them in parallel with sub-agents.

You can also build **custom agents** for your workflows and share them with your team.

## 500+ Models, One Picker, Auto-Routers That Save You Money

Every major frontier lab (OpenAI, Anthropic, Google), leading open-source models (NVIDIA, Moonshot, MiniMax, Z AI, DeepSeek, Qwen), and providers from every geography — available in one model picker.

**Don't want to choose?** Kilo's auto-routers pick for you:

- **Auto Efficient** — checks your request against Kilo Bench (their coding benchmark), sends it to the **cheapest model proven capable** of that task
- **Auto Balanced** — best price/performance for general coding
- **Auto Best** — maximum capability regardless of cost

You pay for what the job needs. Stop using your most expensive model for every edit.

## Local Models: Your Code Never Leaves Your Machine

Some work should never leave your hardware. Kilo Desktop includes a **local model server** that runs open models directly on your machine. One setting controls whether local requests carry Kilo's full agent toolkit (for coding) or run without it (for lighter, faster interactions).

For privacy-sensitive work, this is the only "cloud agent" experience that actually runs locally.

```bash

# 7. Try a notebook

```

## FAQ

**Is Kilo Desktop free?**
Yes to download and use with your own model keys/local models. Kilo's hosted models and some enterprise features have pricing. The core app + local models + BYO keys = free.

**Does it replace the VS Code extension?**
The extension continues (v7.8.8 released Oct 7). Desktop is the new flagship — full workspaces, notebooks, conda, local model server. The extension stays for VS Code loyalists.

**Can I import my VS Code extension settings?**
Yes — Desktop detects existing Kilo config and offers to import workspaces, skills, MCP servers, and model configs.

**What's the license?**
Source-available (not OSI-approved open source). Code on GitHub at [github.com/Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode). Free for individual and commercial use with some restrictions on hosted SaaS competition.

**Does it work on Linux?**
Yes — `.deb` for Debian/Ubuntu, AppImage for other distros. Flatpak/Snap requested by community (see GitHub issues).

**Can I run it fully air-gapped?**
Local models + local conda + no cloud sign-in = fully offline capable. Cloud models and sync features need connectivity.
