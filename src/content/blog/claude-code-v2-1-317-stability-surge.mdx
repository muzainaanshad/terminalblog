## The Fixes You'll Actually Notice

### 1. Nested Session ID Leak Fixed — Self-Hosted Runners Finally Work Right

**Before:** You run `claude -p` inside a self-hosted runner session. It **shares that session's ID and transcript**. A restart resumes the wrong conversation. Your session history gets polluted with print-mode noise.

**After (v2.1.317):** Set `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID=1` on your self-hosted runner. Now `claude -p` inside a session **creates its own session ID and transcript**. Clean separation. Restarts resume the right conversation.

```bash
# On your self-hosted runner:
export CLAUDE_CODE_DISABLE_NESTED_SESSION_ID=1

# Now:
claude -p "quick task"  # Creates its own session, doesn't pollute parent
```

**Why it matters:** If you run self-hosted runners for CI/CD or automation, this was a silent data corruption bug. Fixed.

---

### 2. Project & Local MCP Servers No Longer Disconnect After First Turn (Desktop)

**Before:** In some Claude Desktop sessions, your project MCP servers and local MCP servers **disconnect after the first turn**. You lose your tools mid-conversation. Restart Desktop to reconnect.

**After:** Fixed. MCP connections **stay alive** across turns. Your tools work the whole session.

---

### 3. Auto-Mode Survives Gateway 403/422 Responses

**Before:** You run an LLM gateway as your base URL. It returns 403 or 422 on its server-side safety check. Auto-mode **fails every single turn**. Session unusable.

**After:** Fixed. Auto-mode **handles gateway safety check failures gracefully**. Session continues. (Note: 403 with `apiKeyHelper` is unchanged — that's auth, not safety.)

---

### 4. `claude auth status` No Longer Races Slow Token Refresh

**Before:** Your token refresh is slow (network latency, proxy). `claude auth status` **exits before the refresh saves**. Next run signs you out. You log in again. And again.

**After:** Fixed. Auth status **waits for token refresh to complete** before exiting. You stay logged in.

---

### 5. `effortLevel` Setting Finally Respected in Pre-Started Sessions

**Before:** You open a new session in Claude Desktop's Code tab. The app starts the session *ahead of time*, then opens it in your project. Your project's `effortLevel` setting? **Ignored**. Session runs at default effort.

**After:** Fixed. Pre-started sessions **respect the project's `effortLevel`**. Your config works everywhere.

---

### 6. Cloud Session Titles No Longer Lost During Generation

**Before:** A new message or Stop arrives while the session title is generating. The title **gets lost**. Cloud and SDK sessions end up with generic titles.

**After:** Fixed. Title generation **handles concurrent events**. Your session keeps its meaningful title.

---

### 7. Screen Readers Stop Announcing Subagent Token Counts Every Change

**Before:** In screen reader mode, a running subagent's elapsed time and token count **announce on every change**. Audio spam. Unusable for accessibility.

**After:** Fixed. Subagent progress **announced appropriately, not every delta**.

---

### 8. Region/Network Blocks (HTTP 403) No Longer Masquerade as Sign-In Failures

**Before:** Your network blocks Anthropic (corporate firewall, country block). HTTP 403. Claude says **"sign-in failed"**. You troubleshoot auth. It's not auth.

**After:** Fixed. 403 from region/network block **explains the block**. You know it's network, not credentials.

---

### 9. `claude -p` Exits 1 (Not 0) When Disk Full / Quota Exhausted

**Before:** Full disk or quota loses transcript or `~/.claude.json` writes. `claude -p` **exits 0** (success). Your CI passes. Data lost silently.

**After:** Fixed. Exits **1 with error message**. In text/JSON output, you see the failure. CI catches it. (Full NFS exports may still be missed.)

---

### 10. Settings File Edits at Launch Take Effect Immediately

**Before:** You edit a settings file in the first second after launch. Changes **don't apply** until another settings file changes. Confusing.

**After:** Fixed. Early edits **take effect immediately**. Your config changes work on first try.
