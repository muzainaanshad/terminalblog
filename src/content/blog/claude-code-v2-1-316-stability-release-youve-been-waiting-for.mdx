## The Fixes You'll Actually Notice

### 1. Shell Commands No Longer Leak When Claude Exits

**Before:** You're in a cloud session. Credentials get refused, or the session archives. Claude exits — but the shell commands it started **keep running in the background**. Orphaned processes. Wasted CPU. Confusion when you come back.

**After (v2.1.316):** Fixed on macOS and Linux. When Claude Code exits (credentials refused, cloud session archived, any self-exit), **it cleans up its child processes**. No more orphaned shells.

```bash
# Test it:
# 1. Start a long-running command via Claude
# 2. Revoke credentials / archive cloud session
# 3. Claude exits → command stops. No zombies.
```

### 2. Bash Aliases with Line Breaks Finally Work (Git Bash)

**Before:** Your `.bashrc` has aliases spanning multiple lines, or functions named like `my-func`. In Git Bash on Windows, they'd **garble or disappear** when Claude's Bash tool loaded them.

**After:** Fixed. Line-break aliases load correctly. Functions starting with a dash load correctly. Your shell config **just works** in Git Bash.

```bash
# These now work in Claude Code on Windows Git Bash:
alias my-long-alias='echo "line 1" &&
                     echo "line 2"'

my-func() { echo "dash function works"; }
```

### 3. PowerShell Hooks Now Block on Exit Code 2

**Before:** You set up a PreToolUse hook in PowerShell. It returns exit code 2 (block). Claude **ignores it** if the command starts with a type cast (`[int]`), `param`, `using`, or an attribute (`[CmdletBinding()]`). The hook fires but the tool runs anyway.

**After:** Fixed. Exit code 2 **always blocks**, regardless of command prefix. Your security hooks are reliable again.

### 4. Network Requests Don't Hang on Corrupted Compressed Responses

**Before:** A compressed response gets cut off or corrupted mid-stream. The request **hangs indefinitely** — no timeout, no error, just frozen.

**After:** Fixed. Truncated/corrupted compressed responses **fail fast with a clear error**. No more silent hangs.

### 5. Vertex AI & Bedrock Model Switching Works

**Before:** You're on Sonnet 5.5 via Vertex AI. It's not available in your region. Claude shows an error **mid-session** instead of gracefully falling back to an older available model.

**After:** Fixed. When the newest model isn't available to your account/region, Claude **switches to an older model** instead of erroring. Session continues.

### 6. Auto-Mode Server Setting Works Behind Proxies

**Before:** You run `CLAUDE_CODE_AUTO_MODE_SERVER=1` in a session started by a host app (Claude Desktop) behind a proxy/LLM gateway with experimental betas off. The setting is **ignored**. Auto mode doesn't engage.

**After:** Fixed. The setting is **respected** regardless of proxy/gateway configuration.

### 7. Cloud Sessions Mark Failed When Auto Mode Stops

**Before:** Auto mode stops a turn because the server returns no safety verdict. The cloud session / scheduled task **stays marked "running"** instead of "failed." You think it's still working. It's not.

**After:** Fixed. Sessions **correctly mark failed** when auto mode stops for safety verdict absence.

### 8. `claude -p` Text Output Explains Why Auto Mode Stopped

**Before:** You run `claude -p` (print mode). A background agent is still running. Auto mode stops the turn. The output **doesn't say why** — just cuts off.

**After:** Fixed. Print mode output **includes the stop reason** even with background agents running.

### 9. Plugin MCP `headersHelper` Gets Correct Environment

**Before:** Your plugin's `headersHelper` script receives a **corrupted `CLAUDE_PLUGIN_ROOT`** and server URL when a credential-named env var is set to a switch value like `1`. Your auth headers break.

**After:** Fixed. Environment variables passed to `headersHelper` are **clean and correct**.

### 10. SDK `register_repo_root` Loads External CLAUDE.md

**Before:** You use the SDK's `register_repo_root` to load a CLAUDE.md from outside the working directory (with `CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1`). It **doesn't load**.

**After:** Fixed. External CLAUDE.md files **load correctly** via the SDK control request.

## New Environment Variables (For Power Users)

```bash
# Turn off the `ultrathink` keyword entirely
export CLAUDE_CODE_DISABLE_ULTRATHINK=1

# Keep system cross-certificates that certify each other in a loop
# (for servers whose private CA needs one)
export CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP=1

# Set default effort level for subagents (instead of inheriting session's)
export CLAUDE_CODE_SUBAGENT_EFFORT=xhigh  # or high, medium, low
```

## Deprecation Notice: Opus 4.8 Fast Mode

**Fast mode for Opus 4.8 is deprecated as of October 30, 2026.** It will be **removed on November 30, 2026**.

After removal:
- Fast mode requests on Opus 4.8 return an error
- They do **not** fall back to standard Opus 4.8
- **Migrate to Opus 5.5** to keep the speedup
