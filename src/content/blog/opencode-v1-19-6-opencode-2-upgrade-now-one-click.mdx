**OpenCode v1.19.6 dropped November 17** — and it brings the OpenCode 2 upgrade path to the desktop app. No more command-line only. One click in the desktop UI → OpenCode 2 downloads in background → you choose: **Restart to upgrade**, **Upgrade on quit**, or **Later**. Your sessions, projects, and settings are kept.

---

## The Big One: Desktop App Gets the OpenCode 2 Upgrade Offer

This is the same `opencode upgrade --major` that CLI users got in v1.19.0, but now **in the desktop app UI**.

**What happens:**
1. OpenCode 1 detects OpenCode 2 is available
2. Downloads it in the background (no interruption)
3. Presents three options:
   - **Restart to upgrade** — switch now
   - **Upgrade on quit** — seamless, next time you close the app
   - **Later** — dismiss, come back when ready

**Your sessions, projects, and settings survive the migration.** Plugins made for OpenCode 1 will need updates (the plugin API changed in v2), but your core workflow is preserved.

---

## Two Quiet Fixes That Matter

### 1. Image History Compaction (No More Oversized Requests)

**Before:** Sessions with many images → request body grows → eventually hits provider limits → turn fails.

**Now:** When image history passes **25 MiB**, oldest images are replaced with placeholders. The session keeps running. You lose visual history for early images, but **the turn doesn't crash**.

### 2. Oversized Request Auto-Compaction + Retry

**Before:** Provider returns "request body too large" → turn fails → you manually compact → retry.

**Now:** Provider error for oversized body → **auto-starts compaction** → **auto-retries the turn**. You don't intervene.

```bash
# CLI
npm update -g opencode
# or
brew upgrade opencode

# Desktop
# Check for updates in-app, or download from:
# https://github.com/sst/opencode/releases/tag/v1.19.6
```

Verify:
```bash
opencode --version

```
