## v2.1.305 (Oct 20) — The Heavy Lifter

This is the bigger release with fixes across every subsystem.

### 1. Worktree Isolation Fixed for Git 2.56+ — Stops Repo Corruption
**The bug**: Worktree isolation refused to create or resume worktrees under git 2.56 or later when a stray `.git` file pointed at a directory that doesn't exist. This silently corrupted repos.

**The fix**: Worktree isolation now handles git 2.56's reftable format correctly. If you use worktrees (and you should — they're the safest way to run agents in parallel), **upgrade immediately**.

### 2. Windows exFAT/FAT32 File Writes — Every Write Was Refused
**The bug**: Every file write was refused or prompted for projects on exFAT or FAT32 drives — including sessions started with `--plugin-dir`. This made Claude Code unusable on external drives and some Windows setups.

**The fix**: File writes on exFAT/FAT32 now work without permission prompts.

### 3. Cloud Session Reliability — Stops Losing Your Work
**The bug cluster**:
- Cost/usage restarting from zero after session resume in new process
- Scheduled routine runs failing partway, then repeating work (posting same report twice)
- Open cloud sessions not showing messages from other devices until reload
- "Rewind to here" failing on every message except newest
- Diff view missing changes after repo rename/move

**The fix**: All addressed. Cloud sessions now persist state correctly across process boundaries, device switches, and repo operations.

### 4. MCP Protocol 2026-07-28 Support Fixed
**The bug**: MCP servers negotiating protocol version 2026-07-28 but omitting `resultType`, `ttlMs`, or `cacheScope` showed no tools or failed every call.

**The fix**: MCP servers with incomplete protocol negotiation now work correctly.

### 5. Plugin Performance — Startup Is Now Fast with Many Plugins
**The bug**: Plugin command and agent files took excessive file system calls to load, especially on Windows. Startup with 20+ plugins was painfully slow.

**The fix**: Plugin loading now takes far fewer file system calls. Most improvement on Windows. If you run many plugins, you'll notice the difference immediately.

### 6. Vertex, Bedrock & Gateway Tool Search Regression Fixed
**The bug**: v2.1.304 introduced a regression where every request failed on Vertex, Bedrock, and other providers when the endpoint or a gateway rejects tool search, and behind gateways with ToolSearch disallowed or left out of `--tools`.

**The fix**: Claude Code now retries without tool search when rejected.

### 7. Remote Control Offline Handling
**The bug**: Subagent pane spun forever when computer went offline.

**The fix**: Now shows "Remote Control disconnected" instead of spinning.

## v2.1.304 (Oct 19) — The Setup & UX Release

### 1. `/auto-mode-setup` — Guided Auto Mode Configuration
**What it is**: A guided setup that reads your project and recent sessions to teach auto mode about your environment. Now also available on Bedrock, Vertex, Foundry, Claude apps gateway, and telemetry-disabled sessions.

**Why it matters**: Auto mode used to be "turn it on and hope." Now it learns your codebase and workflow. Run `/auto-mode-setup` once, and auto mode actually understands your project.

### 2. Usage Limit Warning Before Resume
**What it is**: Added a warning on Pro and Max plans when resuming an inactive conversation would use a noticeable share of your 5-hour usage limit. Options: resume anyway, or start a new conversation and Claude can look up the previous one if you refer to it.

**Why it matters**: No more surprise usage burns. You see the cost *before* you resume.

### 3. Compaction Summary Shows Tool Names
**What it is**: The compaction summary in the transcript view (Ctrl+O) now includes the names of tools called earlier.

**Why it matters**: When you review what got compacted, you can see *which tools* were used, not just the text summary.

### 4. Organization Policy Refresh Fix
**The bug**: Organization policy didn't refresh until the hourly check after approving an `ANTHROPIC_API_KEY` at startup or switching "Use custom API key" in `/config`.

**The fix**: Policy now refreshes immediately.

### 5. Plugin Hook Transparency
**What it is**: Added a transcript line when a plugin that runs first skips one of your mod's hooks, naming the event and the plugin.

**Why it matters**: Debugging "why didn't my hook run?" is now possible — you see which plugin intercepted it.

## What's NOT Fixed (Still Watching)

- **No new features** — these are purely stability releases
- **Auto mode model selection** — server-side classifier model still not configurable (only client-side via `CLAUDE_CODE_AUTO_MODE_MODEL`)
- **Fully offline mode** — cloud sessions still require connectivity
- **Android Remote Control** — iOS only for now
