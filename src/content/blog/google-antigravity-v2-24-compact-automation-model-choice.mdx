**Google Antigravity v2.24.0 landed October 15** — and it's the first release that makes the desktop app feel like a workspace you actually live in, not just a chat window you visit.

The headline: **a `/compact` command that summarizes long conversations**, **a redesigned side panel that gathers artifacts/changed files/links/uploads in one place**, and **model choice for automations** (Flash Lite, Flash, or Pro — not just the default). Plus 13 improvements and 11 fixes that quietly solve daily paper cuts.

---

## The Headline Features (Ranked by Daily Impact)

### 1. `/compact` — Finally, a Way to Summarize Long Conversations

**What it is:** Type `/compact` in any conversation and the agent summarizes everything so far, freeing up context space so it can keep working. No more "context full" errors mid-task.

**Why it matters:** Long-running agent sessions hit context limits. Before this, you had to start fresh, lose all history, and re-explain the task. Now: `/compact` → agent writes a summary → you continue with full context headroom.

**For beginners:** This is the difference between "my agent stopped working halfway through" and "my agent runs all night."

```bash
# In Antigravity desktop, just type:
/compact
# Agent summarizes, frees tokens, keeps working
```

---

### 2. Redesigned Side Panel — Everything in One Place

**What changed:** The side panel now has an **overview panel** that gathers:
- Artifacts (generated files, UI previews, charts)
- Changed files (diffs in one list)
- Links (referenced URLs, docs, PRs)
- Uploads (images, PDFs, zips you attached)

**Keyboard shortcut:** `Cmd+Shift+M` (macOS) / `Ctrl+Shift+M` (Windows/Linux) maximizes the panel — it slides over the conversation instead of squeezing it.

**Why it matters:** Before, you hunted across tabs for the artifact, the diff, the link the agent shared. Now: one panel, everything visible. Press the shortcut, see it all.

---

### 3. Model Choice for Automations — Pick Flash Lite, Flash, or Pro

**What changed:** When creating or editing an automation (scheduled task), you can now **pick the model** — Flash Lite (fast/cheap), Flash (balanced), or Pro (best reasoning). New automations still default to Flash.

**Why it matters:** Not every scheduled task needs Pro. A nightly dependabot review? Flash Lite is fine. A weekly architecture refactor? Pro. You control the cost/quality tradeoff per automation.

**For teams:** This is the first real "automation budgeting" knob. Set cheap models for routine chores, expensive models for high-stakes work.

---

### 4. Display Options That Actually Make Sense

**New controls:**
- Separate **Sort Conversations** and **Sort Projects** menus when grouped by project
- Sort by Last Updated, Last Prompt, or Custom Order
- **Auto Pin** option — pins a conversation whenever you send it a message (off by default)
- Pinned section now has its own sort menu

**Why it matters:** If you run 20+ concurrent agent conversations (and you will), these sorting options stop the sidebar from becoming a mess.

---

### 5. Paste Plain Text — No More Formatting Surprises

**Shortcut:** `Cmd+Shift+V` (macOS) / `Ctrl+Shift+V` (Windows/Linux) pastes as plain text into the message box.

**Why it matters:** Copy a stack trace, paste it, and it doesn't bring weird formatting that confuses the agent. Small thing, saves friction daily.

---

### 6. Full-Screen Media Viewer — Frame-Step Videos, Zoom Images

In the full-screen viewer:
- `,` and `.` keys step video back/forward **one frame**
- Double-click an image to **zoom in on the spot under your pointer**

**Why it matters:** When the agent generates a UI recording or a diagram, you can actually inspect it properly. No more squinting at thumbnails.

---

### 7. Mark All as Read — Command Palette Access

When you have unread conversations, "Mark All as Read" is now in the command palette. One keystroke clears the noise.

| Add Comment button no longer moves out of reach on last lines of artifact | Can comment anywhere |

| Conversations no longer briefly appear in wrong section at startup | Clean startup |

## The Windows-Specific Win

**Fixed: "every sandboxed command failed with 'Access is denied' on Windows when PowerShell was installed from the Microsoft Store."**

If you're on Windows and installed PowerShell from the Store (common), Antigravity's sandbox couldn't reach it. **Now it works.** This unblocks a huge chunk of Windows users who were stuck.

## How to Update

Antigravity auto-updates. To force check:

1. Open Antigravity desktop
2. Settings → About → Check for updates
3. Should show **v2.24.0** (released Oct 15, 2026)

**CLI users:** The CLI shares the same harness. Update via:

```bash
# Re-run installer
curl -fsSL https://antigravity.google/download/cli | sh

# Verify
antigravity --version
# Should show 2.24.0+
```

## The Bigger Picture: Antigravity Is Becoming a Real Platform

Google's strategy is clear: **unify the harness across CLI, desktop, cloud, and SDK.** Every release improves the shared brain:

- **v2.21.1** added Advanced Search (⌘+K) and grouped agent actions
- **v2.22.0** added UI Extensions (custom UIs in side panel from plugins)
- **v2.23.0** added permissions picker, .zip attachments, plugin suggested prompts
- **v2.24.0** adds `/compact`, side panel overview, automation model choice

The desktop app isn't just "the CLI with a GUI" anymore — it's the **orchestration layer** where you review, approve, schedule, and monitor. The CLI is for execution. The cloud is for scale. The SDK is for building your own surfaces.

**This is the AWS-for-agents play** — and v2.24.0 is the first release where the desktop console actually feels like a production control plane.
