## The Features You'll Actually Use Daily

### 1. Worktree Shortcuts — `Ctrl+Alt+O` / `Ctrl+Alt+B` / `Ctrl+Shift+X`

**What it is:** Three keyboard shortcuts that change how you navigate multi-worktree projects:

| Shortcut | Action |
|----------|--------|
| `Ctrl+Alt+O` (Win/Linux) / `⌘⌥O` (Mac) | Choose a worktree |
| `Ctrl+Alt+B` / `⌘⌥B` | Choose base branch for new worktree |
| `Ctrl+Shift+X` / `⌘⇧X` | Toggle shell mode in composer |

**Why it matters:** You're in a deep refactor across three worktrees. Old way: `opencode worktree list` → copy path → `cd` → restart. New way: `Ctrl+Alt+O` → pick → done. Shell mode toggle means you drop into a real shell *inside* the composer, run a quick command, toggle back. No context switch.

```bash
# In opencode.json — the shortcuts are built-in, but you can see them in Settings → Shortcuts
# Desktop: tooltip shows the binding on hover
# TUI: command palette has "Choose Worktree" and "Choose Base Branch"
```

**For beginners:** Worktrees = parallel working directories sharing one `.git`. You can have `main`, `feature-auth`, `hotfix-login` all checked out simultaneously. This release makes switching between them *instant*.

---

### 2. Percentage Compaction Buffer — `"buffer": "20%"`

**What it is:** Set `compaction.buffer` as a **percentage of the model's context window** instead of a fixed token count.

```json
// opencode.json
{
  "compaction": {
    "buffer": "20%"
  }
}
```

**Why it matters:** One setting works for *every* model. `20%` on a 32K model = 6.4K buffer. `20%` on a 1M model = 200K buffer. No more recalculating when you switch from Haiku to Opus to a local 128K model.

**The old way:** `buffer: 8000` — works for small models, wastes space on large ones, crashes on huge ones.
**The new way:** `buffer: "20%"` — scales automatically.

---

### 3. Persistent Desktop Terminals — Finally

**What it is:** Desktop terminals now:
- **Belong to the session** (not the server process)
- **Survive server restarts** with full scrollback intact
- **Stay synchronized** with TUI and other windows
- **Keep renamed names** across restarts

**Why it matters:** You named a terminal "prod-debug", ran a 3-hour log tail, server restarted for an update. Old way: terminal gone, scrollback gone, rename gone. New way: it's exactly where you left it.

This is shared PTY infrastructure — the same terminal appears in Desktop, TUI, and any other connected window. Rename in one, reflects everywhere.

---

### 4. Guided Claude Agent Setup — Zero-Friction Onboarding

**What it is:** Provider picker now has **"Claude Agent"** option. Select it → OpenCode:
1. Copies `claude auth login` to clipboard
2. Installs Claude Code if missing
3. Verifies the connection works
4. *Then* lets you pick the model

**Why it matters:** The #1 friction point for new OpenCode users was "how do I connect my Claude subscription?" Now it's a guided wizard. Raw API key still works — this is just the easy path.

---

### 5. MCP 10MiB Message Fix — Large Contexts Just Work

**What it was:** MCP servers sending stdio messages >10MiB got disconnected. Large file reads, big diffs, heavy tool outputs — all failed silently.

**What it is now:** Messages up to **10MiB+** are read *faster* and *don't disconnect*. The streaming parser was rewritten for large payloads.

**Why it matters:** If you use MCP servers for big repos (grep across 50K files, read massive logs), this was a hard blocker. Gone.

---

### 6. LiteLLM Context Errors → Compaction (Not Crash)

**What it was:** LiteLLM context window errors stopped the session entirely. You'd lose momentum mid-task.

**What it is now:** Context errors **trigger compaction automatically**. The session continues. You might not even notice.
