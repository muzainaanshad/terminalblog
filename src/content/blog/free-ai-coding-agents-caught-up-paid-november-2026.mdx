## 1. OpenCode: The Terminal UX Benchmark Just Went Free

**Released Nov 6 (v2.2.6)** — after the v2.2.0 breaking release and 5 patches in 7 days.

What you get for $0:
- **Persistent Desktop terminals** — close the app, reopen tomorrow, your scrollback is there. Syncs across TUI and Desktop.
- **Worktree shortcuts** — `Ctrl+Alt+O/B/X` for instant branch switching. No `cd`, no restart.
- **Percentage compaction** — `"buffer": "20%"` works for every model (32K → 1M context). One config, done.
- **Shared MCP connections** — `pool: true` shares one connection across projects. Faster startup, fewer processes.
- **Mobile composer dock** — proper touch targets (44px) on phones/tablets. Not a squashed desktop UI.
- **Scripted worktree runs** — `opencode run -w` spins up isolated git worktrees for CI/automation.
- **Guided Claude setup** — subscription users onboard in 30 seconds.

**The honest take:** OpenCode v2.2.5+ is the best *terminal* experience for coding agents, paid or free. If you live in a terminal, this is your daily driver. The v2.2.0 breaking changes are fixed. The polish is real.

**Caveat:** GitHub stars (14K) and commits (0 in 30 days) signal "hype ahead of habit." But the UX speaks louder than stars.

## 2. Hermes: The Platform That Does Everything Free Tools Don't

**Released Nov 15 (v0.23.1 canary)** — 270+ new plugins in one night (600 → 1,050+).

What you get for $0:
- **1,050+ plugins** — model providers (10+ new), memory (6), voice (10+), search (7), desktop themes (10+), Windows ops (5), games/3D (6), infra (5), payments (5).
- **Group Chats** — multiple people + multiple agents in one conversation. `@mention` specific agents. Routing rules decide who answers.
- **Plugin OAuth** — plugins sign you in via browser. Never see your tokens. Scope-limited. Revoke in one click.
- **MCP tool costs + spend limits** — servers declare per-tool cost. You set per-chat limit. Hard guardrail even in YOLO mode.
- **Skill locking** — `hermes curator lock <skill>` = immutable. Agent reads, uses, **cannot break**. Deploy skills, sleep better.
- **Multi-profile gateway** — plugins behave the same everywhere. No "works in CLI, broken in Desktop."
- **Remote config backend** — `HERMES_CONFIG_BACKEND=remote` manages 100 instances from one dashboard. Push config, lock settings, zero SSH.
- **~1s faster startup** — 15 git calls down to 2 per command.

**The honest take:** Hermes is the only free agent shipping a *full platform* — cron, webapp, memory (mem0), Telegram ops, plugin marketplace, multi-provider routing, group chats, skill locking. It's not a CLI. It's infrastructure.

**Caveat:** Canary = daily, may have rough edges. Stable v0.23.1 coming. Configuration curve is real — this is not "install and go."

## 3. Qwen Code: Managed Agents Go Production-Ready

**Released Nov 15 (v0.27.4)** — the 4th patch since v0.27.0 launched the managed agent platform Oct 25.

What you get for $0:
- **Local directory grants** — managed agents access your filesystem via temporary browser grants. No stored creds, no persisted paths. Session ends → access revoked.
- **Feishu/WeCom webhooks** — long replies split into ordered segments instead of truncation. Native for Chinese enterprise teams (Lark/WeCom).
- **Auto Mode guardrails** — explicit authorization for destructive/bulk actions. Classifier timeout review. No HTTP(S) filesystem lookups (prevents Windows network stalls). Full Access mode visibly marked.
- **Multi-workspace Goals** — merge goals from trusted workspaces, workspace badges, new goals target selected workspace.
- **`/memory` CLI restored** — persistent workspace settings, typed SDK APIs for Codex memory imports.
- **HTTP fallback** — works in restricted/corporate networks when native UUID fails.
- **Security deps updated** — `qs`, `fast-uri`, `ip-address`, `Hono`, `glob`, `minimatch`, `unzipper`, MCP, DOMPurify patched.

**The honest take:** v0.27.0 = "here's the platform." v0.27.1-3 = "fix rough edges." **v0.27.4 = "now it works for real teams."** Local access + webhooks + guardrails + persistence = first managed agent release I'd recommend for team adoption.

**Caveat:** Alibaba-backed. Data residency questions for some orgs. Windows managed agents need WSL2/Linux runner.

## 4. OpenClaw: The Desktop Agent With Vision, Cron, Browser — Free

**Released Nov 16 (v2026.11.4)** — 220 commits, 125 PRs, **90 contributors** in one release window.

What you get for $0:
- **Vision built-in** — screenshots, UI analysis, visual debugging. No separate tool.
- **Browser automation** — real web interaction, not just fetch.
- **Cron + scheduled tasks** — runs while you sleep.
- **Private subagent results** — sensitive subagent completions stay out of chat stream.
- **Reliable child-task handoffs** — cancel a child, hand off to replacement without blocked receipts.
- **Visible tool failures** — no more silent ends. You know when something broke.
- **Telegram widgets (beta)** — interactive buttons, forms, selectors in Telegram DMs.
- **Paged history (beta)** — 1000+ message threads stay browsable.
- **macOS secret preservation** — credentials survive config hiccups.

**The honest take:** 90 contributors in one release = distributed ownership, not bus factor. This is a desktop agent with vision, cron, browser, and multi-agent orchestration that's genuinely free. The beta channel iterating daily shows velocity.

**Caveat:** Smaller community than Hermes/OpenCode. Less plugin ecosystem. Newer project = more unknowns.
