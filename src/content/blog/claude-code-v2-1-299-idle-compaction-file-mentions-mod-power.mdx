Claude Code v2.1.299 dropped **October 14, 2026** — and it quietly solves the biggest silent money leak in your workflow.

You leave a 300K-token session open overnight. Come back. Your next message *should* be instant (prompt cache hit). Instead, it reprocesses the entire conversation. **Tokens burned. Money gone.**

v2.1.299 fixes this with **idle compaction** — plus file mention control, mod media access, and 50+ fixes that actually change daily work.

## The Headline: Idle Compaction That Saves Real Money

**What it does:** A conversation sitting idle for ~54 minutes with 200K+ tokens now **auto-compacts** before the one-hour prompt cache expires.

```bash
# Your session at 2 PM: 300K tokens, you step away
# 2:54 PM: Claude silently compacts to ~50K summary
# 3:00 PM: You return. Next message = cache hit. Instant. Cheap.
```

**Knobs you control:**
- `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` — change the 200K threshold
- `"idleCompaction": false` in settings.json — turn it off entirely
- Requires v2.1.290+ (you have it if you updated recently)

**Why beginners care:** You didn't know prompt cache expires in an hour. You didn't know idle conversations silently burn thousands of tokens on resume. **Now you don't lose money while grabbing coffee.**

## File Mentions: Stop Leaking File Contents to the Model

**New env var:** `CLAUDE_CODE_DISABLE_FILE_MENTIONS=1`

**Before:** You type `@src/config.ts` — Claude gets the *entire file contents* dumped into context. Every mention. Every file. Tokens you didn't ask for.

**Now:** With this flag, Claude gets **only the path**. It reads the file with its own tools when it needs to. You control the context.

```bash
export CLAUDE_CODE_DISABLE_FILE_MENTIONS=1
claude
# @ mentions now pass paths, not contents
```

**Why it matters:** Large codebases = massive context bloat from casual `@` references. This flag puts you back in charge of what enters the conversation.

## Mods Get Media Access — Your Agents Can Now See

**New hook capability:** `$.prompt.media` in `prompt.submit` hooks (for mods installed via managed settings).

```javascript
// In your mod's prompt.submit hook
export async function promptSubmit({ prompt, $ }) {
  const images = $.prompt.media?.images || []
  const docs = $.prompt.media?.documents || []
  
  if (images.length) {
    // Analyze attached screenshots, diagrams, mockups
    const analysis = await $.llm.chat({
      messages: [{ role: 'user', content: ['Analyze this UI:', ...images] }]
    })
    // Inject context back into the prompt
    return { ...prompt, metadata: { uiAnalysis: analysis } }
  }
}
```

**What this enables:**
- Mods that read attached screenshots and auto-generate UI code
- Document-aware agents that reference PDFs you drop in
- Security mods that scan uploaded images for secrets before the model sees them

**For beginners:** Mods were blind to attachments. Now they're not. The ecosystem just got eyes.

## Session Identity for Managed Mods

**New:** `$.session.identity()` — tells mods how the session is signed in, org, and email when `forceLoginOrgUUID` is set.

```javascript
const identity = $.session.identity()
// { type: 'managed', orgUuid: '...', email: 'user@company.com' }
// or { type: 'personal' }
// or { type: 'api-key' }
```

Enterprise mods can now enforce policies per-identity. Personal mods can adapt behavior. The agent knows *who* it's working for.

## Effort & Fast Mode in Agent View

**New slash commands in agent view (peek panel):**
- `/effort` — set default reasoning effort for new sessions
- `/fast` — toggle fast mode default
- Bare `/model`, `/effort`, `/fast` now open pickers instead of doing nothing

**Why it matters:** You configure your *defaults* once. Every new session inherits them. No more `/model sonnet` `/effort high` every single time.
