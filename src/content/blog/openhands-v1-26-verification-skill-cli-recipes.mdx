## 1. verify-openhands: The Test Suite Your Agent Platform Needed

**Before v1.26:** You updated OpenHands, crossed fingers, and waited for users to report breaks.

**Now:** You have a **skill that verifies the platform itself.**

### What It Verifies (20+ Behaviors Mapped)

| Category | Behaviors Verified |
|----------|-------------------|
| **Agent Profiles** | Delegation tools saved, runtime services provided, auto-filled names follow model |
| **Automations** | Load more past 100, delete confirmation modal, preset actions hide agent profiles |
| **Chat** | Long `/btw` responses scrollable, message text kept after "Branch from here", voice dictation |
| **MCP** | STDIO connection test errors explained without URL hint, catalog identity kept for repeated installs |
| **Settings** | LLM profile row menu keyboard-operable, server message shown (not raw HttpError), router list contrast |
| **WebSocket** | Reconnect on foreground, clean disconnect on mobile background, backoff refetch bursts |

### The CLI: `control-openhands`

```bash
# One-off verification run
control-openhands verify --once

# Daily scheduled pass (add to cron/systemd)
control-openhands verify --daily

# Run specific behavior subset
control-openhands verify --behaviors agent-profiles,automations

# View last run results
control-openhands verify --status
```

**Results appear in the verification dashboard** — each behavior shows pass/fail, linked live recipe, and if failed, a filed defect with reproduction steps.

### Live Recipes = Reproducible Tests

Each verified behavior has a **live recipe** — a runnable test that reproduces the behavior. When something breaks:
1. Recipe fails
2. Defect auto-filed with: steps to reproduce, expected vs actual, environment snapshot
3. You fix → recipe passes → defect auto-closes

This is **CI/CD for your agent platform's own behaviors.**

## 2. Authenticated Backend View: See What Users See

**New:** `feat(apps): add authenticated backend view helper`

Admins can now **view any backend as an authenticated user** — without impersonation tokens or shared credentials.

```typescript
// In your admin panel
import { createAuthenticatedBackendView } from '@openhands/app';

// Generates a time-limited view URL
const viewUrl = await createAuthenticatedBackendView({
  backendId: 'prod-us-east-1',
  userId: 'user-123',
  ttlMinutes: 30
});
```

Use cases:
- Debug "it works for me but not for user X" — see their exact view
- Verify RBAC/permission changes instantly
- Support tickets: "I see what you see" in 30 seconds
