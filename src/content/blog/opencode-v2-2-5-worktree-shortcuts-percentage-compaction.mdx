Opencode **v2.2.5 dropped October 30** — just 3 days after v2.2.0's breaking changes. This patch doesn't change APIs. It changes **how fast you move**.

Three things you'll use every session: **worktree shortcuts**, **quote-send from popups**, and **percentage compaction buffers**. Plus fixes that stop MCP disconnections and idle restarts.

But wait — v2.2.4 and v2.2.3 dropped the *same day* (October 30). You get all three patches in one go if you update now. Here's the full wave:

## The v2.2.3 + v2.2.4 Features You Also Get (Released Same Day)

### v2.2.4 — Persistent Desktop Terminals, Artifacts, Guided Claude Setup

**Persistent Desktop Terminals** — Terminals now belong to the session, survive server restarts with their scrollback, and stay synchronized with the TUI and other windows. Renamed terminals keep their names across restarts.

**Publish Interactive Artifacts** — Enable `"experimental": { "artifacts": true }` in `opencode.json` to let agents publish, update, and serve HTML or static artifacts through the built-in local provider or plugin-provided storage.

**Guided Claude Agent Setup** — Select **Claude Agent** from the provider picker to copy `claude auth login`, install Claude Code, and verify the connection before continuing to model selection.

**Choose a Base Branch Quickly** — While creating a worktree, open **Choose base branch** with `Cmd+Opt+.` on macOS or `Ctrl+Alt+.` on Windows/Linux.

### v2.2.3 — Use Claude Code in OpenCode, Faster Long Sessions, Desktop Stability

**Use Claude Code in OpenCode** — Install Claude Code, run `claude auth login`, then select **Claude Agent** in `/connect` to use your Claude Code login and models. `OPENCODE_CLAUDE_PATH` can override the Claude executable.

**Faster Long Sessions in Desktop** — Streaming replies and long conversations now do much less rendering work.

**Desktop Stability Fixes** — Fixes side-panel tabs, repeated "Session not found" toasts, and **Open file** over HTTP.

## The Headline: Worktree Switching Is Now One Keystroke

### Before: Context Switching Tax

You're in a worktree. You need to check the main branch. You:

1. `Ctrl+C` out of current task
2. Type `opencode worktree list`
3. Find the name
4. Type `opencode worktree switch <name>`
5. Wait for context reload

### After: `Cmd+Opt+O` (Mac) / `Ctrl+Alt+O` (Win/Linux)

A dropdown opens. You pick. Done.

```
┌─ Worktrees ────────────────────────┐
│ ▸ feature/auth-refactor   (HEAD)   │
│   main                        3h   │
│   bugfix/login-race         2d     │
│   experiment/new-ui         1w     │
└────────────────────────────────────┘
```

**Base branch shortcut too:** `Cmd+Opt+B` / `Ctrl+Alt+B` picks the base branch for the current worktree.

**Shell mode toggle:** `Cmd+Shift+X` / `Ctrl+Shift+X` flips the composer between chat and shell. No menu diving.

*Desktop only for now — TUI shortcuts coming.*

## Quote-Send From Comment Popups — The "Just Send This One" Feature

You're reviewing a diff. You highlight a line. A comment popup appears. You type a reply.

**Old way:** Close popup → find the comment in composer → send → go back to diff.

**New way:** Hold `Cmd` (Mac) / `Ctrl` (Win/Linux) in the popup. The checkmark turns into a **send button**. Press `Cmd+Enter` / `Ctrl+Enter` — just that quote and comment send. The rest of your composer stays untouched.

```bash
# What this enables:
# 1. Review diff
# 2. Highlight line → type "this logic is inverted"
# 3. Hold Cmd → press Enter
# 4. Comment posted, diff still open, composer unchanged
# 5. Move to next line
```

Tiny UX change. Massive workflow speedup for code review.

## Percentage Compaction Buffers — One Setting Fits All Models

### The Problem

You set `compaction.buffer: 50000` tokens. Works great for 200K context models. But you switch to a 32K model — compaction never triggers. Switch to 1M — compaction fires too early.

### The Fix

```json
{
  "compaction": {
    "buffer": "20%"
  }
}
```

**20% of whatever model's context window.** Switch models, buffer scales automatically. Token counts still work if you prefer absolute numbers.

## Fixes That Stop Daily Annoyances

| Fix | Why You'll Notice |
|-----|-------------------|
| **MCP servers no longer disconnect on >10MB stdio messages** | Large tool outputs (logs, dumps) used to kill the connection. Now they stream fast and stay connected. |
| **Idle locations don't restart MCP servers immediately after shutdown** | No more "wait, it just started" flicker when you return to a session. |
| **Compaction caps prompt at model's context window** | Input limit larger than context? Compaction respects the real ceiling. |
| **LiteLLM context errors trigger compaction instead of stopping** | Session keeps going instead of hard-failing on provider quirks. |
| **Reasoning preserved when switching models mid-response** | No more request errors from reasoning text leaking into new model calls. |
| **Connect menu no longer lists MCP servers** | MCP management has its own place. Connect menu stays clean. |
