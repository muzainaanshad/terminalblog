Zed **v1.29.1-pre** dropped November 11. It's a pre-release, but Zed's pre-releases are typically production-ready — and this one packs features that change how you work with Git, navigate code, and use AI.

## The Headline Features

### Git Panel Branch Mode — See What Actually Changed

This is the big one. The Git Panel now has a **branch mode** that lists every file changed since a base branch (like `origin/main`).

1. Open the Git Panel → **Changes** tab
2. Click the new menu at the top → **"Compare Against Base"**
3. Pick your base branch (defaults to the default branch)

Files show up as diffs you can open, but you can't stage or restore from this view — it's for **reviewing what's different**, not managing the index. Perfect for PR prep or catching up after a rebase.

Run it from the command palette: `git panel: show branch changes`.

### Bookmark Picker — Finally, a Way to Browse Bookmarks

`project bookmarks: toggle` opens a searchable, previewable picker for every bookmark in your workspace. No more remembering line numbers or hunting through the sidebar.

### Configurable Git Date Formats

Finally, Git dates your way. New settings:

- `git.date_format` — `"locale"`, `"iso"`, or any strftime format like `"%Y-%m-%d %H:%M"`
- Per-view `date_style`: `git.blame.date_style`, `git.inline_blame.date_style`, `git.branch_picker.date_style`, `git.stash_picker.date_style`, `git_panel.date_style`, `git_graph.date_style`

Each can be `"relative"` or `"absolute"` independently. Your blame view can show "2 hours ago" while the branch picker shows exact timestamps.

### Disable Automatic Agent Thread Titles

`agent.auto_generate_thread_titles: false` turns off Zed's habit of naming your agent threads. Sometimes you want "debug auth flow" not "Fixed login bug #42".

### Claude Fable 5.2 & Mythos 5.2 Support

Anthropic's newest models are now available in the Anthropic provider. If you're on the Claude subscription, you get them automatically.

## AI Quality-of-Life Improvements

- **Copy button confirmation** — Agent response copy buttons now show a brief checkmark so you know it worked
- **ACP agent config ordering** — The first option an ACP agent provides now appears next to the send button (less hunting)
- **Better ACP compatibility** — Handles missing sessions, plan updates, diff formats, permission request cancellation

## Git Polish That Matters

- Commit view opens scrolled to the blamed file (not the top of the diff)
- Git status refresh is faster in huge repos with many changes
- Branch rename trims whitespace and replaces spaces with dashes, with a live preview
- Repository selector distinguishes repos that share a directory name
- `git.commit_view.expand_description` and `git.commit_view.expand_files` control whether commit view opens expanded

## Bug Fixes Worth Knowing

- **Fixed:** Opening a file via `workspace: open` replaced the whole project with just that file
- **Fixed:** Switching branches in remote projects resent full Git history over SSH, stalling everything
- **Fixed:** SSH "Missing remote shell" when remote shell reads from stdin on startup
- **Fixed:** SSH to macOS hosts stuck on "Starting Proxy" when pasteboard inaccessible
- **Fixed:** File finder now shows files outside project when searching by absolute path
- **Fixed:** Agent thread copy button could copy an earlier turn's response
- **Fixed:** Read-only toggle shown on tabs that don't support it
- **Fixed:** Animated WebP only showing first frame
- **Fixed:** Bold text using wrong theme colors in Markdown previews
- **Fixed:** `cmd-o` opening file dialog instead of symbol search with JetBrains keymap on macOS
- **Fixed:** Combining marks (like `v̄`) rendering incorrectly on Linux
- **Fixed:** Commit messages losing line breaks in commit view
- **Fixed:** `zed` CLI rejecting multiple `ssh://` paths on same host
- **Fixed:** `zed://file` and `file://` links with drive letters opening empty window on Windows

## Why This Release Matters

Zed keeps shipping **compound improvements** — the kind that don't make headlines but eliminate daily friction. Branch mode alone changes how you review changes before pushing. Bookmarks become actually usable. Git dates stop being a "deal with it" situation.

The pre-release tag means it's not on the stable channel yet, but Zed's track record: pre-releases are what most people run daily.
