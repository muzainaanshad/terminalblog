## Feature 1: Agent Command Center — Your Mission Control

**What it is:** A new TUI dashboard: `codex agents --no-daemon`

- **Session picker** shows all your agent sessions
- **Unread markers** — bold sessions have new results waiting
- **No daemon mode** — runs without background service, purely interactive

```bash
# Open command center
codex agents --no-daemon

# Navigate with arrows, Enter to resume, 'q' to quit
```

**Why it matters:** Before 0.167, finding which background agent finished meant checking each session manually. Now: **one view, instant signal**. The unread markers alone save 30 seconds per context switch.

---

## Feature 2: Local Image Attachments — Finally, Screenshots Work

**What it is:** Drag or paste an image into the composer. It **previews inline** while you type. Click the transcript path to open the full image.

```bash
# In Codex TUI:
# 1. Paste screenshot (Cmd+V / Ctrl+V)
# 2. See thumbnail preview in composer
# 3. Send — image goes with your prompt
# 4. Later: click transcript path → opens full image
```

**Supported terminals:** Works on terminals with image protocol support (iTerm2, Kitty, WezTerm, Ghostty, VS Code terminal, Warp).

**Why it matters:** \"Here's the error\" + screenshot used to mean: save file → describe path → hope agent finds it. Now: **paste → send → agent sees it**. Beginner-friendly, expert-fast.

---

## Feature 3: Backend Switching That Keeps Your Drafts

**What it is:** Switch between connected backends (OpenAI, Azure, Vertex, Bedrock, etc.) from the session picker. **Your unsent draft survives the switch.**

```bash
# In session picker:
# 1. Highlight session
# 2. Press 'b' for backend menu
# 3. Select new provider
# 4. Your draft is still there
```

**Why it matters:** Testing model behavior across providers used to mean: copy draft → switch → paste → repeat. Now: **switch → same draft → compare results instantly**.

---

## Feature 4: Vertex AI Setup Wizard Built Into Onboarding

**What it is:** New \"Sign in another way\" menu includes **Google Cloud Vertex AI**. Enable `gcp_setup_wizard` and it walks you through:

- Application Default Credentials (ADC)
- Service account key file
- Project/region selection

```bash
# Enable in Codex:
/experimental gcp_setup_wizard true

# Then: Sign in another way → Google Cloud Vertex AI
```

**Why it matters:** Vertex AI setup used to be \"read docs, configure gcloud, pray.\" Now: **wizard does it**. GCP teams can onboard in 2 minutes.

---

## Feature 5: System Proxy Support (macOS/Windows)

**What it is:** Opt into your OS proxy settings from `/experimental`:

```bash
/experimental system_proxy true
```

Codex now respects your system proxy (corporate, VPN, etc.) without manual `HTTP_PROXY`/`HTTPS_PROXY` env vars.

**Why it matters:** Enterprise users behind proxies no longer need IT tickets to configure Codex. **It just works**.

---

## Feature 6: Expandable Patch Details in Approval Prompts

**What it is:** When an approval prompt opens (tool call needs permission), you can now **expand the patch/diff inline** to see exactly what changes.

```bash
# Before: "Allow edit to src/auth.ts?" → [Allow] [Deny]
# After:  "Allow edit to src/auth.ts?"
#         [▼ Show diff] → shows unified diff inline
#         [Allow] [Deny]
```

**Why it matters:** Blind approvals are how bugs ship. **See the change, then decide**.
