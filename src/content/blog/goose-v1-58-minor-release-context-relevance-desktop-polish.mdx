## The Headline Features (Ranked by Daily Impact)

### 1. Context Relevance Operation — Opt-In, Measures What Matters

**What it is:** A new **opt-in context relevance operation** (#12589) that scores how relevant retrieved context is to the current task. The agent can now evaluate whether the context it pulled actually helps — or if it's just noise.

**Why it matters:** RAG and context retrieval often dump irrelevant files into the prompt. This gives the agent a **relevance signal** — it can deprioritize or discard low-score context, keeping the context window focused.

```bash
# Enable in config (opt-in)
# goose.json
{
  "contextRelevance": {
    "enabled": true,
    "threshold": 0.7  # only keep context above 70% relevance
  }
}
```

**For beginners:** You don't need to configure this. It's opt-in. But when you hit "why is the agent hallucinating from irrelevant files?" — this is the knob you'll want.

---

### 2. Desktop: Thinking Collapsed by Default + Setting to Control It

**What it is:** **Thinking/reasoning blocks are now collapsed by default** in the Desktop app (#12660), with a new setting to toggle the behavior.

**Why it matters:** 
- **Cleaner UI** — you see the answer first, expand thinking only when you want to audit the reasoning
- **Configurable** — if you *like* seeing the raw reasoning stream, flip the setting back
- **Less visual noise** — especially on smaller screens or when running multiple agents side-by-side

```bash
# Settings → Desktop → "Collapse thinking by default" (now ON by default)
# Toggle OFF if you prefer the v1.57 behavior (always expanded)
```

**For beginners:** This is the "it just looks cleaner" update. You'll notice the chat feels less cluttered immediately.

---

### 3. Desktop: Tool Call Titles Removed — Cleaner Conversation Flow

**What it is:** **Tool-specific tool call titles have been dropped** in the Desktop UI (#13107). Instead of verbose titles like "Read file: src/auth/login.ts" or "Bash: npm test", you now get cleaner, consistent tool call display.

**Why it matters:** 
- **Less visual clutter** in long agent sessions
- **Consistent formatting** — tool calls look uniform regardless of type
- **Easier scanning** — your eye catches the *action*, not the label

---

### 4. Computer Controller: Stopped Lying About Screenshot Tool

**What it is:** The computer controller was **telling the model a screenshot tool exists** even when it wasn't available (#13279). Fixed — the model now only sees tools that are actually usable in the current environment.

**Why it matters:** 
- **No more hallucinated tool calls** — the agent won't try to call `screenshot` if it's not configured
- **Cleaner tool schema** — only real capabilities exposed
- **Trust** — the model's tool awareness matches reality

## How to Upgrade

```bash

goose upgrade

# Or re-run the installer
curl -fsSL https://raw.githubusercontent.com/block/goose/main/scripts/install.sh | bash

# Desktop: auto-updater handles it (enabled since v1.49)
# Windows: download NSIS installer from releases page
# https://github.com/aaif-goose/goose/releases

# Docker
```
