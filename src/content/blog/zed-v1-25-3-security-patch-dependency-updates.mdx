## What Actually Changed

Zed v1.25.3 (and the pre-release v1.26.2-pre, released the same day) **updated dependencies to address recent software ecosystem vulnerabilities** ([#66023](https://github.com/zed-industries/zed/pull/66023), [#65963](https://github.com/zed-industries/zed/pull/65963)).

That's the entire changelog. Two PRs. One purpose: **close the doors that supply-chain attacks walk through**.

---

## Why This Matters (Even If You Don't See It)

Your editor is **one of the most privileged processes on your machine**:

- Reads your entire codebase (every file, every secret you accidentally committed)
- Executes language servers that run arbitrary code (TypeScript, Rust, Go, Python analyzers)
- Communicates with remote AI endpoints (Anthropic, OpenAI, OpenRouter, local Ollama)
- Runs terminal commands, git operations, build tools
- Has filesystem access to your project directories

**Every dependency in Zed's supply chain is an attack surface.**

A vulnerability in a transitive dependency? A malicious maintainer publishes a compromised patch? A build-time injection? Your editor — with full codebase access — becomes the delivery vehicle.

**v1.25.3 updates the dependency graph to current, patched versions.** You don't need to read the CVEs. You just need to run the update.
