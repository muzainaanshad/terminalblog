Claude Code v2.1.300 landed **October 15, 2026** — and it's the first release where mods stop feeling like hacks and start feeling like platform primitives.

You get `/advisor` on AWS, OpenTelemetry GenAI semantic conventions, `virtualText` that draws in the prompt box without polluting context, a `prompt.change` hook that catches every non-typed edit, and 80+ fixes that collectively eliminate entire classes of daily friction.

## The Headline: `/advisor` Arrives on AWS — Your Agent Gets a Second Brain

**New command:** `/advisor` — picks an advisor model that reviews your agent's work *before* it commits.

```bash
# In a Claude Code session on AWS
/advisor                    # pick from available advisors
/advisorModel opus-5.5      # or set via flag
--advisor sonnet-5.5        # CLI flag
CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1  # disable entirely
```

**How it works:** No advisor runs until you explicitly choose one. The advisor sees the agent's proposed actions and can approve, modify, or block. Think of it as a senior engineer reviewing a junior's PR — except it happens in real-time, every turn.

**Why it matters:** This is the first native "agent overseeing agent" primitive in Claude Code. For teams on AWS, it means:
- Security review on every dangerous tool call
- Cost control via cheaper advisor models
- Compliance gates without leaving the terminal

## Mods Get `virtualText` — UI That Doesn't Pollute Context

**New:** `virtualText` on mod prompt decorations — text rendered in the prompt box that **never enters the draft or submitted prompt**.

```javascript
// In your mod
export function promptDecorations({ prompt, $ }) {
  return {
    virtualText: [
      { text: '🔒 Secrets scan: clean', color: 'green' },
      { text: '💰 Est. cost: $0.03', color: 'yellow' },
      { text: '⚠️ 3 files modified', color: 'red' }
    ]
  }
}
```

**Before:** Mods injected status into the actual prompt — bloating context, confusing the model, showing up in transcripts.

**Now:** Visual hints for the *human only*. The model never sees them. Your context stays clean. Your transcripts stay readable.

**Use cases that just became trivial:**
- Live token/cost estimates in the prompt box
- Security scan results without context pollution
- Git status, test status, lint warnings — all visible, none in context
- Multi-line "heads up" displays that vanish on submit

## OpenTelemetry GenAI Tracing — Finally, Real Observability

**New semantic attributes** on every trace span:

```
gen_ai.provider.name        // "anthropic"
gen_ai.conversation.id      // stable session ID
gen_ai.tool.name            // "Bash", "Edit", "Agent", etc.
gen_ai.request.model        // "claude-opus-5.5"
gen_ai.usage.cache_creation_5m_tokens
gen_ai.usage.cache_creation_1h_tokens
error.type                  // standardized error classification
```

**Plus:** `cache_creation_5m_tokens` and `cache_creation_1h_tokens` split out on `api_request` events — you can finally see *exactly* how much cache write traffic you're generating at each TTL tier.

**Why you care:** Before this, you got generic spans. Now you get **industry-standard GenAI attributes**. Your Datadog, Honeycomb, Grafana, or custom dashboards can:
- Alert on error.type spikes per tool
- Track cache efficiency by conversation
- Cost-attribute per model per session
- Correlate latency with tool type

No more parsing JSON blobs. It just works with your existing OTel stack.

## The `prompt.change` Hook — Catch Every Edit, Not Just Keystrokes

**New hook:** `prompt.change` fires when the prompt box content changes *without a typed edit*:

- History recall (up-arrow)
- Clear (Escape)
- Undo (Ctrl+Z)
- Plugin `fill` operations
- Paste (in some contexts)

```javascript
export async function promptChange({ prompt, previousPrompt, $ }) {
  // Detect: user recalled a command from history
  if (prompt.startsWith('/') && !previousPrompt.startsWith('/')) {
    // They recalled a slash command — inject context
    return { ...prompt, metadata: { recalledFromHistory: true } }
  }
  
  // Detect: plugin filled the prompt
  if (prompt.length > previousPrompt.length + 50) {
    // Likely a plugin fill — log for audit
    await $.audit.log({ type: 'plugin-fill', prompt })
  }
}
```

**Why this changes everything:** Previously, mods only saw `prompt.submit` (on Enter) and `prompt.edit` (on keystroke). They were blind to history recall, undo, clear, and plugin fills. Now you can react to *intent*, not just keystrokes.

## Agent Spawn Rewriting — Mods Can Now Rewrite Workflow Agents

**Before:** `agent.spawn` mod hook could only **refuse** workflow agents.

**Now:** It can **rewrite** the agent's `prompt` and `model` before launch.

```javascript
export async function agentSpawn({ agent, $ }) {
  if (agent.type === 'workflow') {
    // Force workflow agents to use cheaper model
    // Inject extra context from org policy
    return {
      ...agent,
      model: 'sonnet-5.5',
      prompt: `${agent.prompt}\n\n[ORG POLICY] All file writes require tests.`
    }
  }
}
```

**Enterprise impact:** Security teams can now enforce model choice, inject policy context, and rewrite agent instructions *at spawn time* — without blocking the agent entirely.

## Right-to-Left Text Support — `dir` Prop on Mod Text

**New:** `dir: 'rtl'` on a mod's `Text` component — rows read right-to-left and sit flush right on Windows and VS Code terminals.

```javascript
$.ui.render({
  Text: { content: 'مرحبا بالعالم', dir: 'rtl' }
})
```

Small feature. Huge for Arabic/Hebrew/Persian developers who've been fighting terminal alignment for years.
