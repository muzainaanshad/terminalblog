Nous Research **revamped Hermes Agent subscriptions on October 27** — and the change is bigger than a pricing tweak. Every new plan now includes a **hosted Cloud agent out of the box**, and the old \"one monthly credit block\" model is gone. In its place: **daily limits, weekly limits, and a monthly allowance** that all apply at the same time.

Subscribers can switch immediately at `portal.nousresearch.com/billing`.

---

## What Actually Changed

| Old Model | New Model |
|-----------|-----------|
| Single monthly credit bucket | Daily + weekly + monthly allowances (all active simultaneously) |
| Cloud agent = separate add-on | **Cloud agent included in every plan** |
| Credits depleted → stop or buy more | Switch to free models, wait for reset, or enable pay-as-you-go credits |
| No visibility into usage windows | Usage page shows exact reset times for each window |

The philosophy shift: **usage windows protect you from burning a month's budget in one weekend.** A daily reset won't restore usage if you've already hit your weekly or monthly cap — the limits stack.

---

## The New Plan Structure

Every tier gives you **access to every model**. What changes is *how much* included usage you get, and the size of the Cloud agent bundled with your plan.

| Plan | Included Usage | Cloud Agent Size | Large-Model Monthly Limit |
|------|----------------|------------------|---------------------------|
| **Plus** | Baseline | Small | Yes (model-dependent) |
| **Super** | Substantially more than Plus | Medium | Higher threshold |
| **Ultra** | Most included usage | Large | Highest threshold |

**\"Substantially more\" is intentional vagueness** — the exact token counts depend on which models you use and how large your tasks are. A coding task on GPT-6 Sol burns allowance faster than a research task on a local Qwen model.

---

## What Counts Toward Your Allowance

- **Model inference** (all providers routed through Hermes)
- **Included tool usage** (web search, code execution, file ops, etc.)
- **Hosting for one Cloud agent** (this is the big one — previously a separate line item)

**What doesn't count:**
- API-key requests you make directly (BYOK)
- Additional Cloud agents beyond the included one (pay-as-you-go)

---

## The Migration Path for Existing Subscribers

If you're on a legacy paid plan:

1. Go to `portal.nousresearch.com/billing`
2. Switch to a new plan
3. **Unused subscription credits carry over as pay-as-you-go credits** (up to one month of your current plan's value)
4. Same-price switches take effect immediately at no charge
5. Upgrades charge the difference; downgrades take effect at end of billing period

**Critical: Once you switch, you cannot return to the legacy plan.** The old credit-block system is deprecated.

---

## Why This Matters for Operators

### 1. Cloud Agent Is No Longer a Luxury
Every tier includes a hosted agent. That means **zero-infrastructure deployments** are now the default, not the premium upsell. You sign in, pick a plan, and you have a persistent Cloud agent running — no Docker, no VPS, no gateway config.

### 2. Daily/Weekly Limits Change How You Plan Work
The old model encouraged \"save credits for the big task.\" The new model encourages **steady, sustainable usage**. If you hit your daily limit, you don't lose the week — you wait 24 hours or switch to a free model. The weekly limit prevents the \"Monday blowout\" problem.

### 3. Large-Model Limits Are Per-Model, Not Per-Plan
Expensive models (GPT-6 Sol, Opus 5.5, etc.) have their own monthly sub-limit. Hit that? **Other models keep working.** You're not locked out of the agent — just steered toward cheaper models until the window resets.

### 4. Pay-As-You-Go Is Opt-In, Not Forced
\"Keep going on credits\" is a toggle. Leave it off and Hermes simply stops using paid models when your included allowance runs out. No surprise bills.

## The Hidden Detail: Usage Page Finally Exists

The announcement mentions a **Usage page** that shows:
- Current consumption per window (daily/weekly/monthly)
- Exact reset timestamps
- Large-model allowance status
- Pay-as-you-go balance

This is the first time Hermes has real-time usage visibility built into the product. No more guessing whether you'll make it to month-end.

## What This Signals About Hermes' Direction

| Signal | What It Means |
|--------|---------------|
| Cloud agent in every plan | **Managed/hosted is the primary product** — self-host is for power users |
| Daily/weekly/monthly stacking | **Predictable economics over max utilization** — they want sustainable operators, not churn |
| Free-model fallback | **Local/cheap models are first-class** — not a compromise, a feature |
| No legacy return | **Clean break** — they're done supporting the old billing architecture |

This isn't a pricing page update. It's a **product architecture decision** baked into billing. The agent, the cloud runtime, and the usage model are now one thing.
