## 1. Drag-and-Drop Project Reorder: Your Mental Model, Preserved

**What it does:** In Agent Manager sidebar, **drag projects to reorder them**. The order survives restarts.

**Before:** Projects sorted alphabetically or by last opened. Your "main work" project buried at the bottom.

**Now:** Drag your active project to the top. It stays there. Next restart — still at top.

**Why beginners care:** You have 8 projects. 3 are active *right now*. Before, you scanned a list. Now, **your priority order = the UI order**. Muscle memory builds on stable positions.

This is a tiny feature that compounds daily. You stop hunting. You start working.

---

## 2. Shift-Click Links: You Choose Where They Open

**What it does:** With Integrated Browser enabled:
- **Normal click** → opens in integrated browser tab (inside Kilo)
- **Shift+click** → opens in your **system browser** (Chrome, Edge, Firefox)

**Also new:** "Open in external browser" button on the integrated browser toolbar — pops the current page out.

**Why it matters:** Integrated browser is great for quick docs, PR reviews, Stack Overflow. But sometimes you *need* the real browser — extensions, devtools, logged-in sessions, multiple tabs.

**Now you decide per link.** No settings toggle. No context menu hunting. **Shift+click = your browser.** Done.

---

## 3. Unified Agent/Model/Reasoning Picker: One Control, Three Choices

**What it does:** The prompt toolbar and Agent Manager "New Worktree" dialog now show **agent, model, and reasoning level as one split control**.

- Hover one section → switch to it
- Left/Right arrow keys → cycle between pickers
- Reasoning level only shows when set and space permits
- Narrow sidebar? Less-used actions collapse into "More actions" menu
- Voice input and Send **always stay visible**
- Toolbar **always stays one row** — long model names truncate, actions don't hide

**Why it matters:** Before, you clicked three different dropdowns in three different places. Now: **one control, three decisions, zero hunting.**

---

## 4. Theme-Matched Integrated Browser: No More Flashbang

**What it does:** Integrated browser pages now **match your IDE theme** via `prefers-color-scheme`.

- Dark IDE → dark Wikipedia, dark GitHub, dark Stack Overflow
- Light IDE → light everything
- Pages that support it (most modern sites) render correctly automatically

**Also fixed:**
- Page loads and SPA route changes keep current page visible until next paint (no blank flash)
- Resize panel → preview updates live, no stretch
- Clear warning when browser opened without active session
- Page cursor feedback (text fields, resize handles, drag controls) without changing scroll/compositing

**Why it matters:** You're in dark mode at 11 PM. Click a link. **No white flash.** Your eyes thank you.

---

## 5. Smarter Connection Retries: No More Session Stalls

**What it does:** Provider connection resets (`Connection reset by server`) now **retry through the normal retry path with backoff** instead of pausing the session waiting for network reconnection.

**Before:** Transient server hiccup → session pauses → "waiting for network" → you wait.

**Now:** Transient server hiccup → automatic retry with backoff → session continues. **Only genuine network disconnections trigger offline wait.**

**Why it matters:** You're in flow. The model API burps for 2 seconds. Old Kilo: session stalls, you context-switch. New Kilo: you barely notice.

---

## 6. Subagent Permission Prompt Fix: No More Stuck Approvals

**What it does:** Fixed permission prompts from subagents failing with **"Failed to update permissions"** and getting stuck indefinitely.

**Why it matters:** You're running a multi-agent workflow. Subagent needs approval. Prompt appears. You click approve. **Nothing happens. Prompt stays. Session blocked.**

This was a silent productivity killer. v7.8.9 closes it.

## How to Upgrade

```bash

# Search "Kilo Code" → Update

# Or via CLI (pre-release)
npm update -g @kilocode/cli@next

# JetBrains plugin: check for updates (7.1.9+)
```

**Breaking changes:** None. Safe to upgrade immediately.

**Note:** v7.8.9 is marked **pre-release**. If you're on stable channel, you won't auto-update. Enable pre-release in VS Code extensions settings or use the CLI `@next` tag to test.
