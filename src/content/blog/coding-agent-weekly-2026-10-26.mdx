8 high-signal links · security, pricing, adoption

High-signal only — no just-shipped noise.

### [AmpCode Just Removed Trust in Compromised Certificate Authorities — Update Your CLI Now](https://terminalblog.com/blog/ampcode-security-certificate-authorities-october-2026/)

AmpCode's October 22 security update removes trust in eMudhra (emSign) certificates. If your MCP servers or proxies use these CAs, you'll see 'untrusted certificate' errors. Here's what to do and why it matters for your agent's supply chain.

### [Hermes Agent Security Fixes Are Ready — But 3 Weeks Later, They're Still Not Merged](https://terminalblog.com/blog/hermes-agent-security-fixes-ready-not-merged/)

The October 2026 security audit found 403 vulnerabilities (6 HIGH) in Hermes Agent. Local fixes exist and pass all tests. Three weeks later, zero have been merged upstream. If you run Hermes, you're still exposed.

### [Zed Just Quietly Patched Your Editor — Dependency Security Fixes in v1.25.3](https://terminalblog.com/blog/zed-v1-25-3-security-patch-dependency-updates/)

Zed v1.25.3 (October 23) is a pure security maintenance release updating dependencies to address recent software ecosystem vulnerabilities. No new features — just the silent security fix your IDE needed.

### [OpenCode Just Made MCP Actually Usable — The v2.1.4 Release Developers Have Been Waiting For](https://terminalblog.com/blog/opencode-v2-1-4-mcp-forms-background-compaction/)

OpenCode v2.1.4 (October 23) fixes the biggest MCP pain point: forms now appear instead of timing out. Plus background compaction, Bun 1.4.4 security fixes, faster code display, and voice model discovery. Here's what actually matters.

### [KiloCode Just Patched the eMudhra Certificate Compromise — Browser Links and MCP OAuth Now Locked Down](https://terminalblog.com/blog/kilocode-v7-8-17-security-patch-browser-mcp-fixes/)

KiloCode v7.8.17 (Oct 23) is a security patch release that blocks compromised eMudhra certificate chains with a pinned Bun runtime, restricts browser links and MCP OAuth URLs to HTTPS only, and treats shell expressions in MCP prompts as literal text. Plus session PR badges restored and Kilo Cloud provider added.

### [Beware: OpenClaw Leaks Google OAuth Client Secrets to AI Models — Your GOCSPX Keys Are Visible in Plain Text](https://terminalblog.com/blog/beware-openclaw-google-oauth-client-secret-leak/)

OpenClaw's redaction system misses Google OAuth client secrets (GOCSPX-...). When agents read credential files, these secrets enter the model context and session transcripts unmasked. Here's how to check if you're affected and what to do.

### [Check Point Just Exposed How Your Coding Agent Can Be Weaponized — Clone a Repo, Get Hacked](https://terminalblog.com/blog/beware-checkpoint-claude-code-hooks-mcp-rce-api-theft/)

Check Point Research disclosed CVE-2025-59536 and CVE-2026-21852: cloning an untrusted repository with Claude Code can execute arbitrary shell commands and exfiltrate your Anthropic API key — before you even click 'trust.' Here's what happened, why it matters, and how to protect yourself.

### [Beware: LiteLLM 1.107.0 Supply Chain Attack — PyPI & Docker Images Shipped a Credential Stealer and Backdoor](https://terminalblog.com/blog/beware-litellm-1-107-0-supply-chain-attack/)

LiteLLM 1.107.0 was compromised for ~2 hours on October 21, 2026. All 7 PyPI wheels and matching Docker images contained a credential stealer (cook.pth) and an hourly remote code loader. If you installed or pulled this version, rotate ALL credentials immediately.
