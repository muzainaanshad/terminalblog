Zed **v1.23.2 dropped October 7**, and it's the rare release that doesn't add flashy features -- it just **stops the paper cuts** that make AI coding feel fragile.

The headlines: **agent thread retention you control**, **Google AI auto-retries when overloaded**, **ACP plan updates that actually refresh the panel**, **expired sign-in errors that make sense**, and **a dozen agent panel bugs that vanished**. If you code with AI in Zed daily, this is the update you've been waiting for.

---

## 1. You Finally Control How Many Idle Agent Threads Stay Loaded

**New setting:** `agent.max_idle_retained_threads`

Before: Zed kept every agent thread loaded forever. Switch between five conversations? All five sit in memory. On large projects with long threads, this meant **memory bloat you couldn't control**.

Now: **you decide**. Set it to `3`, `5`, `10` -- whatever your RAM budget allows. Idle threads beyond that limit unload gracefully. Switch back, they reload in context.

For beginners: this is the "why is Zed using 4GB RAM?" fix. You're not imagining it -- Zed was holding onto everything. Now you're in charge.

---

## 2. Google AI Overload? Zed Retries Automatically

**New:** Improved Google AI error messages + **automatic retries on model overload**.

Before: Google's models hit capacity -> you got a cryptic error -> manual retry -> hope it works this time.

Now: **Zed detects overload (HTTP 529/429), backs off, and retries**. You see a clear "model overloaded, retrying..." message instead of a dead end. It just works.

This is the "I hate babysitting my AI provider" fix. You prompt, Zed handles the infrastructure hiccups.

---

## 3. ACP Agent Plan Updates Actually Refresh the Panel

**Fixed:** Plan updates from ACP agents now trigger **panel refreshes after status changes**.

Before: An ACP agent (Claude Code, Amp, OpenCode, etc.) updates its plan -> the Agent Panel shows stale info -> you wonder if it's stuck -> you close/reopen the panel.

Now: **The panel updates live**. Status changes, new steps, completed tasks -- you see them as they happen. The agent panel finally feels like a live dashboard, not a screenshot.

---

## 4. Expired Zed Sign-In: Error That Tells You What to Do

**Improved:** Agent Panel error on expired Zed sign-in is now **actionable**.

Before: "Authentication failed" or generic network error. You're left guessing -- is it my API key? My internet? Zed's servers?

Now: **"Your Zed sign-in has expired. Sign in again to continue."** One click, you're back. No mystery, no forum search, no support ticket.

---

## 5. Keyboard-Selected Agent Conversions Are Finally Visible

**Improved:** Visibility of keyboard-selected agent conversations in the Threads Sidebar.

Before: You navigate threads with keyboard -> the selection highlight is invisible or barely there -> you lose track of which thread you're on.

Now: **Clear, visible selection**. You always know which conversation you're about to open. Small thing, huge daily impact.

---

These aren't "features." They're **the difference between trusting your AI workflow and fighting your editor**.

## 7. JSONL/NDJSON Table Previews (Bonus: It's Not Just for AI)

**Added:** JSONL and NDJSON files now render as **sortable, filterable, virtualized tables** (`cmd-k v` / `ctrl-k v`).

Your LLM streaming outputs, application logs, analytics exports, dataset files -- **browsable instantly**. Millions of rows, sortable columns, right-click copy as JSON/CSV/TSV. Same engine that powers CSV/TSV previews, now extended to the format every AI workflow produces.

**Yes.** v1.23.2 is a stable release (not pre). The AI fixes alone are worth it if you use agents daily. The bug fixes compound -- you'll notice fewer "wait, what just happened?" moments within an hour.
